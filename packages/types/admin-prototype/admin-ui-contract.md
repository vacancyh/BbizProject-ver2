# Admin UI Contract

## Route IDs
- dashboard
- orders
- products
- members
- shipping
- settlement
- coupons
- stats
- reviews
- settings

## Feedback Policy
- 위험 작업: ConfirmModal
- 중요 작업 완료: ResultModal
- 일반 저장/메모: FloatingResult

## Container Policy
- dashboard: wide responsive grid
- table pages: wide table container
- settings/forms: constrained readable container
