# shop 어드민 리플랫폼 — 도메인별 기능정의서

> **목적**: Medusa v2.15.3 기반 자체 Next.js 관리자(`apps/admin`, host :7002)가 OUR 백엔드(`backend/services/api`, Medusa 기반, host :9000)에 연결되어 현재까지 구현한 기능을 도메인별로 정의합니다.
> **범위**: Strangler Migration(점진 이전) 진행분 기준. 본 문서는 FEATURE_MATRIX 상 `DONE`(게이트 통과)인 항목만 "구현됨"으로 적고, `TODO`는 "예정"으로 구분합니다.
> **절대 원칙**: Medusa 코어·DB 스키마 미수정. 커머스 로직은 호출/래핑만(복사·재구현 금지).
>
> **갭유형 범례**
> - **MATCH** — Medusa REST(`/admin/*`) 직접 호출/래핑으로 충족 → **Medusa 이식분**
> - **GAP_A** — Medusa에 기능은 있으나 우리 메뉴에 자리가 없어 신규 화면을 만들어 이전한 것 → **Medusa 이식분**
> - **GAP_B** — Medusa에 없어 우리가 커스텀 모듈로 추가한 것 → **기능 추가분** (한국 커머스/법규 대응)
>
> 본 문서에서는 **MATCH·GAP_A를 "Medusa 이식분"**, **GAP_B를 "기능 추가분(커스텀)"**으로 묶어 도메인마다 시각적으로 분리합니다.
>
> 출처: `apps/admin/FEATURE_MATRIX.md`(SSOT) + `apps/admin/docs/gaps/**` + 커밋 이력. 작성일 2026-06-01.

## 도메인 0. 기반(횡단) — RBAC · 감사로그 · 정책

**개요**: 모든 도메인이 의존하는 횡단 기반 계층입니다. 관리자 권한 검사, 모든 쓰기 액션의 감사 기록, 운영 정책의 단일 저장을 담당하며, `/admin/*` 쓰기 요청은 미들웨어(`backend/services/api/src/api/middlewares.ts`)를 통과하면서 권한 검사·감사 기록을 받습니다. **보안 메뉴(권한·정책·감사로그)는 조회(GET)도 super 전용으로 제한**됩니다. 이 도메인은 Medusa에 대응 기능이 전혀 없어 **전부 기능 추가분(GAP_B)**입니다.

### Medusa 이식분 (MATCH/GAP_A)
- 없음 (이 도메인은 전부 커스텀입니다).

## 도메인 5. 관리자 보안 — 2단계 인증(2FA)

**개요**: 관리자 계정 옵트인 TOTP(RFC 6238) 2단계 인증. `설정 > 2단계 인증`(`/settings/security`)에서 등록(QR/수동키)·활성화·해제하고, 활성 시 로그인이 비밀번호 → OTP 2단계가 된다. 외부 라이브러리/네트워크 0(순수 Node crypto + 자체 QR 인코더).

| 기능 | 설명 | 라우트/구현 | 상태 |
|---|---|---|---|
| 등록·활성화 | 시크릿+QR 발급 → 코드 검증 후 활성 + 백업코드 10개 | `POST /admin/2fa/setup|activate` | DONE |
| 로그인 2단계·게이팅 | OTP/백업코드 검증, 미검증 토큰 `/admin/*` 403 | `POST /admin/2fa/verify` + `twoFactorGuard` | DONE |
| 시크릿 암호화·백업코드 | AES-256-GCM 저장, 1회용 복구코드 | `_utils/secret-crypto.ts`, `admin_2fa_backup_code` | DONE |

**구현 상태**: **DONE** — 모듈 `admin-2fa`(테이블 3: `admin_totp`·`admin_totp_session`·`admin_2fa_backup_code`). 게이팅 13/13 + 강화 18/18 + QR 실디코딩 + 실브라우저 로그인 검증. 기본 admin 계정은 미활성(E2E 무영향). 상세 → `docs/gaps/ours-only/admin-2fa.md`.
커밋: `795a051 feat(admin): 회원 도메인 — 회원/회원 그룹 (Medusa REST 래핑, PII 마스킹)`
