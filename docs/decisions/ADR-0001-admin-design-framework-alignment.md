# ADR-0001 관리자 디자인 파일 표준 구조 정렬

## 결정
정적 디자인 ZIP을 프로젝트 표준 구조에 맞춰 `apps/admin/prototype` 아래로 옮기고, 추후 실제 구현 기준 문서를 `packages`, `modules`, `docs`에 분리한다.

## 이유
기존 ZIP은 화면 단위로만 나뉘어 있어 실제 앱 구조와 맞지 않았다. 표준 구조에 맞춰 앱/공통 UI/타입/도메인/문서를 분리해야 Claude Code와 사람이 같은 기준으로 작업할 수 있다.

## 결과
정적 프로토타입은 실행 가능성을 보존하고, 실제 구현에서는 React/TypeScript 도메인 구조로 재분해한다.
