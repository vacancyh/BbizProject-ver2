# 문서목록표 — shop 관리자 main_plan (신구조)

> 가이드 v2.6 구조(`도메인=DAG / 기능=task`)로 재편한 산출물 전체 인덱스. 본 문서는 검증 제외(doc_type: ignore).
> 정본 진입점: `plan.md`(상세기획서) → `dag/dag_index.md`(도메인 목차) → 각 도메인 `task_index.md` → `t<n>_*.md`(task_spec).

## 1. 디렉토리 구조

```text
main_plan/
├── plan.md                      # 상세기획서 (doc_type: plan)
├── dag/
│   ├── dag_index.md             # 도메인 전체 목차 (doc_type: dag_index)
│   └── d<n>_<도메인>/
│       ├── task_index.md        # 도메인 기능 목차 (doc_type: program_spec)
│       └── t<n>_<기능>.md       # 기능 상세명세 (doc_type: task_spec)
├── unit_test/
│   └── unit_<NNN>_<기능>.md     # task 단위 검증 (doc_type: unit_test)
├── qa/
│   └── qa_<NN>_<도메인>.md      # DAG 연계 검증 (doc_type: qa)
├── storyboard/                  # PPT(참고용, 검증 제외)
├── user_plan/                   # 사용자 기획 입력
├── 외부참조문서/                # Medusa 등 외부 참조
└── _archive/                    # 흡수 완료 구산출물(freeze 보존)
```
