# 한국형 자체 쇼핑몰 — 기능 갭 분석 (국내 표준 대비 누락 점검)

**작성일**: 2026-06-16
**기준 문서**: [한국이커머스조사.md](./한국이커머스조사.md) (Cafe24·고도몰5·메이크샵·아임웹·스마트스토어 등 8개 솔루션 + 전자상거래법/개인정보보호법 교차조사)
**대조 대상**: 본 프로젝트의 계획 83개 태스크(FEATURE_MATRIX.md, docs/main_plan/dag) + 실제 구현 모듈(backend/services/api/src/modules, apps/admin)
**범위 메모**: 단독몰(브랜드 자사몰) 기준. **세금계산서·현금영수증 발행은 추후 별도 작업 예정이므로 본 분석에서 제외.**

---

## 0. 요약

본 프로젝트는 국내 특화 기능을 **이미 상당 부분 보유**하고 있다:
적립금·회원등급·제재(블랙리스트)·동의이력·정산 상태머신·한국형 쿠폰·타임세일·상품정보제공고시·청약철회 7일·카카오 알림톡·RBAC·감사로그 등.

그러나 **국내 쇼핑몰에선 사실상 표준인데 계획에조차 없는** 핵심 공백이 존재한다. 아래는 우선순위별 정리다.

### 의도적 제외(누락 아님) — 참고
| 항목 | 근거 |
|---|---|
| 멀티쇼핑몰 / 공급사 정산 | 단독몰(자사몰)이라 비대상 |
| 본인인증(사용자인증) 설계 | `docs/main_plan/_archive/`로 이동(보류) |
| 장바구니/위시리스트 상세설계 | `docs/main_plan/_archive/`로 이동(보류) |
| 세금계산서·현금영수증 발행 | **추후 별도 작업 예정(본 문서 제외)** |
