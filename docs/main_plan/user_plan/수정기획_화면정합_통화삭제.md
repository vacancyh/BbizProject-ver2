# 수정 기획 — 화면 정합 · 통화 전체 삭제 · 401 복구 (2026-06-02)

## 0. 배경 (사장님 명령 3건)
1. 디자인 파일(`apps/admin/prototype/`) 그대로 모든 항목이 화면에 보여야 한다.
2. 메두사 기능을 화면에 붙인다(화면이 메두사보다 기능이 많음 = 화면 기준 유지).
3. 통화는 한국(KRW) 한정 → 통화 관련 데이터/UI 전체 삭제. 단 **다국어(i18n)는 유지**, 통화만 삭제.
- 외부 연동(결제 PG·택배 API) 제외.

## 1. 내부 조사 결론 (병렬 3축)
- **디자인 원본** = `prototype/index.html` + `prototype/assets/scripts/core/admin-shell.js` (정적 프로토타입).
  NAV = 10메뉴 3섹션(대시보드·주문·상품·회원·배송 / 정산·쿠폰·통계 / 리뷰문의·설정), 상단 = **언어(globe) 토글만**. **통화 UI는 디자인 상단에 없음**.
- **현재 NAV(`src/lib/nav/navigation.ts`)** = 디자인 10메뉴 + 추가 6(상품분류체계·카테고리·마케팅·권한·감사·정책, gap 배지로 구분). → **NAV 누락 0건**.
- **디자인 대비 실제 누락(화면 내부)** = ①정산 5탭(정산대시보드·정산내역·미정산·환불차감·수수료) ②리뷰 "신고·블라인드" 탭.
- **통화** = `formatCurrency(amount, code)` 27곳 + 통화선택 드롭다운 3곳(products·coupons·marketing) + 기본값 `eur` 3곳(dashboard.ts·settlement.ts·stats.ts) + 코드 직접노출 2곳(products·shipping). 다국어 `toLocaleString("ko-KR")`는 별개(유지).
- **401 폭탄 근본원인** = `client.ts`가 401시 throw만 하고, `(admin)/layout.tsx`에 **토큰 가드·리다이렉트 부재** → 만료 시 화면 렌더 후 호출 전멸 → 토스트 누적. (§V0 재발방지 대상)

## 2. 실행 계획 (3 병렬 워크스트림, 파일 비충돌)
### A. 401 복구 (최우선 — "모든 화면 안나옴" 직접 해결)
- `lib/api/client.ts`: 401 → `clearToken()` + 브라우저면 1회 `location.replace("/login?expired=1")` (중복 가드) → 토스트 폭탄 차단.
- `(admin)/layout.tsx` + 신규 `components/layout/AuthGuard.tsx`("use client"): 토큰 없으면 `/login` 리다이렉트.
- 로그인 페이지: `?expired=1` 안내 문구.
- **재발방지 레이어**: 라우트 가드(State machine) + 401 중앙처리(client). 다음 만료에도 폭탄 0건.

### B. 통화 삭제 코어
- `lib/utils.ts` `formatCurrency`: 인자 무시, **KRW 고정**(`₩`, 소수 0자리). 시그니처 호환 유지 → 27 호출처 무수정 일괄 해결.
- 통화선택 드롭다운 제거: products·coupons·marketing.
- 기본값 `eur`→`krw`: dashboard.ts·stats.ts (settlement.ts는 C 담당).
- 코드 직접노출 제거: products(`currency_code.toUpperCase()`)·shipping. shipping `supported_currencies`→KRW 고정.
- settings 통화 UI 제거(있을 경우). **다국어/locale·날짜/숫자 ko-KR 포맷은 유지**.

### C. 디자인 누락 보완 + settlement 통화
- `settlement/page.tsx`: 디자인 5탭 추가(기존 실데이터 집계 활용). `lib/api/settlement.ts` 기본값 krw.
- `reviews/page.tsx`: "신고·블라인드" 탭 추가(기존 리뷰/문의 유지).

## 3. 검증 (테스트)
- 각 에이전트 `npx tsc --noEmit` 0.
- main: 전체 tsc → 백엔드 재로그인(admin@local.test) → Playwright 로 (1)401 만료 시 /login 이동, (2)통화 ₩ 표기·드롭다운 소멸, (3)정산 5탭·리뷰 신고탭 렌더 확인.
