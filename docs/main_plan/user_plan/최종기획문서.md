## §0. 문서 목적 · 범위

1. **목적**: 한국 자체 쇼핑몰(브랜드 단독몰) 관리자의 *시장 표준 기능*과 *현재 우리가 구축한 어드민 리플랫폼*을 도메인별로 대조하여, "Medusa 기능 이식(완료분)" 위에 **앞으로 붙일 한국형 기능(우리꺼)** 의 우선순위 로드맵을 확정한다.
2. **전략(사장님 합의)**: "**Medusa 기능 먼저 다 옮기고(=#1 완료) → 우리꺼(한국형) 붙이기**". 본 문서는 그 "우리꺼" 범위를 시장 표준 대비 확정하는 기획이다.
3. **★ 범위 제외(고정)**: **외부 연동의 *구현* 은 본 기획에서 제외** — (a) 결제 PG 연동, (b) 택배사 배송 API 연동. 단 *운영 기능*(정산 집계·배송 상태 관리·무통장 확인 흐름 등)은 포함한다. 한국 법정 필수이나 외부 시스템에 의존하는 항목(현금영수증/세금계산서 국세청 전송, 휴대폰 본인인증)은 **로드맵에 포함하되 외부 연동부는 stub/수기 처리**로 한정 표기한다.

### 커버리지 상태 표기
- **[이식完]** = Medusa REST 래핑으로 구축 완료(#1, 이번 사이클 포함)
- **[모듈完]** = 우리 커스텀 모듈로 구축 완료 (rbac·audit·policy·고시·order-ops-kr·정산·통계·리뷰·delivery-kr 등)
- **[갭]** = 미구축 = "우리꺼 붙이기" 대상
- **[제외]** = 외부 연동 구현 제외
