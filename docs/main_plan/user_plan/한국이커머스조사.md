## 1. 상품 관리

### 핵심 기능
- **상품 등록/수정/삭제**: 상품명, 판매가, 원가(공급가), 마진율 자동 계산, 과세/면세 구분, 상품 요약설명·상세설명(에디터), 검색 키워드 태그
- **옵션 관리**: 단일/조합 옵션, 옵션별 추가금액 및 재고 독립 관리, 옵션 품절 처리, 필수/선택 옵션 분리
- **추가상품(사은품·세트 구성)**: 주문 시 연동 노출, 주문서에 반영
- **상품 분류(카테고리)**: 다중 분류 매핑, 카테고리 depth 관리, 분류별 배너·설명 삽입
- **진열 관리**: 메인 진열 영역별 상품 배치(신상품/베스트/추천), 수동·자동 정렬, 진열 기간 설정, 노출/비노출 전환
- **품절 관리**: 품절 자동 전환 임계값, 품절 시 노출 여부, 입고 알림 신청 수집
- **재고 관리**: 옵션별 재고 수량, 안전재고 설정 및 경고, 재고 수기 조정, 재고 이력 로그
- **상품 복사·일괄 수정**: 엑셀 업로드/다운로드, 대량 가격·재고 변경
- **브랜드·제조사 관리**: 브랜드별 상품 분류, 공급사 연결
- **상품 검색 최적화**: SEO 메타 설정, 상품 URL Slug, 구조화 데이터

### 한국 특유 요건
- **상품정보제공고시** (전자상거래법 제13조): 의류·식품·전기제품 등 약 30개 품목별 원산지·유통기한·품질보증기준 등 법정 항목 입력 UI 필수 제공 (고도몰·카페24·메이크샵 모두 품목별 템플릿 제공)
- **KC 인증·원산지 표시**: 품목별 법정 표기 입력 필드
- **가격 비교 사이트 연동 등록**: 네이버쇼핑·다나와 피드 생성 지원 (카페24·고도몰)

## 2. 주문 관리

### 핵심 기능
- **주문 현황 대시보드**: 입금대기·결제완료·배송준비·배송중·배송완료·구매확정 단계별 카운트 실시간 표시
- **주문 상세 조회**: 주문자·수령인 정보, 결제수단·금액, 쿠폰·적립금 사용 내역, 배송지 수정
- **결제 확인**: 무통장 입금 확인 처리, 가상계좌 자동 입금 연동
- **배송 처리**: 배송준비중 → 배송대기 → 배송중 상태 전환, 송장번호 입력(직접/엑셀), 택배사별 배송조회 연동
- **취소 처리**: 결제 전/후 취소, 부분 취소, 환불 금액 자동 계산, PG 취소 API 호출
- **교환 처리**: 교환 신청 접수 → 수거 확인 → 재발송 → 완료 단계 관리
- **반품 처리**: 반품 신청 접수 → 수거 완료 → 환불 단계 관리, 반품 귀책(판매자/구매자) 분류, 반품 배송비 차감
- **구매확정 관리**: 자동 확정 D+day 설정, 수동 확정, 확정 후 적립금 지급 트리거
- **주문 메모**: 내부 운영 메모, CS 상담 내용 연결
- **일괄 처리**: 송장번호 엑셀 일괄 업로드, 배송 상태 일괄 변경
- **주문서 출력**: 거래명세서·영수증·배송라벨 출력

### 한국 특유 요건
- **무통장 입금 확인**: 입금 기한 설정, 미입금 자동 취소 기능 (한국 쇼핑몰 필수 결제 흐름)
- **현금영수증/전자세금계산서 발행**: 주문 건별 영수증 발행 → 국세청 자동 전송 연동 (메이크샵 세금계산서 관리 메뉴, 카페24 모두 제공)
- **공정거래위원회 청약철회 7일 기준**: 반품 가능 기간 표시 및 시스템 적용
- **전자상거래법상 배송 기한(30일) 자동 취소**: 미발송 시 자동 주문 취소 처리

- **전국 당일·새벽 배송 설정**: 배송 유형별 상품 분류 및 배송 마감 시간 설정

## 4. 회원/등급 관리

### 핵심 기능
- **회원 목록·검색**: 다중 조건 검색(가입일·등급·구매 이력·지역), 엑셀 다운로드
- **회원 상세 조회**: 주문 이력, 적립금 내역, 쿠폰 보유 현황, CS 이력, 로그인 이력
- **회원 등급 시스템**: 등급 기준(구매 금액/횟수/기간) 설정, 등급별 할인율·적립률 차등 적용, 등급 자동 승급/강등
- **적립금(마일리지) 관리**: 상품 구매·리뷰 작성·추천인 등 지급 규칙 설정, 소멸 정책(유효기간), 수기 지급/차감, 적립금 내역 조회
- **예치금 관리**: 환불 시 예치금 전환, 예치금 사용 설정
- **포인트 vs 적립금 통합**: 이벤트 포인트 별도 발행 가능
- **회원 그룹 태깅**: 특정 회원 수동 그룹 지정, 타겟 마케팅용 세그먼트
- **휴면 회원 관리**: 1년 미이용 시 휴면 전환 알림 발송, 개인정보 분리 보관/파기
- **탈퇴 회원 처리**: 탈퇴 신청 수락, 개인정보 파기 로그 관리
- **블랙리스트 관리**: 부정 주문자 등록, 주문 차단, 사유 기록
- **부운영자 계정**: 관리자 계정 역할별 메뉴 접근 권한 세분화

### 한국 특유 요건
- **본인인증 연동**: 휴대폰 인증(통신사 본인확인), 아이핀(iPIN), 성인인증(성인몰) 설정
- **SNS 간편 가입**: 카카오, 네이버, 페이스북 OAuth 가입 지원
- **개인정보보호법 준수**: 미이용 1년 이상 회원 자동 휴면 전환, 법정 고지 발송, 분리 보관 처리
- **실명 확인**: 휴대폰 번호 기반 중복 가입 방지

## 5. 프로모션 — 쿠폰/할인/특가

### 핵심 기능
- **쿠폰 발행**: 자동 발급(회원가입·첫 구매·생일), 수동 발급, 다운로드 쿠폰, 코드 쿠폰
- **쿠폰 유형**: 정액 할인 / 정률 할인 / 배송비 할인 / 특정 상품 한정
- **쿠폰 제한 조건**: 적용 상품·카테고리·회원 등급, 최소 주문 금액, 중복 사용 여부, 유효 기간
- **쿠폰 발급 이력 및 사용 현황 조회**
- **기획전 관리**: 기획전 생성(테마/시즌), 기획전 상품 묶음 진열, 기간 설정, 배너 연결
- **타임세일**: 특정 시간대 할인 가격 자동 적용/해제
- **묶음 할인/세트 할인**: N개 이상 구매 시 추가 할인, 세트 상품 구성
- **등급 할인**: 회원 등급별 자동 할인율 적용
- **번들·추가상품 판매**: 메인 상품 구매 시 연관 상품 할인 제공
- **카트 할인**: 장바구니 금액 구간별 자동 할인 적용
- **이벤트 관리**: 출석체크·댓글·공유 이벤트 설정

## 6. 정산 관리

### 핵심 기능
- **매출 집계**: 기간별(일/주/월/분기/연) 총 매출, 실 결제 금액, 취소·환불 공제 후 순매출 산출
- **결제 수단별 매출 분리**: 신용카드·무통장·가상계좌·간편결제(카카오페이·네이버페이·토스페이) 별 집계
- **정산 예정 금액 조회**: PG사 정산 주기(일/주/월)별 입금 예정액 확인
- **판매 수수료 관리**: PG 수수료 차감 내역, 플랫폼 수수료(자사몰은 0) 정리
- **공급사 정산**: 입점 공급사별 판매 금액 집계, 수수료 차감 후 정산 금액 산출, 정산서 발행
- **매출 이익 계산**: 원가(공급가) 대비 판매가 마진율, 상품별·카테고리별 이익 리포트
- **엑셀 정산 다운로드**: 세금 신고용 매출 데이터 내보내기
- **현금영수증 발행 내역**: 건별 발행 상태, 미발행 건 일괄 처리
- **세금계산서 관리**: 사업자 구매자 대상 발행, 국세청 전자세금계산서 시스템 연동 상태 확인

### 한국 특유 요건
- **부가가치세 신고 자료**: 신용카드 매출·현금영수증·기타(간편결제) 유형별 분리 추출 (네이버·카페24·고도몰 모두 부가세 신고용 데이터 다운로드 제공)
- **전자세금계산서 발행**: 기업 고객(B2B) 대상 국세청 연동 발행 (메이크샵·카페24 제공)
- **정산 주기 관리**: PG사별 정산 D+n일 주기 파악 및 예측 현금흐름 관리

## 7. 통계/리포트

### 핵심 기능
- **매출 분석**: 일/주/월별 매출 그래프, 결제 수단별 매출, 멀티쇼핑몰별 매출 비교
- **상품 분석**: 판매 상품 랭킹, 카테고리별 판매 순위, 취소/반품 상품 랭킹, 장바구니 담기 순위, 위시리스트 순위, 공급사/브랜드별 판매 순위
- **고객 분석**: 요일·시간대별 구매 패턴, 회원 등급별 구매 분석, 배송 지역 분포, 신규·재구매 회원 비율
- **적립금/쿠폰 사용 통계**: 발행 대비 사용률, 할인 금액 집계
- **접속 통계**: UV/PV, 유입 경로(직접·검색·SNS·광고), 이탈률, 체류 시간

## 8. CS — 문의/리뷰/반품·교환

### 핵심 기능
- **상품 문의 관리**: 문의 목록 조회, 답변 등록, 공개/비공개 처리, 미답변 건 필터링
- **1:1 문의(고객센터)**: 문의 접수 → 처리 중 → 답변 완료 상태 관리, 담당자 지정, 문의 유형 분류(배송/교환/상품/기타)
- **주문 문의 연결**: 문의 내 주문 번호 연결, 주문 상세로 바로 이동
- **리뷰 관리**: 리뷰 목록 조회(상품별/기간별), 답글 등록, 숨김 처리, 포토리뷰 승인, 리뷰 적립금 지급
- **반품·교환 처리**: §2 주문 관리 참조 (접수 → 수거 → 처리 → 완료 단계 관리)
- **블랙리스트 연동**: 악성 문의자 계정 차단 연동
- **CS 통계**: 문의 유형별·처리 시간별 집계, 미처리 건 SLA 알림
- **채팅 상담 연동**: 카카오 상담톡·채널톡·채티스 등 실시간 채팅 솔루션 연결 (카페24 제공)

### 한국 특유 요건

## 9. 마케팅/CMS

### 핵심 기능
- **배너 관리**: 메인·서브 페이지별 배너 등록, 링크 설정, 기간 설정, 순서 변경, 모바일/PC 배너 분리
- **팝업 관리**: 팝업 노출 조건(신규 방문자/재방문자/특정 URL), 노출 기간, "오늘 하루 보지 않기" 옵션
- **공지사항 관리**: 쇼핑몰 공지, 관리자 내부 공지 분리
- **게시판 관리**: 게시판 생성(자유게시판·FAQ·갤러리), 게시판별 권한 설정, 비밀글·첨부파일 설정, 최대 13개 게시판 (카페24)
- **이메일 발송**: 회원 전체/그룹/등급별 이메일 발송, HTML 템플릿 편집, 발송 예약
- **SMS/문자 발송**: 회원 대상 수동·자동 발송, 광고 수신 동의자 필터링
- **카카오 알림톡**: 주문 상태 변경 자동 발송(결제 완료·배송 시작·배송 완료 등), 사전 승인 템플릿 사용, SMS fallback 설정
- **카카오 친구톡(광고성)**: 광고 수신 동의 회원 대상 마케팅 메시지 발송
- **마케팅 자동화**: 재구매 유도(구매 후 N일), 장바구니 이탈 알림, 휴면 전환 전 재방문 유도, 생일 쿠폰 자동 발송
- **SNS 연동**: 인스타그램·페이스북·카카오채널·유튜브 링크 설정, 소셜 공유 버튼
- **SEO 관리**: 페이지별 타이틀·디스크립션·OG 태그 설정, 사이트맵 생성
- **네이버 쇼핑 피드**: 상품 XML 피드 자동 생성 및 갱신 (카페24·고도몰 제공)
- **리타게팅 픽셀 설정**: 카카오 픽셀, 메타 픽셀, 네이버 전환 추적 스크립트 삽입

### 한국 특유 요건
- **카카오 알림톡 필수화**: 한국 고객 주문 알림의 70% 이상이 알림톡으로 수신 → 미적용 시 고객 신뢰도 저하
- **광고성 문자 수신 동의 관리**: 개인정보보호법·정보통신망법 기반 동의 여부 DB 관리, 무단 발송 차단
- **네이버쇼핑·카카오쇼핑·쿠팡 채널 피드**: 자사몰 운영 시에도 채널 연동 피드 자동 생성 필요

## 10. 설정/권한/보안

### 핵심 기능
- **쇼핑몰 기본 정보**: 상호·사업자번호·대표자·통신판매업 신고번호·고객센터 전화번호, 쇼핑몰 로고·파비콘 설정
- **운영자(부운영자) 계정 관리**: 계정 생성/수정/삭제, 역할별 메뉴 접근 권한 세분화 (상품관리만/주문관리만 등), 최초 로그인 시 비밀번호 강제 변경, IP 접근 제한
- **관리자 로그**: 어드민 접속 이력, 주요 데이터 변경 이력 감사(audit log)
- **도메인 관리**: 대표 도메인 설정, 멀티 도메인, SSL 인증서 관리
- **결제 설정**: PG사 선택·계약 정보 입력, 결제 수단별 노출 설정(신용카드·무통장·가상계좌·간편결제)
- **배송 설정**: 배송비 정책, 출고지 주소 (§3 참조)
- **약관 관리**: 이용약관·개인정보 처리방침·청약철회 안내 에디터 관리
- **쇼핑몰 접근 설정**: 점검 모드, 쇼핑몰 일시 비공개, 비밀번호 보호 접근
- **모바일 최적화 설정**: 모바일 전용 화면 활성화, AMP 설정
- **멀티쇼핑몰 관리**: 복수 쇼핑몰(국내/해외) 한 어드민에서 관리 (카페24 지원)
- **앱/플러그인 마켓**: 솔루션 부가 기능 스토어에서 앱 설치·관리 (카페24 앱스토어, 고도몰 플러스앱)
- **데이터 백업/복구**: 상품·주문·회원 데이터 주기적 백업, 디자인 백업

### 한국 특유 요건
- **통신판매업 신고번호 표시**: 전자상거래법상 쇼핑몰 하단 필수 표기 항목, 어드민에서 입력 관리
- **개인정보 처리방침 버전 관리**: 법 개정 시 이전 버전 보관, 동의 이력 로그 관리 의무
- **이중 인증(2FA) 옵션**: 관리자 로그인 OTP 설정 (고도몰·카페24 지원)
