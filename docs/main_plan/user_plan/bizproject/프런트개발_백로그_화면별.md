# 스토어프론트 개발 백로그 (화면별) — Step 0 현황·갭 도출

**작성일**: (현황 점검 결과) — apps/web 실제 코드·구동 기준
**전제**: `apps/web`는 Medusa Next.js 스타터라 **기본 구매여정이 이미 존재**. 그린필드 아님 → **검증 → 현지화(🔧) → 한국형 추가(❌)** 순.
**범례**: ✅ 있음(검증만) · 🔧 있으나 현지화/보강 · ❌ 신규(없음, 백엔드 미구현이면 mock 계약)
**담당**: A 카탈로그 · B 구매/결제 · C 회원/마이 · D 공통/CS (회의자료 분담)

> 점검 요약: 스토어프론트는 **KRW 백엔드에 정상 기동**, 루트가 `/kr`로 리다이렉트(기본 리전 한국). 통화는 `currency_code` 기반(✅)이나 표기 locale이 `en-US` 하드코딩(🔧→ko-KR). 홈은 **컬렉션 의존**이라 컬렉션 0개면 빈 화면.
