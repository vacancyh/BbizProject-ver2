# 디자인·레이아웃 검증 (모바일·웹 · 양 언어) — 2026-08-06

> 지금까지 본 것은 **"페이지에 가로 스크롤이 생기는가"** 뿐이었다.
> 그것만으로는 못 잡는 것들이 있어 요소 단위로 다시 봤다.

---

## 무엇을 봤나

| 검사 | 왜 |
|---|---|
| 요소가 화면 밖으로 삐져나감 | 조상이 `overflow:hidden` 이면 **페이지 스크롤은 안 생긴다** — 기존 검사로는 안 잡힌다 |
| 이미지 깨짐 (`naturalWidth === 0`) | 빈 칸으로 남아도 에러가 안 난다 |
| 텍스트 잘림 | 넘치는데 말줄임도 없는 경우 |
| 터치 타깃 크기 | 모바일에서 못 누르는 컨트롤 (WCAG 2.5.8 최소 24×24) |
| 페이지 가로 스크롤 | 기존 검사 |

**범위**: 스토어프론트 5화면 × 4폭(320·390·768·1280) × 2언어 = 40조합
추가로 1920 폭과 관리자 7화면 × 3폭(1024·1280·1440)까지 훑었다.

## 결과

| 대상 | 결과 |
|---|---|
| 스토어프론트 (60조합: 2언어 × 5뷰포트 × 6화면) | **60/60 정상** |
| 관리자 (21조합: 3뷰포트 × 7화면) | **21/21 정상** |

**요소 화면밖 · 텍스트 잘림 · 이미지 깨짐 · 페이지 가로 스크롤 = 전부 0건.**
영문이 한글보다 길어지는 화면에서도 레이아웃이 버텼다.

스크린샷으로도 확인했다 — 홈·목록·장바구니·로그인·고객센터·약관을 모바일/데스크톱 × 양 언어.

---

## 고친 것 — 누르기 힘든 컨트롤 2종

둘 다 **양 언어 공통**이라 번역과 무관한 기존 이슈였다.

### ① 히어로 배너 점 8×8

```
button [배너 1] 8×8   ← 모바일에서 사실상 못 누른다
```

**보이는 점은 8px 그대로 두고 누르는 영역만 24×24 로** 넓혔다.
버튼을 키우면 디자인이 바뀌므로, 버튼 안에 `<span>` 으로 점을 넣고 버튼에 `grid place-items-center` 를 줬다.
`gap-2 → gap-0` 으로 조정해 **시각적 간격도 그대로** 유지된다.

```
수정 후: 누르는 영역 24×24 · 보이는 점 8×8   (스크린샷으로 모양 동일 확인)
```

`aria-current` 도 함께 붙여 현재 배너를 스크린리더가 알 수 있게 했다.

### ② 푸터 로고 링크 18×18

`Powered by Medusa & Next.js` 의 로고 링크. 같은 방식으로 24×24 로 넓혔다.

> 곁다리: 처음엔 `h-6 w-6` 만 줬더니 **20×24** 가 나왔다.
> flex 자식이라 가로가 줄어든 것이라 `shrink-0` 을 추가해야 했다.

## 오탐 2건 — 기록해 둔다

검사 기준을 잘못 잡아 **없는 문제를 만들 뻔했다.** 같은 실수를 반복하지 않도록 남긴다.

### 관리자 표 40건이 전부 오탐이었다

```
table.dt "주문번호 ▼주문일시…" left=273 right=1480 / vw=1440   ← 화면밖으로 보고됨
```

실제로는 표가 **가로 스크롤 컨테이너 안**에 있었다. 넓은 표를 내부에서 스크롤시키는 건 정상 패턴이다.
원인은 스크롤 컨테이너를 **클래스명으로 판단**한 것 — 앱마다 클래스가 다르다.
→ **조상의 계산된 `overflow-x`** 를 직접 보도록 고쳤다. 21/21 정상으로 바뀌었다.

### 본문 속 링크 24건이 오탐이었다

```
a "쇼핑몰" 54×20 · a "Forgot your password?" 123×20
```

문장 안의 인라인 링크는 줄 높이만큼만 차지하는 게 정상이고, WCAG 도 예외로 둔다.
가로·세로가 **둘 다** 24 미만인 것만 잡도록 좁혔다. 진짜 문제(8×8, 18×18)만 남았다.

> 교훈: **"넘쳤다/작다"는 판정은 맥락을 봐야 한다.** 숫자만 보면 멀쩡한 것을 고치게 된다.

## 남은 참고 사항

- 홈 화면은 **팝업 배너가 히어로를 덮는다**(신규 회원 적립금 안내). 의도된 동작이며,
  스크린샷에서 배너 점이 안 보이는 이유다. 점 확인은 팝업을 닫고 따로 측정했다.
- 미전환 UI 라벨(메뉴·검색 placeholder·푸터)은 영어 화면에서도 한국어로 나온다.
  **깨짐이 아니라 의도된 폴백**이다 — [12. 다국어 가이드](../01_팀원용/12_다국어_가이드.md) 참조.
