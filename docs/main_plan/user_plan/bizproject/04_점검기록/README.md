## 실행 가능한 검증 도구

문서만 남기지 않고 **다시 돌릴 수 있게** 만들었습니다.

```bash
cd 보안점검
export BASE=http://localhost:9000 PUBKEY=pk_...

node presale-security-probe.mjs      # 27건 — IDOR·인젝션·헤더·레이트리밋
node audit2-probe.mjs                # 19건 — 토큰위조·권한상승·CORS·입력경계
node audit3-concurrency-probe.mjs    #  6건 — 적립금/환불/취소 동시 이중집행
node storefront-readiness-probe.mjs  # 고객 화면 자리표시자 검출
```

> ⚠️ `audit3` 은 실제 주문·결제를 만듭니다. **운영 DB 에서 실행 금지.**
