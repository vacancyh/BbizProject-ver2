| 상품 목록(`/store`) | ✅ | 한글화(`전체 상품`/정렬 `신상품순·낮은가격순·높은가격순`)+미니멀 그리드(4열). 검색 결과/빈상태 통합 |
| 상품 상세(옵션/가격) | ✅ | 한글화+미니멀 리스킨(옵션 각진 버튼·`장바구니 담기`·`최저`/`정상가`·관련상품). 찜 버튼 인라인 추가 |
| **상품정보고시** 탭 | ✅(실연동) | **product_disclosure 테이블 마이그레이션 생성·적용** + **store 라우트 신설** `GET /store/products/:id/disclosure`(product-disclosure 모듈, getActiveDisclosure). `lib/data/disclosure`+상세 하단 고시표. 검증: 면100% 등 항목 렌더(전자상거래법 충족) |
| 카테고리 | ✅ | 검증 + **헤더 메뉴에 admin 카테고리 노출**(상품 있는 상위 카테고리, `(kr-test)` 표식 정리). store 연동 검증(카테고리→상품) |
| 컬렉션/기획전 | 🔧 | 컬렉션 있음, 기획전(배너·기간·큐레이션)은 보강 |
| **검색** | ✅(실연동) | 헤더 검색바 + `/store?q=` → **실제 `/store/products?q=` 백엔드 검색**. **인기 검색어 실집계**(`GET/POST /store/popular-search-terms`, 최소 2회 임계·IP rate limit)+최근검색어(localStorage) 검색 제안. 결과없음 처리 |
| **위시리스트** | ✅(쿠키+실상품) | `lib/data/wishlist`(쿠키 영속 서버액션)+`/wishlist` 페이지+카드/상세 찜 버튼+계정 탭. 상품 데이터는 실제 store API 조회 |
| **타임세일** | ✅(실연동) | **store 라우트** `GET /store/time-sales`(time-sale 모듈 listActiveSales). 홈 노출영역(할인배지·할인가·실시간 카운트다운). 검증: 20%↓ 12,000원 |
| **재입고 알림** | ✅(실연동) | **신규 모듈+테이블** restock-notification + `POST /store/restock-notifications`. 품절 변형 시 상세에 알림신청 폼(중복방지·이메일검증). 검증: 구독 1건 |
| 리뷰 탭 | ✅(실연동) | `GET/POST /store/products/:id/reviews`. 조회(평균/분포/목록) + **리뷰 작성 폼**(별점·제목·내용→pending→관리자 검수). 검증: 작성→admin 리뷰관리 노출 |
