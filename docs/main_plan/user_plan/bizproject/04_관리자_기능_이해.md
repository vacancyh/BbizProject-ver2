# 04. 관리자(운영자) 기능 이해

## 이 문서는

관리자(운영자)가 무엇을 하는지 이해해서, **프런트(스토어프론트)가 무엇을 만들어야 하는지 감을 잡기 위한** 문서입니다.

> 중요: **프런트 개발자는 관리자 앱을 직접 만들지 않습니다.** 관리자 앱은 운영자가 쓰는 백오피스이고, 우리가 만드는 쇼핑몰(고객용)은 그 데이터를 "보여주는" 쪽입니다. 그래서 관리자 기능을 알면 프런트가 다룰 데이터와 흐름이 보입니다.

---

## 관리자 접속

| 항목 | 값 |
|---|---|
| 주소 | http://localhost:7002 |
| 아이디 | `admin@shop.local` |
| 비밀번호 | `admin1234!` |

- 위 계정은 **로컬 개발 전용**입니다(운영 계정 아님).
- 일부 보안 메뉴(**권한 관리·정책 관리·감사 로그**)는 조회조차 **super 역할** 계정만 가능합니다. 일반 운영자 계정으로는 보이지 않거나 403이 납니다.

---

## 화면 지도 (메뉴 그룹)

관리자 사이드바는 4개 그룹, 총 28개 화면으로 구성됩니다. (실제 라우트 폴더 기준)

### 운영
대시보드 · 주문 관리 · 상품 관리 · 상품 통계·큐레이션 · 타임세일 · 상품 분류 체계 · 카테고리 · 회원 관리 · 배송 관리 · 창고 관리 · 배송정책 관리

### 매출 · 마케팅
정산 관리 · 쿠폰·프로모션 · 마케팅 · 통계·리포트

### 고객 · 설정
리뷰·문의 · 쇼핑몰 설정 · 판매채널 · API 연동키 · 워크플로우 로그 · 반품·환불 사유 · 약관 관리 · 고객센터 콘텐츠 · 배너·팝업 · 홈 큐레이션 · 점검 모드 · **2단계 인증(2FA)**

> **2단계 인증(2FA)** (`설정 > 2단계 인증`, `/settings/security`): 관리자 계정 옵트인 TOTP. 등록(QR 스캔 또는 수동 키) → 6자리 코드로 활성화 → 백업 코드 발급. 로그인 시 비밀번호 통과 후 OTP 단계가 추가되고, 서버측 게이팅으로 미인증 접근이 차단됩니다. 시크릿은 AES-256-GCM 암호화 저장.

### 보안 (super 전용)
권한 관리 · 정책 관리 · 감사 로그

> 참고: 커스텀 한국형 기능(쿠폰·포인트·등급·리뷰/문의·CMS 등) 상당수는 아직 고객용 store API가 없어서, **프런트는 당분간 mock 데이터로 화면을 만듭니다.** (어떤 게 실데이터고 어떤 게 mock인지는 `05_데이터모델_ERD.md`에서 다룹니다.)

## 화면별 설명 표

### 운영 그룹

| 화면 | 무엇을 하나 | 프런트 연관 |
|---|---|---|
| 대시보드 | 매출·주문 등 핵심 지표를 요약해 보여줍니다. | (운영용, 직접 대응 없음) |
| 주문 관리 | 주문 목록/상세 조회, 출고·송장 등록·배송완료·환불·강제취소 처리. | 마이페이지 **주문내역/주문상세**, **주문상태** 표시, 취소/반품·교환 신청 |
| 상품 관리 | 상품 등록/수정, 변형(옵션)·가격·이미지 관리, 상품정보고시 입력. | **상품 목록/상세**, 가격·옵션 선택, 상품정보고시 탭 |
| 상품 통계·큐레이션 | 조회수·판매량·위시·인기검색어를 모아 홈 큐레이션(베스트 등) 구성. | 홈 **베스트/인기 상품**, 인기 검색어 |
| 타임세일 | 기간·재고 한정 특가를 설정(종료 시 원가 복원). | **타임세일 노출**, 남은 시간/수량 표시 |
| 상품 분류 체계 | "무엇을 파는가"의 분류 축(분야→분류) + 분류별 옵션·고시 필수항목 템플릿. | 상품 상세의 **상품정보고시 탭**(분류별 필수항목) |
| 카테고리 | 진열 카테고리(트리/노출), 컬렉션·기획전, 상품 태그 관리. | **카탈로그 내비게이션**, 기획전 페이지, 태그 필터 |
| 회원 관리 | 회원/회원 그룹 조회·수정, 주소·주문이력, PII 마스킹. | **로그인/마이페이지**, 등급, 배송지 관리 |
| 배송 관리 | 출고지·서비스 구역·배송비·국내 택배사 설정. | 배송비 안내, **배송 방법/예상 배송비** 표시 |
| 창고 관리 | 창고(재고 보관 위치)와 위치별 재고 관리. | 상품 **가용 수량/품절** 표시 |
| 배송정책 관리 | 배송 프로파일·구역별 정책 설정. | 배송 안내/정책 페이지 |

### 매출 · 마케팅 그룹

| 화면 | 무엇을 하나 | 프런트 연관 |
|---|---|---|
| 정산 관리 | 매출 집계·정산 KPI 관리. | (운영용, 직접 대응 없음) |
| 쿠폰·프로모션 | 프로모션/쿠폰(정률·정액·최소주문 등) 생성·관리, 캠페인. | **체크아웃 쿠폰코드** 입력, **마이 쿠폰함** |
| 마케팅 | 이메일·SMS·카카오 알림톡 발송, 세그먼트, CMS(공지/FAQ/배너/팝업). | **배너·팝업·공지/FAQ** 노출, 알림 수신 |
| 통계·리포트 | 매출·상품·회원 통계 조회와 리포트 스케줄. | (운영용, 직접 대응 없음) |

### 고객 · 설정 그룹

| 화면 | 무엇을 하나 | 프런트 연관 |
|---|---|---|
| 리뷰·문의 | 상품 리뷰와 1:1/Q&A 문의를 운영자가 확인·답변. | 상품 **리뷰 탭**, CS **1:1 문의/상품 Q&A** |
| 쇼핑몰 설정 | 내 계정·스토어 기본정보 등 운영 설정. | (운영용, 직접 대응 없음) |
| 판매채널 | 판매 채널(단독몰=1) 및 채널-상품 연결. | 어떤 상품이 몰에 노출되는지 결정 |
| API 연동키 | 스토어프론트용 publishable 키 등 연동 키 발급. | 프런트가 store API 호출 시 쓰는 **publishable 키** |
| 워크플로우 로그 | 백엔드 워크플로우 실행 단계/상태 모니터링. | (운영용, 직접 대응 없음) |
| 반품·환불 사유 | 반품/환불 사유 코드 관리. | 반품·교환 신청 시 **사유 선택 목록** |
| 약관 관리 | 약관/문서(이용약관·개인정보 등) 버전 관리. | **약관 페이지**, 가입 시 **동의 항목** |
| 점검 모드 | 몰 점검 모드 ON/OFF(super 필요). | 점검 중 **점검 안내 페이지** 노출 |

### 보안 그룹 (super 역할 전용)

| 화면 | 무엇을 하나 | 프런트 연관 |
|---|---|---|
| 권한 관리 | 관리자 등급(SUPER/OPERATION/CS/MARKETER) 권한 매트릭스 설정. | 없음 (운영자 내부용) |
| 정책 관리 | 미입금 자동취소·환불 SLA·청약철회 기간 등 정책 단일 관리. | 정책 값이 간접적으로 프런트 안내 문구에 반영 |
| 감사 로그 | 모든 쓰기 작업 기록(행위자·시각·diff, PII 마스킹). | 없음 (운영자 내부용) |

## 알아둘 운영 개념

각 줄: 개념 1줄 + 프런트가 어떻게 보여줄지 1줄.

- **결제 상태**: 결제대기 / 결제완료 / 취소 / 부분환불 등 결제의 진행 단계.
  → 프런트: 주문상세에서 "결제완료" 같은 **결제 상태 배지**로 표시.
- **배송 상태**: 배송준비 → 배송중 → 배송완료의 단계.
  → 프런트: 주문상세에 **배송 진행 단계/송장번호** 표시.
- **주문 상태**: 주문 전체 진행(주문접수·처리중·완료·취소 등).
  → 프런트: 주문내역 목록의 **상태 라벨**.
- **재고 추적(manage_inventory)·예약·품절**: 변형별 재고를 추적하고, 주문 시 예약(차감)하며 0이면 품절.
  → 프런트: 상품 상세의 **가용 수량/품절(SOLD OUT)** 표시, 장바구니 담기 제한.
- **회원 vs 비회원(게스트)**: 로그인 회원과 비회원 주문을 구분.
  → 프런트: **로그인 여부에 따라** 마이페이지/주문조회 방식 분기.
- **등급·적립금·제재·동의**: 회원 등급, 포인트(적립금), 제재(블랙리스트), 개인정보 동의 이력.
  → 프런트: 마이페이지의 **등급·적립금 표시**, 가입/주문 시 **동의 체크**.
- **점검 모드**: 운영자가 몰 전체를 일시 점검 상태로 전환.
  → 프런트: 점검 ON이면 **점검 안내 화면**으로 대체.
