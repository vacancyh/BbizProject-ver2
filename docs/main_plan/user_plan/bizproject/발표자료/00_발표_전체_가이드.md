# 발표 전체 가이드 및 개요

## 발표 구성 (총 20분)

4명이 각각 4~5분씩 발표하며, AI를 활용한 쇼핑몰 개발 과정을 공유합니다.

---

## 발표자별 담당 내용

### 발표자 1: 프로젝트 소개 및 환경 설정, 전체 설계 (4~5분)
- **파일**: `발표자1_프로젝트소개_환경_설계.md`
- **주요 내용**:
  - 프로젝트 배경 및 목표
  - 기술 스택 선정 (AI에게 추천받기)
  - 개발 환경 셋업 (Docker, .env)
  - 전체 아키텍처 설계 (DB 스키마, 모듈 구조, API 설계)
  - 문서화
- **강조 포인트**: AI와의 초기 대화, 설계 검증 과정
- **프롬프트 스타일**: 체계적, 설명 중심
- **소감**: 빠른 프로토타이핑, 검증 필수, 문서화 중요

### 발표자 2: 주문/결제 시스템 (4~5분)
- **파일**: `발표자2_주문_결제_시스템.md`
- **주요 내용**:
  - 복잡한 주문 프로세스 설계 (Workflow)
  - 엣지 케이스 검증 (동시성, 할인 순서)
  - 단계별 구현 (재고 체크, 할인, 적립금)
  - 관리자 주문 관리 UI
  - 통합 테스트
- **강조 포인트**: 복잡한 비즈니스 로직을 AI와 단계별로 해결
- **프롬프트 스타일**: 실전 중심, 에러 해결 과정 강조
- **소감**: 단계별 구현, 엣지 케이스 질문, 에러 빠른 공유, 테스트 중요

### 발표자 3: 상품/회원 시스템 (4~5분)
- **파일**: `발표자3_상품_회원_시스템.md`
- **주요 내용**:
  - 상품 옵션 구조 설계 (사이즈, 색상 조합)
  - 관리자 상품 등록 UI (복잡한 폼)
  - 고객용 상품 상세 페이지 (이미지 갤러리, 옵션 선택)
  - 회원 등급 및 적립금 시스템
  - 재고 관리
- **강조 포인트**: UI 구현 빠름, 비즈니스 로직 검증, 재사용성
- **프롬프트 스타일**: 코드 중심, 구현 디테일
- **소감**: UI는 AI가 빠름, 로직은 검증 필요, 재사용성 고려, 모바일 테스트

### 발표자 4: 보안 및 성능 최적화 (4~5분)
- **파일**: `발표자4_보안_성능_최적화.md`
- **주요 내용**:
  - 관리자 2FA (TOTP, QR, 백업 코드)
  - API Rate Limiting (Redis)
  - 베스트 랭킹 성능 최적화 (캐싱)
  - 인기 검색어 실시간 트래킹
  - 전체 프로젝트 종합 소감
- **강조 포인트**: 보안/성능은 나중이 아니라 처음부터, 측정과 개선
- **프롬프트 스타일**: 문제 해결 중심, 최적화
- **소감**: 보안 초기부터, 성능 측정, 캐싱 만능, AI는 베스트 프랙티스 제공

## 전체 발표 메시지

**"평범한 개발자가 AI를 활용해서 쇼핑몰을 완성한 과정"**

### 핵심 포인트:
1. **모든 단계에서 AI 활용** - 설계, 구현, 테스트, 문서화
2. **하지만 맹신하지 않기** - 검증, 질문, 테스트 필수
3. **구체적인 프롬프트** - 컨텍스트, 제약사항, 예시 제공
4. **단계별 진행** - 한 번에 다 하지 말기
5. **에러 활용** - 에러 나면 바로 AI에게 공유

### 프로젝트 성과:
- 기간: 2개월
- 규모: 50,000줄 코드, 800+ 파일
- 기능: 주문/결제, 상품/재고, 회원/등급/적립금, 쿠폰, 리뷰, 2FA, 랭킹 등
- 효과: AI 없었으면 6개월+ 소요 예상

## 발표 시 주의사항

### 전체 공통:
- **자연스러운 말투** - AI가 만든 것처럼 들리지 않게
- **실제 경험 강조** - 에러, 시행착오, 수정 과정 보여주기
- **프롬프트 예시** - 각 파트마다 2~3개 핵심 프롬프트 소개
- **시간 엄수** - 각자 4~5분, 전체 20분 넘지 않기
- **슬라이드 활용** - 코드/구조/UI는 시각적으로 보여주기

### 발표 흐름:
1. 발표자 1: 프로젝트 시작, "AI 어떻게 활용하나?" 궁금증 유발
2. 발표자 2: 복잡한 로직 해결, "AI로 이런 것도 되네?" 감탄
3. 발표자 3: UI/UX까지 완성, "생각보다 실용적이네" 공감
4. 발표자 4: 보안/성능까지, "실서비스 가능하네" + 전체 정리

### 청중 반응 유도:
- 실제 화면/데모 보여주기
- "여러분도 해보실 수 있습니다" 메시지
- 구체적인 프롬프트 예시로 바로 적용 가능하게

## 예상 질문 및 답변

**Q: AI가 다 만들어준 건가요?**
A: 아니요, AI는 초안과 제안을 주고 저희가 검증하고 수정했습니다. AI가 잘못된 코드 준 경우도 많았어요.

**Q: 어떤 AI 도구를 사용했나요?**
A: ChatGPT, Claude, GitHub Copilot 등을 상황에 따라 활용했습니다.

**Q: AI 없이도 할 수 있었을 것 같은데?**
A: 가능하지만 시간이 훨씬 더 걸렸을 겁니다. 특히 초기 설계와 반복 작업에서 큰 도움을 받았어요.

**Q: 프롬프트 작성이 어렵지 않았나요?**
A: 처음엔 애매하게 물어봐서 원하는 답을 못 받았어요. 구체적으로, 컨텍스트 제공하면서 물어보니 좋아졌습니다.

**Q: 실제 서비스로 운영 가능한가요?**
A: 네, 보안과 성능 최적화까지 했고 테스트도 완료했습니다. 실제 결제 연동만 하면 바로 사용 가능합니다.

## 각자 수정 가이드

각 발표자는 자신의 파일을 보고:
1. **본인 스타일로 수정** - 말투, 단어 선택
2. **실제 경험 추가** - 기억나는 에러, 재미있었던 순간
3. **프롬프트 구체화** - 실제로 썼던 프롬프트로 교체
4. **소감 개인화** - 본인이 진짜 느낀 점으로
