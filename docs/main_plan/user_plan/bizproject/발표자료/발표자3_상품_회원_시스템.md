## 1. 상품 관리 시스템 - 옵션이 복잡하다 (1분 30초)

**[슬라이드: 상품 구조]**

한국 쇼핑몰 상품은 단순하지 않습니다. 같은 티셔츠도 색상, 사이즈별로 재고와 가격이 다를 수 있어요.

### 요구사항:

- 상품 기본 정보 (이름, 설명, 카테고리)
- 다중 이미지 (썸네일, 상세 이미지)
- 옵션 (사이즈: S/M/L, 색상: 빨강/파랑/검정)
- 옵션 조합별 재고 및 가격 (예: 빨강-M 10개, 파랑-L 5개)
- 할인가 설정

이걸 AI한테 어떻게 설계하면 좋을지 물었습니다.

```
상품 관리 데이터 구조 설계해줘.
(※ 데이터 구조: 상품 정보를 어떻게 저장할지)

요구사항:
- 상품 하나에 여러 옵션 (사이즈, 색상)
- 옵션 조합마다 재고, 가격 다름
- 이미지는 여러 개 (순서 있음)
- 할인가 따로 관리

어떻게 만들면 돼?
```

```
AI 답변:

"기본 구조 활용해서 확장하세요:

상품(Product)
  ├─ 옵션 종류(ProductOption)
  │    예: 사이즈: S, M, L
  │       색상: 빨강, 파랑
  │
  ├─ 옵션 조합(ProductVariant)
  │    예: M + 빨강 → 가격 25,000원, 할인가 20,000원, 재고 10개
  │
  └─ 이미지(ProductImage)
       썸네일, 상세 이미지 등 순서대로 저장

추가 필드:
- 상품 상태 (판매중/품절/단종)
- 재고 관리 코드

[상세 구조...]"
```

근데 이걸 어떻게 입력받을지가 고민이었어요.

## 2. 관리자 상품 등록 UI - 복잡한 폼 (1분)

**[슬라이드: 상품 등록 화면]**

관리자가 상품을 등록할 때 옵션 조합을 자동으로 만들어줘야 했습니다.

```
관리자 상품 등록 화면 만들어줘.

기능:
1. 기본 정보 입력 (이름, 설명, 카테고리)
2. 이미지 업로드 (여러 개, 드래그로 순서 변경)
3. 옵션 설정
   - 옵션 종류 추가 (사이즈, 색상 등)
   - 각 옵션의 값 입력 (S,M,L / 빨강,파랑)
4. 옵션 조합 자동 생성
   - 사이즈 3개 × 색상 2개 = 6개 조합
   - 각 조합별로 가격, 재고 입력
5. 미리보기
```

AI가 화면을 만들어줬는데, 옵션 조합 만드는 부분이 복잡했어요.

```
옵션 조합 만드는 코드 다시 봐줘.

현재:
- 옵션1: S, M, L
- 옵션2: 빨강, 파랑

이걸 모든 조합으로 만들어야 해:
(※ 조합: 가능한 모든 경우의 수)

[
  S + 빨강,
  S + 파랑,
  M + 빨강,
  M + 파랑,
  L + 빨강,
  L + 파랑
]
```

```
AI: "간단한 방법으로 만들 수 있습니다:

[옵션 조합 생성 코드 설명]
1. 첫 번째 옵션들로 시작
2. 다음 옵션의 각 값을 앞에 것들과 하나씩 조합
3. 모든 옵션에 대해 반복

예시:
사이즈: S, M
색상: 빨강, 파랑
→ 4개 조합 자동 생성"
```

이 방법으로 해결했습니다.

## 3. 상품 상세 페이지 - 고객용 UI (1분)

**[슬라이드: 프론트 상품 상세]**

이제 고객이 볼 상품 상세 페이지를 만들었습니다.

```
상품 상세 화면 만들어줘.

구성:
1. 이미지 갤러리
   - 메인 큰 이미지
   - 하단에 작은 이미지들
   - 작은 이미지 클릭하면 메인이 바뀜
   
2. 상품 정보
   - 이름, 가격 (할인가 있으면 정가는 취소선)
   - 옵션 선택 (선택 상자 또는 버튼)
   - 수량 선택 (+/- 버튼)
   - 장바구니 담기, 바로 구매 버튼
   
3. 상세 설명 (탭)
   - 상품 설명
   - 리뷰
   - 배송/교환/환불

모바일에서도 잘 보이게"
```

받아서 실행해보니:

```
"모바일에서 이미지 갤러리가 너무 작아.
손가락으로 스와이프도 되게 해줘."
(※ 스와이프: 화면을 손가락으로 밀어서 넘기기)
```

```
AI: "터치 제스처 라이브러리 추천합니다.

설치: npm install react-swipeable

[터치 제스처 추가된 코드]
"
```

이렇게 수정하니까 모바일에서도 잘 됐습니다.

## 4. 회원 시스템 - 등급과 적립금 (1분 30초)

**[슬라이드: 회원 관리]**

한국 쇼핑몰은 회원 등급과 적립금이 필수입니다.

### 등급 시스템 설계:

```
회원 등급 시스템 설계해줘.

등급:
- BRONZE (기본)
- SILVER (총 구매 10만원 이상)
- GOLD (총 구매 50만원 이상)
- VIP (총 구매 100만원 이상)

등급별 혜택:
- 적립률 (BRONZE 1%, SILVER 2%, GOLD 3%, VIP 5%)
- 쿠폰 (등급별로 다른 쿠폰 지급)

구매할 때마다 자동으로 등급 업데이트되게
```

```
AI: "등급 관리 테이블:
     (※ 테이블: 데이터를 정리해서 저장하는 곳)
     
- 고객 번호
- 등급 (BRONZE/SILVER/GOLD/VIP)
- 총 구매 금액
- 혜택 정보 (적립률, 무료배송 등)

주문 완료 때 자동 처리:
  1. 주문 금액을 총 구매 금액에 더하기
  2. 등급 조건 확인
  3. 등급이 올라가면 쿠폰 지급

[구현 코드...]"
```

### 적립금 시스템:

```
적립금 시스템 만들어줘.

요구사항:
- 주문 완료 시 자동 적립 (등급별로 다른 비율)
- 적립금 사용 (결제 시 차감)
- 만료 기한 (적립 후 1년)
- 사용 내역 조회

적립금 거래 기록 테이블 만들고
적립/사용/만료 처리하는 기능 만들어줘.
```

```
AI: "적립금 거래 테이블:
- 고객 번호
- 타입 (적립 | 사용 | 만료)
- 금액 (+/-)
- 주문 번호
- 설명
- 만료일
- 생성일

주요 기능:
- earnPoints(고객번호, 금액, 주문번호) - 적립
- usePoints(고객번호, 금액, 주문번호) - 사용
- getBalance(고객번호) - 잔액 조회 (모든 거래 합산)
- getHistory(고객번호) - 거래 내역
- expirePoints() - 만료 처리 (매일 자동 실행)

[상세 구현...]"
```

### 마이페이지 구현:

```
고객 마이페이지 만들어줘.

탭 구성:
1. 주문 내역 (상태별 필터)
2. 적립금 (잔액, 사용 내역)
3. 쿠폰함
4. 내 정보 수정
5. 등급 정보 (현재 등급, 다음 등급까지 필요 금액)

모바일에서도 잘 보이게
```

AI가 화면을 만들어줬는데, 등급 진행률 표시가 없어서:

```
등급 탭에 진행률 바 추가해줘.
(※ 진행률 바: 목표까지 얼마나 진행됐는지 보여주는 막대)

예: SILVER인데 GOLD까지 20만원 남았으면
진행률 60% (30만원/50만원) 표시
```

```
AI: [진행률 바 추가된 코드]
```

## 5. 재고 관리 - 실시간 업데이트 (30초)

**[슬라이드: 재고 관리]**

상품 판매되면 재고가 자동으로 줄어야 하고, 관리자는 재고를 추가할 수 있어야 합니다.

```
재고 관리 기능 만들어줘.

자동 처리:
- 주문 완료 시 재고 줄이기
- 주문 취소 시 재고 복구
- 재고 0이면 품절 표시

관리자 기능:
- 재고 조회 (옵션별)
- 재고 추가/차감
- 재고 변동 내역
- 재고 부족 알림 (기준 설정)
```

AI가 재고 관리 기능과 관리자 화면을 만들어줬고, 주문 기능에 재고 차감 로직을 연결했습니다.

## 6. 나의 소감 및 배운 점 (30초)

**[슬라이드: 소감]**

상품/회원 시스템 개발하면서:

**1. UI 구현은 AI가 정말 빠르다**
- 폼, 테이블, 카드 같은 일반적인 UI는 AI가 잘 만들어줍니다.
- 디자인 수정도 "이렇게 바꿔줘" 하면 바로 반영돼요.

**2. 복잡한 기능은 검증이 중요**
- 등급 업데이트, 적립금 계산 같은 건 AI가 제안해도 꼭 확인해야 합니다.
- 테스트를 많이 만들어서 돌려보세요.

**3. 화면 재사용성 고려**
- AI한테 "재사용 가능하게" 요청하면 여러 곳에서 쓸 수 있게 만들어줍니다.
- 상품 카드, 목록 같은 건 여러 곳에서 쓰니까 처음부터 범용적으로 만들기.

**4. 실제로 사용해보면서 테스트**
- 모바일에서 직접 써보니까 문제가 많이 보였어요.
- AI는 기본적으로 PC 화면 기준으로 만드는 경향이 있어서 모바일은 꼭 확인하세요.
