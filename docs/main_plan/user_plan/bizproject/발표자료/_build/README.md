# 발표자료 PDF 빌드

발표장에서 쓸 **슬라이드 PDF**와 손에 들 **대본 PDF**를 만드는 도구입니다.

`.md` 원고는 읽기용으로 남겨두고, 실제 발표에 쓸 인쇄물은 여기서 뽑습니다.

---

## 실행

```bash
cd docs/main_plan/user_plan/bizproject/발표자료/_build
node build.mjs
```

한 폴더 위(`발표자료/`)에 PDF 5개가 떨어집니다.

| 파일 | 용도 |
|---|---|
| `발표_전체.pdf` | **당일 프로젝터용.** 표지 + 파트 구분 + 전 슬라이드 |
| `발표1_AI를_어떻게_썼나.pdf` | 발표자 1 개인 연습·수정용 |
| `발표2_AI로_무엇을_만들었나.pdf` | 발표자 2 |
| `발표3_AI_결과를_어떻게_검증했나.pdf` | 발표자 3 |
| `발표자대본.pdf` | A4 세로. 슬라이드별 말할 내용 + 시간 배분 |

별도 설치는 필요 없습니다. Chromium 은 `apps/web` 의 `@playwright/test` 것을 빌려 씁니다.

---

## 내용 수정

**`slides.mjs` 한 파일만 고치면 됩니다.**

- `DECK.sections[].slides` — 슬라이드 내용
- `SCRIPT` — 대본 (슬라이드명, 시간, 말할 내용)
- `DECK.sections[].tips` — 대본 하단 "발표 팁"

`render.mjs` 는 모양만 담당하므로 글자 크기·색을 바꿀 때만 엽니다.

### 슬라이드 종류

| type | 쓸 곳 |
|---|---|
| `big` | 한 문장 강조 (전환·마무리) |
| `bullets` | 항목 나열. 3~6개일 때 글자 크기가 자동 조정됨 |
| `code` | 프롬프트·터미널 출력. `danger: true` 면 빨간 톤 |
| `compare` | 좌우 비교. 기본은 좌=나쁨/우=좋음, `tone: "neutral"` 로 중립 가능 |
| `table` | 표 |
| `metrics` | 큰 숫자 나열 |

본문에는 `<b>`, `<code>`, `<span class="dim">` 을 그대로 쓸 수 있습니다.

## 넘침 검사

슬라이드는 넘쳐도 PDF 에서 **조용히 잘려 나갑니다.** 눈으로만 보면 놓칩니다.

```bash
node check.mjs          # 720px 안에 들어가는지 전 장 검사
node check.mjs --shot   # 넘친 장을 PNG 로도 저장
```

내용을 늘린 뒤에는 반드시 돌리세요. 넘친 장이 있으면 종료 코드 1 을 냅니다.

---

## 왜 HTML→PDF 인가

- 파워포인트 파일은 diff 가 안 됩니다. 여기 방식은 **텍스트라 git 이력이 남습니다.**
- 발표 내용이 바뀔 때마다 슬라이드를 손으로 다시 맞출 필요가 없습니다.
- 중간 산출물 `.html` 은 `_build/` 에 남으니 브라우저로 바로 열어봐도 됩니다.

> 파워포인트로 직접 편집해야 한다면 `발표_전체.pdf` 를 PowerPoint 에서 열거나
> Adobe Acrobat 으로 변환하세요. 다만 그 뒤로는 이 스크립트와 내용이 갈라집니다.
