# 02_AI용 — AI 에게 그대로 주는 문서

⚠️ **사람이 읽으라고 쓴 문서가 아닙니다.**
AI(Claude·ChatGPT 등)에게 **통째로 붙여넣어** 프로젝트 컨텍스트를 채우는 용도입니다.

## 사람용 문서와 무엇이 다른가

| | 01_팀원용 | 02_AI용 (여기) |
|---|---|---|
| 독자 | 사람 | AI |
| 서술 | 설명·비유·배경 | **사실의 나열** |
| 강조 | "왜 그렇게 했나" | **정확한 타입·경로·제약** |
| 분량 | 읽기 좋게 | 토큰 효율 우선 |
| 시작 | 개요 | "이 문서를 읽는 AI는 …" 지시문 |

사람용 문서를 AI 에게 주면 비유·배경이 토큰만 잡아먹고 정확도가 떨어집니다.
반대로 이 폴더 문서를 사람이 읽으면 "그래서 왜?"가 안 보입니다.
