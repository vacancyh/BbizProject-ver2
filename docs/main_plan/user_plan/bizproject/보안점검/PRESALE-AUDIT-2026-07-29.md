## 5. 🚀 운영 모드 실제 검증

시크릿 없이 `NODE_ENV=production` 부팅 → **의도대로 차단**:
```
[security] JWT_SECRET must be set to a strong random value (>=16 chars) in production
```

시크릿 주입 + **하드닝 플래그 ON**(`SECURITY_GUARD_FAIL_CLOSED`, `ADMIN_MONEY_ACTIONS_SUPER_ONLY`) 상태로 기동해:
- 통합테스트 **127/127 통과**(과다 차단으로 인한 기능 저하 없음)
- 비super 관리자의 환불 시도 → **403 `SUPER_REQUIRED`**
- super 의 환불 경로는 정상(오작동 없음)
- 보안 헤더 유지, 오류 응답에 내부 정보 없음
