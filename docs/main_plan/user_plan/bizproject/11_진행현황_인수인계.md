## 2. ★표준 패턴 — "리뷰 탭" 따라하기 (신규 도메인 복제용)

백엔드 store API가 없는 기능(❌)은 **계약 우선 → mock → 화면 → 교체** 순으로 막힘 없이 개발합니다.
리뷰가 그 **완성된 예시**입니다. 검색·포인트·쿠폰·위시·CS 등 모두 이 4단계를 그대로 복제하세요.

### 단계 1 — 데이터 계약 + mock (`lib/data/<도메인>.ts`)
`apps/web/src/lib/data/reviews.ts` 참고. 핵심 규칙:
- **타입(export type)을 먼저** 정의 = 백엔드와의 계약. 화면은 이 타입에만 의존.
- mock은 **결정적(deterministic)** 으로. `Math.random()`/현재시각 쓰지 말 것(SSR 스냅샷 흔들림).
- 교체 지점에 `// TODO(backend): ...` 로 **실제 fetch 코드(주석)** 를 남겨둔다 → 백엔드 준비 시 그 줄만 교체.
```ts
export type ProductReview = { id: string; rating: number; ... }
export async function listProductReviews(productId: string): Promise<...> {
  // TODO(backend): GET /store/products/:id/reviews 준비 시 교체
  return /* mock */
}
```

### 단계 2 — UI 컴포넌트 (`modules/<도메인>/components/...`)
`product-reviews/index.tsx` 참고:
- 가능하면 **서버 컴포넌트**(async)로 `lib/data` 직접 호출. 상호작용 필요한 부분만 `"use client"` 분리.
- **빈 상태/0건** 처리 필수(예: "아직 등록된 리뷰가 없습니다").
- 통화는 `convertToLocale`, 숫자/날짜는 ko-KR 표기.

### 단계 3 — 배치 (라우트/템플릿에 연결)
- 서버 컴포넌트는 서버 템플릿에 `<Suspense>`로 배치(예: `modules/products/templates/index.tsx`).
- ⚠️ **client 컴포넌트 안에 async 서버 컴포넌트를 넣지 말 것** — 리뷰는 client인 `product-tabs` 대신 서버 템플릿에 배치한 이유.

### 단계 4 — 검증 → 문서 체크 → 커밋
- `cd apps/web && npx tsc --noEmit` (web엔 `pnpm typecheck` 없음 — tsc 직접).
- 실제 페이지 1건 렌더 확인.
- **07 백로그에서 해당 행 체크/메모 갱신** (문서화 규율).
- 커밋(작은 단위) → push. 메시지에 검증 결과 한 줄.

## 4. 운영 주의 (반드시 알 것)

1. **백엔드 데이터 변경 후 스토어프론트가 안 바뀌면 → 캐시 문제**
   - 증상: 새 컬렉션이 홈에 안 뜸, 신규 상품 상세가 404.
   - 원인: 데이터 생성 **이전에 캐시된** Next fetch-cache.
   - 해결: 스토어프론트 dev 재시작(+ `apps/web/.next/cache/fetch-cache` 삭제). 운영에선 `revalidateTag` 경로 사용.
2. **시드/설정 스크립트** (백엔드 `backend/services/api`에서 `npx medusa exec`)
   - `setup-korea.ts` — 한국 리전/통화/세금/배송(필수 선행)
   - `seed-test-data.ts` — 상품/회원/주문 등 테스트 데이터
   - `seed-home-collections.ts` — 홈 진열용 컬렉션(없으면 홈 빈화면)
3. **퍼블리셔블 키 헤더 필수** — 모든 `/store` 호출. `apps/web/.env.local`의 `NEXT_PUBLIC_MEDUSA_PUBLISHABLE_KEY`.
4. **web엔 `typecheck` 스크립트 없음** → `npx tsc --noEmit` 사용.
5. **플레이스홀더 교체 대상**(운영 전): 푸터 사업자정보, 고객센터 번호, 리뷰 mock 등 `TODO(backend)`/"운영 전 교체" 주석 검색.
