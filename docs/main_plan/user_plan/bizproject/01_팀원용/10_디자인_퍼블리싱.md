# 10. 디자인·퍼블리싱 (방향 합의용)

> 📄 **문서 #10** · 디자인 톤 후보·참고 사이트·레퍼런스 주는 법. 👉 다음: [11. 진행현황·인수인계](./11_진행현황_인수인계.md)

> **이 문서의 역할**: 스토어프론트를 "이쁘게" 만들기 위한 **참고처·진행방식·디자인 톤 후보**를 모아,
> 팀원이 함께 보고 **방향을 합의**하기 위한 자료입니다.
> ⚠️ 아직 구현 전 단계 — **회의에서 톤(아래 §3)을 먼저 정한 뒤** 디자인 토큰 작업을 시작합니다.
> 기술 전제: 신규 디자인 프레임워크 도입 없이 **Tailwind + `@medusajs/ui-preset`** 위에서 퍼블리싱.

## 2. AI에게 레퍼런스 주는 방법 (정확도 높은 순)
1. **스크린샷 이미지 첨부** ✅ 최고 — 레이아웃·여백·색·타이포·카드 스타일을 보고 Tailwind로 재현
2. **컬러/폰트/라운드 값** (예: 포인트색 `#FF5722`, 폰트 `Pretendard`, radius `12px`) → 디자인 토큰부터 세팅
3. **shadcn/Tailwind UI 특정 컴포넌트 이름·코드** → 우리 구조에 이식
4. URL만 주는 것도 가능하나, AI는 사이트를 **텍스트(HTML)** 로만 읽어 **시각 재현은 스크린샷이 훨씬 정확**

> ⚠️ **저작권**: 브랜드 로고·이미지·문구를 1:1 복제하지 않습니다. **스타일(레이아웃·톤·컴포넌트)만 참고**하고 자산은 우리 것으로.

## 3. 디자인 톤 후보 (회의에서 1개 선택)

선택한 톤을 기준으로 §4의 디자인 토큰·공통 컴포넌트를 잡습니다.

### A. 미니멀·고감도 (29CM / 무신사)
흑백 + 넓은 여백, 타이포 중심, 큰 상품 이미지. 세련되고 군더더기 없음. 포인트색 최소.
```
┌──────────────────────────┐
│  쇼핑몰              내계정 🛒 │
├──────────────────────────┤
│     [ 큰 상품 이미지 ]       │
│  OVERSIZED TEE            │
│  39,000원                 │
│  ──── 넓은 여백 강조 ────     │
│  [상품][상품][상품][상품]     │
└──────────────────────────┘
```

### B. 라이프스타일·큐레이션 (마켓컬리 / 오늘의집)
부드러운 색, 큰 이미지 + 카피, 기획전/큐레이션 배너 중심. 따뜻하고 감성적. 큰 라운드 + 그림자.
```

│  🟢 신상품                │
│ [카드][카드][카드]         │
```

정보 밀도 높음, 가격·할인율·뱃지 강조, 빠른 탐색. 실용·직관적. 빨강 계열 포인트.


### D. 프리미엄·브랜드 (SSF / W컨셉)
고급스러운 럭셔리 톤, 절제된 색, 큰 비주얼 + 세리프 타이포. 브랜드 격조 강조. 블랙/아이보리.

## 4. 추천 진행 방식 (합의 후)
화면마다 따로 만들면 톤이 들쭉날쭉 → **디자인 시스템(토큰) 먼저 → 공통 컴포넌트 → 화면** 순. (M0의 "디자인시스템 정리" 항목과 연결)
```
① 디자인 토큰: 색·타이포·간격·라운드·그림자 → tailwind.config + ui-preset 확장
② 공통 컴포넌트 리스킨: 버튼 / 상품카드 / 가격·뱃지 / 섹션헤더 / 빈·로딩 상태
③ 화면 적용: 임팩트 큰 순서(홈 → 상품카드/리스트 → 상세)
```
- 폰트는 한국어 가독성 좋은 **Pretendard** 권장(웹폰트).
- 모바일 우선(반응형) — 한국 커머스는 모바일 비중이 큼.
