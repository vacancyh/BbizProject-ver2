# 📚 스토어프론트 프런트 개발 — 문서 허브 (여기부터 읽으세요)

처음 오셨나요? **이 페이지가 목차입니다.** 아래 **읽는 순서(01→11)** 를 따라가면 됩니다.
이 프로젝트는 **AI 보조 개발**을 전제로 합니다 — 환경 구축부터 화면 개발까지 AI에게 시킬 수 있게 각 문서에 프롬프트가 들어 있습니다.

---

## ⚡ 30초 요약

- **무엇을 만드나**: 고객용 **스토어프론트**(`apps/web`, Next.js). 관리자앱·백엔드는 **이미 완성**되어 있습니다.
- **기반**: TypeScript + Next.js 15(App Router) + React 19 + Tailwind. 백엔드 Medusa(:9000)의 **`/store` API**만 호출.
- **국내 기반**: 통화·리전·세금·배송·가격이 **한국/KRW로 설정 완료**(기본 진입 `/kr`). 테스트 데이터도 채워져 있음.
- **개발 방식**: 한국형 일부 기능은 백엔드 store API가 없어 **mock으로 먼저 개발**(나중에 교체). 모든 백엔드 호출은 `lib/data/*` 경유.

## 🤖 AI로 개발하기 (이 프로젝트의 기본 방식)

1. **환경**: 02 문서의 프롬프트로 AI에게 로컬 환경을 잡게 합니다(또는 수동 절차).
2. **이해**: 01·04·05로 도메인·데이터를 파악합니다(AI에게도 이 문서들을 컨텍스트로 줍니다).
3. **개발**: 09의 **프롬프트 템플릿** + 11의 **표준 패턴(계약→mock→화면→교체)** 으로 화면 1개씩.
4. **검증·기록**: 화면 완료 시 07 백로그·11 보드를 갱신(문서화 규율, 09 참조).

> 💡 AI에게 일을 시킬 때는 항상 **관련 문서(01/04/05/해당 화면 백로그)를 컨텍스트로 첨부**하세요. 그래야 우리 구조·규약에 맞는 결과가 나옵니다.
