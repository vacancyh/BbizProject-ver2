# bizproject — 스토어프론트 4인 팀 문서

스토어프론트(`apps/web`) 4인 개발의 **팀 문서 모음** 폴더입니다.

## 폴더 규약
- **팀 전원 공통 문서** → 이 폴더(`bizproject/`) 루트에 둔다.
- **개인 작업 문서** → 각자 `bizproject/<담당or이름>/` 하위 폴더를 만들어 정리한다.
  - 예: `bizproject/catalog/`, `bizproject/checkout/`, `bizproject/account/`, `bizproject/common-cs/`
