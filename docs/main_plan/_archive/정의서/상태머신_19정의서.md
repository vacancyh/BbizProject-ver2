# 상태머신(state-machine) 도메인 정의서

> 이 프로젝트 커스텀 모듈 | 확인 경로: `src/modules/state-machine/`

---

## 1. 도메인 개요

모든 도메인(주문·결제·환불·이행)의 상태 전이를 감사(audit) 로그로 기록하고,
상태 그래프를 데이터베이스에서 관리할 수 있게 하는 커스텀 모듈입니다.

---

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 StateHistory (상태 이력)

모든 도메인의 상태 전이를 통합 기록하는 감사 로그.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `entity_id` | string (INDEX) | 대상 엔티티 ID (order_id / payment_id / refund_id / fulfillment_id 등) |
| `domain` | string (INDEX) | 도메인 식별자 (`order` / `payment` / `refund` / `fulfillment`) |
| `from_state` | string | 이전 상태 |
| `to_state` | string | 이후 상태 |
| `actor` | string | 전이 주체 (`system` / `admin` / `customer` / `webhook` 등) |
| `metadata` | JSON \| null | 추가 정보 (PG 응답, 운송장 코드, 청약철회 사유 등) |
| `created_at` | datetime | 이력 생성 일시 |

### 2.2 StateMachineConfig (상태머신 설정)

도메인별 허용 상태 및 전이 그래프를 DB 에 저장.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `domain` | string (UNIQUE) | 도메인 식별자 |
| `states` | JSON | 허용 상태 배열 (예: `["pending", "completed", "canceled"]`) |
| `transitions` | JSON | 전이 그래프 (`{ [fromState]: string[] }`) |

---

## 3. 엔티티 간 관계

```
StateMachineConfig (도메인당 1행, seed 초기화)
StateHistory (모든 도메인 상태 전이 누적 로그)
```

다른 모듈과는 직접 FK 관계 없이, `domain + entity_id` 로 연결됩니다.

---

## 4. 주요 기능/유스케이스

1. **전이 검증**: `StateMachineConfig.transitions` 기준으로 허용되지 않는 상태 전이 차단
2. **이력 기록**: 모든 상태 변경 시 `StateHistory` 레코드 생성
3. **감사 추적**: 주문/결제 상태 변경 이력 조회 (이커머스 분쟁 해결)
4. **설정 오버라이드**: P3 Admin UI 에서 런타임 전이 그래프 변경

---

## 5. 초기 시드 데이터 (4개 도메인)

`src/modules/state-machine/seed.ts` 로 초기화됩니다.

| domain | 주요 상태 |
|--------|---------|
| `order` | `pending` → `completed` / `canceled` / `requires_action` |
| `payment` | `pending` → `authorized` → `captured` / `refunded` / `canceled` |
| `refund` | `requested` → `processing` → `completed` / `failed` |
| `fulfillment` | `pending` → `shipped` → `delivered` / `canceled` |

---

## 6. 이 도메인의 활용 포인트

- **청약철회 이력**: `domain=order, actor=customer, metadata.withdrawal_reason=simple_change`
- **PG 응답 기록**: `domain=payment, metadata.pg_response={...}` 으로 PG 원본 응답 보존
- **분쟁 증거**: StateHistory 로 상태 전이 타임스탬프 전체 추적 가능
