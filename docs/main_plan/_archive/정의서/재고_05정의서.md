# 재고(Inventory) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/inventory` | 확인 경로: `node_modules/.pnpm/@medusajs+inventory@2.15.3.../dist/models/`

---

## 1. 도메인 개요

재고 도메인은 SKU(ProductVariant) 단위의 재고 수량을 위치(StockLocation)별로 추적합니다.
주문 생성 시 예약(Reservation)이 발생하고, 이행(Fulfillment) 완료 시 실제 재고가 차감됩니다.

---

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 InventoryItem (재고 아이템)

ProductVariant 1:1 연결 (Link 모듈을 통해).

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 (prefix: `iitem_`) |
| `sku` | string \| null | SKU 코드 |
| `origin_country` | string \| null | 원산지 |
| `hs_code` | string \| null | 관세청 품목분류코드 |
| `mid_code` | string \| null | MID 코드 |
| `material` | string \| null | 소재 |
| `weight` | number \| null | 무게 |
| `length` / `height` / `width` | number \| null | 규격 |
| `requires_shipping` | boolean | 배송 필요 여부 |
| `description` | string \| null | 설명 |
| `title` | string \| null | 이름 |
| `thumbnail` | string \| null | 이미지 URL |
| `metadata` | JSON \| null | 커스텀 메타데이터 |
| `reserved_quantity` | number \| null | 예약된 총 수량 (computed) |
| `stocked_quantity` | number \| null | 총 재고 수량 (computed) |

### 2.2 InventoryLevel (재고 레벨)

InventoryItem 이 특정 StockLocation 에서 보유하는 수량.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `location_id` | string | StockLocation ID |
| `stocked_quantity` | bigNumber | 현재 재고 수량 |
| `reserved_quantity` | bigNumber | 예약된 수량 (주문 대기) |
| `incoming_quantity` | bigNumber | 입고 예정 수량 |
| `available_quantity` | number \| null | 가용 수량 = stocked - reserved (computed) |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.3 ReservationItem (재고 예약)

주문 라인 아이템 1개에 대한 재고 예약 레코드.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `line_item_id` | string \| null | 주문 LineItem ID |
| `location_id` | string | StockLocation ID |
| `quantity` | bigNumber | 예약 수량 |
| `allow_backorder` | boolean | 품절 시 주문 허용 여부 |
| `external_id` | string \| null | 외부 식별자 |
| `description` | string \| null | 설명 |
| `created_by` | string \| null | 생성 주체 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

## 3. 엔티티 간 관계

```
InventoryItem
  ├── 1:N ── location_levels (InventoryLevel)
  │             └── N:1 ── StockLocation (stock-location 모듈)
  └── 1:N ── reservation_items (ReservationItem)
               └── N:1 ── StockLocation
```

ProductVariant ↔ InventoryItem 연결은 `product-variant-inventory` Link 테이블로 관리됩니다.

---

## 4. 주요 기능/유스케이스

1. **재고 조회**: 위치별/아이템별 가용 수량 실시간 확인
2. **재고 예약**: 주문 시 `ReservationItem` 생성 (가용 수량 = stocked - reserved)
3. **재고 조정**: 입고·출고·손실 처리 (stocked_quantity 직접 조정)
4. **다창고 관리**: 여러 StockLocation 별 수량 분리 관리
5. **입고 예정 관리**: `incoming_quantity` 로 선주문/예약 주문 처리

## 5. 대표 API 엔드포인트

### Admin API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/admin/inventory-items` | 재고 아이템 목록 |
| `GET` | `/admin/inventory-items/:id` | 재고 아이템 단건 |
| `POST` | `/admin/inventory-items/:id` | 재고 아이템 수정 |
| `GET/POST/DELETE` | `/admin/inventory-items/:id/location-levels` | 위치별 재고 레벨 CRUD |
| `GET/POST/DELETE` | `/admin/reservations` | 예약 CRUD |
| `GET/POST/DELETE` | `/admin/stock-locations` | 재고 위치 CRUD |

## 6. 관련 워크플로우 / 이벤트

- `createInventoryItemsWorkflow`: 재고 아이템 생성
- `reserveInventoryStep`: 주문 시 재고 예약
- `adjustInventoryLevelsWorkflow`: 재고 수준 조정
- `confirmInventoryStep`: 이행 완료 시 예약 해제 + 실재고 차감

---

## 7. 이 프로젝트에서의 활용/확장 포인트

- 다창고 운영: 서울 물류센터 + 부산 물류센터 분리 관리
- 반품 수령 시 재고 복원: RMA 확장 모듈의 `ReturnInspection.resellable = true` 판정 시 `InventoryLevel.stocked_quantity` 증가
- 품절 알림: `available_quantity = 0` 감지 → Notification 발송
