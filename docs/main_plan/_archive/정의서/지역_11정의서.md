# 지역(Region) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/region` | 확인 경로: `node_modules/.pnpm/@medusajs+region@2.15.3.../dist/models/`

---

## 1. 도메인 개요

지역 도메인은 통화·자동 세금 적용 여부를 묶는 시장 단위를 정의합니다.
하나의 Region 은 하나의 통화와 여러 국가를 포함하며,
Cart/Order 생성 시 Region 이 통화와 세금 기본값을 결정합니다.

---

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 Region (지역)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 (prefix: `reg_`) |
| `name` | string | 지역명 (예: "한국") |
| `currency_code` | string | 통화 코드 (예: `krw`) |
| `automatic_taxes` | boolean | 자동 세금 계산 여부 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.2 Country (국가)

| 필드 | 타입 | 설명 |
|------|------|------|
| `iso_2` | string (PK) | ISO 2자리 국가 코드 (예: `kr`) |
| `iso_3` | string | ISO 3자리 국가 코드 (예: `kor`) |
| `num_code` | string | 숫자 국가 코드 |
| `name` | string | 영문 국가명 |
| `display_name` | string | 표시 국가명 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

---

## 3. 엔티티 간 관계

```
Region
  └── 1:N ── countries (Country, table: region_country)
```

---

## 4. 주요 기능/유스케이스

1. **한국 시장 설정**: `Region(name=한국, currency_code=krw, automatic_taxes=true)`
2. **글로벌 확장**: 달러권(USD), 유로권(EUR) 등 별도 Region 생성
3. **장바구니 통화 자동 설정**: 고객 국가 감지 → Region 매핑 → `cart.currency_code` 자동 설정

---

## 5. 대표 API 엔드포인트

### Admin API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET/POST` | `/admin/regions` | 지역 목록/생성 |
| `GET/POST/DELETE` | `/admin/regions/:id` | 지역 단건 관리 |

### Store API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/store/regions` | 공개 지역 목록 |

---

## 6. 이 프로젝트에서의 활용/확장 포인트

- 초기 설정: `Region(name=한국, currency_code=krw, automatic_taxes=true)` + `Country(iso_2=kr)` 연결
- 글로벌 전환 시 달러 Region 추가 후 상품 가격 PriceRule 에 `region_id` 조건 추가
