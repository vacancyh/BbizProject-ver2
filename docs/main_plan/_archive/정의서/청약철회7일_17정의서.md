# 한국 청약철회 7일(legal-kr/withdrawal-7day) 도메인 정의서

> 이 프로젝트 커스텀 모듈 | 확인 경로: `src/modules/legal-kr/withdrawal-7day/`

---

## 1. 도메인 개요

전자상거래 등에서의 소비자보호에 관한 법률(이하 "전자상거래법") §17~§18 준수를 위한 커스텀 모듈입니다.
재화 인도일로부터 7일 이내 청약철회 권리를 전산으로 관리합니다.

**법적 근거**:
- §17 ① 소비자는 재화 인도일로부터 7일 이내 청약 철회 가능
- §17 ② 예외 사유: 소비자 책임 멸실, 사용으로 가치 감소, 시간 경과 재판매 곤란, 복제 가능 디지털 재화
- §18 ① 사업자는 청약철회 접수 후 3영업일 이내 환불 의무

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 WithdrawalEligibility (청약철회 가능 여부)

주문 1개 = 레코드 1개 (1:1 Link).

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 (prefix: `wele`) |
| `order_id` | string (UNIQUE) | Medusa Order ID (Link 연결점) |
| `delivered_at` | datetime | 인도일 (7일 기산점) |
| `eligible_until` | datetime | `delivered_at + 7일` (청약철회 가능 마감) |
| `is_eligible` | boolean | 청약철회 가능 여부 |
| `disqualified_reason` | string \| null | 예외 사유 (§17 ② 단서) |
| `created_at` | datetime | 생성 일시 |
| `updated_at` | datetime | 수정 일시 |

### 2.2 WithdrawalReasonRecord (청약철회 신청 이력)

주문 1개에 여러 신청 이력 가능 (1:N Link).

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 (prefix: `wrsn`) |
| `order_id` | string (INDEX) | Medusa Order ID (Link 연결점) |
| `reason` | enum | `simple_change` / `defect` / `wrong_item` / `other` |
| `description` | string \| null | 소비자 상세 설명 |
| `claimed_at` | datetime | 신청 일시 (환불 3영업일 기산점) |
| `created_at` | datetime | 생성 일시 |
| `updated_at` | datetime | 수정 일시 |

#### WithdrawalReason Enum 설명

| 코드 | 한국어 | 반품 배송비 부담 |
|------|-------|----------------|
| `simple_change` | 단순변심 | 소비자 부담 |
| `defect` | 상품불량 | 사업자 부담 |
| `wrong_item` | 오배송 | 사업자 부담 |
| `other` | 기타 | 정책 따라 |

## 3. 엔티티 간 관계

```
Order (Medusa core)
  ├── 1:1 Link ── WithdrawalEligibility
  └── 1:N Link ── WithdrawalReasonRecord
```

Link 정의 파일: `src/links/order-withdrawal.ts`

---

## 4. 주요 기능/유스케이스

1. **청약철회 가능 여부 자동 생성**: 배송 완료(`delivered_at`) 이벤트 수신 시 `WithdrawalEligibility` 자동 생성
2. **청약철회 신청**: 소비자가 사유 선택 → `WithdrawalReasonRecord` 생성
3. **가능 여부 조회**: `is_eligible = true && eligible_until >= now()` 확인
4. **예외 사유 설정**: 관리자가 `is_eligible = false + disqualified_reason` 설정
5. **만료 알림**: Scheduled Job (`jobs/` 폴더)으로 만료 D-1 알림 발송

## 6. 관련 Subscriber / Job

- **Subscriber**: `order.delivered` 이벤트 → `WithdrawalEligibility` 자동 생성
- **Scheduled Job**: 매일 자정 만료 임박 레코드 감지 → 알림 발송

---

## 7. 이 도메인의 한국 법규 준수 포인트

- 기산일 계산: 달력일 기준 7일 (공휴일·영업일 포함)
- 복제 가능 디지털 재화 예외: `disqualified_reason` 에 "digital_goods_opened" 기록
- 환불 기산점: `WithdrawalReasonRecord.claimed_at` 기준 3영업일 (§18 ①)
- 반품 배송비: `WithdrawalReason.simple_change` → 소비자 부담, `defect/wrong_item` → 사업자 부담
