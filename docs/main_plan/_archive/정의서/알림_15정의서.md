# 알림(Notification) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/notification` | 확인 경로: `node_modules/.pnpm/@medusajs+notification@2.15.3.../dist/models/`

---

## 1. 도메인 개요

알림 도메인은 이메일·SMS·푸시 알림 발송 이력을 관리합니다.
Medusa v2 는 NotificationProvider 인터페이스로 다양한 채널을 추상화하며,
기본 제공 공급자는 `notification-local` (콘솔 출력)과 `notification-sendgrid` (이메일) 입니다.

---

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 Notification (알림)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `to` | string | 수신자 (이메일/전화번호/토큰) |
| `from` | string \| null | 발신자 |
| `channel` | string | 채널 (예: `email`, `sms`, `push`) |
| `template` | string \| null | 템플릿 ID |
| `data` | JSON \| null | 템플릿 렌더링 데이터 |
| `provider_data` | JSON \| null | 공급자 응답 데이터 |
| `trigger_type` | string \| null | 트리거 유형 (예: `order.placed`) |
| `resource_id` | string \| null | 트리거 리소스 ID |
| `resource_type` | string \| null | 트리거 리소스 유형 |
| `receiver_id` | string \| null | 수신자 ID (customer_id 등) |
| `original_notification_id` | string \| null | 재발송 원본 알림 ID |
| `idempotency_key` | string \| null | 중복 발송 방지 키 |
| `external_id` | string \| null | 공급자 외부 ID (예: SendGrid message ID) |
| `status` | enum | `pending` / `success` / `failure` |

### 2.2 NotificationProvider (알림 공급자)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 공급자 ID (예: `sendgrid`) |
| `handle` | string | 핸들 (예: `sendgrid`) |
| `name` | string | 공급자명 |
| `is_enabled` | boolean | 활성화 여부 |
| `channels` | string[] | 지원 채널 목록 |

## 4. 주요 기능/유스케이스

1. **주문 확인 이메일**: `order.placed` 이벤트 → 고객에게 주문 확인 이메일 발송
2. **배송 완료 알림**: `fulfillment.delivered` 이벤트 → SMS/이메일 발송
3. **청약철회 기간 만료 알림**: 청약철회 마감 D-1 알림 (사전 발송)
4. **재발송**: `original_notification_id` 로 실패 알림 재시도
5. **중복 방지**: `idempotency_key` 로 동일 알림 재발송 차단

## 5. 대표 API 엔드포인트

### Admin API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/admin/notifications` | 알림 발송 이력 조회 |
| `POST` | `/admin/notifications/:id/resend` | 알림 재발송 |

---

## 6. 이 프로젝트에서의 활용/확장 포인트

- **이메일 공급자**: `notification-sendgrid` 패키지 설치됨, SendGrid API Key 설정 필요
- **한국어 이메일 템플릿**: `template` 필드에 SendGrid 동적 템플릿 ID 참조
- **SMS 알림**: 카카오 알림톡, 네이버 클라우드 SMS 등 커스텀 NotificationProvider 구현 (추가 확인 필요)
- **청약철회 관련**: `withdrawal-7day` 모듈의 Scheduled Job 에서 만료 임박 알림 발송
