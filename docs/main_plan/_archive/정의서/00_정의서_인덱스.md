## 주요 도메인 의존 관계 (Link 맵)

```
Product ─── (variant_price_set link) ─── PriceSet (Pricing)
Product ─── (product_variant_inventory link) ─── InventoryItem (Inventory)
Product ─── (product_sales_channel link) ─── SalesChannel

Cart ──────── region_id ──────── Region
Cart ──────── customer_id ────── Customer
Cart ──────── completed_at → Order (주문 변환)

Order ─────── (order-withdrawal link) ─── WithdrawalEligibility / WithdrawalReasonRecord
Order.Return ─ (order-return-rma link) ── ReimbursementMethod / ReturnInspection
Order ─────── StateHistory (state-machine)

InventoryItem ─── InventoryLevel → StockLocation
StockLocation ─── FulfillmentSet → ServiceZone → ShippingOption
StockLocation ─── (sales-channel link) ─── SalesChannel
```

## 참고 사항

- Medusa v2 는 모든 모듈이 격리된 독립 서비스이며 데이터 공유는 `defineLink` + `Remote Query`로만 가능합니다.
- `BigNumber` 타입은 금액 정밀도를 위해 소수점 지원합니다 (KRW 는 정수만 사용).
- 모든 엔티티에는 `created_at` / `updated_at` / `deleted_at` (소프트 삭제)가 자동 추가됩니다.
