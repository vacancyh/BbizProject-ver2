# 프로모션(Promotion) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/promotion` | 확인 경로: `node_modules/.pnpm/@medusajs+promotion@2.15.3.../dist/models/`

---

## 1. 도메인 개요

프로모션 도메인은 쿠폰 코드·자동 할인·캠페인을 관리합니다.
장바구니에 적용되어 LineItemAdjustment 로 할인 금액이 기록됩니다.

---

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 Promotion (프로모션)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `code` | string | 프로모션 코드 (쿠폰 코드) |
| `is_automatic` | boolean | 자동 적용 여부 |
| `is_tax_inclusive` | boolean | 세금 포함 할인 여부 |
| `type` | enum | `standard` / `buyget` |
| `status` | enum | `active` / `inactive` / `scheduled` / `expired` |
| `limit` | number \| null | 사용 가능 총 횟수 (v2.12.0 이후) |
| `used` | number | 사용된 횟수 (v2.12.0 이후) |

### 2.2 ApplicationMethod (할인 적용 방식)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `type` | enum | `fixed` / `percentage` |
| `target_type` | enum | `items` / `shipping` / `order` |
| `value` | bigNumber | 할인값 (고정 금액 또는 비율) |
| `currency_code` | string \| null | 통화 코드 (fixed 타입 시) |
| `max_quantity` | number \| null | 최대 적용 수량 |
| `apply_to_quantity` | number \| null | 적용 수량 (buyget 타입) |
| `buy_rules_min_quantity` | number \| null | 구매 조건 최소 수량 |

### 2.3 PromotionRule (프로모션 규칙)

프로모션 적용 조건.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `attribute` | string | 조건 속성 (예: `customer_group_id`, `product_category_id`) |
| `operator` | enum | `eq` / `ne` / `in` / `nin` / `lte` / `gte` |
| `description` | string \| null | 규칙 설명 |

### 2.4 Campaign (캠페인)

여러 프로모션을 묶는 마케팅 캠페인.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `name` | string | 캠페인명 |
| `description` | string \| null | 설명 |
| `campaign_identifier` | string | 캠페인 고유 식별자 (URL 등) |
| `starts_at` | datetime \| null | 시작 일시 |
| `ends_at` | datetime \| null | 종료 일시 |

### 2.5 CampaignBudget (캠페인 예산)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `type` | enum | `spend` / `usage` |
| `currency_code` | string \| null | 통화 코드 |
| `limit` | bigNumber \| null | 예산 한도 |
| `used` | bigNumber | 사용된 금액/횟수 |
| `attribute` | string \| null | 예산 집계 기준 속성 |

## 3. 엔티티 간 관계

```
Campaign
  ├── 1:1 ── budget (CampaignBudget)
  └── 1:N ── promotions (Promotion)
               ├── 1:1 ── application_method (ApplicationMethod)
               │             └── 1:N ── target_rules (PromotionRule)
               │             └── 1:N ── buy_rules (PromotionRule)
               └── 1:N ── rules (PromotionRule)
```

---

## 4. 주요 기능/유스케이스

1. **쿠폰 코드 발급**: `is_automatic = false`, `code` 설정
2. **자동 할인**: `is_automatic = true` (코드 입력 불필요)
3. **특정 카테고리 할인**: `PromotionRule(product_category_id = ...)` 조건 설정
4. **회원 전용 쿠폰**: `PromotionRule(customer_group_id = ...)` 설정
5. **사용 횟수 제한**: `limit` 설정으로 선착순 쿠폰 구현
6. **기간 한정 캠페인**: Campaign `starts_at / ends_at` 설정
7. **무료 배송 쿠폰**: `ApplicationMethod.target_type = shipping`

## 5. 대표 API 엔드포인트

### Admin API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET/POST` | `/admin/promotions` | 프로모션 목록/생성 |
| `GET/POST/DELETE` | `/admin/promotions/:id` | 프로모션 단건 조회/수정/삭제 |
| `GET/POST` | `/admin/campaigns` | 캠페인 목록/생성 |
| `GET/POST/DELETE` | `/admin/campaigns/:id` | 캠페인 단건 관리 |

### Store API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `POST` | `/store/carts/:id/promotions` | 장바구니에 프로모션 코드 적용 |
| `DELETE` | `/store/carts/:id/promotions/:code` | 프로모션 코드 제거 |

## 6. 이 프로젝트에서의 활용/확장 포인트

- **한국 특화 쿠폰**: 카카오 채널 쿠폰, 네이버 스마트스토어 연동 시 `code` 활용
- **할인 표시**: `compare_at_unit_price` + `LineItemAdjustment` 로 정가/할인가 표시
- **복수 프로모션 중복 적용**: Medusa v2 는 기본적으로 중복 적용 가능 (사업 정책에 따라 제한 필요)
