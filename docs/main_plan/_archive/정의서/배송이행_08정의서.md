# 배송/이행(Fulfillment) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/fulfillment` | 확인 경로: `node_modules/.pnpm/@medusajs+fulfillment@2.15.3.../dist/models/`

---

## 1. 도메인 개요

배송/이행 도메인은 주문 이후의 실물 처리(포장·발송·추적)를 관리합니다.
FulfillmentSet → ServiceZone → ShippingOption 계층으로 배송 서비스를 구성하며,
실제 배송 발생 시 Fulfillment 엔티티로 기록합니다.

---

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 Fulfillment (이행)

주문 일부 또는 전체에 대한 실제 발송 기록.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 (prefix: `ful_`) |
| `location_id` | string | 발송 StockLocation ID |
| `packed_at` | datetime \| null | 포장 완료 일시 |
| `shipped_at` | datetime \| null | 발송 완료 일시 |
| `marked_shipped_by` | string \| null | 발송 처리 담당자 ID |
| `created_by` | string \| null | 생성 주체 |
| `delivered_at` | datetime \| null | 배달 완료 일시 |
| `canceled_at` | datetime \| null | 취소 일시 |
| `data` | JSON \| null | 배송 공급자 응답 데이터 |
| `requires_shipping` | boolean | 배송 필요 여부 |

### 2.2 FulfillmentItem (이행 아이템)

Fulfillment 에 포함된 개별 상품.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `title` | string | 상품명 스냅샷 |
| `sku` | string | SKU 스냅샷 |
| `barcode` | string | 바코드 스냅샷 |
| `quantity` | bigNumber | 발송 수량 |
| `line_item_id` | string \| null | 원본 OrderLineItem ID |
| `inventory_item_id` | string \| null | InventoryItem ID |

### 2.3 FulfillmentLabel (배송 라벨)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `tracking_number` | string | 운송장 번호 |
| `tracking_url` | string | 배송 추적 URL |
| `label_url` | string | 라벨 이미지 URL |

### 2.4 ShippingOption (배송 옵션)

고객에게 제공하는 배송 방법 (예: 표준배송, 새벽배송).

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `name` | string | 배송 옵션명 |
| `price_type` | enum | `flat_rate` / `calculated` |
| `data` | JSON \| null | 공급자 설정 데이터 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.5 ShippingProfile (배송 프로필)

상품 유형별 배송 설정 묶음 (예: 일반, 냉장, 디지털).

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `name` | string | 프로필명 |
| `type` | string | 유형 (예: `default`, `gift_card`) |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.6 FulfillmentSet (이행 세트)

위치(StockLocation)에 연결된 배송 서비스 묶음.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `name` | string | 세트명 |
| `type` | string | 유형 (예: `pickup`, `shipping`) |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.7 ServiceZone (서비스 구역)

FulfillmentSet 내 배송 가능 지역 단위.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `name` | string | 구역명 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.8 GeoZone (지리 구역)

ServiceZone 의 배송 가능 지역 정의 (국가·도시·우편번호 범위).

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `type` | enum | `country` / `province` / `city` / `zip` |
| `country_code` | string | 국가 코드 |
| `province_code` | string \| null | 도/시 코드 |
| `city` | string \| null | 도시 |
| `postal_expression` | JSON \| null | 우편번호 범위 표현 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

## 3. 엔티티 간 관계

```
StockLocation (stock-location 모듈)
  └── 1:N ── fulfillment_sets (FulfillmentSet)
               └── 1:N ── service_zones (ServiceZone)
                           ├── 1:N ── geo_zones (GeoZone)
                           └── 1:N ── shipping_options (ShippingOption)
                                       ├── N:1 ── shipping_profile
                                       ├── N:1 ── provider (FulfillmentProvider)
                                       ├── 1:N ── rules (ShippingOptionRule)
                                       └── 1:N ── type (ShippingOptionType)

Fulfillment
  ├── 1:N ── items (FulfillmentItem)
  ├── 1:N ── labels (FulfillmentLabel)
  ├── N:1 ── provider (FulfillmentProvider)
  └── N:1 ── shipping_option (ShippingOption)
```

## 4. 주요 기능/유스케이스

1. **배송 옵션 설정**: 지역·금액 조건별 배송 방법 구성
2. **이행 생성**: 주문 이행 시작 → Fulfillment 레코드 생성
3. **운송장 등록**: FulfillmentLabel 에 운송장 번호·추적 URL 기록
4. **배달 완료 처리**: `delivered_at` 업데이트 → 청약철회 7일 기산점 트리거
5. **배송비 계산**: `price_type=flat_rate` (고정) 또는 `calculated` (동적)

## 5. 대표 API 엔드포인트

### Admin API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET/POST` | `/admin/fulfillment-sets` | 이행 세트 관리 |
| `GET/POST` | `/admin/shipping-options` | 배송 옵션 관리 |
| `GET/POST` | `/admin/shipping-profiles` | 배송 프로필 관리 |
| `GET/POST` | `/admin/stock-locations` | 재고 위치 관리 |
| `POST` | `/admin/orders/:id/fulfillments` | 이행 생성 |
| `POST` | `/admin/fulfillments/:id/shipment` | 발송 처리 (운송장 등록) |
| `POST` | `/admin/fulfillments/:id/cancel` | 이행 취소 |

### Store API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/store/shipping-options` | 배송 옵션 목록 (장바구니 기준) |

## 6. 이 프로젝트에서의 활용/확장 포인트

- **청약철회 7일 트리거**: Fulfillment `delivered_at` 업데이트 이벤트 구독 → `WithdrawalEligibility` 자동 생성
- **반품 배송**: RMA 확장 모듈의 `ReturnShippingFeePolicy` 와 연동하여 반품 배송비 자동 계산
- **한국 배송사 연동**: CJ대한통운, 한진택배 등 FulfillmentProvider 구현 (추가 확인 필요)
- **운송장 자동 조회**: `FulfillmentLabel.tracking_url` + 스마트택배 API 연동
