# 주문(Order) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/order` | 확인 경로: `node_modules/.pnpm/@medusajs+order@2.15.3.../dist/models/`

---

## 1. 도메인 개요

주문 도메인은 고객이 결제를 완료한 이후의 모든 주문 생명주기를 관리합니다.
Medusa v2 에서 주문은 버저닝(versioning) 방식으로 변경 이력을 추적하며,
클레임(Claim), 교환(Exchange), 반품(Return) 이 모두 주문 도메인에 포함됩니다.

이 프로젝트에서는 한국 법규(전자상거래법 §17/§18) 기반의 청약철회 7일,
RMA 확장 모듈이 이 도메인과 Link 로 연결됩니다.

## 3. 엔티티 간 관계

```
Order
  ├── 1:1 ── shipping_address (Address)
  ├── 1:1 ── billing_address (Address)
  ├── 1:N ── items (LineItem)
  │             └── 1:N ── line_item_adjustments (할인 조정)
  │             └── 1:N ── line_item_tax_lines (세금 라인)
  ├── 1:N ── shipping_methods (ShippingMethod)
  ├── 1:N ── transactions (Transaction)
  ├── 1:N ── credit_lines (CreditLine)
  ├── 1:N ── summary (OrderSummary)
  ├── 1:N ── returns (Return)
  │             ├── 1:N ── return_items (ReturnItem)
  │             ├── N:1 ── exchange (Exchange)
  │             └── N:1 ── claim (Claim)
  └── 1:N ── order_changes (OrderChange)
               └── 1:N ── order_change_actions
```

## 4. 주요 기능/유스케이스

1. **주문 생성**: 장바구니 완료(완료 체크아웃) 시 Cart → Order 변환
2. **주문 이행(Fulfillment)**: 배송 처리 트리거
3. **반품 요청/수령**: Return 생성 → 상태 전이
4. **교환 처리**: Return + 신규 배송
5. **클레임 처리**: 결함/오배송 → replace/refund
6. **주문 수정(Order Edit)**: OrderChange 생성 → 버전 증가
7. **드래프트 주문**: 관리자가 수동으로 주문 생성

## 7. 이 프로젝트에서의 활용/확장 포인트

### 7.1 청약철회 7일 연동 (한국 전자상거래법 §17)

`src/links/order-withdrawal.ts` 에서 정의된 Link 로 연결됩니다.

- `order.id ↔ WithdrawalEligibility.order_id` (1:1): 청약철회 가능 여부
- `order.id ↔ WithdrawalReasonRecord.order_id` (1:N): 청약철회 신청 이력

배송 완료 이벤트(`order.delivered`) 수신 시 자동으로 `WithdrawalEligibility` 레코드를 생성하고
`delivered_at + 7일`을 `eligible_until`로 계산합니다.

### 7.2 RMA 확장 연동

`src/links/order-return-rma.ts` 에서 정의된 Link 로 연결됩니다.

- `return.id ↔ ReimbursementMethod.order_return_id` (1:1): 환불 방식 결정
- `return.id ↔ ReturnInspection.order_return_id` (1:N): 검수 결과 기록

### 7.3 상태머신 연동

`state-machine` 모듈의 `StateHistory` 로 모든 Order 상태 전이 이력을 기록합니다.
`domain = "order"`, `entity_id = order.id` 로 조회 가능합니다.

### 7.4 한국 법규 준수 포인트

- 환불 기산점: 청약철회 신청 일시(`claimed_at`) 기준 3영업일 이내 환불 의무 (§18 ①)
- 반품 배송비 부담: `WithdrawalReason` enum 으로 소비자/사업자 구분
- 주문 이메일: `order.email` 필드로 전자상거래법 §8 (주문 확인 이메일) 발송 연동
