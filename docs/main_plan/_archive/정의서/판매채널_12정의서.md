# 판매채널(Sales Channel) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/sales-channel` | 확인 경로: `node_modules/.pnpm/@medusajs+sales-channel@2.15.3.../dist/models/`

---

## 1. 도메인 개요

판매채널 도메인은 상품이 판매되는 채널(온라인 쇼핑몰, 앱, POS 등)을 구분합니다.
상품·재고·주문을 채널별로 격리하여 멀티채널 운영을 지원합니다.

---

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 SalesChannel (판매채널)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 (prefix: `sc_`) |
| `name` | string | 채널명 (예: "웹 스토어", "모바일 앱") |
| `description` | string \| null | 채널 설명 |
| `is_disabled` | boolean | 비활성 여부 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |
| `created_at` | datetime | 생성 일시 |
| `updated_at` | datetime | 수정 일시 |

---

## 3. 엔티티 간 관계

SalesChannel 은 다음과 Link 로 연결됩니다.

- `SalesChannel ↔ Product` (Link): 채널별 상품 노출 제어
- `SalesChannel ↔ StockLocation` (Link): 채널별 재고 위치 연결
- `Cart.sales_channel_id`, `Order.sales_channel_id`: 주문/장바구니의 채널 식별

---

## 4. 주요 기능/유스케이스

1. **채널별 상품 노출**: 웹몰 전용 상품 vs 앱 전용 상품 분리
2. **채널별 재고 배분**: 온라인/오프라인 재고 분리 운영
3. **채널별 주문 집계**: 판매 리포트 채널 단위 분석

---

## 5. 대표 API 엔드포인트

### Admin API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET/POST` | `/admin/sales-channels` | 판매채널 목록/생성 |
| `GET/POST/DELETE` | `/admin/sales-channels/:id` | 단건 관리 |
| `POST/DELETE` | `/admin/sales-channels/:id/products` | 채널 상품 추가/제거 |
| `POST/DELETE` | `/admin/sales-channels/:id/stock-locations` | 채널 재고위치 연결 |

---

## 6. 이 프로젝트에서의 활용/확장 포인트

- 초기 설정: "Default Sales Channel" 1개로 시작
- 확장 시: 웹/앱/B2B 채널 분리 운영 가능
