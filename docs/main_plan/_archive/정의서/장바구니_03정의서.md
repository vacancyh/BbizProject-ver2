# 장바구니(Cart) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/cart` | 확인 경로: `node_modules/.pnpm/@medusajs+cart@2.15.3.../dist/models/`

---

## 1. 도메인 개요

장바구니 도메인은 고객이 결제 전까지 상품을 담고 배송지·결제 수단·프로모션을 설정하는
체크아웃 과정 전반을 관리합니다.
결제 완료 시(`complete_cart`) Cart → Order 로 변환됩니다.

---

## 3. 엔티티 간 관계

```
Cart
  ├── 1:1 ── shipping_address (Address)
  ├── 1:1 ── billing_address (Address)
  ├── 1:N ── items (LineItem)
  │             ├── 1:N ── adjustments (LineItemAdjustment)
  │             └── 1:N ── tax_lines (LineItemTaxLine)
  ├── 1:N ── shipping_methods (ShippingMethod)
  │             ├── 1:N ── adjustments (ShippingMethodAdjustment)
  │             └── 1:N ── tax_lines (ShippingMethodTaxLine)
  └── 1:N ── credit_lines (CreditLine)
```

## 4. 주요 기능/유스케이스

1. **장바구니 생성**: 비회원/회원 모두 가능, 고객 정보 연동은 선택적
2. **상품 추가/수정/삭제**: 수량 변경 포함
3. **배송지 설정**: shipping_address / billing_address 업데이트
4. **배송 방법 선택**: ShippingOption 목록에서 선택 → ShippingMethod 생성
5. **프로모션 코드 적용**: LineItemAdjustment 생성
6. **세금 계산**: Tax 모듈 연동 → LineItemTaxLine 생성
7. **결제 완료**: `completeCartWorkflow` 실행 → Cart → Order 변환

|--------|------|------|
| `POST` | `/store/carts` | 장바구니 생성 |

| `POST` | `/store/carts/:id/shipping-methods` | 배송 방법 선택 |

## 6. 관련 워크플로우 / 이벤트

- `createCartWorkflow`: 장바구니 생성
- `addToCartWorkflow`: 아이템 추가
- `updateLineItemInCartWorkflow`: 아이템 수량 수정
- `deleteLineItemsWorkflow`: 아이템 삭제
- `refreshCartItemsWorkflow`: 장바구니 새로고침 (가격 재계산)
- `addShippingMethodToCartWorkflow`: 배송 방법 추가
- `applyPromotionsToCartWorkflow`: 프로모션 적용
- `completeCartWorkflow`: 장바구니 완료 → Order/Payment 생성

## 7. 이 프로젝트에서의 활용/확장 포인트

### 7.1 한국 세금 처리

- `Cart.currency_code = "krw"` 기본 설정
- `LineItemTaxLine.rate = 10`: 부가가치세 10% 자동 적용 (Tax 모듈 연동)
- `is_tax_inclusive = true`: 한국 소비자가는 부가세 포함 가격 표시 관례 지원

### 7.2 로케일 처리 (v2.12.3 이후)

- `Cart.locale = "ko-KR"`: 한국어 로케일 지정으로 UI 언어 제어

### 7.3 체크아웃 UX 개선 포인트

- 비회원 장바구니 → 로그인 후 병합: `customer_id` 업데이트
- 배송비 무료 기준: `ShippingOption` 룰 설정 (FulfillmentModule)
- 포인트/적립금 적용: `CreditLine` 활용
