# 가격(Pricing) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/pricing` | 확인 경로: `node_modules/.pnpm/@medusajs+pricing@2.15.3.../dist/models/`

---

## 1. 도메인 개요

가격 도메인은 상품 변형(ProductVariant)의 판매 가격을 컨텍스트(통화·지역·고객 그룹·수량)에 따라
유연하게 관리합니다. Medusa v2 의 가격 아키텍처는 `PriceSet → Price → PriceRule` 의 3단 구조로
기존 v1 보다 훨씬 유연한 가격 정책을 지원합니다.

---

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 PriceSet (가격 세트)

ProductVariant 1개에 연결되는 가격 컨테이너.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 (prefix: `pset_`) |

### 2.2 Price (가격)

PriceSet 안의 단일 가격 레코드. 통화+규칙 조합으로 최적 가격이 선택됩니다.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `title` | string \| null | 가격 설명 |
| `currency_code` | string | 통화 코드 (예: `krw`) |
| `amount` | bigNumber | 금액 |
| `min_quantity` | number \| null | 최소 구매 수량 (수량 할인) |
| `max_quantity` | number \| null | 최대 구매 수량 |
| `rules_count` | number \| null | 연결된 규칙 수 (최적 가격 선택 우선순위) |

### 2.3 PriceRule (가격 규칙)

Price 에 적용되는 컨텍스트 조건 (예: region_id = kr, customer_group_id = vip).

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `attribute` | string | 조건 속성 (예: `region_id`, `customer_group_id`) |
| `value` | string | 조건값 (예: `reg_kr`, `cg_vip`) |
| `operator` | enum | 비교 연산자 (`eq` / `lte` / `gte` / ...) |
| `priority` | number | 우선순위 (높을수록 먼저 적용) |

### 2.4 PriceList (가격 목록)

기간·조건이 있는 특별 가격 그룹 (할인 행사, 플래시 세일).

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `title` | string | 목록명 |
| `description` | string | 설명 |
| `status` | enum | `active` / `expired` / `draft` |
| `type` | enum | `sale` / `override` |
| `starts_at` | datetime \| null | 시작 일시 |
| `ends_at` | datetime \| null | 종료 일시 |
| `rules_count` | number \| null | 규칙 수 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.5 PricePreference (가격 선호도)

지역/통화별 세금 포함 여부 기본값 설정.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `attribute` | string | 속성 (예: `region_id`) |
| `value` | string | 값 |
| `is_tax_inclusive` | boolean | 세금 포함 여부 |

---

## 3. 엔티티 간 관계

```
PriceSet
  └── 1:N ── prices (Price)
               ├── 1:N ── price_rules (PriceRule)
               └── N:1 ── price_list (PriceList) [optional]
                            └── 1:N ── price_list_rules (PriceListRule)
```

ProductVariant ↔ PriceSet 연결은 `variant_price_set` Link 테이블로 관리됩니다.

---

## 4. 주요 기능/유스케이스

1. **기본 가격 설정**: 통화별 기본 판매가 등록
2. **지역별 가격 차등**: PriceRule(`region_id`) 로 한국/미국 가격 분리
3. **고객 그룹 할인**: PriceRule(`customer_group_id`) 로 VIP 가격 적용
4. **수량 할인**: `min_quantity` / `max_quantity` 로 대량 구매 할인
5. **기간 한정 세일**: PriceList (`type=sale`, `starts_at`, `ends_at`)
6. **가격 완전 대체**: PriceList (`type=override`) 로 기간 중 기존 가격 무효화

## 5. 대표 API 엔드포인트

### Admin API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET/POST` | `/admin/price-lists` | 가격 목록 CRUD |
| `GET/POST/DELETE` | `/admin/price-lists/:id/prices` | 가격 목록 내 가격 관리 |
| `GET/POST` | `/admin/price-preferences` | 가격 선호도 설정 |

- `createPriceSetsWorkflow`: 가격 세트 생성
- `updatePriceSetsWorkflow`: 가격 세트 업데이트
- `createPriceListsWorkflow`: 가격 목록 생성
- `updatePriceListsWorkflow`: 가격 목록 업데이트

---

## 7. 이 프로젝트에서의 활용/확장 포인트

- **KRW 전용 통화**: `currency_code = "krw"`, `PricePreference.is_tax_inclusive = true` (한국 소비자가 부가세 포함)
- **VIP 가격**: `CustomerGroup` + `PriceRule(customer_group_id)` 조합으로 멤버십 할인 구현
- **타임 세일**: PriceList `type=sale` + `starts_at/ends_at` 설정
