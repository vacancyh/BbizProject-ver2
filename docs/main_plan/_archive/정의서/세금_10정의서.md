# 세금(Tax) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/tax` | 확인 경로: `node_modules/.pnpm/@medusajs+tax@2.15.3.../dist/models/`

---

## 1. 도메인 개요

세금 도메인은 국가·도/시별 세금 구역(TaxRegion)과 세율(TaxRate)을 관리합니다.
장바구니 체크아웃 시 Tax 모듈이 LineItemTaxLine / ShippingMethodTaxLine 을 생성합니다.

---

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 TaxRegion (세금 구역)

국가 또는 도/시 단위의 세금 구역. 계층 구조 지원.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `country_code` | string | 국가 코드 (예: `kr`) |
| `province_code` | string \| null | 도/시 코드 (하위 구역) |
| `created_by` | string \| null | 생성 주체 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.2 TaxRate (세율)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `rate` | number \| null | 세율 (예: 10.0) |
| `code` | string | 세금 코드 (예: `VAT`) |
| `name` | string | 세금명 (예: "부가가치세") |
| `is_default` | boolean | 기본 세율 여부 |
| `is_combinable` | boolean | 복합 세율 적용 가능 여부 |
| `created_by` | string \| null | 생성 주체 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.3 TaxRateRule (세율 규칙)

특정 상품/유형에만 세율 적용 조건.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `reference` | string | 참조 엔티티 타입 (예: `product_type_id`) |
| `reference_id` | string | 참조 엔티티 ID |
| `created_by` | string \| null | 생성 주체 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

---

## 3. 엔티티 간 관계

```
TaxRegion (계층, self-join: parent → children)
  └── 1:N ── tax_rates (TaxRate)
               └── 1:N ── rules (TaxRateRule)
```

---

## 4. 주요 기능/유스케이스

1. **국가별 세율 설정**: 한국 `country_code=kr`, 기본 부가가치세 10%
2. **도/시별 세율 차등**: TaxRegion 계층으로 특별구역 세율 지원
3. **상품 유형별 세율 적용**: TaxRateRule 로 특정 유형(식품 등) 0% 세율 설정
4. **자동 세금 계산**: 장바구니 업데이트 시 Tax 모듈 자동 호출

## 5. 대표 API 엔드포인트

### Admin API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET/POST` | `/admin/tax-regions` | 세금 구역 관리 |
| `GET/POST/DELETE` | `/admin/tax-regions/:id` | 세금 구역 단건 관리 |
| `GET/POST/DELETE` | `/admin/tax-rates` | 세율 관리 |
| `GET` | `/admin/tax-providers` | 세금 공급자 목록 |

---

## 6. 이 프로젝트에서의 활용/확장 포인트

- **한국 부가가치세**: `TaxRegion(country_code=kr)` + `TaxRate(rate=10, code=VAT, is_default=true)`
- **면세 상품**: `TaxRateRule(reference=product_type_id, reference_id=...)` 로 면세 상품 유형 지정
- **역직구**: 해외 고객 배송 시 `country_code = us/jp` 등 해당 국가 세율 자동 적용
