# 상품(Product) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/product` | 확인 경로: `node_modules/.pnpm/@medusajs+product@2.15.3.../dist/models/`

---

## 1. 도메인 개요

상품 도메인은 쇼핑몰에서 판매하는 모든 상품의 카탈로그 정보를 관리합니다.
Medusa v2 에서 상품 도메인은 독립된 모듈(`@medusajs/product`)로 분리되어 있으며,
가격·재고·판매채널과는 별도 모듈로 분리된 뒤 Link 로 연결됩니다.

이 프로젝트에서는 카테고리별 옵션 템플릿(한국특화 기능)을 이 모듈 위에 얹을 예정으로,
가장 중요한 핵심 도메인입니다.

---

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 Product (상품)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 (prefix: `prod_`) |
| `title` | string | 상품 표시명 (필수) |
| `handle` | string | URL 슬러그 (고유) |
| `subtitle` | string \| null | 부제목 |
| `description` | string \| null | 상품 설명 |
| `is_giftcard` | boolean | 기프트카드 여부 |
| `status` | enum | 상태: `draft` / `published` / `proposed` / `rejected` |
| `thumbnail` | string \| null | 대표 이미지 URL |
| `weight` | number \| null | 무게 (g) |
| `length` | number \| null | 길이 |
| `height` | number \| null | 높이 |
| `width` | number \| null | 너비 |
| `origin_country` | string \| null | 원산지 |
| `hs_code` | string \| null | 관세청 품목분류코드 |
| `mid_code` | string \| null | MID 코드 |
| `material` | string \| null | 소재 |
| `discountable` | boolean | 할인 적용 가능 여부 |
| `external_id` | string \| null | 외부 시스템 식별자 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |
| `created_at` | datetime | 생성 일시 (자동) |
| `updated_at` | datetime | 수정 일시 (자동) |
| `deleted_at` | datetime \| null | 소프트 삭제 일시 |

### 2.2 ProductVariant (상품 변형 = SKU)

**가격·재고의 단위**입니다. Product 1개는 Variant N개를 가집니다.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 (prefix: `variant_`) |
| `title` | string | 변형 표시명 (예: "L / 블랙") |
| `sku` | string \| null | 재고 관리 코드 |
| `barcode` | string \| null | 바코드 |
| `ean` | string \| null | EAN 코드 |
| `upc` | string \| null | UPC 코드 |
| `allow_backorder` | boolean | 품절 시 주문 허용 여부 |
| `manage_inventory` | boolean | 재고 관리 여부 |
| `hs_code` | string \| null | 관세청 품목분류코드 |
| `origin_country` | string \| null | 원산지 |
| `mid_code` | string \| null | MID 코드 |
| `material` | string \| null | 소재 |
| `weight` | number \| null | 무게 |
| `length` / `height` / `width` | number \| null | 규격 |
| `variant_rank` | number \| null | 진열 순서 |
| `thumbnail` | string \| null | 변형별 이미지 URL (v2.11.2 이후) |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.3 ProductOption (상품 옵션)

| 필드 | 타입 | 설명 |

| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.4 ProductOptionValue (옵션값)

| `id` | string (PK) | 고유 식별자 |
| `value` | string | 옵션값 (예: "빨강") |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.5 ProductCategory (카테고리)

계층 구조를 지원하는 트리 구조의 카테고리입니다.

| 필드 | 타입 | 설명 |

## 3. 엔티티 간 관계

```
ProductCategory (트리, self-join)
    └── N:N ── Product
                ├── 1:N ── ProductOption
                │           └── 1:N ── ProductOptionValue
                │                         └── N:N ── ProductVariant (SKU)
                ├── 1:N ── ProductVariant
                │           └── N:N ── ProductImage
                ├── 1:N ── ProductImage
                ├── N:1 ── ProductCollection (optional)
                ├── N:1 ── ProductType (optional)
                └── N:N ── ProductTag
```

**중요**: ProductVariant ↔ ProductOptionValue 는 ManyToMany 관계입니다.
Variant 하나에 여러 OptionValue 가 연결되며, 이것이 "색상=빨강 + 사이즈=L" 조합을 표현합니다.

## 4. 주요 기능/유스케이스

1. **상품 등록/수정/삭제**: 제목·설명·옵션·변형(SKU) 일괄 생성
2. **상품 상태 관리**: `draft → published` 전환으로 상점 노출 제어
3. **카테고리 트리 관리**: `mpath`를 이용한 계층 탐색, 부모-자식 카테고리 구성
4. **변형(SKU) 관리**: 옵션값 조합으로 SKU 자동 생성
5. **대량 가져오기/내보내기**: Admin API의 `import` / `export` 엔드포인트 활용
6. **컬렉션 큐레이션**: 기획전·시즌 컬렉션 구성
7. **태그/유형 분류**: 검색·필터링용 메타데이터 부여

### Admin API (`/admin/`)

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/admin/products` | 상품 목록 조회 (필터, 페이지네이션) |
| `POST` | `/admin/products` | 상품 생성 |

| `POST` | `/admin/products/batch` | 상품 일괄 처리 |
| `POST` | `/admin/products/imports` | CSV 가져오기 |

## 6. 관련 워크플로우(core-flows) / 이벤트

Medusa v2 의 core-flows 는 `@medusajs/medusa/dist/core-flows` 에 있으며, 상품 도메인 주요 흐름은 다음과 같습니다.

- `createProductsWorkflow`: 상품 + 변형 + 옵션 + 이미지 일괄 생성
- `updateProductsWorkflow`: 상품 + 하위 엔티티 업데이트
- `deleteProductsWorkflow`: 소프트 삭제 + 재고/가격 연결 정리
- `createProductVariantsWorkflow`: 변형 추가
- `updateProductVariantsWorkflow`: 변형 업데이트
- `batchProductsWorkflow`: 상품 배치 처리 (생성/수정/삭제 혼합)

## 7. 이 프로젝트에서의 활용/확장 포인트

### 7.1 카테고리별 옵션 템플릿 (한국특화 핵심 기능)

이 프로젝트는 `ProductCategory` 기반의 **옵션 템플릿** 레이어를 추가할 예정입니다.

- 예: 카테고리 "의류" → 기본 옵션 ["색상", "사이즈"]
- 예: 카테고리 "신발" → 기본 옵션 ["색상", "사이즈(mm/KR 기준)"]
- 카테고리 선택 시 해당 카테고리의 옵션 템플릿이 자동 적용되어 관리자 상품 등록 UX 개선

**구현 방향 (추가 확인 필요)**:
- `ProductCategory.metadata` 에 옵션 템플릿 JSON 저장 방식 (단순, 제약 있음)
- 별도 커스텀 모듈 `category-option-template` 생성 후 `defineLink` 로 연결 (권장)

### 7.2 한국 법규 연동 포인트

- `ProductVariant.hs_code`: 관세청 품목분류코드 → 세관 신고용 (해외직구 주문 시)
- `Product.is_giftcard`: 상품권 특례 적용 여부 판별 (전자상거래법 §17 ② 예외)
- `Product.metadata`: 전기용품안전법 인증번호, 식품표시사항 등 한국 법규 준수 정보 저장

### 7.3 재고 연동

`ProductVariant` 는 `@medusajs/inventory` 의 `InventoryItem` 과
`inventory_items_variant_id` Link 테이블로 연결됩니다.
`manage_inventory = true` 인 변형만 재고 추적됩니다.
