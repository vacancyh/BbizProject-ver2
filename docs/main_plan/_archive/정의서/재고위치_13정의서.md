# 재고위치(Stock Location) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/stock-location` | 확인 경로: `node_modules/.pnpm/@medusajs+stock-location@2.15.3.../dist/models/`

---

## 1. 도메인 개요

재고위치 도메인은 물리적 창고·매장·픽업 포인트를 관리합니다.
InventoryLevel 이 StockLocation 단위로 재고 수량을 기록하고,
FulfillmentSet 이 StockLocation 에 연결되어 배송 가능 구역을 정의합니다.

---

## 2. 핵심 데이터 모델(엔티티)과 주요 필드

### 2.1 StockLocation (재고 위치)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 (prefix: `sloc_`) |
| `name` | string | 위치명 (예: "서울 물류센터") |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

### 2.2 StockLocationAddress (위치 주소)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string (PK) | 고유 식별자 |
| `address_1` | string | 주소 1 |
| `address_2` | string \| null | 주소 2 |
| `company` | string \| null | 회사명 |
| `city` | string \| null | 도시 |
| `country_code` | string | 국가 코드 |
| `phone` | string \| null | 전화번호 |
| `province` | string \| null | 도/시 |
| `postal_code` | string \| null | 우편번호 |
| `metadata` | JSON \| null | 커스텀 메타데이터 |

---

## 3. 엔티티 간 관계

```
StockLocation
  ├── 1:1 ── address (StockLocationAddress)
  ├── 1:N ── inventory_levels (InventoryLevel) [inventory 모듈 Link]
  ├── 1:N ── fulfillment_sets (FulfillmentSet) [fulfillment 모듈 Link]
  └── N:N ── sales_channels (SalesChannel) [sales-channel 모듈 Link]
```

---

## 4. 주요 기능/유스케이스

1. **창고 등록**: 물리적 발송 위치 설정
2. **판매채널 연결**: 채널별 발송 가능 창고 지정
3. **다창고 이행**: 주문 수량을 여러 창고에서 분할 처리

---

## 5. 대표 API 엔드포인트

### Admin API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET/POST` | `/admin/stock-locations` | 재고 위치 목록/생성 |
| `GET/POST/DELETE` | `/admin/stock-locations/:id` | 단건 관리 |
| `POST/DELETE` | `/admin/stock-locations/:id/sales-channels` | 판매채널 연결 |
| `POST/DELETE` | `/admin/stock-locations/:id/fulfillment-sets` | 이행 세트 연결 |

---

## 6. 이 프로젝트에서의 활용/확장 포인트

- 초기: 단일 창고 운영 ("서울 물류센터")
- 확장: 지역별 창고 추가 (부산, 광주 등) + InventoryLevel 분산 관리
