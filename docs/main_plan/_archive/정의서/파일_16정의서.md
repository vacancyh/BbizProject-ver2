# 파일(File) 도메인 정의서

> Medusa v2.15.3 | `@medusajs/file` | 확인 경로: `node_modules/.pnpm/@medusajs+file@2.15.3.../`

---

## 1. 도메인 개요

파일 도메인은 상품 이미지·CSV 임포트 파일 등 파일 업로드/다운로드를 추상화합니다.
파일 스토리지 백엔드는 공급자 패턴으로 교체 가능합니다.
기본 제공 공급자: `file-local` (로컬 파일시스템), `file-s3` (AWS S3).

---

## 2. 핵심 데이터 모델

File 도메인은 데이터베이스 엔티티를 별도로 정의하지 않으며,
파일 업로드/다운로드 인터페이스만 제공합니다.
반환값은 `{ url: string }` 형태의 파일 URL 입니다.

### FileModuleOptions (설정)

| 옵션 | 설명 |
|------|------|
| `provider.resolve` | 파일 공급자 모듈 경로 |
| `provider.id` | 공급자 ID (예: `s3`) |
| `provider.options` | 공급자별 설정 (S3 bucket, region 등) |

---

## 3. 주요 기능/유스케이스

1. **이미지 업로드**: 상품·변형 이미지 업로드 → URL 반환
2. **파일 업로드**: CSV/엑셀 임포트용 파일 임시 저장
3. **파일 다운로드**: 생성된 파일 URL로 브라우저 다운로드

---

## 4. 대표 API 엔드포인트

### Admin API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `POST` | `/admin/uploads` | 파일 업로드 |
| `DELETE` | `/admin/uploads` | 파일 삭제 |

---

## 5. 이 프로젝트에서의 활용/확장 포인트

- **개발 환경**: `file-local` 공급자로 로컬 저장
- **프로덕션**: `file-s3` 공급자 + AWS S3 버킷 설정 (추가 확인 필요)
- **CDN 연동**: S3 + CloudFront 조합으로 이미지 CDN 적용
- **이미지 최적화**: 업로드 후 리사이징 Webhook 구성 가능
