## 3. 종합 (BLOCKER/MAJOR 건수 + 최중대 3건)

- **BLOCKER: 3건** (L-01 환불 기산점 오기 / L-02 지연이자 누락 / L-03 상품정보제공고시 검증 후순위·미구현)
- **MAJOR: 7건** (L-04 현금영수증 / L-05 만14세 실효성 / L-06 대가성표시 노출범위 / L-07 접속기록 보관 / L-08 card_hash 보관 / L-09 비회원 알림 개인정보 / L-10 포인트 소멸 고지)
- **MINOR: 4건** (L-11 / L-12 / L-13 / L-14)

### 가장 중대한 3건 요약

1. **[L-01 BLOCKER] 환불 기산점 오기 (주문·결제·배송 횡단)** — 배송 §4.4가 "청약철회 통지받은 날부터 3영업일 환불"로 단정했으나, 전자상거래법 §18은 **재화를 공급한 경우 "재화를 반환받은 날"부터** 3영업일이다. 반품(배송완료 후 회수) 건에 통지일 기산을 적용하면 사업자가 물건도 받기 전에 환불해야 하는 모순 + 회수 지연 시 법정기한 자동 초과. 기산점을 (미배송=청약철회일 / 배송 후 반품=반환·검수완료일)로 2분기 필수.

2. **[L-02 BLOCKER] 환불 지연배상금(연 15%) 전면 누락 (결제)** — §18②의 지연이자 규정이 10개 설계서 어디에도 없다. 환불 재시도 큐(최대 5회×10분)·검수→환불 3단계 등 정상 흐름이 3영업일을 초과할 수 있는데 지연이자 산정·지급 로직이 없어 미지급 시 곧바로 법 위반. `refunds.due_date` + 지연이자 자동산정 필드 신설 필요.

3. **[L-03 BLOCKER] 상품정보제공고시 필수항목 검증 미구현·후순위 (상품)** — 품목별 법정 필수항목(소재·원산지·제조국·KC인증·사용기한 등) 게시 전 검증을 "단계 2(다음)"로 미뤄, 필수항목 누락 상태로 상품 게시가 가능하다. 전자상거래법 §13 + 공정위 고시 위반 직접 노출. 최소 MVP 취급 품목(악세서리/주얼리) 고시항목 검증은 **immediate로 승격** 필요 (대전제 ①오류없음과 정면 충돌).
