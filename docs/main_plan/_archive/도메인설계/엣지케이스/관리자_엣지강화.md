## 2. 핵심 3건 (최우선 처리)

1. **E-03 SUPER 단독 계정 잠김 데드락** — SUPER 1명 잠금/MFA 분실 시 전 시스템 통제 불가. 처리 = 최소 SUPER는 "계정 존재"만 강제(잠금과 분리) + MFA 백업코드 10개 운영 + CLI 부트스트랩 복구 경로(감사 외부 기록). F11과 F5의 상호작용이 만드는 락아웃을 명시 해소.
2. **E-13/E-15/E-16 감사 무결성·보관·SIEM 트랙** — append-only(UPDATE/DELETE revoke) + WORM/SIEM 스트림 + **업무 5년/접속기록 2년+월1회 점검 분리**(검수 L-07: 법적 의무이므로 비용 종속 금지) + outbox at-least-once로 SIEM 누락 방지. ISMS-P 2.9.4·개인정보보호법 시행령 §48 직접 충족.
3. **E-27/E-28 마케팅 야간발송·수신거부 후 발송** — 다중 방어선(견적 경고 #6 → BE 422 #7 → 워커 BLOCK #8 → 발송직전 동의 재조회 #9)으로 야간(§50의5)·opt-out(§50) 발송을 코드 레벨에서 차단. 발송 직전 consent 재조회가 세그먼트 추출↔발송 사이 경합을 닫는 핵심 게이트.

## 3. 미결 (사장님 결정 종속 — 본 엣지 설계가 처리하나 값 확정 필요)

- **E-20 정책 SoT** = system_policies 단일(A) vs 도메인 로컬(B) 택1 (검수 M-09 미해소). 미결정 시 정책 동기화 공백 잔존.
- **E-21 점검모드 scope=both** 허용 여부 (Q1).
- **E-25/E-26 IP allowlist·운영시간** 적용 범위 (전 관리자 vs 부운영자 한정).
- **E-27 야간 도달 시** 발송 연기 vs 취소 (f21-Q02).
- **E-03 MFA 백업코드** 운영 정책 (Q5) — 본 엣지는 운영 권장.
- **RBAC 커스텀 vs native** = 검수 03 과설계 지적에 따라 scope×action 세분 권한 실수요 전까지 native `@medusajs/rbac` 우선, 커스텀 4테이블 보류 (PL 단계 실측 후 결정).
