## 2. 핵심 멱등·정합 설계 요약

엣지케이스 중 **재발 위험이 높은 3대 정합 포인트**:

1. **발송 멱등(E-15·E-16)**: 즉시(subscriber) + 배치(jobs) 이중 경로 → **조건부 UPDATE(`notified_at IS NULL`일 때만 SET) 후 발송** 패턴으로 단일화. 0 rows affected = 이미 처리됨 → skip.
2. **발송 실패 롤백(E-12·E-13·E-14)**: notified_at = "발송 시도 완료". 실패 콜백 → 롤백(NULL) + 재시도 큐(최대 3회 권장, 백오프). 성공/실패 실제 결과는 발송 로그(S4) success 플래그로 분리 기록.
3. **위시↔카트 단위 변환(E-05·E-07·E-09·E-30)**: 위시=상품 단위, 카트=SKU 단위. 옵션 상품 = 모달 강제, 단일 SKU = 직접 담기. 품절/단종 skip → 옵션 모달 → 카트 50 한도 skip 순서. 재고 최종 차단은 카트 1단계 위임(B-04).
