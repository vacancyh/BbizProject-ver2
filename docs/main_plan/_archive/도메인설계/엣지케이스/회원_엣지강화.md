## 0. 정합 기준 (상위 권위 인용)

- **확정 보강(`_보강설계_결정반영.md`)**: 회원 MFA = 관리자 native 즉시 + 사용자 옵션(후순위) / 만14세 = **단순 차단(생년월일 필수 + 14세 미만 즉시 차단)** 유지 / 블랙리스트 진행주문 = paid·preparing **자동취소 안 함(운영 수동)** + 신규 주문만 차단 / 이벤트명 `order.confirmed` 통일.
- **검수 회원 지적(`01_법령정합_검수.md`)**: L-05(만14세 자진입력 우회 위험) / L-07(접속기록 보관기간 분리) / L-08(card_hash 보관·파기, 회원 blacklist phone/email 해시 연계) / L-09(비회원 알림 개인정보 — 위시 영역이나 회원 phone 해시 연계) / L-12(마케팅 수신동의 2년 재확인·opt-out 즉시) / L-14(수집근거 명시).
- **엔티티 권위(d11 §2)**: `members`·`member_oauth`·`member_consent`(INSERT-only)·`member_sanctions`·`member_blacklist`·`auth_sessions`(Token Rotation)·`password_resets`(30분·1회)·`member_notification_settings`.
- **법령**: 개인정보보호법 §22조의2(만14세 법정대리인 동의)·§15·§22(수집동의)·§39조의6 폐지(휴면 분리보관 의무 폐지, 2024-01-01) / 정보통신망법 §50·§50의5·§50⑧(2년 재확인) / 전자상거래법 §6(주문 5년 보존).

## 9. 종합

- **엣지케이스 총 건수: 57건**
  - 가입(ME) 7 · 로그인/세션(MS) 9 · 비번재설정(MP) 6 · 소셜(MO) 7 · 탈퇴/PII(MW) 9 · 제재/블랙/동의(MB) 9 · 등급/배치(MG) 5 · MFA/관리자(MF) 5 = **7+9+6+7+9+9+5+5 = 57건**.

### 가장 중요한 3건

1. **[MS-03] Refresh Token 탈취·재사용 → token_family 전체 revoke** — 세션 하이재킹 직결. Token Rotation 재사용 감지 시 패밀리 전체 무효화(F2)로 탈취 차단. 인증 기반 도메인의 보안 최후 방어선.

2. **[MW-08] 접속기록 보관기간 분리(개인정보처리시스템 접속기록 최소 2년 + 월1회 점검)** — 검수 L-07 BLOCKER급 법령 의무. "비용 시 분리"는 오류이며 점검 의무는 비용 무관 강제. 미이행 시 개인정보보호법 시행령 §48 위반.

3. **[MO-01] 소셜 이메일 ↔ 기존 계정 충돌 시 자동병합 금지(409 + 명시적 연동 유도)** — 자동 병합 허용 시 계정 탈취(이메일 선점) 위험. 일반 로그인 후 명시적 link만 허용하는 한국 관행·보안 정합. MO-05(유일 인증수단 unlink lock-out)와 함께 소셜 계정 lock-out·탈취를 모두 차단.
