## B. BLOCKER 8건 해소 (캐노니컬)

### B-법령 (3건)

**L-01 환불 기산점 — 2분기 확정**
- §18 정합: **(a) 미배송·미공급 = 청약철회한 날** / **(b) 배송완료 후 반품 = 재화 반환받은(검수완료) 날** 기산.
- `legal-kr/withdrawal-7day` `requireBusinessDayRefundSLA(orderId, originType)` — `originType ∈ {withdrawal_date, return_received_date}` 파라미터 추가.
- 배송 설계서 §4.4 "통지받은 날 3영업일" 문구 → 위 2분기로 정정.

**L-02 환불 지연이자(연 15%) — 모델 신설**
- `refunds`(payment-kr)에 `due_date`(기산점+영업일3) + `delayed_days` + `delayed_interest`(연 15% 일할) 필드 추가.
- 환불 재시도 큐가 `due_date` 초과 시 지연이자 자동 산정 + 관리자 알림 job. 환불 실행 시 원금+지연이자 합산.

**L-03 상품정보제공고시 검증 — immediate 승격**
- 상품유형(`product_type_template`)에 **고시 필수항목 정의** `product_type_disclosure_field`(field_key, label, required, sort_order, input_type) 추가 = 설계 단계2 → **단계1.5로 승격**.
- `product_disclosure_value`(product_id, field_key, value)에 입력값 저장. **게시(status=published) 전 required 필드 검증 hook** — 누락 시 게시 차단.
- MVP 취급 품목(악세서리/주얼리: 소재·치수·제조국·A/S·품질보증) 최소 항목 시드.

### B-도메인 간 (5건)

**B-01 반올림 단일 권위** → A-1 #1로 해소. `금액 산출순서 = 상품금액 → 쿠폰할인 → 포인트사용 → 배송비`, 부분취소 = 라인별 adjustment 역산 + `FLOOR`. 주문 d16이 산식·반올림 상수 소유, 결제·쿠폰 참조.

**B-02 0원 결제 흐름 명시**
- 결제: 최종결제액 0원(포인트/쿠폰 100%) → PG 미호출, `payment.zero_payment_confirmed` 발행.
- **주문이 `payment.zero_payment_confirmed` 구독** → `order.paid` 전이. (주문 구독목록에 추가)

**B-03 상태 단일 권위 + 매핑표**
- **state-machine 모듈 config = 단일 권위**. 주문/배송이 각자 status 정의 금지, config 참조.
- state-machine `config/order.ts`에 누락 5종 `preparing/confirmed/partially_cancelled/partially_returned/partially_exchanged` 보강.
- 주문 status ↔ 배송 fulfillment status **rollup 매핑표** 박제: 전 shipment `delivered` → order `delivered`; 일부 → `partially_delivered`.

**B-04 위시→카트 변환 계약**
- 위시=상품 단위 / 카트=SKU 단위. 변환: **옵션 있는 상품 = 옵션선택 모달 강제**, 단일 SKU만 직접 담기.
- bulk 이동 시 카트 라인 50 한도 초과분 = skip + 사유 반환. 재고검증은 카트 1단계 재검증 위임.

**B-05 적립 권위 + 이벤트명 통일**
- 포인트 적립 **금액 권위 = 쿠폰포인트 도메인 정책**(리뷰는 트리거만). 리뷰 Q1·쿠폰 Q2 중복 미결 → 쿠폰 1곳으로 통합("가능한 만큼 회수").
- **이벤트명 통일: `order.confirmed`** (구매확정). 회원·쿠폰포인트·리뷰의 `order.purchase_confirmed` 구독 → `order.confirmed`로 수정.
- (연계) 배송 발행 `return.completed`/`exchange.completed` ↔ 주문 구독 prefix 통일.

## C. 내 설계서(상품_카테고리) MAJOR 2건 해소 (A-1 #4 반영)

- **A1 (트리 단수)**: 한국 표준 **4단(대>중>소>상세)** 채택 → **S0 d13 갱신 필요**(1-2단 → 4단, Q1 해소). 근거 = 카페24 표준 + 대전제②한국친화.
