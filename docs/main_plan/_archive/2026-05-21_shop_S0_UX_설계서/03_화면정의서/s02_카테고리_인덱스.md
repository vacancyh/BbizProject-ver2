## 3. 컴포넌트 명세

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **헤더 띠 (선택)** | 본문 최상단 | static 또는 admin 운영 | "전체 컬렉션을 둘러보세요" — 브랜드 카피. 운영자 비노출 가능 |
| **H1 "SHOP ALL" + 서브 캡션** | 본문 상단 중앙 | static + `GET /api/categories/count` | "4개의 컬렉션" — 카테고리 개수 동적 표시 |
| **카테고리 카드 (반지)** | 그리드 1열 | `category[slug=rings]` + `GET /api/products/count?cat=rings` | 대표 이미지 (정사각, lazy load 1차 viewport 제외) + 카테고리명 "반지" + 영문 "Rings" + 상품 개수 "N개 상품" + [둘러보기→] CTA. 카드 전체 클릭 → `/shop/rings` |
| **카테고리 카드 (목걸이)** | 그리드 2열 | `category[slug=necklaces]` | 동일 패턴. `/shop/necklaces` |
| **카테고리 카드 (귀걸이)** | 그리드 3열 | `category[slug=earrings]` | 동일 패턴. `/shop/earrings` |
| **카테고리 카드 (팔찌)** | 그리드 4열 | `category[slug=bracelets]` | 동일 패턴. `/shop/bracelets` |
| **추천 상품 그리드 (선택)** | 본문 하단 | `GET /api/products/curated?type=shop_all` | 홈과 동일 패턴. 8개 상품. 운영자 큐레이션 가능 |
| **추천 상품 카드** | 그리드 각 셀 | product 데이터 | 썸네일 + 상품명 + 가격 + 위시리스트 ♡ (회원). 클릭 → `/product/[id]` |

## 4. 상태 (State Matrix)

| 상태 | UI / 동작 |
|---|---|
| **초기 / 정상** | 4 카테고리 카드 + (선택) 추천 상품 정상 노출 |
| **로딩 (ISR 캐시 미스)** | 카테고리 카드 skeleton 4개 + 추천 상품 skeleton 8개 |
| **이미지 lazy load 실패** | 대체 이미지 (브랜드 로고 워터마크 + 회색 배경) + alt 텍스트 |
| **상품 개수 0건 (특정 카테고리)** | 카드 노출 유지 + "준비 중인 컬렉션" 캡션 (회색) + CTA 비활성화 또는 "곧 만나요" 카피 |
| **추천 상품 0건** | 추천 상품 섹션 자체 미노출 (관리자 큐레이션 안 했을 시) |
| **카테고리 비활성화 (admin 처리)** | 해당 카드 미노출 (deleted_at IS NOT NULL) — 3개만 노출. ISR 재생성 트리거 |
| **네트워크 오류 (API)** | 카드 skeleton 유지 + 토스트 "네트워크가 불안정해요" + retry 버튼 |

## 8. SEO · 접근성 · 성능

### 8.1 SEO (★ 핵심)

- `<title>`: "LUMI 컬렉션 — 반지·목걸이·귀걸이·팔찌 | LUMI"
- `<meta name="description">`: "LUMI의 모든 컬렉션을 한 곳에서 만나보세요. 반지, 목걸이, 귀걸이, 팔찌까지 — 일상에 빛을 더하는 주얼리"
- `<meta name="robots" content="index, follow">`
- `<link rel="canonical" href="https://lumi.example.com/shop">`
- **Open Graph**: og:title, og:description, og:image (LUMI 브랜드 대표 이미지), og:type=website
- **Twitter Card**: summary_large_image
- **Structured Data (JSON-LD)**: BreadcrumbList (홈 → SHOP) + WebPage + ItemList (4 카테고리)
- 사이트맵 포함 (`sitemap.xml`)
- 검색 키워드 타겟팅: "주얼리 쇼핑", "반지 추천", "목걸이 브랜드", "데일리 주얼리"

### 8.2 접근성 (WCAG AA / KWCAG 2.2)

- H1 "SHOP ALL" 페이지당 1회
- 카테고리 카드 `<a>` 태그 (router link) + 카드 전체가 클릭 영역 (모바일)
- 대표 이미지 `alt="<카테고리명> 컬렉션 대표 이미지"`
- 카드 내 정보 위계 명확 (이미지 → 카테고리명 → 영문 → 상품 개수 → CTA)
- 키보드 Tab 순서: 카테고리 4종 → 추천 상품 8개 → 위시리스트 ♡ (각 상품)
- 위시리스트 ♡ `aria-label="<상품명> 위시리스트에 추가"` + `aria-pressed`
- 카드 hover 효과는 keyboard focus에도 동일 적용 (`:focus-visible`)
- 컬러 대비 4.5:1 이상 (카테고리명 텍스트)

### 8.3 성능 (Core Web Vitals)

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.0s | 카테고리 카드 4개 중 1st viewport는 priority + preload. 모바일은 2개 priority |
| INP | ≤ 200ms | 카드 클릭 즉시 router push (prefetch on hover) |
| CLS | ≤ 0.05 | 이미지 1:1 비율 강제 + width/height 명시 |

- 카테고리 대표 이미지는 next/image priority (1st viewport)
- 추천 상품 이미지는 lazy load
- ISR 60분으로 SSR 부하 최소화
- CDN edge cache (Vercel/Cloudflare)
- prefetch: 카드 hover 시 다음 페이지(s03) prefetch
