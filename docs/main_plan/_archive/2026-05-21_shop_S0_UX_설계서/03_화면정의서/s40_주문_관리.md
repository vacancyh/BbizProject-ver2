| **상태 전이 — 역순 시도** | 차단 모달 "역순 전환은 불가능해요. shipping → preparing 불가" (F3, ORD-A-004) |
| **두 관리자 동시 상태 변경** | 낙관락 충돌 → 409 응답 → 모달 "다른 관리자가 먼저 변경했어요. 새로고침해 주세요" (F14, ORD-A-008) |
| **내부 메모 저장** | textarea 하단 [저장] 클릭 → 즉시 반영 + 감사 로그 (action=`order.memo.added`) |
| **내부 메모 길이 초과 (1000자)** | 인라인 캡션 "1000자 이내로 입력해주셔요" |
| **CS 권한 진입** | 일부 정보 마스킹 (연락처·결제 카드 마스킹) + 강제 취소·환불 CTA 비활성 |
