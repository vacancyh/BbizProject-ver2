## 1. 개요

| 항목 | 내용 |
|---|---|
| URL | `/mypage/orders/[orderId]/return` |
| 라우트 타입 | CSR + 본인 검증 (server) + 진입 조건 검증 (status=delivered, 반품 기간 내) |
| 진입 경로 | s23 주문 상세 "반품 신청" CTA / s22 카드 "반품 신청" CTA |
| 목적 | (1) 반품 대상 라인 선택 (2) 사유 선택 + 상세 입력 (3) 불량 시 이미지 첨부 (4) 회수 주소 확인·수정 (5) 환불 방식 선택 (6) returns INSERT (status=requested) |
| 액터 | 회원 전용 + 본인만 + status=delivered + 반품 기간 내 + 미반품/교환 라인 보유 |
| SEO 인덱싱 | X |
| 진입 차단 | 비로그인 → 로그인 게이트 / 본인 아님 → 403 / 기간 초과 → 안내 페이지 + "고객센터 문의" |

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |

| **반품 대상 라인 선택 (멀티 체크)** | ③ | `GET /api/orders/{id}` items[] (status=active만 선택 가능) | 이미 반품/교환 진행 중 라인은 회색 + 배지 "이미 다른 처리 진행 중" (Tier 1 §3.D #1 — `LINE_ALREADY_IN_PROCESS` 차단). 수량 선택 (1 ~ 라인 수량) — 옵션 SKU 단위 |

| **사유 선택 (라디오)** | ④ | static enum (returns.reason) | 단순변심 / 사이즈색상불일치 / 불량파손 / 오배송 / 이미지와 다름 / 기타. 단순변심은 회수 배송비 청구 캡션 강조. 불량은 이미지 첨부 필수 활성화 |
| **상세 사유 (textarea)** | ⑤ | 회원 입력 | 100자 제한, 선택 (기타 선택 시는 필수). escape 처리 |
| **이미지 첨부** | ⑥ | 회원 업로드 | 사유=불량 또는 이미지와 다름 시 **필수 1장 이상**. 그 외 선택. 최대 5장, 1장 5MB 이하, jpg/png/webp. presigned URL 업로드 (`POST /api/uploads/presign`) |
| **회수 주소 (라디오 + 폼)** | ⑦ | `orders.address_snapshot` + `GET /api/me/addresses` | 기본=주문 시점 배송지. "다른 주소" 선택 시 배송지 목록에서 택1 또는 신규 입력 (다음 우편번호 위젯) |
| **환불 방식 안내 카드 — 비례 배분 미리보기 (Tier 1 §3.B·§3.C)** | ⑧ | server 계산 (`/api/orders/{id}/return/preview`) | "결제 카드로 환불" (카드 단일) + 사용 쿠폰·포인트 복원 안내. **비례 배분 미리보기 표** = 선택 라인 상품금액 / 쿠폰 비례 차감 (`coupon × returned_subtotal/total`) / 포인트 비례 회수 / 회수 배송비 (단순변심만) / **잔여 무료배송 추가 청구** (Tier 1 §3.C — 부분반품 후 잔여 상품금액 < 무료배송 임계(50,000원) AND 원배송비 == 0 → 배송비 3,000원 추가 차감 안내 "잔여 주문 금액이 무료배송 기준 미만이 되어 배송비 3,000원이 추가 청구됩니다") / **환불 예상 금액**. 단순변심 시 sale 컬러 강조. **다건 동일 사유** = 한 표 / **라인별 사유** = 라인별 표 N개 |
| **주의 사항 동의 (체크박스)** | ⑨ | 회원 액션 | 2개 모두 체크 필수. 미체크 시 CTA disabled |
| **[반품 신청하기] CTA** | ⑩ | 검증 통과 | (1) 라인 1개 이상 선택 (2) 사유 선택 (3) 불량/이미지와 다름 시 이미지 1장 이상 (4) 회수 주소 유효 (5) 주의 사항 동의. 모두 만족 시 활성 → `POST /api/orders/{id}/return` (Idempotency-Key) → 성공 시 모달 "반품이 접수됐어요" + `[주문 상세로]` |
| **예상 환불 금액 (계산기)** | ⑩ 또는 ⑧ | client + server (`POST /api/orders/{id}/return/preview`) | 선택 변경 시 debounce 500ms 후 server 계산. 4-way 검증 차단 (client 추정값 ≠ server 계산값) |

## 4. 상태 (State Matrix)

| 상태 | UI / 동작 |
|---|---|
| **초기 (로딩)** | 라인 영역 skeleton + 폼 disabled |
| **데이터 OK** | 위 §3 정상 동작 |
| **기간 초과 (delivered + N일 경과)** | 안내 페이지 "반품 가능 기간이 지났어요. 고객센터로 문의해주셔요" + s23 복귀 CTA |
| **미반품 라인 0건 (이미 모두 반품/교환 진행 중)** | "반품 가능한 상품이 없어요" + s23 복귀 |
| **사유=불량/이미지와 다름 + 이미지 미첨부** | CTA disabled + 캡션 "사진 1장 이상 첨부해주셔요" |
| **이미지 업로드 진행 중** | 진행률 바 + 업로드 완료 시 썸네일 |
| **이미지 업로드 실패 (용량/형식)** | 토스트 "5MB 이하 jpg/png/webp 파일만 가능해요" |
| **회수 주소 미선택** | CTA disabled + 캡션 |
| **신청 진행 중** | CTA spinner + disabled + 전체 폼 disabled |
| **신청 성공** | 모달 "반품이 접수됐어요" + 회수 안내 (검수 후 환불 안내) + `[주문 상세로]` (status=requested 상태 표시) |
| **신청 실패 (이미 다른 작업 진행 중)** | 모달 "처리 중인 작업이 있어요. 새로고침 후 다시 시도해주셔요" |
| **신청 실패 — 동일 라인 중복 차단 (Tier 1 §3.D #1 — `LINE_ALREADY_IN_PROCESS`)** | 모달 "선택하신 상품 중 일부는 이미 다른 처리(반품/교환)가 진행 중입니다. 진행 상황은 [주문 상세 → 반품/교환 이력]에서 확인할 수 있어요" + 해당 라인 자동 비활성화 + 신청 폼 리셋 옵션 |
| **신청 실패 (네트워크)** | 토스트 + 재시도 (Idempotency-Key 유지 — 중복 차단). **Idempotency-Key (Level 2)** = `{order_id}:return:{nonce}` (Tier 1 §3.I) — 클라이언트 발급 (T1-Q07 권장) |
| **잔여 무료배송 임계 추가 청구 안내 (Tier 1 §3.C)** | 라인 체크 변경 시 server preview 응답에 `additional_shipping_charge` 포함된 경우 ⑧ 카드에 노란 강조 박스 "잔여 주문 금액이 무료배송 기준(50,000원) 미만이 되어 배송비 3,000원이 추가 청구됩니다" — 신청 전 사용자 인지 보장 |

## 6. 연결 도메인 · API 면

### 6.1 도메인

| 도메인 | 사용 영역 |
|---|---|
| delivery | returns INSERT (status=requested) + 회수 주소 |
| order | order_items 상태 (active 검증) |
| payment | 환불 금액 사전 계산 (실제 환불은 검수 후) |
| product | 검수 후 재고 복구 (본 화면은 트리거 X) |
| member | 본인 검증 + 배송지 목록 |

### 6.2 API 면

| 엔드포인트 | 메서드 | 응답 | 캐시 |
|---|---|---|---|
| `/api/orders/{id}/return/init` | GET | `{ returnable_items: [], delivery_address_snapshot, member_addresses: [], return_shipping_fee, return_period_remaining_days, reasons_enum }` | no cache |
| `/api/orders/{id}/return/preview` | POST | body `{ item_ids: [{id, qty}], reason }`. 응답 `{ refund_breakdown: { item_refund, coupon_restore, point_restore, shipping_fee_charge, total }}` | no cache |
| `/api/orders/{id}/return` | POST + Idempotency-Key | body `{ item_ids[], reason, reason_detail?, images?, pickup_address }`. 응답 `{ return_id, status }` | no cache |
| `/api/uploads/presign` | POST | 이미지 업로드 presigned URL (S3 등) | no cache |
