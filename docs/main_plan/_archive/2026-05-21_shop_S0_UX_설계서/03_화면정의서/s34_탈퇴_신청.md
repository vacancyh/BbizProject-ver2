## 5. 예외·엣지 케이스

- **진행 중 주문 정의** = `orders.status IN (paid, preparing, shipping)` AND `delivered + 구매확정 대기` (d18 deliveries.status != confirmed)
- **반품/교환 진행 중** → 진행 중 주문에 포함 (반품 완료 + 환불 완료까지 차단)
- **신청 즉시 처리** = 세션 강제 revoke (d11 F4) + status=withdrawn + grace_until = now + 30일 + member_blacklist 사전 등록 (이메일·전화 해시)
- **30일 내 복구** → 관리자 CS 1:1 문의 통해 신청 → 관리자가 withdrawal_grace_until UNSET + status=active → member.withdraw.restored 이벤트 발행
- **30일 경과 자동 처리** → 배치 (UC-MEM-U-11) → PII 마스킹 + 이메일·전화번호 해시 보존 (d11 F15/F16)
- **재가입 차단 기간** → 탈퇴 후 30일 + a (구체 기간은 시스템 정책 — d11 F16) → 이메일/전화 해시 매칭 시 가입 차단 (MEM-U-038)
- **소셜 전용 계정의 비번 미보유** → Step 3에서 비번 input 대신 소셜 재인증 (Q1: OTP 또는 OAuth 재인증)
- **마케팅·동의 이력 처리** → PII 마스킹 후 동의 이력은 법적 보존 기간만큼 유지 (개인정보보호법)
- **포인트 음수 잔액 회원 (CS 케이스)** → 탈퇴 신청 차단 + CS 안내 (음수 정산 후 신청)
- **이미 탈퇴 신청 상태 회원 진입** → 본 화면 = "신청 완료 화면" 모드로 전환 + [신청 취소] 노출 (UC-MEM-U-... cancel API)
- **Q-MEM-Q3 정지 회원 탈퇴 정책 미결** → 권장 = 차단 (정지 만료 후 신청 가능) — 사장님 확정 필요

## 7. 권한·접근 제어

- 비로그인 = `/auth/login?next=/mypage/withdraw` 리다이렉트
- 본인 정보만 (IDOR — A-API-002)
- 정지 회원 = 정책 분기 (Q-MEM-Q3 미결, d11 MEM-U-039)
- 블랙리스트 = 본 화면 진입 차단 (이미 탈퇴 처리 흐름)
- 이미 탈퇴 대기 회원 = 본 화면 = 신청 완료 모드 (재신청 차단)
- 신청 즉시 = 세션 revoke → 다른 기기 다음 API 호출 시 401

## 8. SEO · 접근성 · 성능

- **SEO**: `noindex, nofollow`
- **접근성**:
  - Step indicator = `aria-current="step"` + 스크린 리더 안내 ("3단계 중 1단계")
  - 사유 라디오 = `<fieldset>` + `<legend>` ("탈퇴 사유를 선택해주세요")
  - 동의 체크박스 = label-id 명시 연결 + 필수 = `aria-required="true"`
  - 위험 CTA = `role="button"` + `aria-label="탈퇴 신청 (되돌릴 수 없는 작업)"` + 색상 외 텍스트로 위험 표시
  - 재확인 다이얼로그 = `role="alertdialog"` + focus trap + ESC 닫기
  - 비밀번호 input = autocomplete="current-password"
- **성능**:
  - preview API = 단일 호출 (포인트·쿠폰·위시·주문 합산 서버 측 집계)
  - Step 전환 = 클라이언트 라우팅 (페이지 전환 없음, single SPA)
  - 모바일 sticky CTA 미적용 (실수 클릭 방지 — 사장님 결정 강조)
