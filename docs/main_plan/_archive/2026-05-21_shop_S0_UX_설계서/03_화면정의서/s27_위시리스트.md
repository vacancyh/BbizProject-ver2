| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |

| **정렬 (드롭다운)** | ② | URL query `sort` | latest (기본) / popular / soldout_first. 변경 시 fetch 갱신 |
| **[공유 링크 생성] CTA** | ② | `POST /api/wishlist/share` | 모달 → 발급된 share_url 표시 + [카카오톡 공유] [링크 복사] + 만료일 (30일) + 기존 공유 링크 있으면 갱신 |
| **선택 모드 토글** | ② | 회원 액션 | 토글 ON 시 카드에 체크박스 노출 + 하단 액션 바 표시 |
| **위시 카드** | ③ | items[] (실시간 재검증) | 이미지 / 카테고리 eyebrow / 상품명 / 가격 / 상태 배지 / 액션 |
| **♡ active 아이콘** | 카드 좌상 | 회원 액션 | 클릭 시 즉시 위시 해제 (optimistic UI) + 토스트 "위시에서 빠졌어요" + DELETE 호출 |
| **[장바구니 담기] CTA** | 카드 하단 | 재고 ≥ 1 | 옵션 미지정 상품은 옵션 선택 모달 (d14 UC-CRT-U-09). 단일 옵션 상품은 즉시 카트 담기 |
| **[품절] 배지** | 카드 | 재고 = 0 | 회색 처리 + "품절" 배지 |
| **🔔 재입고 알림 토글** | 카드 | `restock_alerts` | 품절 시 노출. 토글 ON 시 `POST /api/wishlist/restock-alert` (sku_id 지정 옵션 — 다중 옵션 상품은 옵션 선택 모달, 단일은 NULL). 채널 동의 OFF 시 안내 모달 |
| **단종 배지** | 카드 | `product.status=discontinued` | "단종" 배지 + 카드 회색 + 카트 담기 비활성. 라인 유지 (자동 삭제 X) |
| **가격 변동 배지 (선택)** | 카드 | `current_price != base_price` | "가격 변동" 캡션 (선택 — d15 §F* 결합) |
| **선택 체크박스** | 카드 좌상 (선택 모드 시) | 회원 액션 | 멀티 선택 |
| **하단 sticky 액션 바** | ④ | 선택 ≥ 1 | "전체 선택" 체크박스 + "N건 선택" 카운트 + [카트 담기] [삭제]. 카트 담기는 d14 UC-CRT-U-09 호출. 삭제는 confirm 모달 후 일괄 DELETE |
| **빈 상태** | ③ 자리 | items.length === 0 | "아직 모은 작은 빛이 없어요" (LUMI 보이스) + `[쇼핑 둘러보기 →]` |
