## 1. 개요

| 항목 | 내용 |
|---|---|
| URL | `/search?q=<검색어>&sort=<>&filter=<>&page=<>` |
| 라우트 타입 | CSR (Client) — 검색 결과 100% 동적. SSR 시 캐시 위험·SEO 미적합 |
| 진입 경로 | (1) 헤더 검색 아이콘(🔍) 클릭 후 키워드 입력·엔터 (2) 헤더 검색바 직접 입력 (3) 홈 검색 placeholder 클릭 (4) 카테고리 목록(s03) 결과 0건 시 "더 넓게 검색" CTA (5) 푸터 검색 링크 (6) 최근 검색어 / 인기 검색어 클릭 |
| 목적 | (1) 키워드 매칭 상품 노출 (상품명·옵션·태그) (2) 빈 결과 시 추천 키워드·인기 상품 노출 (이탈 방지) (3) 필터·정렬로 결과 좁히기 (s03와 동일 UI 재사용) (4) 최근 검색어 / 인기 검색어 노출 (재탐색 유도) |
| 액터 | **전 액터** (비로그인 포함). 최근 검색어는 로컬스토리지 (회원도 동일 — 디바이스별 분리) |
| SEO 인덱싱 | **X** (`<meta name="robots" content="noindex, follow">` + `robots.txt: Disallow: /search`) — **I-03 확정**. 검색 결과는 중복 콘텐츠 / 무한 조합 — SEO 제외 |
| 회원 가드 | 없음 (공개) |

## 4. 상태 (State Matrix)

| 상태 | UI / 동작 |
|---|---|
| **초기 (q 없음)** | URL `?q=` 누락 → 검색바 빈 상태 + 본문에 "검색어를 입력해주세요" + 인기 검색어 + 인기 상품 노출 |
| **로딩 (검색 중)** | 본문 skeleton (필터 패널 유지, 상품 그리드 12개 skeleton) |
| **정상 결과 (1건 이상)** | §3.3 정상 노출 |
| **빈 결과 (0건)** | §3.4 정상 노출 (추천 키워드 + 인기 상품) |
| **검색어 너무 짧음 (< 2자)** | "검색어는 2자 이상 입력해주세요" + 빈 결과와 동일 UI |
| **검색어 너무 김 (> 64자)** | 자동 truncate + 토스트 "64자까지 입력 가능해요" |
| **금칙어 포함** | "다시 검색해주세요" + 빈 결과 UI (금칙어 자체 노출 X) + 운영자 로그 |
| **필터 적용 후 0건** | "검색 결과가 없어요. 필터를 조정해보세요" + [필터 초기화] CTA 강조 |
| **네트워크 오류** | 본문 retry 버튼 + 토스트 |
| **rate limit (검색 너무 많음)** | 분당 30회 이상 시 토스트 "잠시 후 다시 시도해주세요" |
| **자동완성 (입력 중)** | debounce 300ms 후 드롭다운 노출. 결과 0건 시 드롭다운 미노출 |
| **자동완성 키보드 탐색** | ↑/↓ 키로 항목 이동, 엔터로 선택 |
| **최근 검색어 비어 있음** | 섹션 자체 미노출 또는 "검색 기록이 없어요" 캡션 |
| **로컬스토리지 비활성 (privacy mode)** | 최근 검색어 비활성 + 캡션 "검색 기록 저장이 비활성화돼 있어요" |

| **연속 띄어쓰기 / 특수문자만** | "   " / "@#$%" | 빈 결과 처리 (검색어 정규화: trim + 특수문자 제거 권장) |
| **한영 자판 혼동 (e.g. "tjfqj" = "실버")** | 검색 결과 0건 | "혹시 이걸 찾으셨나요? '실버'" 안내 (선택 — s05-Q03) |
| **오타** | "실버바지" (반지 오타) | 유사어 검색 (Edit Distance 2 이하) 자동 제안 (선택 — s05-Q04) |
| **최근 검색어 동기화** | 로그인 시 디바이스 간 동기화? | 권장 미적용 (디바이스별 localStorage). 회원 동기화는 Phase 4 결정 |
| **인기 검색어 — 자동 집계 vs admin 운영** | 자동 집계 (지난 7일 기준 상위 10개) + admin 수동 보정 가능 | Phase 4 (admin 도메인) |
| **검색어 트래킹 (GA4)** | `view_search_results` 이벤트 | 키워드 + 결과 수 + 필터 + 정렬 동봉 (단 개인 식별 정보 비식별) |
| **검색 → 0건 → 1:1 문의** | 사용자 이탈 방지 동선 | 빈 결과 화면에 [1:1 문의하기 →] CTA. 회원 로그인 게이트 |
| **모바일 필터 Bottom Sheet** | s03와 동일 패턴 | 컴포넌트 재사용 — Phase 4 (FE 구현 시) 공유 컴포넌트화 |
| **무한 스크롤 vs [더 보기]** | UX 결정 | s03와 동일 — [더 보기] 권장 (전환 추적 용이). 무한 스크롤은 회수율 낮음 |

## 8. SEO · 접근성 · 성능

### 8.1 SEO (★ noindex)

- `<title>`: `"<검색어>" 검색 결과 | LUMI` (단 결과 페이지는 인덱싱 안 함 — title은 사용자 UX용)
- `<meta name="robots" content="noindex, follow">` (★ I-03 확정)
- `robots.txt`: `Disallow: /search`
- 사이트맵 미포함
- Open Graph 미설정 (공유는 가능하나 SEO 추적 X)
- 검색 결과는 중복 콘텐츠 / 무한 조합 → SEO 제외 (Google 권장사항)

### 8.2 접근성 (WCAG AA / KWCAG 2.2)

- 검색 입력 필드 `<label>` 명시 + `aria-label="검색"`
- 검색 결과 헤더 `<h1>` (검색어 포함, escape 처리)
- 결과 수 변경 `aria-live="polite"` (필터 변경 시)
- 자동완성 드롭다운 `role="listbox"` + 항목 `role="option"` + `aria-activedescendant`
- 키보드 탐색 (자동완성 ↑/↓/Enter/Esc 지원)
- 빈 결과 일러스트 `aria-hidden="true"` + 안내 카피가 본문 의미 전달
- 최근 검색어 chip [×] 버튼 `aria-label="<키워드> 삭제"`
- 추천 키워드 chip `<a>` 태그 (router link)
- Tab 순서: 검색 입력 → 검색 CTA → 필터 → 정렬 → 상품 그리드 → 더 보기 → 최근 검색어 → 인기 검색어
- 컬러 대비 4.5:1 이상

### 8.3 성능 (Core Web Vitals)

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.5s | 검색바 + 결과 헤더 critical. 상품 카드는 first 4개 priority |
| INP | ≤ 200ms | 필터 변경 즉시 optimistic UI (이전 결과 dim + 새 결과 fetch) |
| CLS | ≤ 0.05 | 상품 카드 height 고정, skeleton과 동일 |

- 검색 API는 Redis 5분 캐시 (동일 키워드 조합)
- 자동완성은 debounce 300ms + 결과 60초 캐시
- 인기 검색어는 ISR 30분
- prefetch: 상품 카드 hover 시 s04 prefetch
