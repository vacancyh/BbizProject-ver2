## 1. 개요

| 항목 | 값 |
|---|---|
| URL | `/mypage/chat` (메인) · `/mypage/chat?session={id}` (재진입) |
| 라우트 타입 | App Router (회원 가드) — 단일 화면. WebSocket 또는 SSE 양방향 전송 (T-NF 미결 별도) |
| 진입 경로 | (1) 마이페이지 인덱스(s21) → "실시간 채팅" (2) 마이페이지 사이드 §4.2 "CS → 실시간 채팅" (3) 푸터 고객센터 → "실시간 채팅" (4) 1:1 문의(s31) 화면 상단 "급한 문의는 실시간 채팅 →" 링크 |
| 목적 | 운영시간 내 상담사 1:1 동기 채팅. s31(1:1 문의=비동기)와 책임 분리. 운영시간 외에는 자동으로 1:1 문의 작성 폼으로 fallback (Q-12 권장안 = 평일 10~19 + 토 10~14) |
| 액터 | 로그인 회원 (MEMBER) |
| SEO 인덱싱 | `noindex, nofollow` (마이페이지 전체) |
| s31과의 책임 경계 | s31 = **비동기 비공개 텍스트 CS (SLA 24h)**. 본 s51 = **동기 1:1 채팅 (운영시간 내 상담사 응답 평균 1~3분 목표)**. 운영시간 외 진입 시 본 화면이 s31 작성 폼으로 자동 라우팅 (Q-12 미결 + f17-Q04 권장안 = 자동 전환) |

## 4. 상태 (State Matrix)

| 상태 | 조건 | UI |
|---|---|---|
| 초기 진입 (운영시간 내, 활성 세션 없음) | 운영시간 + 본인 active 세션 0 | "상담을 시작하시려면 메시지를 입력해주세요" + 입력 영역 활성 |
| 세션 시작 진행 중 | POST /sessions 호출 | 스피너 + "상담사 배정 중..." |

## 5. 예외·엣지 케이스

- **동시 다중 세션 시도** → 본인 active 세션이 이미 있을 시 기존 세션으로 라우팅 (`?session={id}`) + 토스트 "기존 상담을 계속 진행합니다"
- **상담사 측 일방 종료** → 시스템 메시지 + 만족도 평가 모달 (사용자 측 종료와 동일 흐름, end_reason=agent_close)
- **첨부 파일 형식 위반** → 클라이언트 차단 + 토스트 "이미지(JPEG/PNG/WebP) 또는 PDF만 첨부 가능합니다"
- **MIME 위변조** → 서버 검증 거부 (A-FILE-001~010)
- **본문 XSS / 금칙어** → 서버 escape + 금칙어는 마스킹 표시 (운영자 로그)
- **회원 측 새로고침** → session_id를 localStorage + URL 양쪽 저장 → 자동 재진입 (메시지 since 파라미터)
- **운영시간 도중 종료 도달 + 메시지 미답** → grace 5분 후 시스템 메시지 "미답 메시지를 1:1 문의로 자동 전환합니다" + s31 신규 문의 생성 + redirect (f17-Q08 권장 = b)
- **상담사 부재 (배정 5분 초과)** → 시스템 메시지 + 대안 안내 "지금 상담사 응답이 지연되고 있습니다. 1:1 문의로 작성하시면 빠른 답변이 가능합니다" + [s31로 이동]
- **transcript 보관 기간 경과 후 다운로드 시도** → 410 GONE + "보관 기간(3년)이 경과해 다운로드할 수 없습니다" (d19 F13, f17-Q05 권장 = a 3년)
- **휴면 회원 진입 시도** → 휴면 해제 안내 (f21-Q10과 일관)
- **외부 채널 fallback** → 본 MVP 범위 외 (카카오 알림톡 채팅 등)

## 6. 연결 도메인·API

| 도메인 | API | 용도 |
|---|---|---|
| d19 chat_sessions | `GET /api/chat/operation-hours` | 운영시간 조회 (public, 캐시 10분) |
| d19 chat_sessions | `POST /api/chat/sessions` | 세션 시작 (운영시간 외 → 423 OFFLINE + s31 fallback) |
| d19 chat_sessions | `GET /api/chat/sessions/{id}` | 세션 상태 조회 (재진입) |
| d19 chat_sessions | `POST /api/chat/sessions/{id}/end` | 사용자 종료 |
| d19 chat_sessions | `POST /api/chat/sessions/{id}/rating` | 만족도 평가 (별점 + 코멘트) |
| d19 chat_sessions | `GET /api/chat/sessions/{id}/transcript` | transcript PDF 다운 (본인+보관기간 내) |
| d19 chat_messages | `GET /api/chat/sessions/{id}/messages?since=` | 메시지 초기 로드 |
| d19 chat_messages | `POST /api/chat/sessions/{id}/messages` | 메시지 전송 (멱등 client_msg_id) |
| d19 chat_messages | `WS /ws/chat/sessions/{id}` | 양방향 실시간 (subscribe + typing + presence) |
| 파일 | `POST /api/uploads` (presigned) | 첨부 (이미지+PDF, 최대 3장 / 5MB) |
| d11 회원 | (세션 middleware) | 본인만 + 정지·블랙리스트 차단 |

> **신규 인프라**: WebSocket 게이트웨이 필요 (또는 SSE 단방향 + POST 응답). T-NF-CHAT 으로 미결 박제 (인프라 트랙).

**공통 에러**: 401 / 403 (본인 아님) / 409 (이미 종료 / 다른 세션 active) / 410 (transcript 만료) / 413 (첨부 크기) / 422 (검증) / 423 (운영시간 외).

- 본인 세션만 조회·메시지 전송 (서버 강제 — A-API-002)

- transcript 다운로드 = 본인만 (보관기간 3년)
- 상담사 측 = s45 (관리자 화면) — 본 화면은 사용자 측 단방향

## 8. SEO · 접근성 · 성능

- **SEO**: `noindex, nofollow`
- **접근성**:
  - 메시지 리스트 `role="log"` + `aria-live="polite"` (신규 메시지 스크린리더 announce)
  - 새 메시지 도착 시 시각 + 청각 알림 (사용자 토글)
  - 입력 textarea = label 명시 + Enter 전송 / Shift+Enter 줄바꿈 안내 캡션
  - 첨부 업로드 = 키보드 접근 가능 (Tab + Enter)
  - 상담사 정보 시스템 메시지 = 별도 `aria-live="assertive"` (배정 announce)
  - 종료 confirm 모달 = focus trap + ESC 닫기
  - 색 대비 — 회원/상담사 말풍선 컬러 + 텍스트 라벨 ("회원" / "상담사")
- **성능**:
  - WebSocket subscribe (재연결 backoff: 1s · 2s · 5s)
  - 메시지 가상 스크롤 (1000건+ 시)
  - 이미지 lazy load + 썸네일 변형
  - 메시지 전송 = optimistic UI (전송 실패 시 재시도 버튼)
