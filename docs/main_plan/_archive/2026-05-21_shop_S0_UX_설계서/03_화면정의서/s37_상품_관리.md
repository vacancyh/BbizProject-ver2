## 1. 개요

| 항목 | 내용 |
|---|---|
| URL | `/admin/products` (목록) · `/admin/products/new` (등록) · `/admin/products/{id}` (수정) |
| 라우트 타입 | CSR — 관리자 액션 빈도 높음. 목록은 SWR + 무한 스크롤 또는 페이지네이션 |
| 진입 경로 | (1) 사이드 메뉴 "상품" 클릭 (2) 대시보드 빠른 액션 [상품 등록] (3) 재고 부족 알림 라우팅 (s38) |
| 목적 | (1) 상품 CRUD (등록·수정·삭제) (2) 옵션 조합·재고 관리 (3) 이미지 다중 업로드 (4) 카테고리 매핑 (5) 노출 ON/OFF (status 전환) (6) 엑셀 대량 등록 (7) 일괄 가격 변경 |
| 액터 | **MANAGER + SUPER** (CS·MARKETER 미진입 — §7) |
| SEO 인덱싱 | X (`<meta name="robots" content="noindex, nofollow">` + `robots.txt: Disallow: /admin/`) |
| 회원 가드 | middleware: admin JWT 검증 + role IN (SUPER, MANAGER) |

## 3. 컴포넌트 명세

### 3.1 목록 화면

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **검색 input (상품명·SKU)** | 필터 바 좌측 | local state → `GET /api/admin/products?q=` | debounce 300ms |
| **카테고리 필터** | 필터 바 | `GET /api/admin/categories` | 단일 선택 |
| **상태 필터** | 필터 바 | static enum (draft·active·sold_out·discontinued) | |
| **재고 필터** | 필터 바 | static (전체·0개·1~5개·6+개) | |
| **[엑셀 다운] CTA** | 액션 바 | `GET /api/admin/products/export` | CSV 다운로드 |
| **[엑셀 업로드] CTA** | 액션 바 | `POST /api/admin/products/bulk-upload` (FormData) | 모달: 파일 선택 → 업로드 → 결과 리포트 (성공 N건 / 실패 M건 + 사유). **Tier 4 §3.3 일괄 처리 표준 5단계** = (1) **dry-run preview** ("성공 예상 N건 / 실패 예상 M건 + 실패 사유표") (2) **이중 확인 Tier 3 (10건+ 또는 가격 변경 포함)** = 사유 20자+ + 텍스트 타이핑 (3) **비동기 job + 진행률 폴링** (SSE/5초 폴링) (4) **결과 리포트 + 실패 건 CSV 다운로드** (재시도용). **최대 10,000건 (초과 시 분할)** + 각 건 독립 트랜잭션 (1건 실패 무영향) |
| **[일괄 가격 변경] CTA** | 액션 바 | `POST /api/admin/products/bulk-price` | 모달: 선택 상품 + % 인상/인하 입력 (PRD-A-048). **Tier 4 §3.3 동일 표준** + **Tier 4 §3.1 SUPER 알림 의무** (가격 변경 = 매출 영향) — Slack #ops 자동 알림 + 적용 전 영향 분석 표시 (영향 상품 수 · 평균 가격 변화 · 예상 매출 영향) |
| **[+상품 등록] CTA** | 액션 바 우측 | static link | `/admin/products/new` 이동 |
| **상품 테이블 (행)** | 본문 | `GET /api/admin/products` | 컬럼: 체크박스 / 사진 (썸네일) / 상품명·SKU / 카테고리 / 가격(원가·판매가·마진율 — PRD-A-038) / 재고 합계 / 상태 / 노출 / 액션 |
| **노출 ON/OFF 토글** | 행 액션 | `PATCH /api/admin/products/{id}` (body: `{ is_visible }`) | 즉시 반영 + 토스트. 캐시 PURGE 자동 (PRD-A-004) |
| **[편집] CTA** | 행 액션 | static link | `/admin/products/{id}` |
| **[복제] CTA** | 행 액션 | `POST /api/admin/products/{id}/duplicate` | 새 상품 생성 + 편집 화면 자동 진입 |
| **[삭제] CTA** | 행 액션 | `DELETE /api/admin/products/{id}` | confirm 모달 → 소프트 삭제 (deleted_at SET, PRD-A-005). 진행 중 주문 영향 없음 |
| **선택 일괄 처리** | 테이블 하단 | bulk API | 체크된 행에 대해 활성화·비활성화·삭제 (확인 모달 + 사유 입력) |
| **페이지네이션** | 테이블 하단 | 페이지 query | 20건/페이지 |

### 3.2 등록·수정 화면

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **A. 기본 정보 폼** | 좌측 본문 | local state | 상품명·카테고리·브랜드·판매가·원가·구매 수량 제한 입력. **판매가 < 원가 차단 (PRD-A-002)** |
| **B. 옵션 조합 (SKU 자동 생성)** | 본문 | local state → `POST /api/admin/products/{id}/options` | 옵션 그룹 추가 (예: 색상) + 값 추가 (실버·골드) → 조합 자동 생성. 각 SKU에 추가금·재고·상태 입력 |
| **B. SKU 일괄 적용** | 옵션 영역 하단 | local state | 전 SKU에 동일 재고·추가금 일괄 적용 (반복 입력 회피) |
| **C. 이미지 다중 업로드 (드래그)** | 본문 | `POST /api/admin/products/{id}/images` (multipart) | 최대 10장 (PRD-A-008). 형식: jpg/png/webp. 용량: 5MB/장. **MIME 위조 차단** (S3 업로드 전 서버 검증). 대표 이미지 1개 ★ 표시 (status=active 전환 시 필수, PRD-A-003) |
| **C. 이미지 순서 변경 (드래그)** | 본문 | `PATCH /api/admin/products/{id}/images/reorder` (PRD-A-009) | 드래그 → 즉시 반영 + 자동 저장 |
| **D. 상세 설명 에디터** | 본문 | local state | 마크다운 또는 rich text (TipTap 권장). XSS escape 의무 (A-INJ-002) |
| **E. 노출 설정** | 본문 | local state | 판매 상태 라디오 (draft → active → sold_out → discontinued, F36 단방향 전이 검증) / 노출 ON/OFF / 노출 예약 시각 |
| **[취소] CTA** | 푸터 | local | 변경 사항 있을 시 confirm 모달 |
| **[임시 저장 draft] CTA** | 푸터 | `POST /api/admin/products` (status=draft) | draft 상태로 저장 (active 검증 X) |
| **[등록] / [수정] CTA** | 푸터 | `POST /api/admin/products` 또는 `PATCH /api/admin/products/{id}` | (1) active 전환 시 대표 이미지·옵션·가격 검증 (2) 캐시 PURGE (3) 감사 로그 INSERT (4) 토스트 "저장됐어요" + 목록 복귀 |

## 5. 예외·엣지 케이스

| ID | 케이스 | 처리 |
|---|---|---|
| **두 관리자 동시 수정** | A·B 동시 편집 → A 저장 후 B 저장 시 | DB 낙관락 (version) 충돌 → B 측 모달 "다른 관리자가 먼저 수정했어요. 새로고침해 주세요" + 재로드 옵션 |
| **이미지 업로드 중 네트워크 끊김** | 일부 이미지만 업로드된 상태 | 토스트 "일부 이미지 업로드 실패" + 실패 이미지 재시도 버튼 |
| **MIME 위조 (jpg 확장자, 실제 exe)** | 서버 magic number 검증 | 거부 + 토스트 "유효하지 않은 이미지" + admin_audit_logs INSERT (보안 의심) |
| **옵션 삭제 후 카트/주문 영향** | 옵션 삭제 → 해당 SKU 카트 보유자 존재 | 정책 분기: (a) SKU만 비활성 (카트 유지, 결제 시 차단) (b) 강제 카트 제거 — 권장 (a) (PRD-A-033~035) |
| **상품 소프트 삭제 + 활성 주문 진행 중** | 삭제 시 진행 주문 영향 | 영향 없음 (snapshot 기반) — 사용자 마이페이지/주문 상세는 정상 표시 (PRD-A-005) |
| **엑셀 업로드 형식 오류 행 다수** | 100건 중 30건 실패 | 성공 70건 처리 + 실패 30건 사유 리포트 CSV 다운로드 (PRD-A-007) |
| **일괄 가격 변경 — 큰 폭 인상 (예: +50%)** | 자동 적용 vs 경고 | 경고 모달 "10% 이상 가격 변경은 신중히 확인해주셔요" + [확인] [취소] |
| **카테고리 한정 쿠폰 보유 상품 카테고리 변경** | 쿠폰 정책 영향 | 경고 모달 + 영향 받는 쿠폰 목록 표시 (PRD-A-045~046) |
| **타임세일 active 상품 가격 변경 시도** | 가격 정합성 깨짐 | 차단 모달 "현재 타임세일 진행 중인 상품은 가격을 수정할 수 없어요. 타임세일을 먼저 종료해주세요" |
| **재고 -1 입력 시도** | DB CHECK 위반 | 인라인 캡션 "재고는 0 이상이어야 해요" + 자동 0으로 보정 (음수 차단, PRD-A-052) |
| **draft 상태 유지 후 자동 정리** | draft + 30일 미수정 시 자동 삭제 | 정책 박제 (s37-Q06) |

## 8. SEO · 접근성 · 성능

### 8.1 SEO

- `<title>`: "상품 관리 | LUMI ADMIN"
- `<meta name="robots" content="noindex, nofollow">`
- `robots.txt`: `Disallow: /admin/`

### 8.2 접근성

- 테이블 `<table>` + `<th scope="col">` + 체크박스 `aria-label="<상품명> 선택"`
- 이미지 드래그 영역 `role="region"` + `aria-label="이미지 업로드 영역"` + 키보드 폴백 (Tab → Enter → 파일 선택)
- 옵션 조합 표 동적 행 추가 → `aria-live="polite"` 안내
- 모달 (삭제 confirm·옵션 영향·낙관락 충돌) `role="dialog"` + focus trap
- 색상으로만 의미 전달 금지 (상태 라디오에 텍스트 함께)
- Tab 순서: 필터 → 액션 바 → 테이블 헤더 (정렬) → 행 → 페이지네이션

### 8.3 성능

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.5s | 테이블 첫 화면 (20행) 우선 렌더. 이미지 lazy |
| INP | ≤ 200ms | 필터 변경 시 debounce + skeleton 유지. 노출 토글 optimistic UI |
| CLS | ≤ 0.1 | 테이블 행 height 고정. 모달 fade-in |

- 무한 스크롤보다 페이지네이션 권장 (관리자 UX — 위치 추적 용이)
- 이미지 업로드는 S3 presigned URL 직접 업로드 (서버 부하 감소)
- 캐시 PURGE는 백그라운드 큐 (응답 차단 X)
