## 1. 개요

| 항목 | 내용 |
|---|---|
| URL | `/admin/settlement` (인덱스) · `/admin/settlement/daily` (일별 탭) · `/admin/settlement/monthly` (월별 탭) — 단일 페이지 라우트 + Query `?tab=` |

| SEO 인덱싱 | X (`robots.txt: Disallow: /admin/`) — meta `noindex, nofollow` |
| 회원 가드 | middleware: admin JWT + MFA 통과 + role IN (SUPER, MANAGER) + admin 시크릿 분리 (A-AUTH-017) |
| 정산 산식 | **순정산 = 매출 - 환불 - PG 수수료 - 정산 보류** — d16 §2.6 settlement_daily 스키마 기준 (d17 §F17 환불 즉시 차감 보장) |

|---|---|---|---|
| **기간 필터** | 필터 바 | local state → query | 시작·종료 일자 (기본: 이번 달 1일~오늘). 빠른선택(오늘/이번주/이번달/지난달/사용자정의) |

## 8. SEO · 접근성 · 성능

### 8.1 SEO

- `<title>`: "정산 | LUMI ADMIN"
- `<meta name="robots" content="noindex, nofollow">`
- `robots.txt`: `Disallow: /admin/` (A-COMP-006 / d21 §F20)

### 8.2 접근성

- 탭 = `role="tablist"` / `role="tab"` / `aria-controls` 매핑 + 키보드 ←/→
- 요약 카드 = `role="article"` + `aria-label` (예: "총 매출 1230만원")
- 차트 = SVG `<title>` + `<desc>` 대체 텍스트 (스크린리더용 데이터 요약)
- 테이블 `<th scope="col">` + 숫자 컬럼 우측 정렬 + `aria-sort` (정렬 가능 컬럼)
- 상태 배지 = 컬러 + 아이콘 + 텍스트 라벨 (예: failed=red+✗+"실패", held=yellow+⏸+"보류")
- 보류 처리 모달 = focus trap + 사유 textarea 자동 포커스 + 사유 길이 카운터 `aria-live="polite"`
- CSV 다운 백그라운드 안내 = `role="status"`
- 숫자 표시 = `<bdi>` 또는 `data-numeric` (RTL 안전 — 한국어 단일이라 영향 없으나 일관성)
- 통화 표시 = 명시적 단위 (₩ 또는 "원") + screen reader용 `aria-label`
- Tab 순서: 탭 → 필터 → 액션 바 → 요약 카드 → 차트 → 테이블

### 8.3 성능

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.5s | 요약 카드 우선 렌더 → 테이블 비동기 |
| INP | ≤ 200ms | 필터 변경 = debounce 500ms + URL Query 갱신 |
| CLS | ≤ 0.1 | 카드·차트·테이블 height 고정 |

- 통합 GET 분리: summary(5초 캐시) / 목록(30초) / by-method(1분) / by-category(1분)
- CSV 다운 10K↑ = 비동기 backend job + 이메일 (s40 패턴 동일)
- 차트 lazy mount (intersection observer)
- 월별 마감 데이터 = 1시간 캐시 (immutable, 마감 후 변경 없음)
- PG 매칭 업로드 = 클라이언트 사이드 파일 검증 (헤더 체크) 후 업로드
