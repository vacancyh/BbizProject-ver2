## 1. 개요

| 항목 | 값 |
|---|---|
| URL | `/mypage/receipts?tab={card_receipt\|tax_invoice}&page=` |
| 라우트 타입 | App Router (회원 가드, 단일 화면 + 탭 분기) |
| 진입 경로 | (1) 마이페이지 인덱스(s21) → "현금영수증·세금계산서" (2) 마이페이지 사이드 §4.2 "CS·증빙 → 현금영수증·세금계산서" (3) 주문 상세(s23)의 "영수증 보기" 링크 → 본 화면 해당 주문 행으로 앵커 이동 |
| 목적 | 회원이 본인 주문의 **결제 영수증(카드 매출전표·취소 전표)** 을 조회·다운로드(PDF)하고, 사업자 회원은 **세금계산서 발급 신청** 을 수행합니다. 카드 단일 결제(토스 MCP, Q-01 확정)이므로 본 화면의 의미가 축소되어 있으며, "현금영수증"은 카드 결제 운영상 대부분 의미 없음(S-Q12 미결) — 정책 결정 전까지는 안내만 표기 |
| 액터 | 로그인 회원 (MEMBER, 사업자 회원은 세금계산서 탭 추가 노출) |
| SEO 인덱싱 | `noindex, nofollow` (마이페이지 전체) |
| 다른 화면과의 책임 경계 | s22(주문 내역)·s23(주문 상세) = 주문·결제 상태 + receipt_url 단건 링크 노출. 본 s52 = 영수증 전수 통합 조회·다운로드 + 세금계산서 신청 워크플로 (다건 묶음 발급 포함) |

> **카드 단일 결제 메모**: Q-01(2026-05-21 확정 — 카드 단일, 토스 MCP)로 무통장·가상계좌·간편결제는 본 MVP 범위 외입니다. 따라서:
> - **현금영수증**: 본래 현금성 결제(무통장·가상계좌·간편결제 현금 모드)에 발급. 카드 결제는 매출전표(영수증)가 카드사 취소 전표로 대체되므로 **현금영수증 발급 기능은 의미 축소** (S-Q12 미결 — 사장님 결정 전까지는 "현재 카드 결제만 운영해 현금영수증 발급은 해당 없음" 안내만 표기)
> - **세금계산서**: 사업자 회원이 부가가치세 매입세액 공제를 위해 신청. **카드 단일이라도 사업자는 신청 가능** (S-Q13 — 사장님 결정 시 운영 ON/OFF)
> - **카드 매출전표**: 모든 카드 결제 시 토스 PG 응답 `receipt_url` 자동 보존 (d17 §2.1, F-PAY-19) — 본 화면이 본인 영수증 단일 조회 source of truth

## 5. 예외·엣지 케이스

- **카드 단일 운영 + 현금영수증 미운영 (S-Q12 미결)** → 본 화면 카드 매출전표 탭만 노출, 안내 박스에 "현금영수증 미운영" 명시
- **환불된 결제의 매출전표** → 원 매출전표 + 환불 취소 전표 양쪽 표시 (F-PAY-19, d17 §2.3 pg_refund_receipt_url)
- **부분 환불된 결제** → 원 매출전표 + 부분 환불 취소 전표 각각 표시 + "부분 환불 N원" 안내
- **포인트 100% 결제 (PG 미호출, F-PAY-18)** → "포인트 결제 (영수증 없음)" 배지 + 매출전표·세금계산서 발급 불가
- **세금계산서 신청 후 환불 발생** → 발급 완료 = "수정 세금계산서 발급 필요 (관리자 검토)" 안내 + 자동 처리 X (s52-Q03)
- **사업자 정보 변경 후 신청** → 신청 시점 사업자 정보 snapshot 보존 (변경 후 과거 신청에는 영향 X)
- **묶음 신청 한도 초과** → 한도(예: 50건/회) 초과 시 클라이언트 차단 + "한 번에 50건까지 신청 가능합니다"
- **PG receipt_url 만료 (토스 URL TTL 정책)** → 본인 다운로드 시 서버에서 캐시된 PDF 응답 (만료 시 PG 재호출 또는 410)
- **0원 결제건의 세금계산서 신청 시도** → 422 + "포인트 결제 건은 세금계산서 발급 불가"
- **세금계산서 발급 후 PDF 보관 기간 경과** → 410 GONE + "발급 후 5년 경과로 다운로드 불가" (전자세금계산서 보관 5년 의무)
- **탈퇴 회원의 과거 영수증** → 30일 유예 내 복구 시 재조회 가능, 유예 종료 시 본인 조회 불가 (관리자 측 보관)

## 8. SEO · 접근성 · 성능

- **SEO**: `noindex, nofollow` (마이페이지 전체)
- **접근성**:
  - 탭 = `role="tablist"` + `aria-selected` + 화살표 키 네비
  - 카드 = `<article>` + 주문번호 = `<h3>` + 결제일 `<time datetime>`
  - 카드 마스킹 표시 = `aria-label="카드 번호 끝 4자리 1234"` (스크린리더 친화)
  - PDF 다운로드 버튼 = `aria-label="매출전표 PDF 다운로드"`
  - 세금계산서 체크박스 = `<input type="checkbox">` + label 명시 + 그룹 `role="group"` `aria-label="신청 대상 선택"`
  - 신청 결과 토스트 = `aria-live="polite"`
- **성능**:
  - 목록 cursor pagination (offset X)
  - PDF 생성 = 서버 캐시 (한 번 생성 후 24h CDN 캐시, F-PAY-25 거래성 보장)
  - 세금계산서 발급 가능 리스트 = 결제 + 환불 join 서버 단일 쿼리 (N+1 차단)

  - PDF 다운로드 버튼 아이콘 (📄 vs 다운로드 ↓ vs 텍스트만)
