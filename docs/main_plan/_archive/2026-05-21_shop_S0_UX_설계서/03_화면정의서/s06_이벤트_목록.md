## 2. 와이어 구조 (섹션 단위)

### 2.1 데스크톱 (1025+, max-width 1440)

```
┌─────────────────────────────────────────────────────┐
│ 헤더 (GNB sticky)                                    │
├─────────────────────────────────────────────────────┤
│ ① 페이지 헤더                                          │
│    H1 "EVENT" + sub "특별한 혜택을 만나보세요" + 우측 [정렬 셀렉트] │
├─────────────────────────────────────────────────────┤
│ ② 탭 헤더 (sticky 아래)                                │
│    [진행중 12] [예정 3] [종료 24]                      │
├─────────────────────────────────────────────────────┤
│ ③ 이벤트 카드 그리드 (3 컬럼)                            │
│    ┌─────────┐ ┌─────────┐ ┌─────────┐         │
│    │ 썸네일    │ │ 썸네일    │ │ 썸네일    │         │
│    │ D-3 배지  │ │ NEW 배지  │ │ 종료 라벨  │         │
│    ├─────────┤ ├─────────┤ ├─────────┤         │
│    │ 제목      │ │ 제목      │ │ 제목      │         │
│    │ 기간      │ │ 기간      │ │ 기간      │         │
│    │ 한줄 카피  │ │ 한줄 카피  │ │ 한줄 카피  │         │
│    └─────────┘ └─────────┘ └─────────┘         │
│    ... (최대 12장 / 페이지)                              │
├─────────────────────────────────────────────────────┤
│ ④ 페이지네이션 (1 · 2 · 3 · ... · N)                   │
├─────────────────────────────────────────────────────┤
│ 푸터                                                   │
└─────────────────────────────────────────────────────┘
```

### 2.2 태블릿 (769~1024)

- 카드 그리드 = **2 컬럼**
- 탭 헤더 = 동일 (가로 스크롤 미적용)
- 정렬 셀렉트 = 페이지 헤더 우측 유지

### 2.3 모바일 (~768)

- 헤더 = 햄버거 + 로고
- 페이지 헤더 = H1 단독 + sub 줄바꿈, 정렬 셀렉트는 탭 헤더 우측에 통합
- 탭 헤더 = 가로 스크롤 (탭 3개라 보통 한 줄)
- 카드 그리드 = **1 컬럼 풀폭**
- 페이지네이션 = "더 보기" 버튼 또는 무한 스크롤 (권장: "더 보기")

## 3. 컴포넌트 명세

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **페이지 헤더 H1·sub** | 최상단 | static | SEO `<h1>` 1개 / sub 카피 "특별한 혜택을 만나보세요" |
| **정렬 셀렉트** | 페이지 헤더 우상단 | URL `?sort=` | (a) 최신순 (기본) (b) 마감 임박순 (진행중 탭만) (c) 인기순 |
| **탭 헤더** | 페이지 헤더 하단 | URL `?tab=` + API 카운트 | `role="tablist"` / [진행중·예정·종료] 3개 + 옆에 카운트 표시 / sticky |
| **이벤트 카드** | 그리드 | `GET /api/events?tab=&page=&sort=` | 썸네일 + 제목 + 기간 (예: "05.21 ~ 05.31") + 한줄 카피 + 상태 배지 |
| **D-3 배지** | 카드 우상단 | 클라이언트 계산 (`end_at - now`) | 진행중 탭만 / 3일 이내 종료 시 빨간 점 + "D-3" |
| **NEW 배지** | 카드 우상단 | `start_at` 기준 | 시작 후 7일 이내 |
| **종료 라벨** | 카드 전체 오버레이 | `status=ended` | 카드 위 회색 반투명 오버레이 + "종료된 이벤트" |
| **페이지네이션** | 그리드 하단 | URL `?page=` | 12건/페이지 (데스크톱) / 모바일은 "더 보기" 버튼 |
| **빈 상태** | 그리드 자리 | API 빈 응답 | 일러스트 + "진행 중인 이벤트가 없어요" + [공지 보러가기] |

## 5. 예외·엣지 케이스

- **시작 전 이벤트 카드 클릭** → s07 진입 시 "이벤트 시작 전이에요 (D-3)" + 콘텐츠 일부만 노출, 연계 쿠폰 발급 버튼 비활성
- **종료된 이벤트 카드 클릭** → s07 진입 가능 (히스토리 보존), 단 쿠폰 발급 버튼 = "종료된 이벤트입니다" 비활성
- **이벤트 노출 기간 종료 즉시 반영 필요** → ISR 1h 캐시. 즉시 반영 필요 시 관리자 캐시 무효화 (ADM-S-003·004) — 본 화면은 ISR 재생성 시점에 자동 비노출
- **카드 썸네일 로딩 실패** → 기본 placeholder 이미지 + alt 텍스트 (이벤트명) 노출
- **외부 검색 인입 (deep link `?tab=ended`)** → 종료 탭 사전 렌더, robots 인덱싱 OK
- **이벤트 카운트 API 실패** → 탭에 카운트 숨김 (탭 자체는 동작)

## 8. SEO · 접근성 · 성능

### 8.1 SEO
- `<title>`: "이벤트 | LUMI — 매일의 작은 빛"
- `<meta name="description">`: "LUMI의 진행 중인 이벤트와 특별한 혜택을 만나보세요."
- OG: image (대표 이벤트 썸네일) · title · description · type=website
- JSON-LD: `ItemList` 스키마 (`itemListElement`에 진행중 이벤트 12개 카드 메타) — A-COMP-007 sitemap 포함
- canonical: `/events` (탭 파라미터 없는 기본 URL)
- robots: `index, follow`

### 8.2 접근성 (WCAG AA / KWCAG 2.2)
- 탭 = `role="tablist"` / `role="tab"` / `aria-selected` / `aria-controls` / 좌우 화살표 키 탐색
- 카드 = `<a>` 태그 단일 (전체 카드 클릭 가능, 키보드 Tab 도달 + Enter)
- 썸네일 `alt` = 이벤트명 (예: "5월 신상품 출시 기념 이벤트")
- D-3 / NEW / 종료 배지 = `aria-label` 명시 (시각만으로 인지하지 않도록)
- 페이지네이션 = `aria-label="페이지 이동"` + 현재 페이지 `aria-current="page"`

### 8.3 성능 (Core Web Vitals)

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.5s | 첫 화면 6장 카드 = `priority` + WebP/AVIF + `next/image` |
| INP | ≤ 200ms | 탭 전환 = 클라이언트 사이드 fetch (전체 리로드 X) |
| CLS | ≤ 0.1 | 카드 썸네일 `aspect-ratio: 4/3` 고정 |

- 페이지네이션 cursor 기반 권장 (page 번호 + 캐시 키)
- 7번째 이후 카드 = lazy loading
