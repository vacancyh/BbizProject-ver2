## 3. 컴포넌트 명세

### 3.1 트리 화면

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **필터 드롭다운 (전체·활성·비활성)** | 액션 바 좌측 | local state → `GET /api/admin/categories?status=` | 단일 선택. 비활성도 관리자만 조회 (CAT-A-011) |
| **[+ 카테고리 등록] CTA** | 액션 바 우측 | static | 등록 모달 오픈 (parent_id=null 기본, "상위 카테고리" 드롭다운에서 변경 가능) |
| **카테고리 트리 (계층)** | 본문 | `GET /api/admin/categories` (트리 응답) | 1단 = 루트 카테고리 / 2단 = 하위 (parent_id). 트리 렌더링 (들여쓰기 + ⠿) |
| **드래그 핸들 ⠿** | 행 좌측 | dnd-kit 또는 react-beautiful-dnd | 드래그 시작 시 행 강조. 드롭 시 (a) 순서 변경 (b) 다른 부모로 이동 모두 지원 |
| **카테고리명 + 슬러그** | 행 본문 | item | "한국어명 (영문슬러그)" 형식. 슬러그는 mono font |
| **매핑 상품 카운트** | 행 우측 | `GET /api/admin/categories` 응답 (product_count) | 클릭 시 `/admin/products?category_id={id}` 이동 (필터 적용 상태) |
| **노출 ON/OFF 토글** | 행 우측 | `PATCH /api/admin/categories/{id}/active` (CAT-A-003) | 즉시 반영 + 토스트. 캐시 PURGE (F4). 비활성 → 사용자 영역 미노출 + 직접 URL 404 (F3) |
| **[수정] CTA** | 행 우측 | static | 수정 모달 오픈 (기존 데이터 채움) |
| **[삭제] CTA** | 행 우측 | `DELETE /api/admin/categories/{id}` (CAT-A-004) | 삭제 confirm 모달 → 상품 매핑 0건일 때만 정상 진행. 매핑 있으면 차단 안내 (F2) |
| **드래그·드롭 저장** | 본문 전체 | `PATCH /api/admin/categories/reorder` (CAT-A-006) | 드롭 시 자동 저장 (디바운스 500ms) + 토스트 "순서·계층 저장됨" + 캐시 PURGE |
| **빈 결과** | 본문 | 카테고리 0건 | "첫 카테고리를 등록해주세요" + [+ 카테고리 등록] 강조 |

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **한국어 카테고리명 input** | 모달 | local state | 50자 이내 (DB CHECK). 빈 값 차단 |
| **영문 슬러그 input** | 모달 | local state + `GET /api/admin/categories/slug-check?slug=` | 영문·하이픈·숫자만 패턴 검증 (F1). 자동 변환 버튼 (한글명 → slug 추천: 예: "반지" → "rings" 매핑 표 + 사용자 편집 가능). 입력 후 debounce 500ms로 중복 검증 → 사용 가능/사용 중 캡션 |

| **[취소] CTA** | 푸터 | local | 변경 사항 있을 시 confirm 모달 |
| **[등록] / [저장] CTA** | 푸터 | `POST /api/admin/categories` 또는 `PATCH /api/admin/categories/{id}` | 검증 (이름·슬러그 패턴·중복·순환 참조) → 저장 → 캐시 PURGE → 토스트 + 모달 닫기 + 트리 갱신 |

## 5. 예외·엣지 케이스

| ID | 케이스 | 처리 |
|---|---|---|
| **두 관리자 동시 트리 재정렬** | 동시 드래그·드롭 | 마지막 저장 우선 (last-write-wins) — 5초 폴링으로 변경 감지 시 토스트 "다른 관리자가 트리를 수정했어요. 새로고침 권장" (s39-Q01) |
| **슬러그 영문 패턴 위반** | "반지", "ring 1" (공백), "ring!" (특수문자) | 인라인 캡션 + [등록] disabled (F1) |
| **슬러그 중복 (다른 카테고리와)** | 시스템 전체 UNIQUE | 인라인 캡션 + 409 응답 (CAT-A-010) |
| **상위 카테고리 — 자기 자손 선택 (순환 참조)** | A → B → A 시도 | 드롭다운 자동 필터 + 서버 검증 (422 응답) |
| **상위 카테고리 — 2단 이미 + 새 하위 추가 시도** | 1-2단 제한 (P4) | 드롭다운 비활성 + 안내 "현재 2단까지만 지원" — Q1 확정 시 갱신 |
| **상품 매핑 있는 카테고리 삭제 시도** | product 도메인 카운트 > 0 | 차단 + 안내 모달 (F2) — 상품을 다른 카테고리로 이동 후 재시도 |
| **상품 매핑 있는 카테고리 비활성 전환** | 사용자 영역 즉시 미노출 (F3) | 정책: 비활성 카테고리의 매핑 상품은 사용자 측 검색·홈에서도 제외 (E-014 정합). 관리자 측은 정상 노출 |
| **카테고리 비활성 → 사용자가 직접 URL `/shop/rings` 접근** | 404 응답 (F3) | s03 카테고리 목록의 404 처리 |
| **카테고리 한정 쿠폰 보유 카테고리 비활성** | coupon_point 도메인 영향 | 경고 모달 + 영향받는 쿠폰 목록 표시 (PRD-A-045~046) — d20과 동일 패턴 |
| **카테고리 thumb 이미지 MIME 위조 (jpg 확장자, 실제 exe)** | 서버 magic number 검증 | 거부 + 토스트 + admin_audit_logs INSERT (보안 의심, A-FILE-002) |
| **드래그 중 네트워크 끊김** | 저장 PATCH 실패 | 토스트 "저장 실패. 원위치로 되돌렸어요" + 트리 rollback |
| **카테고리명 50자 초과** | DB CHECK | 인라인 캡션 "50자 이내로 입력해주셔요" |
| **2단 자식 카테고리에 또 자식 추가 시도** | 1-2단 제한 (P4) | [+] CTA 자동 비활성 |
| **slug 변경 시 사용자 측 SEO 영향** | URL 변경 → 검색 엔진 캐시 | F4 캐시 PURGE + 안내 캡션 "기존 URL은 더 이상 접근 불가합니다" (s39-Q02) |
| **카테고리 삭제 후 외부 사이트에 남은 링크** | 404 응답 + s03의 "다른 카테고리 둘러보기" | s03 §5 처리 |

## 8. SEO · 접근성 · 성능

### 8.1 SEO

- `<title>`: "카테고리 관리 | LUMI ADMIN"
- `<meta name="robots" content="noindex, nofollow">`
- `robots.txt`: `Disallow: /admin/`

### 8.2 접근성

- 트리 `role="tree"` + 각 행 `role="treeitem"` + `aria-expanded`/`aria-level`
- 드래그 핸들 ⠿ `aria-label="<카테고리명> 순서 또는 계층 변경 (드래그)"` + 키보드 폴백 (Tab → Space → 화살표 ↑/↓로 이동, Enter 확정)
- 노출 토글 `<button>` + `aria-pressed` + 텍스트 "활성"/"비활성"
- 모달 (등록·수정·삭제 confirm) `role="dialog"` + focus trap + ESC 종료
- 슬러그 중복 검증 결과 `aria-live="polite"` (사용 가능/사용 중)
- 색맹 대응: 활성·비활성 = 컬러 + 텍스트·아이콘 함께
- Tab 순서: 액션 바 → 트리 1단 → 2단 → ... → 페이지네이션 (필요 시)

### 8.3 성능

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.5s | 트리 전체 1회 fetch (소규모 — 보통 50개 이하). 이미지 lazy |
| INP | ≤ 200ms | 드래그·드롭 optimistic UI (실패 시 rollback) |
| CLS | ≤ 0.1 | 트리 행 height 고정. 모달 fade-in |

- 트리 데이터는 전체 1회 fetch (페이지네이션 불필요 — 카테고리는 보통 < 50건)
- 드래그·드롭 저장은 debounce 500ms (연속 이동 시 호출 통합)
- thumb 업로드는 S3 직접 업로드 (서버 부하 감소)
