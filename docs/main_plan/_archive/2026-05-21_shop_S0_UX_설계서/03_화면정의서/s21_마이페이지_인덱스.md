| 상태 | UI / 동작 |

| **초기 (로딩)** | 환영 인사 + 사이드 메뉴는 즉시 표시, 우측 카드 5개 skeleton |

## 8. SEO · 접근성 · 성능

### 8.1 SEO

- `<title>`: "마이페이지 | LUMI"
- `<meta name="robots" content="noindex, nofollow">`
- `robots.txt`: `Disallow: /mypage/`
- 사이트맵 미포함

### 8.2 접근성 (WCAG AA / KWCAG 2.2)

- 사이드 메뉴 `<nav aria-label="마이페이지 메뉴">`
- 각 요약 카드 `<a>` 또는 `<button>` 형태로 키보드 접근 가능
- 등급 배지 `aria-label="현재 등급 OOO"`
- 상태 카드 (정지/블랙리스트) `role="alert"` + `aria-live="polite"`
- 알림 패널 `<section aria-label="미열람 알림">` + 각 항목 `<a>`
- Tab 순서: 환영 인사 → 사이드 메뉴 → 주문 상태 카드 → 혜택 카드 → 최근 주문 → 알림

### 8.3 성능 (Core Web Vitals)

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.5s | `/api/mypage/summary` 단일 호출 + 환영 인사·사이드 메뉴 즉시 SSR (사이드 메뉴는 회원 무관 정적) |
| INP | ≤ 200ms | 카드 클릭 시 prefetch (Next.js Link prefetch) |
| CLS | ≤ 0.1 | 카드 height 고정 (조건부 영역 ⑤⑥⑦은 표시 전까지 0px) |
