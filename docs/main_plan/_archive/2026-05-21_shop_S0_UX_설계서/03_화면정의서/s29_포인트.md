## 5. 예외·엣지 케이스 (v4 prefix 정합)
- **포인트 원장 음수 잔액 방지** (CPN-U-021): 서버에서 잔액 < 차감 금액 시 `400 INSUFFICIENT_POINT` 응답
- **포인트 동시 사용 race condition** (CPN-U-025): 1,000P 잔액을 2개 탭에서 동시 전액 사용 → 초과 방지
- **소멸 처리 시점** (CPN-U-026): 일 1회 배치, 유효기간 1년 경과 자동 소멸 — 본 화면 잔액은 배치 후 정확
- **소멸 30일 전 알림** (CPN-U-027): 본 화면 잔액 카드의 sale 컬러 트리거
- **100% 사용 결제** (PAY-U-017B): 본 화면에서는 표시만, 결제(s18)에서 PG 미호출 처리
- **포인트 적립 보류 → 적립** (ORD-U-006 / CPN-U-018 이력): 구매확정(d16) 시 PENDING → EARNED 상태 변환, 본 화면 이력에 즉시 반영
- **취소 시 적립 회수** (CPN-U-023 / CPN-U-023B): 주문 취소 시 EARNED → CANCELLED, 잔액 차감 + 관리자 이력에 '복원' 사유 기록
- **반품 환불 시 비례 복구** (CPN-U-024 / CPN-U-024B): 사용 포인트 비례 복구 + 적립 포인트 회수 → 관리자 이력에 '반품회수' 사유 기록
- **반품 후 즉시 잔액 반영** (CPN-U-038): 환불 PG 응답 후 본 화면 잔액 즉시 갱신
- **관리자 수동 지급/차감 후 즉시 반영** (CPN-U-035 / CPN-U-036): 관리자 (CPN-A-024/025) 처리 후 본 화면 잔액 카드 즉시 갱신 + 이력 표시
- **친구 추천 보상 기록** (CPN-U-039 / CPN-U-039B 신규): 추천 보상 지급 시 이력에 '추천보상' 사유 표시
