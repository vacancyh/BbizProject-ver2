### 2.1 멤버십 (`/mypage/membership`)

#### 데스크톱
```
+--------------------------------------------------+
| 마이페이지 사이드바 | 멤버십 등급                |
|                    |                              |
|                    | ┌─ 현재 등급 카드 ──────┐  |
|                    | │ [GOLD]                  │ |
|                    | │ 적립률 3% · 무료배송 ✓ │ |
|                    | │ 누적 구매 320,000원     │ |
|                    | └────────────────────────┘  |
|                    |                              |
|                    | 다음 등급 (VIP) 까지 180,000원 |
|                    | ████████░░░░░░░░ 64%        |
|                    |                              |
|                    | 등급별 혜택 표              |
|                    | (BRONZE/SILVER/GOLD/VIP × 혜택 항목) |
+--------------------------------------------------+
```

#### 모바일
- 사이드바 → 햄버거
- 현재 등급 카드 = 풀폭 + 시각적 강조
- 진행 바 = 풀폭
- 혜택 표 = 가로 스크롤 (등급 컬럼)

## 5. 예외·엣지 케이스

### 5.1 멤버십
- **등급 자동 전환 시점 vs 표시 시점** → 구매확정 이벤트 수신 즉시 재계산 (d11 UC-MEM-U-08) → 본 화면은 실시간 반영
- **부분 취소로 등급 하락** → 다음 화면 진입 시 즉시 반영 + 알림톡 (d11 UC-MEM-U-09) — 본 화면은 표시만
- **등급 수동 조정 (관리자)** → 관리자 사유 표시 안 함 (사용자 노출 X), 등급만 즉시 반영 (MEM-A-006)
- **집계 기간 = 연간 (정책 P13)** → "최근 12개월 누적" 명시 (사용자 오해 방지)
- **VIP 회원 = 진행 바 100%** → "최고 등급" 강조 (다음 등급 표시 숨김)
- **등급별 적립률 정책 변경 직후** → 사용자 진입 시 새 적립률 즉시 반영 (정책 캐시 무효화)
- **등급 쿠폰 자동 발급 실패** → 본 화면은 표시만, 쿠폰함(s28)에서 등급 변경 후 발급 확인

### 5.2 친구 추천
- **추천 코드 노출 방식** → 8자 영문대문자+숫자 (이메일/실명 노출 X)
- **자기 추천 시도 (본인 코드로 본인 가입)** → 서버 검증 차단 (member_id 동일성)
- **다중 계정 어뷰징 (같은 이름·연락처 다수 가입)** → d11 블랙리스트 매칭 + 보상 보류
- **친구 환불 시 보상 회수** → point_transactions(CANCEL) → 잔액 차감 (잔액 음수면 → 다음 적립으로 상쇄 OR 관리자 CS 케이스)
- **친구 탈퇴 시 보상 회수** → 본인 결제 후 탈퇴 = 보상 유지 / 미결제 후 탈퇴 = 보상 없음 (자명)
- **링크 공유 추적** → `?ref=XYZ-AB12` 쿠키 30일 저장 (피추천인 가입 시 자동 매핑)
- **Kakao SDK 차단 (광고 차단기)** → 복사 fallback
- **Q-04 미정 상태** → 권장 정책 "추천인 적립금 5,000원 + 피추천인 환영쿠폰 5,000원" 가정으로 UI 박제 (사장님 확정 후 정책 캐시 갱신)

## 7. 권한·접근 제어

- 비로그인 = 두 라우트 모두 `/auth/login?next=<path>` 리다이렉트

- 추천 코드는 본인만 조회 가능 (타인 코드 추론 차단 = 8자 랜덤 + rate limit)
- 정지 회원 = 조회만, 신규 공유 차단 (어뷰징 방지)
- 블랙리스트 = 접근 차단

## 8. SEO · 접근성 · 성능

- **SEO**: `noindex, nofollow`
- **접근성**:
  - 등급 카드 = `aria-label="현재 등급: GOLD"` (시각적 라벨 외 텍스트 보강)
  - 진행 바 = `role="progressbar"` + `aria-valuenow/min/max`
  - 등급별 혜택 표 = `<table>` + `<th scope="col/row">` + 본인 등급 = `aria-current="true"`
  - 공유 버튼 = 각 채널 명확한 `aria-label` ("카카오톡으로 추천 코드 공유")
  - 추천 이력 마스킹된 닉네임 = `<abbr title="개인정보 보호">홍**</abbr>`
- **성능**:
  - 등급 카드·진행 바 = 단일 API 조합 (등급 + 정책)
  - Kakao SDK = dynamic import (공유 버튼 첫 클릭 시 로드)
  - 추천 이력 = cursor pagination + 마스킹은 서버 측에서 처리 (PII 누출 차단)
  - 추천 코드 = 페이지 진입 시 1회 fetch + 클라이언트 캐시 (변경 없음)
