### 2.2 태블릿 (769~1024)

- 약관 탭 = 동일 (3개라 한 줄)
- 본문 = 1 컬럼 (목차는 상단 셀렉트로 변환)
- 버전 셀렉트 = 페이지 헤더 우측 또는 본문 상단

### 2.3 모바일 (~768)

- 헤더 = 햄버거 + 로고
- 약관 탭 = 가로 스크롤 (탭 3개라 보통 한 줄)
- 버전 셀렉트 = 본문 상단 풀폭
- 목차 = **상단 셀렉트** (`<select>`) 또는 본문 상단 collapsible
- 본문 = 1 컬럼 풀폭 (line-height 1.6+)
- 개정 안내 = 본문 하단 카드
- PDF 다운로드 = 풀폭 버튼

## 4. 상태 (State Matrix)

| 상태 | 조건 | UI |
|---|---|---|
| **초기 (SSG)** | 첫 진입 | 최신 버전 사전 렌더 / 첫 페인트 즉시 |
| **탭 전환** | 사용자 탭 클릭 | URL 라우트 변경 (`/policy/terms` → `/policy/privacy`) — 클라이언트 사이드 네비게이션 |
| **버전 전환** | 사용자 셀렉트 변경 | URL `?v=` 갱신 + 본문 fetch (CSR) 또는 SSG (모든 버전 사전 렌더) |
| **이전 버전 조회** | `?v=` ≠ current | 본문 상단 노란 워터마크 노출 |
| **로딩 (버전 전환)** | API 호출 중 | 본문 영역 스켈레톤 |
| **데이터 OK** | 정상 | §3 정상 |
| **회원 동의 이력 로딩** | 로그인 + API 호출 중 | "동의 이력 확인 중..." |

## 5. 예외·엣지 케이스

- **약관 개정 → 회원 재동의 트리거** → d11 MEM-A-* 정합 / 본 화면은 노출만, 재동의 게이트는 별도 페이지 또는 모달 (로그인 직후 또는 결제 직전)
- **이전 버전 URL 접근** → `?v=v1` 등 / 본문은 정상 노출 + 상단 노란 워터마크 ("이전 버전입니다") + canonical = 최신 버전 (SEO 중복 회피)
- **존재하지 않는 버전** → 404 (예: `?v=v99`)
- **존재하지 않는 type** → 404 (예: `/policy/unknown`)
- **PDF 다운로드 실패** (서버 PDF 생성 오류) → fallback "텍스트 다운로드" 또는 "잠시 후 다시 시도" 안내
- **개정 안내 박스의 비교 링크 (v1 vs v2 diff)** → s12-Q03 결정 / MVP는 변경 요약 텍스트만, diff UI는 후속
- **본문 MD에 외부 링크** → `rel="noopener noreferrer nofollow"` 강제 + 새 탭
- **본문 MD에 `<script>` 등 주입 시도** → 관리자 등록 시 sanitize-html + 렌더 시 2차 sanitize
- **마케팅 수신동의 약관 = 선택 약관** → 회원가입 시 미동의 시에도 가입 가능 / 본 화면 노출은 동일
- **약관 개정일과 적용일 차이** → 본문 상단에 "공지일: YYYY-MM-DD / 적용일: YYYY-MM-DD" 표시 권장 (전자상거래법: 사전 공지 7일 이상)
- **약관 캐시 즉시 무효화 필요 (긴급 개정)** → ISR 24h 한계 / 관리자 캐시 무효화 (ADM-S-003·004) 필수
- **이전 버전 보관 정책** → 영구 보관 (전자상거래법: 분쟁 대비 5년 의무) — 본 화면은 v1까지 노출
- **개인정보처리방침 내 영업양도·합병 안내 (Tier 5 §3.11)** → 처리방침 본문에 "영업양도·합병 시 개인정보 이전" 조항 포함 (개인정보보호법 §27) — 이전 시 30일 전 사전 통보 + 이전 거부 권리 (탈퇴) 안내 의무. 발생 시 별도 알림 페이지 노출 + 본 화면 본문에 항상 사전 박제.
- **마케팅 수신동의 화면 — 광고 표기·야간 차단 안내 (Tier 5 §3.4)** → 마케팅 수신동의 본문 상단에 다음 의무 사항 안내 카드 노출: (1) 광고성 정보는 제목 prefix `[광고]` 표기 (정보통신망법 §50의4) (2) 야간 21:00~08:00 KST 광고 발송 자동 차단 (정보통신망법 §50의5 — 야간 광고는 별도 사전 동의 필요, 본 사이트는 야간 발송 자체 차단) (3) 수신거부 = 본문 1클릭 링크 또는 마이페이지 알림 설정 토글 (즉시 처리) (4) 거래성 알림 (주문·결제·배송)은 수신거부 불가 (법정 의무) (5) 동의 이력 2년 보관.
- **결제·환불 약관 본문 핵심 조항 (Tier 5 §3.8)** → (1) 결제 수단 = 신용카드 (토스페이먼츠) 단일 (2) 4-way 금액 검증 + 멱등성 키 의무 (3) 결제 실패 3회 → 4회째 차단 (24시간) (4) 0원 결제 (포인트 100%) = PG 미호출 + 즉시 paid (5) 단순 변심 14일 / 불량 90일 환불 (6) **부분 환불 비례 배분 + 잔여 < 50,000원 시 배송비 추가 청구 안내 (Tier 1 §3.C)** (7) **다건 부분 처리 지원 안내 (Tier 1 §3.A·B — 다건 교환 그룹 차액 합산 후 추가 결제 또는 환불)** (8) 환불 SLA = 3 영업일 (PG 정책 — Tier 5 §3.8 T5-Q03) (9) 환불 제외 = 사용·훼손·시간 경과로 가치 감소 (10) 7일 초과 시 한국소비자원 분쟁 조정 가능.
- **청소년 보호 정책 본문 핵심 조항 (Tier 5 §3.9)** → (1) 만 14세 미만 가입 차단 (생년월일 검증, 개인정보보호법 §22) (2) 만 14세 이상 19세 미만 = 보호자 동의 권장 + 마케팅 발송 자동 차단 (3) 보호자 동의 가입 흐름은 MVP 외 (Phase 2+) (4) 본 쇼핑몰 = 주얼리 단일 (성인 콘텐츠 없음) (5) 청소년 보호 책임자 명시 (T5-Q04 사장님 결정 영역).
- **약관 시행일 (T5-Q01)** → 본문 상단에 "공지일 / 시행일" 별도 표기. 시행일 = 출시일 또는 가입 페이지 공지일 (사장님 결정 영역, 권장 출시일).
- **약관 변경 재동의 강제 vs 권장 정책 (T5-Q10)** → 불리한 변경 (예: 환불 조건 강화 · 개인정보 수집 항목 추가) = **강제 재동의** (로그인 직후 별도 페이지 리다이렉트, 미동의 시 서비스 제한). 그 외 일반 변경 = 권장 재동의 (마이페이지 배너).

## 8. SEO · 접근성 · 성능

### 8.1 SEO
- `<title>`: "이용약관 | LUMI" / "개인정보처리방침 | LUMI" / "마케팅 수신동의 | LUMI"
- `<meta name="description">`: 각 약관 요약
- OG: image (브랜드 OG) · title · description · type=article
- **JSON-LD `Article` 스키마**: `headline`, `datePublished` (개정일), `dateModified`, `author: { @type: Organization, name: LUMI }`, `publisher`
- canonical: `/policy/{type}` (이전 버전 `?v=` 의 canonical = 최신 버전 — SEO 중복 회피)
- robots: `index, follow` (이전 버전 `?v=` 도 index 허용 — 단 canonical 정책)
- 사이트맵 포함 (전자상거래법 약관 노출 의무)
- hreflang = 한국어 단일 (생략)

### 8.2 접근성 (WCAG AA / KWCAG 2.2)
- H1 페이지당 1개 / H2 약관 조항 / H3 세부 항목
- 약관 탭 = `role="tablist"` / 좌우 화살표 키
- 버전 셀렉트 = `<label>` 명시 ("약관 버전 선택")
- 목차 (사이드바) = `<nav aria-label="약관 목차">` + 키보드 Tab 도달
- 본문 = `<article>` 시맨틱 / line-height 1.6+ / 본문 max-width 900 (가독성)
- 인쇄 = `@media print` (헤더·푸터·탭 숨김, 본문만 출력)
- 노란 워터마크 (이전 버전) = `aria-label` 명시 + 시각만이 아닌 텍스트 안내
- PDF 다운로드 = `aria-label` ("이용약관 v3 PDF 다운로드 — 약 200KB")
- 외부 링크 = `aria-label` (새 창에서 열림 안내)

### 8.3 성능

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.0s | SSG + 정적 텍스트 (이미지 없음) — 첫 페인트 즉시 |
| INP | ≤ 200ms | 인터랙션 거의 없음 (탭·버전 셀렉트만) |
| CLS | ≤ 0.1 | 폰트 swap + 목차 sticky 고정 |

- 본문 폰트 = `next/font` swap
- PDF = 빌드 타임 생성 또는 런타임 캐시 (CDN 7일)
- 이전 버전 = SSG로 전 버전 사전 렌더 (1 type × 5 version 정도 = 부담 없음)
