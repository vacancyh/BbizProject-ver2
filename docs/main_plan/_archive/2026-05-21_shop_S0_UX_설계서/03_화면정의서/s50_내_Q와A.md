- **상위 문서**: `../02_정보구조.md §2.2 §4.2`, `./00_index.md` (Round 4 보강 — §7.4 인벤토리 누락)

## 1. 개요

| 항목 | 값 |
|---|---|
| URL | `/mypage/qna?tab={open\|answered\|secret}&page=` |
| 라우트 타입 | App Router (회원 가드, 단일 화면 + 탭 분기) |
| 진입 경로 | (1) 마이페이지 인덱스(s21) → "내 Q&A" (2) 마이페이지 사이드 §4.2 "내 활동 → 내 Q&A" (3) 상품 상세(s04)의 Q&A 영역에서 "내 작성 글 보기" 링크 |
| 목적 | 회원이 **상품 상세 페이지(s04) Q&A 탭에서 작성한 공개·비밀 질문**의 본인 작성 내역을 한 곳에서 조회·관리합니다. 작성은 본 화면이 아닌 s04 (상품별)에서만 가능합니다 (조회·수정·삭제·재진입만 본 화면 책임) |
| 액터 | 로그인 회원 (MEMBER) |
| SEO 인덱싱 | `noindex, nofollow` (마이페이지 전체) |
| s31과의 책임 경계 | s31 = **1:1 문의 (비공개 CS 채널, category=order/general/product 통합 — 카테고리=product 도 1:1 비공개)**. 본 s50 = **상품 페이지 공개 Q&A 본인 내역 조회** (s04에서 작성된 inquiries 중 `category='product'` + `product_id IS NOT NULL` 필터). 두 화면 모두 d19 `inquiries` 테이블을 공유하지만 가시성·작성 진입점이 다릅니다. 본 화면은 "공개 Q&A 가시 분”을 중심으로 보고, 비밀글은 별도 탭에서 조회만 노출합니다. |

> **명확화 메모**: d19 `inquiries.category` enum 은 `product`/`order`/`general` 3종이며, s31(1:1 문의)은 셋 모두를 다루지만 항상 비공개 CS 채널입니다. s50(내 Q&A)은 그중 `category='product'` 이면서 **s04 상품 페이지에 공개 노출**된 행만 본인 시점에서 정리합니다 (비밀글 탭은 본인 작성 분 한정 조회만 허용 — s31 데이터와 중복 표시될 수 있으나 양쪽 입구가 다름).

+------------------------------------------------------------+
| 마이페이지 사이드바       | 내 Q&A                          |

|  내 리뷰                  | (Q&A 카드 리스트)                |

### 2.2 모바일 (~768)
- 사이드바 → 햄버거 토글
- 탭 = 상단 가로 스크롤 (3 탭 + 카운트 뱃지)
- 카드 = 1열 풀폭, 우상단 상태 뱃지·비밀글 자물쇠 아이콘
- 본문 미리보기 = 2줄 truncate

### 2.3 카드 (목록 항목)
```
+--------------------------------------------------+
| [상품 썸네일 64] 상품명 (링크 → /product/[id])    |
| Q. 본문 미리보기 (2줄 truncate)                    |
| 2026-05-19 작성 · 답변 대기 / 답변 완료 / 🔒 비밀글|
| [원문 보기 →] (상품 페이지 해당 Q&A 앵커 이동)    |
+--------------------------------------------------+
```

## 3. 컴포넌트 명세

| 컴포넌트 | 위치 | 데이터 source | 동작 |
|---|---|---|---|
| 탭 헤더 | 상단 | URL `?tab=` | 답변 대기(open) / 답변 완료(answered) / 비밀글(is_secret=true) — 각 카운트 뱃지 |
| 상품 필터 | 탭 아래 | URL `?product_id=` | 본인 작성 Q&A 가 걸린 상품 (드롭다운 자동완성) — 빈 시 전체 |
| 검색 input | 탭 아래 | URL `?q=` | 본문·상품명 통합 검색 (debounce 300ms) |
| Q&A 카드 | 메인 | `GET /api/me/qna?tab=&product_id=&q=&page=` | 상품 썸네일·상품명 링크·본문 미리보기·작성일·상태·비밀글 아이콘 |
| [원문 보기 →] | 카드 우하단 | static link | `/product/{product_id}#qna-{inquiry_id}` 앵커 이동 (s04 Q&A 탭 자동 펼침) |
| [수정] | 카드 우상단 (open + 7일 내만) | `PATCH /api/inquiries/{id}` | 모달 (제목·본문·is_secret 토글) — 답변 완료 후 비활성 (d19 F10) |
| [삭제] | 카드 우상단 (open + 7일 내만) | `DELETE /api/inquiries/{id}` | confirm 모달 → soft delete (상품 페이지 Q&A 탭에서도 즉시 미노출) |
| SLA 임박 배지 | open 탭 카드 우상단 | 클라이언트 계산 (created_at + 24h - now) | 12h 이내 = "답변 대기" / 24h 초과 = "답변 지연" (s31와 동일 시각 토큰) |
| 페이지네이션 | 하단 | URL `?page=` | 20건/페이지 (cursor) |

> **작성 경로 없음**: 본 화면은 [+ 새 Q&A 작성] CTA 를 제공하지 않습니다. Q&A 작성은 반드시 **s04 상품 상세의 Q&A 탭**에서 진입해야 product_id 가 자동 바인딩됩니다 (UX 룰 — 상품 컨텍스트 없이 Q&A 작성 불가).

## 5. 예외·엣지 케이스

- **상품 삭제(soft delete)된 Q&A** → 상품 썸네일·상품명 = "(판매 종료된 상품)" 마스킹 + [원문 보기 →] 비활성
- **상품 비활성(hidden) 상태 Q&A** → 상품명 옆 "현재 비공개 상품" 배지 + 원문 링크는 유지 (관리자 정책상 노출 허용)
- **공개 Q&A를 사용자가 사후 비밀글 전환 시도** → 금지 (d19 정책 — 비밀/공개 작성 시점 확정, s31-Q05 참조)
- **답변 후 추가 질문 흐름** → 본 화면에서는 불가, "추가 질문은 상품 페이지에서 새 Q&A로 작성해주세요" 안내 (s31-Q01 권장안과 동일 — 단순성)
- **첨부 이미지 포함 Q&A** → 카드 미리보기에 📎 아이콘 표시 + 원문에서 풀 노출
- **금칙어/스팸 자동 hidden 처리된 본인 Q&A** → 카드에 "운영자 검토 중" 배지 + 본문 미리보기 마스킹 + [문의하기 →] (s31)
- **탈퇴 회원 시점 Q&A 보존** → 본인 탈퇴 후 30일 유예 내 복구 시 본 화면에서 다시 조회 가능 (d11 §7.3 `member.withdrawn_completed` 이벤트 시 상품 페이지에서는 "탈퇴한 회원" 마스킹)
- **SLA 초과 (24h)** → 카드에 "답변 지연" 배지 (s31와 동일 컴포넌트 재사용)

## 6. 연결 도메인·API

| 도메인 | API | 용도 |
|---|---|---|
| d19 문의 | `GET /api/me/qna?tab=&product_id=&q=&page=` | 본인 Q&A 목록 (서버 필터 = `member_id=본인 AND category='product'`) |
| d19 문의 | `PATCH /api/inquiries/{id}` | 수정 (open + 7일 내) |
| d19 문의 | `DELETE /api/inquiries/{id}` | 삭제 (open + 7일 내) |
| d19 문의 | `GET /api/inquiries/{id}` | 원문 단건 조회 (수정 모달 진입 시) |
| d12 상품 | (응답 join) products.name·thumbnail·status | 카드 상품 정보 |

> **신규 API**: `GET /api/me/qna` 는 본 화면 전용 신규 엔드포인트로 박제 (Phase 4 기능정의서 f17 인풋). 기존 `GET /api/me/inquiries` 와는 분리해 운영 — `category='product'` + 가시 분 + 본인 필터를 서버 single source of truth 로 강제하기 위함입니다.

**공통 에러**: 401 (미인증) / 403 (본인 아님 — IDOR) / 409 (수정·삭제 잠금) / 422 (검증).

## 8. SEO · 접근성 · 성능

- **SEO**: `noindex, nofollow` (마이페이지 전체)
- **접근성**:
  - 탭 = `role="tablist"` + `aria-selected` + 화살표 키 네비
  - 카드 = `<article>` + 상품명 `<h3>` + 작성일 `<time datetime>`
  - 비밀글 아이콘 = `aria-label="비밀글"` (아이콘 only 금지)
  - 원문 링크 = "상품 상세의 Q&A로 이동" `aria-label`
  - 수정 모달 = focus trap + 첫 입력 자동 포커스 + ESC 닫기
- **성능**:
  - 목록 cursor pagination
  - 상품 썸네일 lazy load + 64px 전용 변형
  - 카드 inline edit 미사용 (모달) — 본문 그리드 reflow 최소
