## 6. 연결 도메인 · API 면 (admin)

### 6.1 도메인

| 도메인 | 사용 영역 |
|---|---|
| admin (d21) | 모든 인증·MFA·세션·잠금·IP 차단·감사 |
| notification | 정지·IP 차단 발생 시 SUPER 알림 (슬랙·이메일) |

### 6.2 API 면

| 엔드포인트 | 메서드 | 응답 | 캐시 |
|---|---|---|---|
| `/api/admin/auth/login` | POST | body: `{ email, password }`. 응답 `{ mfa_required: true, temp_token, ttl: 300 }` 또는 401/423/429 | no cache |
| `/api/admin/auth/mfa/verify` | POST | body: `{ totp_code }` 또는 `{ backup_code }`. 헤더 `Authorization: Bearer <temp_token>`. 응답 access(15분) + refresh(8h) 쿠키 발급 | no cache |
| `/api/admin/auth/mfa/setup` | POST | bearer (최초 로그인 시) | secret + QR URL + 백업 코드 10개 발급. mfa_enrolled_at NULL인 계정만 호출 가능 (ADM-A-006) |
| `/api/admin/auth/mfa/enroll` | POST | bearer + totp_code 검증 → mfa_enrolled_at SET |
| `/api/admin/auth/refresh` | POST | refresh token cookie 검증 → 새 access/refresh 발급 |
| `/api/admin/auth/logout` | POST | bearer → admin_sessions.revoked_at SET |
| `/api/admin/system/ip-blocks/check` | GET | 본 IP 차단 여부 사전 조회 (Step 1 진입 시 호출 권장, UX) |

**공통 에러**: 401 (자격 증명 실패·MFA 오류·temp_token 만료) / 403 (정지 계정·점검모드) / 423 (계정 잠금) / 429 (rate limit·IP 차단).

### 6.3 시크릿·DB 분리 (F1~F2 강제)

- 관리자 JWT 시크릿 = `ADMIN_JWT_SECRET` 환경변수 (사용자 `USER_JWT_SECRET` 와 별도)
- 관리자 DB pool = `sensitive_pool` (사용자 `main_pool` 과 별도 connection)
- 관리자 쿠키 = `Path=/admin` + Domain admin 서브도메인 (Q-T-A1 박제 시) — 사용자 도메인과 공유 금지

- 모달 (정지·잠금·MFA 미등록·점검모드) `role="dialog"` + focus trap + ESC 닫기 X (의도적 — 닫기 시 폼 비활성 유지)
