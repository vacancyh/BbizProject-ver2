|---|---|---|---|

| **쿠폰 통계 카드 (4)** | 탭1 | `GET /api/admin/coupons/stats` | 활성·발급 누적·사용률·만료 예정 |
| **쿠폰 테이블** | 탭1 본문 | `/api/admin/coupons` | 행 액션 [상세][일괄 발급(SUPER)][복제][강제 회수(SUPER)] |

| **이벤트 코드 발행** | 탭2 | `POST /api/admin/coupon-codes` | 1 코드 N회 사용형. coupon_id 매핑 + max_uses + expires_at + 코드 자동 생성 (16자 영문대문자+숫자) — CPN-A-005 |
| **이벤트 코드 테이블** | 탭2 본문 | `GET /api/admin/coupon-codes` | code · 연결 쿠폰 · max_uses · used_count · expires_at · 액션 [비활성][삭제] |
| **포인트 — 회원별 원장 검색** | 탭3 서브탭1 | `GET /api/admin/points/members/{id}/transactions?type=&from=&to=` | 회원 ID/이메일 → 타입별 (EARN/USE/EXPIRE/CANCEL/ADMIN_ADJUST) — **CPN-A-026** (포인트 지급 이력 사유별 집계: 주문적립/취소복원/반품회수/수동지급/소멸) |
