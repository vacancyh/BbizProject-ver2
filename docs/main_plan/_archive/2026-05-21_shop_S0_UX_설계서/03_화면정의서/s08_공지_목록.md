## 2. 와이어 구조 (섹션 단위)

### 2.1 데스크톱 (1025+, max-width 1200)

```
┌─────────────────────────────────────────────────────┐
│ 헤더 (GNB sticky)                                    │
├─────────────────────────────────────────────────────┤
│ ① 페이지 헤더 (H1 "공지사항" + 우측 검색바)              │
├─────────────────────────────────────────────────────┤
│ ② 카테고리 탭 (가로)                                   │
│    [전체 47] [일반 32] [점검 8] [이벤트 7]              │
├─────────────────────────────────────────────────────┤
│ ③ 공지 리스트 (테이블 형식)                              │
│    ┌─────────────────────────────────────────┐ │
│    │ [📌] [점검] 5월 점검 안내       2026.05.21  │ │  ← 고정 + 카테고리 + 제목 + 일자
│    │ ----------------------------------------│ │
│    │ [📌] [일반] 배송지 정책 변경    2026.05.18  │ │
│    │ ----------------------------------------│ │
│    │ [이벤트] 신상 출시 사전 안내    2026.05.15  │ │
│    │ ----------------------------------------│ │
│    │ [일반] 5월 휴무 안내            2026.05.10  │ │
│    │ ... (15건 / 페이지)                       │ │
│    └─────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────┤
│ ④ 페이지네이션 (1 · 2 · 3 · ... · N)                   │
├─────────────────────────────────────────────────────┤
│ 푸터                                                   │
└─────────────────────────────────────────────────────┘
```

### 2.2 태블릿 (769~1024)

- 테이블 폭 = 100% 유지
- 검색바 = 페이지 헤더 하단 좌측 풀폭
- 카테고리 탭 = 가로 스크롤

### 2.3 모바일 (~768)

- 헤더 = 햄버거 + 로고
- 테이블 → **카드 리스트 변환**: 각 행이 카드 1장 (카테고리 배지 + 제목 + 일자 세로 스택)
- 고정 공지 = 상단 별도 섹션 (배경색 살짝 강조)
- 검색바 = 페이지 헤더 하단 풀폭
- 페이지네이션 = "더 보기" 버튼

## 3. 컴포넌트 명세

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **H1 "공지사항"** | 최상단 | static | SEO `<h1>` 1개 |
| **검색바** | 페이지 헤더 우상단 | 클라이언트 → URL `?q=` | placeholder "공지 검색" / 엔터 또는 [🔍] 클릭 시 검색 / 최소 2자 |
| **카테고리 탭** | 헤더 하단 | URL `?category=` + API 카운트 | `role="tablist"` / 전체·일반·점검·이벤트 4개 + 카운트 표시 / 점검은 점검모드 시 배지 강조 |
| **공지 행 (테이블 row)** | 메인 | `GET /api/notices?category=&page=&q=` | 좌: 📌 고정 아이콘 / 카테고리 배지 / 제목 (클릭 → s09 이동) / 일자 (YYYY.MM.DD) |
| **고정 공지 (sticky)** | 리스트 최상단 | `is_pinned=true` (관리자 지정) | 카테고리 무관 항상 최상단 / 배경 살짝 강조 / 카테고리 필터 시에도 노출 |
| **신규 배지 (N)** | 제목 우측 | `created_at` 7일 이내 | 빨간 점 + "N" |
| **페이지네이션** | 리스트 하단 | URL `?page=` | 15건/페이지 (데스크톱) / 모바일은 "더 보기" |
| **빈 상태** | 리스트 자리 | API 빈 응답 | "검색 결과가 없습니다" + [검색어 초기화] |
| **카테고리 배지** | 각 행 좌측 | `notice.category` | 일반(회색) / 점검(주황) / 이벤트(민트) |

## 4. 상태 (State Matrix)

| 상태 | 조건 | UI |

| **초기 (SSG)** | 첫 진입 | 사전 렌더된 전체 탭 + 1페이지 |

## 5. 예외·엣지 케이스

- **검색어에 SQL 인젝션 시도** → 서버 측 파라미터 바인딩 강제 (A-INJ-001)
- **검색어에 XSS 시도** → 화면 표시 시 자동 escape (React 기본)
- **고정 공지 5개 초과** → 관리자 등록 단계에서 차단 (관리자 화면) — 본 화면은 모두 표시
- **점검 카테고리 공지 + 점검모드 동시** → 본 화면은 점검모드 리다이렉트 우선 / 점검 종료 후 정상 노출
- **공지 즉시 노출 필요 (긴급 점검 등)** → ISR 1h 캐시 한계 / 관리자 캐시 무효화 (ADM-S-003·004) 필수
- **deep link `?q=` 검색 인입** → 검색 결과 페이지 사전 렌더 X (CSR), robots 인덱싱 X 권장 (검색 결과 noindex)
- **카테고리·검색어 동시 적용** → AND 조건 (예: 점검 카테고리 + "5월" 검색)

## 8. SEO · 접근성 · 성능

### 8.1 SEO
- `<title>`: "공지사항 | LUMI"
- `<meta name="description">`: "LUMI의 최신 공지사항과 안내를 확인하세요."
- OG: image (브랜드 OG) · title · description · type=website
- JSON-LD `ItemList` 스키마 (`itemListElement` 최대 10건)
- canonical: `/notice` (기본)
- robots: `index, follow` (단 검색 결과 `?q=` 는 noindex 권장)

### 8.2 접근성 (WCAG AA / KWCAG 2.2)
- 검색바 = `<label>` 명시 ("공지 검색")
- 탭 = `role="tablist"` / 좌우 화살표 키
- 테이블 = `<table>` + `<th scope="col">` (모바일 카드는 `<article>`)
- 고정 공지 = `aria-label="고정 공지"`
- 카테고리 배지 = `aria-label` (색상만이 아닌 텍스트로 카테고리 인지)
- 페이지네이션 = `aria-label="페이지 이동"` + `aria-current="page"`

### 8.3 성능

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.0s | 테이블만 (이미지 없음) — 텍스트 첫 페인트 빠름 |
| INP | ≤ 200ms | 검색 debounce 300ms |
| CLS | ≤ 0.1 | 테이블 row 높이 고정 |

- 검색 결과 캐시 LRU (클라이언트 1분)
