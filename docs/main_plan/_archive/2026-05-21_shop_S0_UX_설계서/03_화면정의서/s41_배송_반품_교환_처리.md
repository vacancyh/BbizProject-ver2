## 8. SEO · 접근성 · 성능

### 8.1 SEO

- `<title>`: "배송·반품·교환 처리 | LUMI ADMIN"
- `<meta name="robots" content="noindex, nofollow">`
- `robots.txt`: `Disallow: /admin/` (A-COMP-006 / d21 F20)

### 8.2 접근성

- 테이블 `<th scope="col">` + 정렬 가능 컬럼 `aria-sort`
- 탭 = `role="tablist"` / `role="tab"` / `aria-controls` 매핑 + 키보드 ←/→ 이동
- 서브 탭 동일 패턴
- 운송장 단건 등록 모달 — focus trap + 첫 입력(주문번호) 자동 포커스
- 검수 모달 — focus trap + 라디오 그룹 `aria-required="true"` + 사유 textarea `aria-multiline="true"`
- 이미지 lightbox — ESC 종료 + 화살표 키 ← → 이전/다음
- 색맹 대응: 상태 배지 = 컬러 + 아이콘 + 텍스트 라벨 (예: shipping=blue+🚚+"발송중", 지연=yellow+⚠+"지연 5일")
- ⚠ 경고 행 — `role="alert"` (스크린리더 즉시 안내)
- webhook 모니터 패널 = `role="complementary"` + 30초 갱신 시 `aria-live="polite"`
- Tab 순서: 탭 → 필터 → 액션 바 → 테이블 → 사이드 패널 → 페이지네이션

### 8.3 성능

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.5s | 테이블 첫 50행 우선. KPI는 별도 SWR (1분) |
| INP | ≤ 200ms | 운송장 단건 등록 optimistic UI (실패 시 rollback) |
| CLS | ≤ 0.1 | 테이블 height 고정 + 사이드 패널 슬롯 고정 |

- 통합 GET (배송 목록 + KPI) — 별도 엔드포인트 분리, 캐시 다르게 (목록 30초 / KPI 5초)
- CSV 업로드 100건 초과 = 백그라운드 처리 (s40 패턴 동일)
- 이미지 lightbox = lazy load + 썸네일/원본 분리
- webhook 모니터 폴링 30초 (s49 SSE 검토는 Q-NF04 미결 — 비용 trade-off)
