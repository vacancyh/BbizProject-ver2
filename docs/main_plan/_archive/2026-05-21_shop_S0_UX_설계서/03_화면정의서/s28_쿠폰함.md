## 1. 개요
| 항목 | 값 |
|---|---|
| URL | `/mypage/coupons?tab={available|used|expired}` |
| 라우트 타입 | App Router (인증 게이트) |

## 2. 와이어 구조

### 데스크톱 (1024px+)
```
+-------------------------------------------------+
| [Header: GNB + 마이페이지 메뉴]                  |
+-------------------------------------------------+
| 마이페이지 사이드바  | 쿠폰함                    |
|  주문/배송           | [보유 12] [사용 8] [만료 5]|
|  취소/반품/교환      |---------------------------|
|  리뷰/문의           | [쿠폰 등록] (코드 입력)    |
|  ▶ 쿠폰함 (active)   |---------------------------|
|  포인트              | (쿠폰 카드 리스트)         |
|  위시리스트          |                           |
|  ...                 |                           |
+-------------------------------------------------+
```

### 태블릿/모바일
- 사이드바 → 햄버거
- 탭 = 상단 가로 스크롤
- 쿠폰 카드 = 1열 풀폭

## 3. 컴포넌트 명세

| 컴포넌트 | 위치 | 데이터 source | 동작 |
|---|---|---|---|
| 탭 헤더 | 상단 | URL `?tab=` | 보유/사용/만료 분기 + 카운트 표시 |
| 쿠폰 등록 입력 | 보유 탭만 | `POST /api/coupons/redeem` | 코드 16자 입력 + [등록] |
| 쿠폰 카드 | 메인 | `GET /api/coupons?tab=` | 쿠폰명·할인·최소주문·만료일·대상 |
| D-3 만료 배지 | 카드 우상단 | 클라이언트 계산 | 빨간 점 + "D-3" 텍스트 (보유 탭만) |
| [사용처 보기] 링크 | 카드 하단 | — | `target` 카테고리/상품 페이지로 이동 |
| 정렬 셀렉트 | 우상단 | URL `?sort=` | 만료일 가까운 순(기본) / 발급일 / 할인 큰 순 |
| 페이지네이션 | 하단 | URL `?page=` | 20건/페이지 |

## 4. 상태 (State Matrix)

| 상태 | 조건 | UI |
|---|---|---|
| 정상 | 쿠폰 1개 이상 | 카드 리스트 |

| 등록 실패 (만료/무효) | redeem 400 | 토스트 "유효하지 않은 쿠폰 코드입니다" |

## 5. 예외·엣지 케이스
- **E-006 (쿠폰 코드 위변조 시도)**: 16자 영문대문자+숫자 정규식 클라이언트 + 서버 이중 검증

- **사용 쿠폰 환불 시 복원**: 주문 취소 시 자동 복원 (d20 PNT-S-009) — 본 화면 사용→보유 이동
