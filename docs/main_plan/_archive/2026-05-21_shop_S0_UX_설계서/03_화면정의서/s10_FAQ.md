## 2. 와이어 구조 (섹션 단위)

### 2.1 데스크톱 (1025+, max-width 1200)

```
┌─────────────────────────────────────────────────────┐
│ 헤더 (GNB sticky)                                    │
├─────────────────────────────────────────────────────┤
│ ① 페이지 헤더                                          │
│    H1 "자주 묻는 질문" + sub "궁금한 점을 빠르게 해결하세요"  │
│    우측 검색바 [🔍 FAQ 검색]                            │
├─────────────────────────────────────────────────────┤
│ ② 카테고리 탭 (가로 sticky)                              │
│    [전체 87] [주문 24] [배송 18] [반품·교환 15]          │
│    [결제 12]  [회원 11]  [기타 7]                       │
├─────────────────────────────────────────────────────┤
│ ③ FAQ 아코디언 (수직 리스트)                             │
│    ┌─────────────────────────────────────────┐ │
│    │ [주문] Q. 주문 후 취소는 언제까지 가능한가요?   ▼  │
│    │   A. 결제 완료 후 배송 준비 전(상품 출고 전)까지...│
│    │      (도움이 되었나요? [👍 32] [👎 2])         │
│    ├─────────────────────────────────────────┤
│    │ [배송] Q. 배송은 얼마나 걸리나요?            ▶  │
│    ├─────────────────────────────────────────┤
│    │ [반품·교환] Q. 단순 변심도 반품 가능한가요? ▶  │
│    │ ... (15건 / 페이지, "더 보기" 버튼)            │
│    └─────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────┤
│ ④ 하단 CTA "원하는 답변을 찾지 못하셨나요?"               │

├─────────────────────────────────────────────────────┤

└─────────────────────────────────────────────────────┘
```

### 2.2 태블릿 (769~1024)

- 카테고리 탭 = 가로 스크롤 (7개 다 안 들어가면)
- 검색바 = 페이지 헤더 하단 풀폭 좌측
- 아코디언 = 동일 (텍스트 크기 약간 축소)

### 2.3 모바일 (~768)

- 헤더 = 햄버거 + 로고
- 페이지 헤더 = H1 단독 + sub 줄바꿈
- 검색바 = 페이지 헤더 하단 풀폭
- 카테고리 탭 = 가로 스크롤 (탭 7개, 좌측 [전체] sticky 권장)
- 아코디언 = 동일 (질문 텍스트 2줄 ellipsis 가능)
- 하단 CTA = 풀폭 2 버튼 세로 스택

## 3. 컴포넌트 명세

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **H1 "자주 묻는 질문"** | 최상단 | static | SEO `<h1>` 1개 |
| **검색바** | 페이지 헤더 우상단 | URL `?q=` | placeholder "FAQ 검색 (예: 배송)" / 엔터 또는 [🔍] 클릭 시 검색 / 최소 2자 / debounce 300ms |
| **카테고리 탭** | 헤더 하단 sticky | URL `?category=` + API 카운트 | `role="tablist"` / 전체·주문·배송·반품·교환·결제·회원·기타 7개 + 카운트 |
| **FAQ 아이템 (아코디언)** | 메인 | `GET /api/faqs?category=&q=&page=` | `<details><summary>` 또는 ARIA disclosure 패턴 / 클릭 시 펼침/접힘 (단일 열림 또는 다중 열림 — Q01) |
| **카테고리 배지** | 각 아이템 좌측 | `faq.category` | 텍스트 라벨 (배지 컬러는 디자인 트랙) |
| **답변 본문** | 펼쳐진 영역 | `faq.answer` (MD 렌더 — XSS escape 강제) | MD → HTML 변환 (sanitize-html / DOMPurify) / 링크는 새 탭 |
| **피드백 버튼** | 답변 하단 | `POST /api/faqs/{id}/feedback` | [👍 도움됨] [👎 안 됨] 1회만 가능 (localStorage `faq_voted_{id}`) / 카운트 즉시 반영 |
| **딥링크 자동 펼침** | URL `?open={id}` | URL 파라미터 | 진입 시 해당 아이템 자동 펼침 + 스크롤 이동 (smooth) |
| **검색 하이라이트** | 질문·답변 텍스트 | 클라이언트 | `?q=` 일치 텍스트 `<mark>` 강조 |
| **빈 상태** | 리스트 자리 | API 빈 응답 | "검색 결과가 없습니다. 다른 키워드로 시도하거나 1:1 문의를 이용해주세요" + [1:1 문의하기] |
| **더 보기 버튼** | 리스트 하단 | URL `?page=` | 15건씩 추가 로드 (페이지네이션 대체) |
| **하단 CTA 카드** | 리스트 하단 | static | [1:1 문의하기] → `/mypage/inquiries/new` (비로그인 시 로그인 후 복귀) / [실시간 채팅 시작] → `/mypage/chat` (운영시간 외 시 안내 — s51 정합) |

## 5. 예외·엣지 케이스

- **검색어 SQL 인젝션 시도** → 서버 측 파라미터 바인딩 강제 (A-INJ-001)
- **검색어 XSS 시도** → React escape + `<mark>` 하이라이트 시도 텍스트 sanitize
- **MD 답변 본문에 `<script>` 삽입 시도** → 관리자 등록 단계에서 sanitize-html 차단 + 본 화면 렌더 시 2차 sanitize
- **딥링크 `?open={id}` 의 id 가 존재하지 않거나 비공개** → URL 파라미터 무시 + 상단부터 표시
- **딥링크 `?open={id}` 의 id 가 다른 카테고리** → `?category=` 도 자동으로 해당 카테고리로 전환
- **카테고리 즉시 추가 필요** → 본 화면은 4종 + 기타 6종 = 7종 고정 (s10-Q03) / 관리자가 카테고리를 추가하려면 우선 본 화면 enum 코드 배포 필요
- **답변 길이 1000자 초과** → 펼쳐진 영역 스크롤 활성화 (max-height) 또는 "전체 보기" 링크
- **피드백 어뷰징 (동일 IP 다중)** → localStorage 1차 차단 + 서버 IP+UA 해시 24h 1회 (관리자 통계 신뢰성)
- **점검 카테고리 공지와 혼동 우려 (예: 점검 FAQ + 점검모드)** → 점검모드 시 본 화면 자체 리다이렉트 (ADM-S-007)
- **외부 검색 인입 (`?q=` 딥링크)** → 검색 결과 자체는 SSG 안됨 (CSR), robots `noindex` 권장 (검색 결과)
- **본문 내 외부 링크** → `rel="noopener noreferrer nofollow"` 강제

## 8. SEO · 접근성 · 성능

### 8.1 SEO
- `<title>`: "자주 묻는 질문 (FAQ) | LUMI"
- `<meta name="description">`: "LUMI의 주문·배송·반품·결제·회원 관련 자주 묻는 질문을 빠르게 확인하세요."
- OG: image (브랜드 OG) · title · description · type=website
- **JSON-LD `FAQPage` 스키마** — `mainEntity` 에 카테고리 전체 또는 카테고리 상위 N개 (Google 리치 결과 노출 핵심)
- canonical: `/faq` (기본 / 카테고리 파라미터는 canonical 자기 자신)
- robots: `index, follow` (검색 결과 `?q=` 는 noindex 권장)
- 사이트맵 포함 (A-COMP-007)

### 8.2 접근성 (WCAG AA / KWCAG 2.2)
- 아코디언 = `<button aria-expanded="false" aria-controls="answer-{id}">` 패턴 또는 `<details>` 시맨틱
- 검색바 = `<label>` 명시 ("FAQ 검색")
- 탭 = `role="tablist"` / 좌우 화살표 키 탐색
- 피드백 버튼 = `aria-label="도움이 되었어요"` / `aria-pressed` (투표 후)
- 카테고리 배지 = `aria-label` (색상만이 아닌 텍스트로 인지)
- 답변 본문 = 키보드 Tab 도달 + 내부 링크 포커스 가능
- 펼침 애니메이션 = `prefers-reduced-motion` 존중

### 8.3 성능

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.0s | 정적 텍스트 (이미지 없음) — 첫 페인트 빠름 |
| INP | ≤ 200ms | 펼침/접힘 즉시 / 검색 debounce 300ms |
| CLS | ≤ 0.1 | 아코디언 펼침 시 layout shift 허용 (max-height 트랜지션) |

- 검색 결과 클라이언트 캐시 LRU (1분)
- MD → HTML 렌더 = 빌드 타임 (SSG) 처리 권장
