## 8. SEO · 접근성 · 성능

### 8.1 SEO

- `<title>`: "장바구니 | LUMI"
- `<meta name="robots" content="noindex, nofollow">`
- `robots.txt`: `Disallow: /cart`
- 사이트맵 미포함

### 8.2 접근성 (WCAG AA / KWCAG 2.2)

- 체크박스 `<label>` 명시 ("상품 선택" / "전체 선택")
- 수량 −/+ 버튼 `aria-label`
- × (삭제) 버튼 `aria-label="삭제"` (아이콘만 있으므로)
- Tab 순서: 진행 단계 → 헤더 (전체 선택, 선택 삭제) → 상품 행 → 무료배송 박스 → 쿠폰 입력 → 주문하기
- 가격 변동 / 품절 알림은 `aria-live="polite"`
- 모달 (선택 삭제 confirm, 정지 안내) `role="dialog"` + focus trap + ESC 닫기

### 8.3 성능 (Core Web Vitals)

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.5s | 카트 상품 사진 lazy 아닌 즉시 로드 (1st viewport) |
| INP | ≤ 200ms | 수량 −/+ 클릭 시 optimistic UI (즉시 반영, 실패 시 rollback) |
| CLS | ≤ 0.1 | 상품 행 height 고정, 요약 카드 sticky 영역 고정 |

- cart_validate는 페이지 진입 시 1회만 호출 (이후는 사용자 액션 시 검증)
- 쿠폰 입력은 debounce 500ms
