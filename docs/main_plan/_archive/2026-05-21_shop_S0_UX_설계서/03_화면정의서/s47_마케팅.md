```
캠페인 작성 폼 (4 step wizard):
Step 1. 기본 (제목·설명·채널 선택 — 이메일/SMS/카카오)
Step 2. 세그먼트 (기존 선택 또는 신규 조건 — 미리보기 카운트)
Step 3. 메시지 (템플릿 선택 또는 직접 작성 — 미리보기 + variable placeholder)
Step 4. 발송 (즉시 / 예약 + 동의·수신거부 검증 결과 + 예상 발송수·예상 비용 + [발송 요청])

대규모 발송 모달 (10만 회원+):
- MANAGER 승인 요청 + 사유 + 이중 확인
- 분할 발송 옵션 (1만/batch × 10 batch)
```

| **세그먼트 새로고침 — 1만+ 회원** | 비동기 작업 + 완료 시 알림 (long polling) |
