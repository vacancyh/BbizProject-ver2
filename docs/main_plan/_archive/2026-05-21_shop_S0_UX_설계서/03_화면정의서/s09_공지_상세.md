### 2.2 태블릿 (769~1024)

- 본문 max-width 700, 좌우 padding 24px
- 하단 액션 = 3 버튼 가로 유지 (이전/목록/다음)
- 관련 공지 카드 = 100% 폭

### 2.3 모바일 (~768)

- 헤더 = 햄버거 + 로고
- Breadcrumb = 가로 스크롤 또는 마지막 2단계만 ("공지사항 > [제목]")
- 본문 = 좌우 padding 20px
- 공유 아이콘 = 우상단 햄버거 메뉴로 묶음 또는 본문 하단 가로 스크롤
- 하단 액션 = "이전/목록/다음" 3 버튼 가로 균등 분할 (icon + 짧은 텍스트)
- 관련 공지 = 세로 카드 리스트 (제목 우선 2줄 + 일자)
- sticky CTA 없음 (콘텐츠 페이지 표준)

## 3. 컴포넌트 명세

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **Breadcrumb** | 최상단 | static + URL + `notice.category` | 홈 > 공지사항 > [카테고리] > [제목] / 각 단계 클릭 시 해당 페이지 이동 (카테고리 클릭 → `/notice?category={cat}`) |
| **카테고리 배지** | 메타 좌상단 | `notice.category` | 일반(회색) / 점검(주황) / 이벤트(민트) — s08과 동일 색상 |
| **고정 배지 (📌)** | 카테고리 배지 우측 | `notice.is_pinned` | 고정 공지일 때만 노출 |
| **신규 배지 (N)** | 고정 배지 우측 | `created_at` 7일 이내 | 빨간 점 + "N" — s08과 동일 정책 |
| **H1 제목** | 메타 중앙 | `notice.title` | SEO `<h1>` 단일 / max 100자 / 줄바꿈 허용 |
| **메타 sub** | H1 하단 | `notice.created_at` / `notice.view_count` | "작성일 YYYY.MM.DD · 조회수 N" 표시 — 조회수 1,000+ 시 "1.0K" 약어 |
| **공유 아이콘 3종** | 메타 우측 | 클라이언트 | 카카오 (SDK) · 링크 복사 (`navigator.clipboard`) · 인쇄 (`window.print`) |
| **공지 본문 (MD/HTML)** | 메타 하단 | `notice.content_html` (sanitize 후) | DOMPurify로 XSS 차단 / `<script>·<iframe>` 금지 / 본문 이미지 lazy load |
| **첨부 파일 리스트** | 본문 하단 | `notice.attachments[]` | 파일명·확장자·용량 표시 / [다운로드] 클릭 → `GET /api/notices/[id]/attachments/[idx]` (Content-Disposition: attachment) |
| **이전/다음 공지 네비** | 하단 액션 | `GET /api/notices/[id]/sibling` | 같은 카테고리 내 이전·다음 ID 조회 / 없으면 비활성 (회색) |

| **404 페이지** | (별도) | `not-found.tsx` | 존재하지 않는 ID 진입 시 "존재하지 않는 공지입니다" + [공지 목록으로] |

## 4. 상태 (State Matrix)

| 상태 | 조건 | UI |
|---|---|---|
| **초기 (SSG)** | 첫 진입 | 사전 렌더된 본문 + 첨부 + 이전/다음 네비 + 관련 공지 |
| **로딩 (ISR refresh)** | 백그라운드 | 사용자 미인지 |
| **데이터 OK** | 응답 정상 | §3 정상 표시 |
| **404 (ID 없음)** | 잘못된 ID / 삭제된 공지 | `not-found.tsx` → "존재하지 않는 공지입니다" + [공지 목록으로] |
| **비공개 공지** | `is_published=false` (관리자 임시저장) | 404 동일 처리 (로그인·권한 무관) |
| **노출 기간 만료** | `expire_at < now` (관리자 지정) | 404 동일 처리 — 목록(s08)에서도 비노출 |
| **첨부 다운로드 진행** | 다운로드 클릭 | 브라우저 기본 다운로드 + 토스트 "다운로드를 시작했어요" |
| **첨부 다운로드 실패** | 4xx/5xx | 토스트 "다운로드에 실패했어요. 잠시 후 다시 시도해주세요" |
| **관련 공지 0건** | 같은 카테고리 본 공지 단일 | 관련 공지 섹션 자체 미노출 (라벨 포함) |
| **이전/다음 네비 끝** | 첫/마지막 공지 | 해당 버튼 비활성 (회색 + `aria-disabled`) |
| **에러 (API 장애)** | 5xx | "공지를 불러올 수 없어요" + [새로고침] 버튼 (본문만 fallback, 헤더·푸터는 정상) |
| **점검 모드** | maintenance ON | 점검 페이지 리다이렉트 (ADM-S-007) |

## 5. 예외·엣지 케이스

- **공지 본문에 외부 이미지 URL 사용** → CSP 화이트리스트 정책 (A-NET-005). 관리자가 외부 URL 입력 시 등록 단계에서 차단 또는 CDN 프록시 권장 — s07과 동일 정책
- **공지 본문에 외부 링크 (`<a href>`)** → `rel="noopener noreferrer"` 자동 부여 + `target="_blank"` 허용
- **공지 본문 XSS 시도** → DOMPurify sanitize + 관리자 등록 시 서버 측 이중 sanitize (A-INJ-002 Stored XSS 방어) — s07과 동일
- **첨부 파일 확장자 우회 시도 (`.exe.pdf` 등)** → 서버 측 MIME 검증 (A-FILE-001 / A-FILE-003 Zip Slip 방어) — 관리자 업로드 단계에서 차단, 본 화면은 검증 통과 파일만 다운로드 가능
- **첨부 파일 사이즈 초과 (대용량)** → 관리자 등록 단계 제한 (단일 10MB / 공지당 5개) — 본 화면은 제한 통과 파일만 노출
- **삭제된 공지 deep link 인입** → 404 처리 + sitemap.xml 에서 자동 제거 (다음 build 시점)
- **숫자 ID 추측 공격 (`/notice/99999`)** → 존재 X → 404 정상 (정보 누출 없음, 일반 404와 구분 없음)
- **카카오 공유 SDK 로드 실패** → 카카오 버튼만 비활성, 링크복사·인쇄는 정상 동작
- **링크 복사 (navigator.clipboard) HTTPS 미적용 시** → fallback (textarea + execCommand) — HTTPS 강제(A-NET-001)로 사실상 미발생
- **인쇄 시 이미지·배경 누락** → CSS `@media print` 정의 (배경색·아이콘 숨김 / 본문 + 메타만 인쇄)
- **점검 카테고리 공지 + 점검모드 동시** → 본 화면은 점검모드 리다이렉트 우선 / 점검 종료 후 정상 노출 — s08과 동일
- **즉시 노출 필요 (긴급 점검 등)** → ISR 1h 캐시 한계 / 관리자 캐시 무효화 (ADM-S-003·004) 필수
- **공지 본문에 회원 개인정보 우발 포함 (관리자 실수)** → 관리자 등록 단계 패턴 매칭 경고 (이메일·휴대폰·주민번호) + 본 화면 노출 시 즉시 제거 신고 채널 (1:1 문의)
- **이전/다음 공지 네비 카테고리 변경 케이스** → 같은 카테고리 내에서만 이동 (전체 시계열이 아닌 카테고리 시계열) — s09-Q03 사장님 컨펌

## 8. SEO · 접근성 · 성능

### 8.1 SEO
- `<title>`: "[공지 제목] | LUMI 공지사항"
- `<meta name="description">`: 본문 첫 150자 자동 추출 (HTML 태그 제거) — 관리자 `summary` 필드 우선
- OG: image (브랜드 OG 기본 / 본문 첫 이미지 있으면 우선) · title · description · type=article
- JSON-LD `Article` 스키마: headline · datePublished · dateModified · author (브랜드명 "LUMI") · publisher · image · articleSection (카테고리)
- canonical: `/notice/[id]`
- sitemap.xml 자동 포함 (A-COMP-007) — `is_published=true` + `expire_at` 유효 한정
- robots: `index, follow` (만료·비공개 시 자동 제외)

### 8.2 접근성 (WCAG AA / KWCAG 2.2)
- H1 단일 / 본문은 H2·H3 위계 사용
- 카테고리 배지 = `aria-label` (색상만이 아닌 텍스트로 카테고리 인지)
- 고정·신규 배지 = `aria-label="고정 공지"` / `aria-label="신규 공지"`
- 본문 이미지 `alt` 필수 (관리자 등록 시 필수 입력 검증)
- 첨부 파일 링크 = `aria-label="첨부 파일 다운로드 attachment_01.pdf (1.2MB)"`
- 공유 버튼 = `aria-label` 명시 ("카카오톡으로 공유" / "링크 복사" / "인쇄")
- 이전/다음 네비 = `aria-label="이전 공지: [제목]"` / 비활성 시 `aria-disabled="true"`
- 키보드 Tab 순서: Breadcrumb → 공유 → 본문 → 첨부 → 이전/목록/다음 → 관련 공지
- 인쇄 모드 = 색상·아이콘 의존 정보 텍스트 대체

### 8.3 성능 (Core Web Vitals)

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.0s | 본문 텍스트 우선 (이미지 lazy) / SSG 사전 렌더 |
| INP | ≤ 200ms | 공유·다운로드 = 클라이언트 단일 액션 |
| CLS | ≤ 0.1 | 본문 이미지 `aspect-ratio` 명시 (관리자 등록 시 width/height 추출) / 카테고리 배지 고정 폭 |

- 본문 이미지 lazy loading
- 폰트 = 본문은 시스템 폰트 + 헤드라인만 Cormorant Garamond (display: swap)
- 첨부 다운로드 = CDN signed URL (서버 부하 경감)
- 조회수 증분 API = 비동기 fire-and-forget (페이지 렌더 차단 X)

## 9. 디자인 트랙 연동
