## 4. 상태 (State Matrix)

| 상태 | UI / 동작 |
|---|---|
| **초기 (인증 통과 직후)** | 스켈레톤 4 카드 + 그래프 + 테이블 → 데이터 로딩 후 fade-in (300ms) |
| **로딩 (백그라운드 갱신)** | "갱신 중" indicator 표시 — 데이터는 기존 값 유지 (UX 깜빡임 방지) |
| **데이터 OK** | 정상 4 카드 + 그래프 + 테이블 표시 |
| **데이터 부분 실패 (예: 시스템 헬스 API 다운)** | 해당 패널만 에러 상태 표시 ("일시적으로 데이터를 가져올 수 없어요" + [재시도] 버튼). 다른 영역은 정상 표시 |
| **처리 필요 0건** | KPI 4 카드 "오늘은 처리할 항목이 없어요" + 회색 처리. 클릭 비활성 |
| **시스템 알림 0건** | 패널 "현재 시스템은 모두 정상이에요" + healthy 컬러 |
| **헬스 alert (down/degraded)** | 시스템 알림 패널 상단에 빨강 배지 + 모달 또는 토스트 자동 표시 (1회만, 디스미스 가능) |
| **권한 부족 (예: CS 권한 + 정산 카드)** | 해당 카드 자체 비노출 (§7) — UI 깨짐 X |
| **자동 로그아웃 (refresh 만료)** | 모달 "세션이 만료됐어요. 다시 로그인해주세요" + `/admin/login` 리다이렉트 (3초 카운트다운) |
| **점검모드 ON (scope=user)** | 본 화면 상단에 노란 배너 "현재 사용자 영역 점검모드입니다 (남은 시간: HH:MM)" + 해제 버튼 (SUPER만) |
| **점검모드 ON (scope=both, 예약)** | 빨강 배너 "예약된 점검: YYYY-MM-DD HH:MM 시작 — 곧 본 화면도 503 처리됩니다" |

| ID | 케이스 | 처리 |
|---|---|---|
| **새로 가입한 관리자 (데이터 0건)** | 매출 0원·주문 0건 표시 | "아직 데이터가 없어요" 안내 (정상 동작) |

| **CS 권한 + 매출 그래프 진입** | 권한 부족 | 본 카드 자체 비노출 (CS는 매출 정보 미열람 — 권한 격리) |

| **알림 벨 클릭 → 라우팅 전 새 알림 도착** | 드롭다운 열린 상태에서 SSE 갱신 | 드롭다운 자동 refresh 또는 "새 알림 N건" 배지 표시 (사용자 다시 클릭 시 갱신) |
| **자동 갱신 중 데이터 불일치 (지표 vs 그래프)** | 일시적으로 KPI 카드와 그래프의 값이 다름 | 정상 — 각 영역 독립 갱신. UX 깜빡임 최소화 |

- 그래프 데이터 = `settlement_daily` 일별 row 직접 조회 (집계 비용 낮음)
- 처리 필요 = 4 개 도메인 카운트 병렬 호출 (Promise.all)

## 8. SEO · 접근성 · 성능

### 8.1 SEO

- `<title>`: "대시보드 | LUMI ADMIN"
- `<meta name="robots" content="noindex, nofollow">`
- `robots.txt`: `Disallow: /admin/`

### 8.2 접근성 (WCAG AA / KWCAG 2.2)

- 4 KPI 카드 `role="region"` + `aria-label="오늘 매출 카드"` 등
- 그래프 `role="img"` + `aria-label="일별 매출 그래프"` + 텍스트 대체 (표 형태 토글 옵션 — Sprint 1+)
- 시스템 알림 `aria-live="polite"` (헬스 alert 자동 안내)
- 최근 주문 테이블 `<table>` + `<th scope="col">` 의무
- Tab 순서: 사이드 메뉴 → 헤더 (알림·로그아웃) → KPI 카드 4개 → 그래프 토글 → 알림 패널 → 최근 주문 테이블 → 빠른 액션 4 버튼
- 모달 (자동 로그아웃·헬스 alert) `role="dialog"` + focus trap

### 8.3 성능 (Core Web Vitals)

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.5s | KPI 4 카드 우선 렌더 (LCP 핵심) — SSR 또는 SSG + 클라이언트 SWR 갱신 |
| INP | ≤ 200ms | 그래프 라이브러리 lazy load. 토글은 클라이언트 상태만 변경 (재요청 X) |
