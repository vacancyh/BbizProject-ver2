## 5. 예외·엣지 케이스
- **E-014 (관리자 권한 변경 시 즉시 효과)**: 본인의 권한이 SUPER → MANAGER로 변경되면 다음 요청부터 계정 탭 접근 차단 (세션 invalidate)
- **SUPER 마지막 1명 삭제/강등 시도 (★ 정정 2026-05-23)**: `400 LAST_SUPER_REMOVAL_DENIED` — **d21 §F11 SUPER 안전장치 룰** (시스템 고정 룰). v4 QA 직접 박제 시나리오 ID 없음. 본 룰은 도메인 정책 영역에서 구현. (v0.1에서 ADM-S-005로 인용했으나 실제 ADM-S-005 = 약관 관리이므로 ID 인용 폐기 — d21 §F11 인용으로 정정)
- **본인 계정 정지 시도**: `400 SELF_SUSPEND_DENIED` 차단 — d21 §F11
- **MFA secret 재발급 후 재로그인 강제**: 기존 세션 invalidate (A-AUTH-005 비밀번호 변경 시 토큰 무효화 패턴 준용)
- **점검모드 ON 중 SUPER 본인 차단 방지**: IP whitelist 또는 admin.* 서브도메인은 항상 우회 — ADM-S-007 점검모드 정책

## 8. SEO · 접근성 · 성능

### SEO
- `noindex, nofollow` (관리자 도메인 전체 robots.txt + meta)

### 접근성
- 테이블 = `<th scope="col">` 헤더 명시
- 모달 = focus trap + ESC 종료 + aria-labelledby
- 색만으로 상태 구분 X (OK/WARN/FAIL은 아이콘 + 텍스트 병기)
- 차트 = SVG title + 대체 텍스트 (스크린리더)

### 성능
- 헬스 메트릭 = 5초 간격 polling (SSE 대안 검토, T-NF04 미결)
- 감사로그 페이지네이션 = 50건/페이지 (cursor 기반)
- CSV 다운로드 = 비동기 백그라운드 job + 완료 시 이메일 (10K+ 행)
