```

├─────────────────────────────────────────────────────┤
```

### 2.2 태블릿 (769~1024)

- 카테고리 타일 / NEW / BEST = **3 컬럼**
- Hero = 좌우 오프셋 유지하되 비율 축소
- Editorial = 좌우 동일 (50:50)

### 2.3 모바일 (~768)

- 헤더: 햄버거(좌) + 로고(중) + 검색·카트·👤(우)
- Hero = 풀폭 사진 1장 + 하단 카피·CTA (세로 스택)
- Category tile = 2 컬럼
- NEW / BEST = 2 컬럼
- Editorial = 사진 → 카피 세로 스택
- Event banner = 전폭 유지
- 카테고리 메가메뉴는 햄버거 → 풀스크린 슬라이드 메뉴

## 8. SEO · 접근성 · 성능

### 8.1 SEO

- `<title>`: "LUMI — 매일의 작은 빛 | 단독 브랜드 925 실버 주얼리" (브랜드 카피 미확정 시 가안)
- `<meta name="description">`: 50~150자, 브랜드·카테고리·가격대 포함
- OG 태그: image · title · description · type=website
- 스키마: `Organization` (JSON-LD)
- 사이트맵: `/sitemap.xml`에 홈 포함, priority 1.0

### 8.2 접근성 (WCAG AA / KWCAG 2.2)

- Hero 이미지 `alt` 필수 (예: "윙 큐빅 오픈링을 착용한 모델 컷")
- 카테고리 카드 `<a>` 텍스트 명확 (아이콘 단독 금지)
- 키보드 Tab 순서: 공지 띠 → 헤더 → Hero CTA → 카테고리 카드 → NEW → ... → Footer
- 텍스트 대비 4.5:1 이상 (검정 텍스트 #111 on 흰 배경 #FFF = OK)

### 8.3 성능 (Core Web Vitals)

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.5s | Hero 이미지 `priority` + WebP/AVIF + `next/image` |
| INP | ≤ 200ms | 카드 hover 애니메이션은 CSS 트랜지션 (JS 미사용) |
| CLS | ≤ 0.1 | 모든 이미지 `aspect-ratio: 1/1` 또는 명시적 width/height |

- 폰트: Cormorant Garamond `display: swap` + preload
- 카드 이미지 lazy loading (Hero 제외)
