## 1. 개요

### 2.2 태블릿 (768~1279)

- 사이드 GNB 축소 (아이콘만)
- 결과 테이블 우측 칼럼 일부 숨김 (가입일·주문수 hide / 모달로 상세 확인)
- 액션 버튼은 "더보기 ⋯" 드롭다운으로 통합

### 2.3 모바일 (~767) — 응급 대응 한정

- 사이드 GNB → 햄버거
- 테이블 → 카드 리스트 (1행 1카드, 이름·이메일·상태·액션 ⋯)
- 검색·필터는 풀스크린 시트
- 정지·블랙리스트·강제 탈퇴 등 위험 액션은 데스크톱 권장 경고 토스트

## 3. 컴포넌트 명세

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **사이드 GNB** | 좌측 fixed | `/api/admin/me` (권한) | 권한별 메뉴 노출 (`../02_정보구조.md §4.3` 표 기준). CS는 회원 조회만, 정지/블랙 액션 hidden |
| **탭 (전체/블랙리스트)** | 페이지 상단 | URL query (`?tab=all` / `?tab=blacklist`) | 탭 전환 시 URL 동기화 |
| **검색·필터 바** | 탭 아래 | 회원 액션 → `GET /api/admin/members?q=&grade=&status=&from=&to=&page=` | 검색어 단일 input + 필드 선택 드롭다운(이름·이메일·전화·ID). debounce 400ms |
| **통계 카드 (4)** | 검색 바 아래 | `GET /api/admin/members/stats` (캐시 60초) | 전체 회원 / 신규 가입(7일) / 정지 / 블랙 카운트 |
| **결과 테이블** | 본문 | `/api/admin/members` 응답 | 정렬 = 가입일 desc 기본. 헤더 클릭 시 정렬 토글. 50건/페이지. **PII 마스킹 (Tier 3 §3.1)** = 이름 `홍*동` / 이메일 `t****@gmail.com` / 연락처 `010-****-5678` 기본 표시 + 행별 "전체 보기" 토글 (클릭 시 admin_audit_logs INSERT `action='admin.view_pii_list'` 박제). CS 권한 = 전체 보기 토글 비활성 (마스킹 강제) |
| **상세 페이지 액션 버튼 그룹** | 상세 우측 | (각 액션 API) | 권한별 버튼 비활성/숨김. 위험 액션은 모달 + 사유 입력 + 이중 확인 |

## 4. 상태 (State Matrix)

| 상태 | UI / 동작 |
|---|---|
| **초기 (목록 로딩)** | 검색·필터 바 + skeleton 행 10개 + 통계 카드 skeleton |
| **데이터 OK** | 결과 테이블 50건 + 페이징 + 통계 카드 |
| **빈 결과 (검색 매칭 0건)** | "검색 조건에 맞는 회원이 없습니다" + `[필터 초기화]` |
| **로딩 (필터 적용 중)** | 테이블 위 progress bar + 행 dim |
| **상세 진입 (loading)** | 회원 카드 skeleton + 탭 placeholder |
| **상세 데이터 OK** | 정상 표시 |
| **상세 — 정지 회원** | 회원 카드 상태 뱃지 빨강 "SUSPENDED(7d)" + 만료 시각 표시 + `[정지 해제]` 버튼 노출 |
| **상세 — 블랙리스트 회원** | 회원 카드 상태 뱃지 검정 "BLACKLISTED" + 사유 표시 + `[블랙리스트 해제]` 노출 |
| **상세 — 탈퇴 신청 회원** | 상태 회색 "WITHDRAWN(grace_until=YYYY-MM-DD)" + `[강제 탈퇴]`(SUPER) 활성 |
| **권한 부족 (CS가 정지/블랙 시도)** | 액션 버튼 disabled + tooltip "MANAGER 이상 권한 필요" |
| **마지막 SUPER 강제 탈퇴/정지 시도** | 모달 차단 "최소 1명의 SUPER가 유지되어야 합니다" (d21 F11) — 단 본 화면은 회원 도메인이므로 admin 계정과 별개 |
| **포인트 차감 잔액 부족** | 모달 inline error "잔액 부족 (보유 N P)" + 호출 차단 (d20 F11) |
| **AuditLog INSERT 실패** | 액션 자체 rollback + 토스트 "감사 로그 박제 실패 — 작업 취소" (d21 F6) |
| **점검모드 (사용자 영역) 진행 중** | 상단 띠 "현재 사용자 영역 점검 모드 ON" 노출 (관리자 영역은 정상) |

## 5. 예외·엣지 케이스

| ID | 케이스 | 처리 |
|---|---|---|
| s43-E01 | 정지된 회원에 추가 정지 처리 | 기존 제재 expires_at 갱신 + 사유 누적 + AuditLog 별도 박제 |
| s43-E02 | 블랙리스트 등록된 회원의 동일 이메일 재가입 시도 (member 도메인 가드) | 회원 도메인이 가입 시 차단 (MEM-U-047). 본 화면은 이력만 표시 |
| s43-E03 | 강제 탈퇴 시 진행 중 주문 존재 | 모달에 "진행 중 주문 N건 (자동 취소 처리됨)" 경고 + 환불 트리거 안내 + 확인 시 진행 |
| s43-E04 | 포인트 수동 차감 후 회원이 동시에 결제 시도 | d20 `points.version` 낙관락으로 처리 — 충돌 시 재시도 |
| s43-E05 | 회원 검색 시 SQL Injection 시도 | 입력 sanitization + parameterized query (A-INJ-001) |
| s43-E06 | 정지 처리 중 회원이 다른 탭에서 활성 세션 | `member.suspended` 이벤트 발행 → auth_sessions 강제 revoke (d11 F4) → 다음 요청 401 |
| s43-E07 | 검색 결과 100,000건 초과 | 통계 카드만 표시 + 테이블 "조건을 더 좁혀주세요" + 페이징 비활성 |
