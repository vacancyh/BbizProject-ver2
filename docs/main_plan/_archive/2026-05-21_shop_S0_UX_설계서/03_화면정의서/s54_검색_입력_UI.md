## 1. 개요

| 항목 | 내용 |
|---|---|
| URL | **라우트 없음 (헤더 컴포넌트)** — 모든 화면(공개·인증·마이페이지)의 GNB 헤더에 포함되는 글로벌 컴포넌트. 본 화면은 별도 라우트가 없으며, [검색] CTA 클릭 시 `/search?q={input}` (s05) 로 이동. |
| 라우트 타입 | (해당 없음 — 컴포넌트) — Client 동작. SSR/CSR 무관 (모든 페이지 헤더에서 동일 |
| 진입 경로 | (1) GNB 우측 검색 아이콘(🔍) 클릭 (모든 페이지에서 가능) (2) 헤더 입력 필드 직접 포커스 (데스크톱) (3) 모바일 GNB 햄버거 메뉴 내 [검색] 항목 클릭 (4) `Ctrl/Cmd + K` 단축키 (옵션, s54-Q01) |
| 목적 | (1) 검색 키워드 입력 받기 (s05 진입 전 UX 게이트) (2) 자동완성 (상품명·카테고리·태그) 노출 → 클릭 시 즉시 s05 또는 s04 이동 (3) 최근 검색어 노출 (localStorage, 최대 10건) — 재탐색 유도 (4) 인기 검색어 노출 (서버, 일 1회 배치 집계) (5) 추천 카테고리 노출 (메가메뉴 단축) (6) ESC 또는 외부 클릭 시 즉시 종료 |
| 액터 | **전 액터** (비로그인 포함). 최근 검색어는 디바이스별 localStorage (회원도 동일 — Phase 4 동기화 결정, s05-Q07) |
| SEO 인덱싱 | **해당 없음 (컴포넌트)** — 본 컴포넌트 자체는 페이지가 아님. 검색 결과 페이지(s05)는 `noindex` (I-03 확정) |
| 회원 가드 | 없음 (공개) |

## 3. 컴포넌트 명세

### 3.1 트리거 (GNB 검색 아이콘)

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **🔍 검색 아이콘 (헤더)** | GNB 우측 | static | 클릭 시 드롭다운/모달 오픈. 활성 시 아이콘 색상 변경 (LUMI primary). `aria-label="검색"` |
| **`Ctrl/Cmd + K` 단축키 (옵션)** | global key listener | local | 모든 페이지에서 단축키 입력 시 드롭다운 오픈 + input autofocus (s54-Q01 결정) |

### 3.2 드롭다운 / 모달 본체

| 컴포넌트 | 위치 | 데이터 source | 동작 / 상태 |
|---|---|---|---|
| **검색 input 필드** | 상단 | URL state X (컴포넌트 local) | `type="search"`, `autocomplete="off"`, `maxLength=64`. 오픈 시 autofocus. 입력 시 debounce 500ms 후 자동완성 호출 |
| **[×] clear 버튼** | input 우측 (입력 있을 때만) | local | 입력값 초기화 + autofocus 유지 |
| **[검색] CTA** | input 우측 | router push | 클릭 시 `/search?q={input}` (s05) 이동. 빈 입력 시 비활성 (또는 "검색어를 입력해주세요" 토스트) |
| **자동완성 영역** | 본문 ① | `GET /api/search/suggest?q=` (debounce 500ms, s54-Q02) | 입력 2자 이상일 때만 호출. 응답 5건 미만 노출. 각 항목: 키워드 + 타입 (상품·카테고리·태그) + 결과 수. 클릭 시 → 상품 (`/product/{id}`) 또는 검색 (`/search?q={keyword}`). 입력 전·결과 0건 시 비노출 |
| **최근 검색어 영역** | 본문 ② | localStorage `recent_searches` (최대 10건, LRU) | chip 가로 나열 (최근순). 각 chip [×] 삭제 + [전체 삭제] CTA. 클릭 시 → `/search?q={keyword}`. 비어 있으면 섹션 미노출 |
| **인기 검색어 영역** | 본문 ③ | `GET /api/search/popular` (ISR 30분, 서버 일 1회 배치 집계) | 1~10위 순위 + 키워드 + 트렌드 아이콘 (🔺 상승 / 🔻 하락 / (-) 유지 / NEW 신규). 클릭 시 → `/search?q={keyword}`. admin 운영 + 자동 집계 하이브리드 (s05-Q08) |
| **추천 카테고리 chip** | 본문 ④ | `GET /api/categories` (활성 1단만, SSG) | 4개 카테고리 (반지·목걸이·귀걸이·팔찌). 클릭 시 → `/shop/[cat]` (s03) |
| **ESC 키 / 외부 클릭 / [×] 닫기** | global | local | 드롭다운/모달 즉시 종료. backdrop 클릭도 동일 |
| **backdrop (외부 dim)** | 데스크톱 드롭다운 외부 | local | 본문 회색 dim. 클릭 시 종료 |
| **키보드 탐색 ↑/↓/Enter/ESC** | 자동완성 + 최근 + 인기 영역 | local | ↑/↓로 항목 이동 (focus 표시) / Enter로 선택 / ESC로 종료. `aria-activedescendant` |

## 4. 상태 (State Matrix)

| 상태 | UI / 동작 |
|---|---|
| **닫힘 (기본)** | GNB 아이콘만 표시. 드롭다운 비노출 |
| **오픈 (입력 전)** | 드롭다운 노출. input autofocus. 자동완성 영역 비노출. 최근 검색어·인기 검색어·추천 카테고리만 노출 |
| **입력 중 (1자, < 2자)** | 자동완성 호출 X. 안내 캡션 "2자 이상 입력해주셔요" |
| **입력 중 (debounce 500ms 진행 중)** | 자동완성 영역 spinner (선택, 또는 표시 X) |
| **자동완성 결과 OK (1~5건)** | 영역 노출. 키보드 ↑/↓ 탐색 가능 |
| **자동완성 결과 0건** | 영역 비노출. 단 안내 캡션 "검색을 눌러 결과를 확인해보세요" (s05의 빈 결과 UI로 안내) |
| **금칙어 입력** | 자동완성 영역 비노출. 안내 캡션 "다시 검색해주세요" + 운영자 로그 (XSS·금칙어는 응답에 echo X — s05 §5 동일) |
| **검색어 64자 초과** | 자동 truncate + 토스트 "64자까지 입력 가능해요" |
| **rate limit (자동완성 너무 많음)** | 분당 60회 이상 시 자동완성 호출 일시 정지 (서버 측 429 응답) + 안내 캡션 "잠시 후 다시 시도해주세요" |
| **네트워크 오류 (자동완성)** | 자동완성 영역 미노출. 단 입력·검색 CTA는 정상 동작 (네트워크 의존 없음) |
| **로컬스토리지 비활성 (privacy mode)** | 최근 검색어 영역 비노출. 캡션 "검색 기록 저장이 비활성화돼 있어요" |
| **최근 검색어 chip [×] 클릭** | 해당 chip 삭제 + localStorage 업데이트 + 영역 즉시 갱신 |
| **최근 검색어 [전체 삭제]** | confirm 모달 (선택) → localStorage clear + 영역 비노출 |
| **검색 CTA 클릭** | `/search?q={input}` 이동 + 드롭다운 자동 종료 + localStorage append (LRU, 최대 10건) |
| **자동완성 항목 클릭** | 항목 타입에 따라: 상품 → `/product/{id}` / 카테고리 → `/shop/[cat]` / 태그 → `/search?q={tag}`. 드롭다운 종료 |
| **인기 검색어 클릭** | `/search?q={keyword}` 이동 + localStorage append |
| **추천 카테고리 클릭** | `/shop/[cat]` (s03) 이동 + 드롭다운 종료 |
| **모바일 풀스크린 — 키보드 ↑ 버튼** | 키보드 dismiss (focus blur) — UX 결정 (s54-Q03) |
| **모바일 풀스크린 — 뒤로 가기 (브라우저 또는 ←)** | 드롭다운 종료 (history.back 또는 컴포넌트 close) |

## 5. 예외·엣지 케이스

| ID | 케이스 | 처리 |
|---|---|---|
| **금칙어 입력** | 욕설·음란·차별 키워드 | admin 금칙어 사전 매칭 시 자동완성 미노출 + 운영자 로그. 키워드 자체는 응답에 echo X (XSS 방어) — s05 §5 정합 |
| **XSS 방어** | `<script>` 등 입력 | React 기본 sanitization. 자동완성 응답은 키워드 escape 의무 |
| **검색어 길이 초과** | 64자 이상 | maxLength 속성 + 토스트 |
| **연속 띄어쓰기 / 특수문자만** | "   " / "@#$%" | 검색 CTA 비활성 또는 빈 결과 처리 (검색어 정규화: trim + 특수문자 제거 권장) |
| **localStorage 비활성 (Safari private)** | 최근 검색어 저장 실패 | try/catch + 영역 비노출 + 안내 캡션. 검색 자체는 정상 동작 |
| **localStorage 용량 초과 (5MB)** | append 실패 | 가장 오래된 항목 자동 제거 (LRU) |
| **자동완성 응답 지연 (네트워크 느림)** | 1초 이상 응답 없음 | 자동완성 영역 비노출 (또는 spinner) + 검색 CTA는 정상 동작 |
| **두 번 빠르게 클릭** | 드롭다운 중복 오픈 시도 | debounce + 이미 오픈 상태면 무시 |
| **검색 중 다른 페이지로 이동 (라우터 변경)** | 드롭다운 자동 종료 (router.events 또는 cleanup) |
| **모바일 풀스크린 모달 — body scroll 차단** | 모달 오픈 시 `body { overflow: hidden }` + 모달 종료 시 복원 |
| **모바일 — 키보드 오픈 시 모달 자동 스크롤** | input이 키보드에 가려지지 않도록 viewport 조정 (`scroll-padding` 또는 `position: sticky`) |
| **검색 CTA 클릭 시 동일 키워드 재검색** | s05에서 동일 페이지 stay + URL `?q` 갱신 + 결과 재조회 |
| **자동완성 클릭 시 키보드 dismiss (모바일)** | 라우터 이동 시 자동 dismiss |
| **다국어 입력 (한자·일본어)** | 자동완성 매칭 X 가능 (한국어 색인) — 안내 캡션 "검색을 눌러 결과를 확인해보세요" |

### 6.2 API 면 (s05와 공유)

| 엔드포인트 | 메서드 | 응답 | 캐시 |
|---|---|---|---|

## 8. SEO · 접근성 · 성능

### 8.1 SEO

- **해당 없음** — 본 컴포넌트는 라우트 없는 헤더 컴포넌트
- 검색 결과 페이지(s05) `noindex` (I-03 확정)

### 8.2 접근성 (WCAG AA / KWCAG 2.2)

- 검색 input `<label>` (시각적 숨김 ok) + `aria-label="검색"`
- 드롭다운/모달 `role="dialog"` + `aria-modal="true"` + `aria-labelledby="search-modal-title"`
- 자동완성 영역 `role="listbox"` + 항목 `role="option"` + `aria-activedescendant`
- 키보드 탐색 ↑/↓/Enter/ESC 의무
- 최근 검색어 chip [×] `aria-label="<키워드> 삭제"`
- 인기 검색어 순위 `<ol>` (의미적 순서)
- 추천 카테고리 chip `<a>` (router link) + `aria-label="<카테고리> 카테고리 이동"`
- 모달 오픈 시 focus trap (모달 내부 Tab 순환)
- 모달 종료 시 트리거(검색 아이콘)에 focus 복원
- 키보드 단축키 `Ctrl/Cmd + K` (옵션, s54-Q01) — `aria-keyshortcuts="Control+K"` 명시
- 컬러 대비 4.5:1 이상
- Tab 순서: input → [×] → [검색] → 자동완성 항목 → 최근 검색어 chip → [전체 삭제] → 인기 검색어 → 추천 카테고리

### 8.3 성능

| 지표 | 목표 | 전략 |
|---|---|---|
| 드롭다운 오픈 응답 | ≤ 100ms | 정적 컴포넌트 (이미 마운트). 인기 검색어·추천 카테고리는 SSG/ISR로 사전 로드 |
| 자동완성 응답 | ≤ 200ms | debounce 500ms + Redis 60초 캐시 |
| INP | ≤ 200ms | 키보드 탐색 즉시 반응. 자동완성은 백그라운드 fetch |

- 본 컴포넌트는 모든 페이지 헤더에 포함 → 번들 크기 최소화 (lazy load 자동완성 fetch만)
- 인기 검색어·추천 카테고리는 헤더와 함께 SSG/ISR로 사전 로드 (드롭다운 오픈 시 fetch X)
- localStorage 접근은 동기 (블로킹 X — 데이터 작음)
- 모바일 모달은 portal 렌더 (body 직속) — 헤더 z-index 영향 회피
