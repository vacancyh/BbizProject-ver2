## 2. 와이어 구조

### 2.1 목록 (`/mypage/inquiries`)

#### 데스크톱 (1024px+)
```
+-------------------------------------------------+
| [Header: GNB + 마이페이지 메뉴]                  |
+-------------------------------------------------+
| 마이페이지 사이드바  | 1:1 문의                  |
|  주문/배송           | [답변 대기 3][답변 완료 12][비밀글 2] |
|  취소/반품/교환      |---------------------------|
|  ▶ 1:1 문의 (active) | [+ 새 문의 작성]           |
|  실시간 채팅         |---------------------------|
|  쿠폰함              | 카테고리▼ | 상태▼ | 검색  |
```

## 5. 예외·엣지 케이스

- **답변 완료 후 수정 시도** → 419 (`409 ANSWER_LOCKED`): "답변 완료된 문의는 수정할 수 없습니다" (d19 F10)
- **비밀글 → 일반글 전환** → 금지 (변경 불가, 작성 시점 확정)
- **카테고리=product 인데 상품 미선택** → 422 검증 차단 (서버)
- **카테고리=order 인데 6개월 초과 주문** → 셀렉트 노출 시 자동 제외 + "최근 6개월 주문만 가능" 안내
- **첨부 이미지 5장 초과 업로드 시도** → 클라이언트 차단 + 토스트 "이미지는 최대 5장까지"
- **MIME 위변조 시도 (예: .exe → .jpg 리네임)** → 서버 검증 거부 (A-FILE-001~010)
- **XSS 본문 (`<script>` 등)** → 서버 escape + 저장 시점 sanitize (A-XSS-001)
- **관리자 답변 알림 미수신 (회원 알림 OFF)** → 회원 알림 설정에 무관하게 답변 알림은 기본 ON (d19 F11) — 단 채널 글로벌 OFF (MEM-A-034) 시 미발송
- **탈퇴 회원의 과거 문의** → 작성자 표시만 마스킹 ("탈퇴한 회원"), 본문·답변 보존 (d19 § 7.3 `member.withdrawn_completed`)
- **SLA 초과 (24h)** → 목록 카드에 "답변 지연" 노란 배지 + 관리자 SLA 큐 진입 (REV-A-008 미답변 필터 — INQ-A-* → REV-A-* 통합)

## 8. SEO · 접근성 · 성능

- **SEO**: `noindex, nofollow` (마이페이지 전체)
- **접근성**:
  - 탭 = `role="tablist"` + `aria-selected` + 화살표 키 네비
  - 카드 = `<article>` + 제목 = `<h3>` + 작성일 `<time datetime>`
  - 비밀글 아이콘 = `aria-label="비밀글"` (텍스트 없이 아이콘만 X)
  - 첨부 라이트박스 = ESC 닫기 + Tab trap + alt 텍스트 ("문의 첨부 이미지 1/5")
  - 작성 폼 = label-input 명시적 연결 + 에러 메시지 `aria-live="polite"`
- **성능**:
  - 목록 cursor pagination (offset X)
  - 첨부 이미지 lazy load + thumbnail 별도 (원본은 라이트박스 클릭 시)
  - 작성 화면 = 카테고리=product 시 상품 검색기 lazy import (코드 스플릿)
