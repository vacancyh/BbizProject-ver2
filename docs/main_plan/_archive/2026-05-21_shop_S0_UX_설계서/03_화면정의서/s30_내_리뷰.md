## 4. 상태 (State Matrix)

| 상태 | 조건 | UI |
|---|---|---|
| 정상 (작성 가능) | eligible 1개 이상 | 카드 리스트 |
| 빈 (작성 가능) | 0개 | "작성 가능한 리뷰가 없습니다" |
| 빈 (작성 완료) | 0개 | "작성한 리뷰가 없습니다" + [작성 가능 보기] |
| 로딩 | API 호출 중 | 스켈레톤 |
| 삭제 성공 | DELETE 200 | 토스트 + 카운트 갱신 + 포인트 회수 안내 |
| HIDDEN | 관리자 블라인드 | 회색 카드 + "운영자에 의해 숨김 처리되었습니다" |
| REPORTED | 신고 누적 | 노란 배지 + 본문 마스킹 |

## 5. 예외·엣지 케이스
- **수정 7일 만료**: 7일 경과 시 [수정] disabled + tooltip "수정 가능 기간이 종료되었습니다"
- **삭제 시 포인트 회수**: 작성 시 적립된 리뷰 보너스 포인트 회수 (d20 PNT-S-007) — 본인 잔액 음수 시 차감 보류 + CS 케이스
- **HIDDEN 리뷰 본인 열람**: 본인은 본문 볼 수 있음 + 신고 사유 안내 (이의 제기 링크)
- **이미지 깨짐**: 첨부 이미지 404 시 placeholder + retry 1회
- **eligible 7일 경과**: 자동 expired 처리 (배치) — 본 화면 작성 가능 탭에서 사라짐
