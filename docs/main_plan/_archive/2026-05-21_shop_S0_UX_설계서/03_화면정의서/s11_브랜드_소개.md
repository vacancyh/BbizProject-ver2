## 5. 예외·엣지 케이스

- **이미지 로딩 실패** → placeholder + alt 텍스트 (PRD-U-029)
- **네이버 지도 API 장애 또는 차단** → iframe fallback ("지도 로딩 실패" + 주소 텍스트 + [주소 복사하기])
- **매장 운영 정보 미입력 (MVP 초기)** → §5 섹션 자체 미렌더링 (DOM 없음 = 빈 공간 없음)
- **소셜 채널 일부 미운영** → 해당 아이콘만 미노출 (예: 유튜브만 OFF)
- **회사 정보 누락 (필수 항목)** → SSG 빌드 시 검증 실패 → 빌드 차단 (사업자등록번호·통신판매업 신고번호 등 전자상거래법 필수)
- **브랜드 스토리 본문에 외부 링크** → `rel="noopener noreferrer nofollow"` 강제
- **브랜드 스토리 본문 MD 안에 `<script>` 등 주입 시도** → 관리자 등록 시 sanitize-html + 렌더 시 2차 sanitize
- **외부 검색 인입 (브랜드 키워드)** → SSG로 즉시 LCP 빠름 / `Organization` JSON-LD 로 사이트링크 노출
- **모바일에서 지도 embed 데이터 사용량 큼** → 사용자 인터랙션(클릭) 후 lazy load 권장
- **관리자 콘텐츠 즉시 반영 필요** → ISR 24h 한계 / 관리자 캐시 무효화 (ADM-S-003·004) 필수

## 8. SEO · 접근성 · 성능

### 8.1 SEO
- `<title>`: "브랜드 소개 | LUMI — 매일의 작은 빛"
- `<meta name="description">`: "LUMI는 매일의 작은 빛을 담은 주얼리 브랜드입니다. 브랜드 스토리와 가치를 만나보세요."
- OG: image (히어로 이미지) · title · description · type=website
- **JSON-LD `Organization` 스키마**: `name`, `logo`, `url`, `sameAs: [instagram, youtube, blog]`, `contactPoint: { telephone, email, contactType: "customer service", areaServed: "KR", availableLanguage: "ko" }`
- **JSON-LD `LocalBusiness` 스키마** (매장 운영 시): `address`, `geo`, `openingHoursSpecification`
- canonical: `/about`
- robots: `index, follow`
- 사이트맵 포함 + 우선순위 0.7 (홈 1.0, 카테고리 0.9, 본 페이지 0.7)

### 8.2 접근성 (WCAG AA / KWCAG 2.2)
- 히어로 이미지 = `alt` 텍스트 ("LUMI 브랜드 히어로 이미지" 등 구체)
- H1 페이지당 1개 / H2 섹션별
- 본문 max-width 800 + 본문 line-height 1.6+ (가독성)
- 가치 카드 = `<article>` 시맨틱 + 아이콘 `aria-hidden="true"` (텍스트가 의미 담당)
- 연혁 = `<ol>` 또는 `<dl>` 시맨틱
- 매장 지도 iframe = `title` 속성 ("LUMI 매장 위치 지도")
- 소셜 링크 = `aria-label` (예: "LUMI 인스타그램 새 창에서 열기")
- 키보드 포커스 = 모든 링크/CTA 도달 가능
- 색 대비 = WCAG AA (히어로 텍스트 + 배경)
- `prefers-reduced-motion` = parallax·페이드 등 모션 OFF

### 8.3 성능

| 지표 | 목표 | 전략 |
|---|---|---|
| LCP | ≤ 2.0s | 히어로 이미지 = `priority` + WebP/AVIF + `next/image` |
| INP | ≤ 200ms | 인터랙션 거의 없음 (CTA 클릭만) |
| CLS | ≤ 0.1 | 이미지 `width`/`height` 명시 + 폰트 swap |

- 페이지 자체 = 100% SSG = 첫 페인트 ms 단위
- 네이버 지도 iframe = lazy load (`loading="lazy"`) + 인터랙션 후 로드 권장
- 본문 폰트 = `next/font` swap
- 이미지 = CDN + WebP/AVIF + lazy (히어로만 priority)

## 9. 디자인 트랙 연동

- LUMI 시안 미보유 → **디자인 트랙 Sprint 1+ 위임**
- 자체 와이어 = 히어로 + 스토리 2 컬럼 + 가치 3 카드 + 연혁 타임라인 + (조건부) 매장 + 소셜 + 회사 정보 + CTA
- 결정 항목 (Sprint 1):
  - 히어로 이미지 톤·카피 (브랜드 디자인 가이드 의존)
  - 가치 카드 아이콘 스타일 (라인 vs 솔리드)
  - 연혁 타임라인 디자인 (좌측 점선·우측 콘텐츠 vs 중앙 점선·좌우 교차)
  - 매장 지도 스타일 (네이버 기본 vs 커스텀 마커)
  - 소셜 아이콘 컬러 (브랜드 컬러 vs 채널 컬러)
  - 폰트 (헤딩·본문 별도 폰트)
