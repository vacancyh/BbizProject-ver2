| **[재고 부족 임계 설정] CTA** | 액션 바 | `GET/PUT /api/admin/policies/product/stock-threshold` (PRD-A-011) | 모달: 기본 임계값 입력 + SKU별 override 가능 |

| **SKU 테이블 (행)** | 본문 | `GET /api/admin/skus` | 컬럼: SKU / 상품명·옵션 / 현재 재고 / 임계 / 상태 (정상·부족·품절) / 최근 변동 (`product_stock_history` 마지막 row) |
| **[+조정] 액션** | 행 액션 | 모달 → `PATCH /api/admin/skus/{id}/stock` | 입고·출고·수정 + 사유 필수 (PRD-A-010/041) → product_stock_history INSERT |
| **[이력] 액션** | 행 액션 | `GET /api/admin/products/{id}/stock-history` | 모달: 변동 이력 (변동 전→후·사유·관리자·시각). 페이지네이션 |
| **[알림 ON/OFF] 토글** | 행 액션 | `PATCH /api/admin/skus/{id}` (notify_on_low_stock) | 재고 부족 알림 수신 여부 |
| **재고 부족 자동 알림** | (백그라운드) | cron + notification | 임계 미달 시 슬랙·이메일 (P2 정책) |

## 5. 예외·엣지 케이스

| ID | 케이스 | 처리 |
|---|---|---|
| **재고 수동 조정 중 동시 주문 발생** | 조정 트랜잭션 + 주문 차감 동시 | DB 락 (FOR UPDATE) → 직렬화. 조정 후 재고 = 조정 결과 + 주문 차감 반영 (PRD-A-052) |
| **CSV 업로드 — 존재하지 않는 SKU 라인** | 오류 라인 skip + 리포트 표시 (PRD-A-007 패턴) |
| **CSV 업로드 — 동시 다중 관리자 업로드** | 각 업로드 독립 처리 — 단 마지막 commit 우세. 권장: 한 번에 1명만 작업 (UX 안내) |
| **타임세일 진행 중 상품 자체 삭제 시도** | s37에서 차단 또는 경고 모달 — 타임세일 종료 후 삭제 권장 |
| **타임세일 + 카테고리 한정 쿠폰 중복** | 가격 정합 검증 — 쿠폰 적용 후 음수 가격 차단 (d20 정책) |
| **타임세일 종료 직후 캐시 미반영** | 캐시 PURGE 실패 시 → 재시도 큐 + 관리자 알림 |
| **재고 0 + 타임세일 진행 중** | 사용자 영역 sold_out 표시 (재고 0 우세). 타임세일 카드 "재고 한도 도달" |
| **임계 설정 변경 → 즉시 알림 폭주** | 신규 임계 이하 SKU 다수 → 알림 throttle (10분 내 동일 임계 변경은 1회만 알림) |
| **음수 재고 발생 (race condition)** | DB CHECK 위반 → 트랜잭션 rollback → 사용자 측 "재고 부족" 응답 (B-ORD-001/002) |
| **타임세일 우선순위 충돌 (동일 값)** | 등록 시점 순서 (created_at) — 안내 캡션 표시 |
| **상품 옵션 SKU 추가 (s37) → 재고 0** | 본 화면에 자동 노출. 임계 미달 알림 발송 (즉시) |
