## 1. 도메인 개요·책임 범위

- **1줄 책임**: 카테고리 트리·필터·탐색·CRUD
- **포지션**: 가장 작은 도메인. 단, product와 cart에 강한 영향 — 카테고리 변경 시 상품 캐시 무효화 + 비활성 카테고리는 상품 필터에서도 제외.
- **본 프로젝트 정책**: 반지·목걸이·귀걸이·팔찌 4개 (가이드 상 트리 2단까지 지원). 사용자는 헤더 네비게이션·홈 카테고리 카드·카테고리 필터로 접근.
- **책임 경계 (out)**: 상품 데이터·재고·이미지는 product 도메인. 카테고리 한정 쿠폰 정책은 coupon_point 도메인 (본 도메인은 카테고리 식별자 제공만).

## 2. 핵심 엔티티

### 2.1 categories

| 필드 | 타입 | 제약 | 비고 |

| id | UUID | PK | |

| thumb_url | VARCHAR(500) | NULL | 홈 카드 썸네일 (선택) |
| created_at | TIMESTAMPTZ | NOT NULL | |
| updated_at | TIMESTAMPTZ | NOT NULL | |

**제약**: `UNIQUE(slug)` · `slug` 영문 패턴 검증.
**인덱스**: `idx_parent_active_order`, `idx_is_active`.

## 5. API 면 (가설)

### 5.1 사용자 API (`/api/categories`)

| Method | Path | 권한 | 캐시 | 요청 (요약) | 응답 (요약) | 주요 에러 |
|---|---|---|---|---|---|---|
| GET | `/api/categories` | public | SSG (변경 시 무효화) | — | 200 + 활성 카테고리 트리 | — |
| GET | `/api/categories/{slug}` | public | SSG | — | 200 + 카테고리 상세 (이름·thumb) | 404 (미존재/비활성) |

### 5.2 관리자 API (`/api/admin/categories`)

| Method | Path | 권한 | 비고 |
|---|---|---|---|
| GET | `/api/admin/categories` | admin | 비활성 포함 전체 조회 (CAT-A-011) / 활성·비활성 배지 (CAT-A-008) |
| POST | `/api/admin/categories` | admin | 신규 생성 (이름·slug·노출 순서·parent_id) (CAT-A-001) |
| GET | `/api/admin/categories/{id}` | admin | 상세 |
| PATCH | `/api/admin/categories/{id}` | admin | 수정 → 캐시 무효화 (CAT-A-002, 012) |
| PATCH | `/api/admin/categories/{id}/active` | admin | 활성/비활성 전환 (CAT-A-003) |
| DELETE | `/api/admin/categories/{id}` | admin | 삭제 (상품 보유 시 409 차단, CAT-A-004) |
| PATCH | `/api/admin/categories/reorder` | admin | 노출 순서 일괄 변경 (드래그) (CAT-A-006) |

**공통 에러**: 401 / 403 / 404 / 409 (slug 중복 또는 상품 보유 삭제 시도) / 422.
