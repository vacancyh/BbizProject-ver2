## 1. 도메인 개요·책임 범위

- **1줄 책임**: 배송지 관리·운송장 발급·배송 상태 추적·배송비 정책·자동 구매확정·반품/교환 라이프사이클.
- **포지션**: order 도메인의 "배송" 단계를 전담. 결제 트랜잭션과는 독립이나, 반품·교환 시 payment 도메인 환불 트리거를 발행함.
- **회원 전용 정책**: 배송지·반품·교환 신청은 회원 전용 (`00_개요.md §2 #8`). 비회원 송장 조회는 정책상 미적용.
- **책임 경계 (out)**: 환불 PG 호출은 payment 도메인 (본 도메인은 환불 트리거 이벤트 발행). 재고 복구는 product 도메인 (본 도메인은 반품/교환 완료 이벤트 발행). 주문 상태 전이(shipping → delivered)는 본 도메인 트리거 + order 도메인이 수신 처리.

### 2.5A shipments / shipment_items (1주문 N운송장 — Tier1 §3.F 신규)

> 기존 `deliveries` (1:1)는 1주문 1운송장 가정. shipments 1:N 신규로 분할 배송 지원 (창고 분리 다박스 / 일부 즉시 출고 + 나머지 예약 발송).

#### 2.5A.1 shipments

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|
| id | UUID | PK | |
| order_id | UUID | FK → orders.id NOT NULL | |
| status | ENUM | NOT NULL DEFAULT 'preparing' | preparing / shipping / delivered |
| courier | ENUM | NOT NULL | cj_logistics / hanjin / lotte / post_office / etc |
| tracking_no | VARCHAR(30) | NOT NULL | 운송장 번호 (택배사 정규식 검증) |
| shipped_at | TIMESTAMPTZ | NULL | shipment 발송 시각 |
| delivered_at | TIMESTAMPTZ | NULL | shipment 배송완료 시각 |
| created_at | TIMESTAMPTZ | NOT NULL | |
| created_by | UUID | NOT NULL FK → admin_accounts.id | |

**인덱스**: `idx_order_id`, `idx_tracking_no`(부분 NOT NULL), `idx_status`.

#### 2.5A.2 shipment_items

| 필드 | 타입 | 제약 |
|---|---|---|
| shipment_id | UUID | FK → shipments.id NOT NULL |
| order_item_id | UUID | FK → order_items.id NOT NULL |
| qty | INTEGER | NOT NULL CHECK > 0 |

**복합 PK**: `(shipment_id, order_item_id)`.

**제약 (Tier1 §3.F)**:
- `UNIQUE(order_item_id) WHERE active` — 동일 order_item 중복 출고 차단
- 합계 qty = `order_items.quantity` 일치 검증 (다건 출고 분할 시 합계 검증 트리거)

**관계 (기존 `deliveries`와의 위치)**:
- 기존 `deliveries` (1:1) = order 단위 status 집계 (하위 shipments 상태 종합) → 잔여
- 신규 `shipments` (1:N) = 실제 운송장 단위 추적
- 단건 출고 = shipments 1행 (기존 deliveries.tracking_no/courier와 1:1 매핑)
- 분할 출고 = shipments N행 + deliveries.status = `shipping` 또는 `partially_delivered` (d16 §6.4 상태 머신 연계)

**API 영향 (메타)**: `POST /api/admin/orders/{order_id}/shipments` 추가 (기존 `POST /api/admin/shipments` 단건 등록과 병행). 다건 출고 body = `{ items: [{order_item_id, qty}, ...], courier, tracking_no }`.
