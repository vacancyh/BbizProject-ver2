## 3. 도메인 .md 표준 구조 (d11~d21 공통)

각 도메인 파일은 다음 9개 섹션 고정 순서로 작성합니다.

| # | 섹션 | 내용 |
|---|---|---|
| 1 | 도메인 개요·책임 범위 | 1줄 정의 + 책임 경계 |
| 2 | 핵심 엔티티 | 필드 / 관계 / 제약 / 인덱스 |
| 3 | UseCase 목록 | 액터 / 전제 / 본문 / 예외 |
| 4 | 사용자 ↔ 관리자 매핑표 | 사용자 ID ↔ 관리자 ID 1:1 (양방향 매핑 의무) |
| 5 | API 면 | 엔드포인트 / 요청 / 응답 / 권한 / 에러 |
| 6 | 도메인 룰·정책 | 비즈니스 룰 (정책 변경 가능 항목 명시) |
| 7 | 다른 도메인 의존 / 이벤트 | 의존 도메인 + 발행/구독 이벤트 명세 |
| 8 | Out-of-scope / 미결 | 본 MVP 범위 외 + 사장님 결정 필요 항목 |
| 9 | QA 추적 | `쇼핑몰_전용_QA_v4.md` + `공통_인프라_보안_QA.md` ID 인용 |
