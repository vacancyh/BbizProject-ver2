## 1. 도메인 개요·책임 범위

- **1줄 책임**: 리뷰·Q&A·1:1 문의·실시간 채팅 — 회원의 모든 컨텐츠 기반 CS 채널 통합.
- **포지션**: order(구매확정), product(평균 별점), member(작성자)와 **다층 의존**. 어뷰징·신고·블라인드 등 컨텐츠 모더레이션 책임.
- **회원 전용 정책**: 리뷰·문의·채팅 모두 회원만 작성 가능 (`00_개요.md §2 #8`). 비밀글은 본인 + 관리자만 조회.
- **CS 채널 분리 룰**:
  - **리뷰** = 구매확정 후 상품 사용 후기 (포인트 적립 트리거)
  - **Q&A** = 상품 상세 페이지 내 공개 질의응답 (구매 전 의사결정 지원)
  - **1:1 문의** = 비공개 텍스트 기반 CS (상품·주문·일반)
  - **실시간 채팅** = 운영시간 내 동기 CS + 상담 (Q-12 미결 — 운영시간·오프라인 메시지 정책)
- **책임 경계 (out)**: 알림 발송 자체는 notification 도메인 (본 도메인은 이벤트 발행만). 포인트 적립 실행은 coupon_point 도메인. 신고된 회원 제재는 member 도메인 (sanctions).

### 2.7A cs_cases (CS 케이스 통합 — Tier4 §3.4 신규)

> 1:1 문의·실시간 채팅·이메일·전화 등 모든 CS 인입 채널을 통합 분류·SLA·에스컬레이션·CSAT 추적하는 횡단 테이블. inquiries / chat_sessions 와는 별개의 메타 레이어 (인입 단위 분류·우선순위·담당자).

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|
| id | UUID | PK | case_no |
| member_id | UUID | FK → members.id NULL | 비회원 인입(이메일·전화) 시 NULL |
| inbound_channel | ENUM | NOT NULL | inquiry / chat / email / phone |
| source_id | UUID | NULL | inquiry_id / chat_session_id (해당 시) |
| category | ENUM | NOT NULL | 정형: order_payment / order_refund / order_delivery / order_partial / member_password / member_lockout / member_mfa / member_cart_merge / member_withdrawn_rejoin / product_review / product_review_point / product_discontinued / 비정형: dispute_refund_fraud / dispute_abuse_content / dispute_multi_account / dispute_privacy_leak / external_pg / external_courier / external_notify / legal_privacy_subject / legal_arbitration / legal_content_report |
| priority | ENUM | NOT NULL | immediate / 4h / 24h / 1d / 7d |
| sla_due_at | TIMESTAMPTZ | NOT NULL | 인입 시각 + priority별 SLA |
| status | ENUM | NOT NULL DEFAULT 'open' | open / assigned / in_progress / escalated / resolved / closed |
| assigned_role | ENUM | NOT NULL | CS / MANAGER / SUPER |
| assigned_admin_id | UUID | NULL FK → admin_accounts.id | |
| escalated_to | ENUM | NULL | MANAGER / SUPER / LEGAL |
| escalated_at | TIMESTAMPTZ | NULL | |
| resolved_at | TIMESTAMPTZ | NULL | |
| resolution_summary | TEXT | NULL | 종료 시 요약 |
| csat_score | SMALLINT | NULL CHECK 1 ≤ csat_score ≤ 5 | 종료 후 7일 내 발송 응답 |
| csat_sent_at | TIMESTAMPTZ | NULL | CSAT 발송 시각 |
| created_at | TIMESTAMPTZ | NOT NULL | |

**인덱스**: `idx_member_id_created_at`, `idx_status_sla_due_at` (SLA 초과 감지), `idx_assigned_admin_id_status`, `idx_category_created_at` (분류 통계), `idx_inbound_channel_created_at`.

**룰 (Tier4 §3.4)**:
- F-CS-01: 모든 CS 인입 = `cs_cases` row INSERT 의무 (분류·SLA·담당자·상태)
- F-CS-02: SLA 초과 (`now > sla_due_at` 미해결) = 자동 에스컬레이션 (`assigned_role` 다음 단계로 자동 승격)
- F-CS-03: 비정형 분쟁·법무 케이스 = SUPER 즉시 통보 (Slack #security)
- F-CS-04: 개인정보 정보주체 권리 케이스 (`legal_privacy_subject`) = 7일 법정 응답 SLA
- F-CS-05: CSAT 측정 = 종료 후 7일 내 1회 발송 (`csat_sent_at` 1회만 SET)

**SLA 매트릭스 (priority별)**:

| priority | 적용 케이스 예 | 응답 SLA |
|---|---|---|
| immediate | 환불 사기 의심·개인정보 유출·PG 장애 | 즉시 (SUPER 즉시 통보) |
| 4h | 환불 지연·악성 리뷰·MFA 분실·이메일 provider 장애 | 4시간 |
| 24h | 결제 실패 문의·배송 지연·다건 부분 반품 교환 | 24시간 |
| 1d | 비회원→회원 카트 병합 오류·리뷰 적립 누락·상품 단종 | 1일 |
| 7d | 개인정보 정보주체 권리·분쟁(소비자원) | 7일 (법정) |
