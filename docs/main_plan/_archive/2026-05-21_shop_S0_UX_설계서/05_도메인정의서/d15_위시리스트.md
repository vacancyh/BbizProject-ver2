## 1. 도메인 개요·책임 범위

- **1줄 책임**: 회원 찜·재입고 알림 구독·장바구니 이동·공유.
- **포지션**: member·product 단순 연결 + notification 도메인의 재입고 알림 트리거 발행자. 결제·재고·트랜잭션 위험은 거의 없는 **저위험 보조 도메인**.
- **회원 전용 정책**: 위시리스트는 회원 전용 (`00_개요.md §2 #8`). 비회원은 위시리스트 버튼 노출 시 로그인 모달 표시.
- **책임 경계 (out)**: 알림 발송 채널 선택(이메일/알림톡/SMS)·발송 자체는 notification 도메인 책임. 재입고 감지(`product.restocked`) 이벤트 발행은 product 도메인(본 도메인은 구독만). 장바구니 합산·검증은 cart 도메인(본 도메인은 일괄 추가 호출만).

## 2. 핵심 엔티티

### 2.1 wishlists (위시리스트 본체)

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|
| member_id | UUID | PK / FK → members.id | 회원당 위시리스트 1건 (1:1) |
| created_at | TIMESTAMPTZ | NOT NULL | |
| updated_at | TIMESTAMPTZ | NOT NULL | 추가·삭제 시 갱신 |
| item_count | INTEGER | NOT NULL DEFAULT 0 | wishlist_items 카운트 캐시 (대시보드용) |

**인덱스**: `idx_updated_at`, `idx_item_count`.

### 2.2 wishlist_items (위시리스트 라인)

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|
| id | UUID | PK | |
| member_id | UUID | FK → wishlists.member_id NOT NULL | |
| product_id | UUID | FK → products.id NOT NULL | 위시는 **상품 단위** (옵션 무관) |
| added_at | TIMESTAMPTZ | NOT NULL | 정렬 키 (최근순) |

**제약**: `UNIQUE(member_id, product_id)` — 중복 추가 차단.
**인덱스**: `idx_member_added_at`(복합), `idx_product_id` (인기 위시 집계).

### 2.3 restock_alerts (재입고 알림 구독)

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|
| id | UUID | PK | |
| member_id | UUID | FK → members.id NOT NULL | |
| product_id | UUID | FK → products.id NOT NULL | |
| sku_id | UUID | NULL FK → product_skus.id | 옵션 조합(option_combination_id) 단위. NULL 시 상품 전체 재입고 |
| subscribed_at | TIMESTAMPTZ | NOT NULL | |
| notified_at | TIMESTAMPTZ | NULL | 재입고 알림 발송 시각 (NULL = 미발송) |
| unsubscribed_at | TIMESTAMPTZ | NULL | 구독 해제 시각 |
| notify_channel | ENUM | NOT NULL DEFAULT 'auto' | auto (회원 동의 우선) / email / sms / kakao |

**제약**: `UNIQUE(member_id, product_id, COALESCE(sku_id, '00000000-0000-0000-0000-000000000000'))` — 중복 구독 차단 (PostgreSQL `EXCLUDE` 또는 부분 인덱스).
**인덱스**: `idx_product_sku_unnotified`(notified_at IS NULL 부분 인덱스 — 발송 배치 최적화), `idx_member_subscribed_at`.

### 2.4 wishlist_share (공유 링크 — 선택)

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|
| id | UUID | PK | |
| member_id | UUID | FK NOT NULL | |
| share_token | VARCHAR(32) | UNIQUE NOT NULL | URL 해시 토큰 (난수화) |
| created_at | TIMESTAMPTZ | NOT NULL | |
| expires_at | TIMESTAMPTZ | NOT NULL | 기본 30일 |
| view_count | INTEGER | NOT NULL DEFAULT 0 | 조회 카운트 |

**룰**: 공유 링크 조회는 **읽기 전용 + 본인 미식별** (수신자에게 회원 식별자 노출 금지).

| F8 | 단종/hidden 상품은 라인 유지하되 "단종" 배지 + 카트 이동 시 자동 skip | d12 §F12 결합, WIS-U-007 |
| F9 | 재입고 알림 발송 트리거 = `product.restocked` 이벤트 (d12 §F9 결합) — sku_id 매칭 우선, NULL 구독은 상품 단위 매칭 | PRD-A-014, WIS-A-003 |
| F10 | 알림 채널 우선순위 = 알림톡(카카오) > 이메일 > SMS (회원 동의 한정, P4 정책 변경 가능) | (도메인 내부 NOT-A-002) |
| F11 | 알림 발송 완료 시 notified_at SET — 중복 발송 차단 (멱등) | (도메인 내부 NOT-U-005) |
| F12 | 회원 status != active (suspended/banned/withdrawn) 시 알림 발송 skip | d11 §F* 결합 |
| F13 | 회원 알림 채널 동의 모두 OFF 시 구독 생성 차단 + 안내 | (도메인 내부 NOT-U-002) |
| F14 | 공유 링크 = share_token 난수화 (32자 base62) + 본인 식별자 미노출 + 30일 TTL | (도메인 신규) |
| F15 | 공유 링크 조회는 읽기 전용 — 위시 추가/삭제/구독 불가 | (도메인 신규) |
| F16 | 위시 라인 → 카트 일괄 이동 시 옵션 미선택 라인은 옵션 선택 모달 (d14 §3 UC-CRT-U-09 결합) | WIS-U-007 |
| F17 | 빈 위시리스트 진입 시 안내 메시지 표시 (UX 고정 문구 — "찜한 상품이 없습니다") | WIS-U-008 |
| F18 | 비로그인 하트 클릭 시 로그인 모달 노출 (위시 액션 자체 차단) | WIS-U-003 |

## 9. QA 추적

### 9.1 사용자 시나리오 (`쇼핑몰_전용_QA_v4.md §5` WIS-U-* 전수, 2026-05-23 v4 prefix 정정)

### 9.2 관리자 시나리오 (`쇼핑몰_전용_QA_v4.md §5` WIS-A-* 전수, 2026-05-23 v4 prefix 정정)

- **재입고 알림 대상 회원 수 조회**: WIS-A-003 (1건)
- **합계 (QA v4 §5 in scope)**: **3건**

> 도메인 자체 시나리오(회원별 위시 상세 CS / 재입고 수동 일괄 발송 / 인기 위시 엑셀 다운로드) = QA v4 §5 에는 ID 없음. §11 알림 영역 후속 합의 필요.

### 9.3 비기능 인용 (`공통_인프라_보안_QA.md`)

- **A-2 API 보안**: A-API-002 (IDOR — 본인 위시), A-API-016 (공유 토큰 추측 불가) (2건)

### 9.4 합계

QA v4 §5 직접 매핑 = 사용자 8 + 관리자 3 + 비기능 5 = **16건** QA 추적 (2026-05-23 v4 정합 재계산).
