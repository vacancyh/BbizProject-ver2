## 1. 도메인 개요·책임 범위

- **1줄 책임**: 가입·로그인·프로필·멤버십·탈퇴·블랙리스트
- **포지션**: 모든 다른 도메인의 **인증·권한 기반**. 회원 식별이 선행되지 않으면 주문·결제·리뷰·문의·쿠폰·포인트 사용 불가.
- **회원 전용 정책**: 비회원 주문 불가 (`00_개요.md §2 #8`). 비회원 장바구니(localStorage)는 결제 진입 시 **로그인 강제 게이트**로 전환.
- **책임 경계 (out)**: 알림 발송 자체는 notification 도메인이 담당. 본 도메인은 알림 **설정 저장/조회**만 담당. 쿠폰·포인트 발급 로직은 coupon_point 도메인 (본 도메인은 이벤트 발행만).

## 2. 핵심 엔티티

### 2.1 members (회원 본체)

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|
| id | UUID | PK | |
| email | VARCHAR(255) | UNIQUE NOT NULL | 소문자 정규화 |
| password_hash | VARCHAR(255) | NULL 허용 (소셜 전용 계정) | bcrypt/argon2 |
| name | VARCHAR(50) | NOT NULL | |
| phone | VARCHAR(20) | NULL | 해시 비교용 인덱스 별도 |
| birthdate | DATE | NULL | 만 14세 검증용 |
| gender | ENUM | NULL | F/M/N |
| status | ENUM | NOT NULL DEFAULT 'active' | active / suspended / banned / withdrawn |
| membership_grade | ENUM | NOT NULL DEFAULT '일반' | 일반 / 실버 / 골드 / VIP |
| total_purchase_amount | DECIMAL(12,0) | DEFAULT 0 | 연 누적 (집계 기간 정책 변경 가능) |
| points_balance | DECIMAL(10,0) | DEFAULT 0 | point_ledger 합계 캐시 |
| created_at | TIMESTAMPTZ | NOT NULL | |
| email_verified_at | TIMESTAMPTZ | NULL | 이메일 인증 완료 시각 |
| withdrawn_at | TIMESTAMPTZ | NULL | 탈퇴 신청 시각 |
| withdrawal_grace_until | TIMESTAMPTZ | NULL | 30일 유예 종료 시각 |
