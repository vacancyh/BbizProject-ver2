## 1. 도메인 개요·책임 범위

- **1줄 책임**: 쿠폰 발급/사용/복원 · 포인트 적립/사용/소멸 · 회계 원장 보존.
- **포지션**: member·order·payment·review와 **다층 의존**. **결제 직전 최종 할인 산출 + 결제 후 원자성 복원**의 책임 도메인.
- **회원 전용 정책**: 쿠폰 발급·포인트 적립 모두 회원 한정 (`00_개요.md §2 #8`).
- **회계 원장 룰**: 포인트는 **잔액(balance) 단일값 + 원장(transactions) 보존** 이중 구조. 잔액 직접 UPDATE 금지 — 모든 변동은 transaction INSERT + balance 재계산.
- **결제 정책 결합**: 포인트 100% 사용 시 PG 미호출 (PAY-U-017B, d17). 쿠폰 + 포인트 동시 적용 = 쿠폰 우선 → 잔액에 포인트 차감.
- **책임 경계 (out)**: 결제 승인·환불 PG 호출은 d17 payment (본 도메인은 PointUsed/CouponUsed 이벤트만). 주문 상태 전이는 d16 order. 알림 발송은 notification.

## 2. 핵심 엔티티

### 2.1 coupons (쿠폰 정책 마스터)

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|
| id | UUID | PK | |
| code | VARCHAR(16) | UNIQUE NOT NULL | 영문대문자+숫자 16자 랜덤 |
| name | VARCHAR(100) | NOT NULL | 쿠폰명 (사용자 노출) |
| type | ENUM | NOT NULL | AMOUNT (정액) / PERCENT (정률) |
| value | DECIMAL(10,0) | NOT NULL CHECK > 0 | AMOUNT=원 / PERCENT=% (1~100) |
| min_order_amount | DECIMAL(12,0) | NOT NULL DEFAULT 0 | 최소 주문 금액 (충족 시 사용 가능) |
| max_discount | DECIMAL(10,0) | NULL | PERCENT 시 할인 상한 (NULL=무제한) |
| valid_from | TIMESTAMPTZ | NOT NULL | 발급 후 유효 시작 |
| valid_to | TIMESTAMPTZ | NOT NULL | 유효 종료 |
| usage_limit | INTEGER | NULL | 전체 발급 한도 (NULL=무제한) |
| per_user_limit | INTEGER | NOT NULL DEFAULT 1 | 1회원 발급 한도 |
| target | ENUM | NOT NULL DEFAULT 'ALL' | ALL / CATEGORY / PRODUCT |
| target_ids | JSONB | NULL | CATEGORY/PRODUCT 시 ID 배열 |
| stackable | BOOLEAN | NOT NULL DEFAULT FALSE | 다른 쿠폰과 중복 사용 가능 여부 |
| issue_trigger | ENUM | NOT NULL | SIGNUP / BIRTHDAY / GRADE_UP / MANUAL / EVENT_CODE |
| status | ENUM | NOT NULL DEFAULT 'active' | active / inactive / expired |
| created_at | TIMESTAMPTZ | NOT NULL | |
| created_by | UUID | FK → admin_users.id NOT NULL | |

**인덱스**: `idx_code`, `idx_status_valid_to`, `idx_issue_trigger`.

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|

**인덱스**: `idx_coupon_id_member_id` (중복 발급 체크), `idx_member_id_status` (사용자 쿠폰함), `idx_expires_at_status` (만료 배치).

### 6.4 낙관락 충돌 재시도 (Tier2 §3.2 — F14 보강)

> 기존 F14 (포인트 사용 = USE row INSERT + balance 차감 단일 트랜잭션, 낙관락)에 자동 재시도 분류 추가.

| # | 룰 | 적용 |
|---|---|---|
| F-OPTLOCK-01 | 낙관락 = `points.version` 필드 (UPDATE 시 +1) | 트랜잭션 |
| F-OPTLOCK-02 | 충돌 시 분류 1 (사용자 의도 — 본인 동시 결제 시도) vs 2 (시스템 race — 환불 + 적립 동시) 판정 | 모든 충돌 |
| F-OPTLOCK-03 | 분류 2 (배치·webhook·시스템) = 50ms × 2회 자동 재시도 | 자동 |
| F-OPTLOCK-04 | 분류 1 = 즉시 409 (재시도 X) | 사용자 의도 충돌 |
| F-OPTLOCK-05 | 멱등키 일치 (`point_transactions.idempotency_key`) = 캐시 응답 | Idempotency-Key 보유 |

### 6.5 트랜잭션 격리 수준 (Tier2 §3.3)

| 트랜잭션 | 격리 수준 | 사유 |
|---|---|---|
| 포인트 적립 (구매확정 EARN) | SERIALIZABLE | 멱등 키 race 차단 + balance 정합 |
| 포인트 사용 (결제 USE) | SERIALIZABLE | balance >= 0 검증 + 동시 결제 race 차단 |
| 포인트 복원 (취소 CANCEL) | SERIALIZABLE | 환불 트랜잭션과 단일 commit (분산 트랜잭션 X — F19) |
| 포인트 소멸 배치 (EXPIRE) | SERIALIZABLE | FIFO 차감 + 동시 사용자 사용 race 차단 |
| 쿠폰 발급 (일괄·자동) | SERIALIZABLE + `coupons.usage_limit` 낙관락 | 한도 race 차단 |
| 쿠폰 사용 (결제) | SERIALIZABLE | 1회용 race (PAY-U-020) 차단 |
| 정합성 감사 배치 (PNT-A-006) | REPEATABLE READ | 집계 일관성 |
| 포인트·쿠폰 잔액 조회 | READ COMMITTED | 읽기 위주 |

| # | 룰 | 적용 |
|---|---|---|
| F-ISO-01 | 결제·환불·취소 트랜잭션 = SERIALIZABLE 의무 | 무결성 |
| F-ISO-05 | serialization_failure (40001) → 자동 재시도 50ms × 2회 | PostgreSQL 안전망 |
