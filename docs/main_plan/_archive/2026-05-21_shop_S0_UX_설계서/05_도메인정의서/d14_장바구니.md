## 1. 도메인 개요·책임 범위

- **1줄 책임**: 회원 카트 보관·옵션/수량 관리·쿠폰 미리 적용·재고 변동 알림·주문서 진입 게이트.
- **포지션**: member·product·coupon_point·order 사이의 **임시 상태 버퍼**. 자체 결제 트랜잭션은 없으며, 결제 직전까지 **수정 가능한 가변 상태**를 보관함.
- **회원 전용 정책**: 회원 카트(`carts` DB 저장)가 표준 (`00_개요.md §2 #8`). 비회원 카트는 클라이언트 localStorage 임시 저장(`b-cart=guest_local_storage`)으로만 허용되며, 결제 진입 시 **로그인 강제 게이트**가 발동되어 로그인 직후 서버 카트로 병합됩니다.
- **책임 경계 (out)**: 재고 차감 실행은 product 도메인(본 도메인은 실시간 조회·재검증 호출만). 쿠폰 발급·잔여 검증은 coupon_point 도메인(본 도메인은 적용 시도/해제만). 결제 트랜잭션·주문 INSERT는 order 도메인(본 도메인은 주문서 진입 페이로드 생성까지).

## 2. 핵심 엔티티

### 2.1 carts (카트 본체)

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|
| member_id | UUID | PK / FK → members.id | 회원당 카트 1건 (1:1) |
| created_at | TIMESTAMPTZ | NOT NULL | |
| updated_at | TIMESTAMPTZ | NOT NULL | 담기·수량·삭제·쿠폰 적용 시 갱신 |
| last_seen_at | TIMESTAMPTZ | NULL | 마지막 카트 조회 시각 (장기 미결제 알림 기준) |
| abandoned_notified_at | TIMESTAMPTZ | NULL | 7일 미결제 알림 발송 시각 (중복 발송 차단) |

**인덱스**: `idx_updated_at`, `idx_last_seen_at`, `idx_abandoned_notified_at`.

### 2.2 cart_items (카트 라인)

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|
| id | UUID | PK | |
| cart_id | UUID | FK → carts.member_id NOT NULL | |
| product_id | UUID | FK → products.id NOT NULL | |
| sku_id | UUID | FK → product_skus.id NOT NULL | 옵션 조합 SKU (option_combination_id) |
| qty | INTEGER | NOT NULL CHECK > 0 | 1 ≤ qty ≤ min(stock, 99) |
| added_at | TIMESTAMPTZ | NOT NULL | |
| selected | BOOLEAN | NOT NULL DEFAULT TRUE | 선택 결제용 체크 상태 (UI 보조) |
| price_at_add | DECIMAL(10,0) | NOT NULL | 담기 시점 단가 스냅샷 (가격 변동 감지용, 결제 금액은 실시간 단가 사용) |
| version | INTEGER | NOT NULL DEFAULT 0 | 동시 수량 변경 last-write-wins 보조 (최종 갱신 시각 비교) |

**제약**: `UNIQUE(cart_id, sku_id)` — 동일 옵션 중복 라인 금지 (분할 담기 시 기존 라인 수량 합산).
**인덱스**: `idx_cart_id`, `idx_sku_id`, `idx_added_at`.

### 2.3 cart_coupon_applied (카트에 미리 적용한 쿠폰)

| 필드 | 타입 | 제약 | 비고 |
|---|---|---|---|
| cart_id | UUID | PK / FK → carts.member_id | 카트당 쿠폰 1건 (정책상 단일 쿠폰 적용) |
| coupon_id | UUID | NOT NULL FK → coupons.id | |
| applied_amount | DECIMAL(10,0) | NOT NULL | 적용 시 계산된 할인액 (UI 표시용 캐시) |
| applied_at | TIMESTAMPTZ | NOT NULL | |

**룰**: 주문 생성 시 본 row 의 coupon_id 를 orders.coupon_id 로 이관 + cart_coupon_applied 삭제. 카트 변경 (담기/삭제/수량) 시 적용 조건 재검증 → 실패 시 자동 해제 + UI 알림.

### 2.4 guest_cart (참고 — 서버 미저장, 클라이언트 전용)

| 필드 | 타입 | 비고 |
|---|---|---|
| (localStorage key) | `shop_guest_cart_v1` | 비회원 카트 (브라우저 한정, 결제 진입 시 로그인 게이트) |
| items[] | { product_id, sku_id, qty, added_at } | TTL 30일 (브라우저 정책) |

**룰**: 로그인 직후 서버 카트와 **병합** — 동일 sku_id 발견 시 수량 합산 (단, min(합산, stock, 99) 상한) / 신규 sku_id 는 INSERT. 병합 후 localStorage 초기화.

### 6.5 트랜잭션 격리 수준 (Tier2 §3.3)

| 트랜잭션 | 격리 수준 | 사유 |
|---|---|---|
| 카트 UPSERT (담기) | READ COMMITTED + `UNIQUE(cart_id, sku_id)` | UPSERT atomic |
| 카트 조회·재검증 | READ COMMITTED | 읽기 위주 |
| 카트 → 주문서 진입 페이로드 생성 | READ COMMITTED + session-level cart_payload_hash | hash 검증 |
| 비회원 → 회원 카트 병합 | SERIALIZABLE | 동시 병합 race + 1인당 한도 검증 정합 |
| 카트 쿠폰 적용 | READ COMMITTED + 쿠폰 사용 조건 즉시 재검증 | 적용은 임시 상태 |

### 6.6 낙관락 — 카트는 last-write-wins (Tier2 §3.2 적용 X)

> 카트는 결제 트랜잭션이 아닌 임시 버퍼이므로 낙관락 충돌 시 자동 재시도 룰 X. F8 (수량 변경 = last-write-wins, version 비교 후 최종 갱신만 채택)이 본 도메인의 동시성 표준.
