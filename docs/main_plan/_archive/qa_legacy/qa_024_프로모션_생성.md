- Admin 로그인

---

## 시나리오 단계

### 1. 프로모션 생성

1. Sidebar -> Promotions -> "Create"
2. **Type** = `standard` / `buyget`
3. **Code** = "BRIDAL2026" (옵션 - 자동 생성 가능)
4. **Discount type** = `fixed` / `percentage`
5. **Discount value** = 10000 (KRW) 또는 10 (%)
6. **Allocation** = `each` (item별 적용) / `across` (전체 차감)
7. **Application method**:
   - **Target** = `items` / `shipping` / `order`
8. **Conditions** (옵션):
   - 최소 주문 금액 / 카테고리 / 컬렉션 / 상품 / 고객 그룹
9. **Validity**:
   - `starts_at` / `ends_at`
10. **Usage limit** (옵션): 총 사용 횟수 / 고객당 사용 횟수
11. **Campaign** (옵션): qa_025 캠페인 매핑
12. Save

### 2. 프로모션 활성화 / 비활성화

- 상세 -> "Activate" / "Deactivate"

### 3. Storefront 적용 검증

- Storefront 결제 진입 -> 프로모션 코드 입력 -> 할인 적용

---

## PASS 기준

- `promotion` row 생성
- `application_method` + `rules` 정합
- Storefront 적용 시 할인 정합
- Usage 카운트 정합

---

## FAIL 케이스 (박제)

| 케이스 | 예상 결과 |
|---|---|
| 동일 code 중복 | 400 |
| Usage limit 초과 | 적용 실패 |
| 기간 외 사용 | 적용 실패 |
| 조건 불충족 | 적용 실패 (silent) |
| Discountable = OFF 상품에 적용 | 적용 안 됨 |
