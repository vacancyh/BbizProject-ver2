## 시나리오 단계 (메두사 user-guide 원문 인용)

user-guide 인용 (`products_create_page.mdx` §How to Create a Product): "To create a new product: 1. Go to the Products page from the sidebar. 2. Click on the Create button in the main section's header. This opens a form with three steps: Details, Organize, and Variants."

### 1. Details Step

1. Admin Sidebar -> Products -> "Create" 클릭
2. **Title** = "14K 골드 심플 목걸이 NB-001" (★ 유일 필수 필드)
3. **Subtitle** = "데일리 펜던트"
4. **Handle** = "necklace-nb-001"
   - user-guide 인용: "The value of the Handle field is used in the product's URL on the storefront ... lowercase letters, numbers, and hyphens (`-`). If not specified, Medusa will generate a handle from the title."
   - 한국어 타이틀 자동 생성 시 handle invalid 가능 -> 명시 입력 필수
5. **Description** = HTML 또는 markdown 본문
6. **Media** = 상품 이미지 1+ 업로드 (drag drop 또는 "Upload images" 박스)
   - 썸네일 지정 = 이미지 row 의 EllipsisHorizontal -> "Make thumbnail"
7. **Variants 토글** = "Yes, this is a product with variants" 활성화
   - Option title = "사이즈", values = "S, M, L" (comma 구분)
8. "Continue" 클릭

### 2. Organize Step

1. **Discountable** = ON (할인 가능)
2. **Type** = "Necklace" (Settings > product-types 사전 생성)
3. **Collection** = "2026 SS Collection"
4. **Categories** = "Necklaces" (계층 카테고리 가능)
5. **Tags** = "14K-gold", "daily"
6. **Shipping profile** = "Default"
7. **Sales channels** = "Storefront" 체크
8. "Continue" 클릭

### 3. Variants Step

user-guide 인용 (§3): "Once you're done, either click the 'Publish' button if there are no more steps, or click the 'Continue' button to go to the next step."

1. 각 variant row 에 대해:
   - **Title** = "14K 골드 심플 목걸이 NB-001 / S"
   - **SKU** = "NB-001-S"
   - **Managed Inventory** = ON
   - **Allow backorder** = OFF
   - **Has inventory kit** = OFF (단일 상품)
   - **Price (KRW)** = 280,000
2. "Publish" 클릭

---

## PASS 기준

- `product` 테이블에 row 1개 생성 (`status = published`)
- `product_variant` 테이블에 3개 row (S/M/L)
- `inventory_item` + `inventory_level` 생성 (`manage_inventory = true` 시)
- `product_sales_channel` 매핑 row 생성
- Storefront 에서 `/products/necklace-nb-001` 접근 가능

---

## FAIL 케이스 (박제)

| 케이스 | 예상 에러 |
|---|---|
| Handle 중복 | 400 "Product with handle: necklace-nb-001, already exists" |
| Title 만 한국어 + Handle 미입력 | handle 자동 생성 시 invalid character |
| Shipping profile 미선택 | 400 또는 storefront 결제 시 shipping_option 매칭 실패 |
| Sales channel 미선택 | storefront 노출 안 됨 (구매 불가) |
| 가격 미입력 | 0 KRW = 무료 노출 |
