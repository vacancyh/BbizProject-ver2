# QA-005 = 컬렉션 관리 (Product Collections)

**출처**: `메두사_www_apps_user-guide_app_products_collections_page.mdx`
**한국 모듈 연동**: 없음
**우선순위**: P1 (필수)

---

## 사전 조건

- Admin 로그인
- 상품 5건 이상 (qa_001 기준)

---

## 시나리오 단계 (메두사 user-guide 원문 인용)

user-guide 인용: "A product collection is a group of products that share a common theme or purpose ... A product can be in a single collection."

### 1. 컬렉션 생성

1. Sidebar -> Products -> Collections
2. "Create" 클릭
3. **Title** = "2026 SS Bridal Collection"
4. **Handle** = "bridal-2026ss" (URL safe)
5. "Create" 클릭

### 2. 상품 매핑

1. 컬렉션 상세 -> Products 섹션 -> EllipsisHorizontal -> "Add"
2. 상품 5건 체크 -> Save

### 3. 컬렉션 편집

1. 컬렉션 상세 -> 첫 섹션 헤더 EllipsisHorizontal -> "Edit"
2. Title / Handle 편집 -> Save

### 4. 컬렉션 삭제

user-guide 인용: "Deleting a collection is irreversible."

1. 첫 섹션 EllipsisHorizontal -> "Delete" -> Confirm

---

## PASS 기준

- `product_collection` 테이블 row 생성
- `product.collection_id` 갱신 (1:N 관계)
- Storefront `/collections/bridal-2026ss` 접근 시 매핑된 상품만 노출

---

## FAIL 케이스 (박제)

| 케이스 | 예상 결과 |
|---|---|
| Handle 중복 | 400 "Collection with handle already exists" |
| 상품을 두 컬렉션에 동시 매핑 | 1 product = 1 collection 룰 -> 마지막 매핑이 우선 |
| 삭제 시 매핑된 상품 처리 | `product.collection_id = null` 갱신 (상품 자체는 보존) |
