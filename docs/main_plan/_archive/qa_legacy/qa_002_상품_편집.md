## 시나리오 단계 (메두사 user-guide 원문 인용)

### 1. 상품 상세 진입

user-guide 인용: "Go to the Products page from the sidebar. Select one of the products to open its details page."

1. Sidebar -> Products -> "14K 골드 심플 목걸이 NB-001" 클릭

### 2. General Details 편집

user-guide 인용 (§Edit Product Details): "Click on the EllipsisHorizontal icon in the first section's header. Choose 'Edit' from the dropdown."

1. 첫 섹션 헤더의 EllipsisHorizontal 클릭
2. "Edit" 선택
3. 측면 윈도우에서:
   - **Status** = "Published" / "Draft" / "Proposed" / "Rejected" 중 변경 가능
   - **Title** / **Subtitle** / **Handle** / **Material** / **Description** / **Discountable**
4. "Save" 클릭

### 3. Media 관리

user-guide 인용 (§Add Images): "Click on the EllipsisHorizontal icon in the 'Media' section's header. Choose 'Edit' from the dropdown."

- 이미지 추가 / 순서 변경 (drag drop) / 썸네일 지정 ('T' 키) / 삭제 ('D' 키)
- variant 별 이미지 연결 = 'M' 키 또는 "Manage associated variants" (Medusa Admin v2.11.2+)

### 4. Options 관리

user-guide 인용 (§Create Options): "Unlike the product-creation form, when you create an option for an existing product you must create the variants manually."

- Options 섹션 -> EllipsisHorizontal -> "Create" -> Option title + Values 입력

### 5. Sales channels / Shipping Configuration / Organize / Attributes / Metadata

- 각 섹션 우측 EllipsisHorizontal -> "Edit" -> 폼 편집 -> Save

---

## PASS 기준

- `product` row 의 `updated_at` 갱신
- Status 변경 시 storefront 노출 즉시 반영 (Published 만 노출)
- Media 순서 변경 시 `rank` 컬럼 정합
- 썸네일 변경 시 `product.thumbnail` 갱신

---

## FAIL 케이스 (박제)

| 케이스 | 예상 결과 |
|---|---|
| Status = Draft -> Storefront 접근 | 404 또는 비노출 |
| 옵션 삭제 시 사전 variant 존재 | 데이터 무결성 위반 / 삭제 차단 |
| 이미지 0개 상태로 Save | thumbnail = null = storefront placeholder |
