## 시나리오 단계 (메두사 user-guide 원문 인용)

### 1. 카테고리 생성

user-guide 인용: "A product category is a group of products that belong to a similar type or theme ... Categories can be nested within other categories to create a hierarchy."

1. Sidebar -> Product -> Categories
2. "Create" 클릭
3. Details Step:
   - **Title** = "목걸이" (필수)
   - **Handle** = "necklaces" (URL safe)
   - **Description** = "14K 골드 / 실버 목걸이"
   - **Status** = "Active" / "Inactive"
   - **Visibility** = "Public" / "Private"
4. "Continue" -> Ranking step -> Save

### 2. 카테고리 중첩 (Nesting)

1. "Edit ranking" 버튼 클릭
2. DotsSix drag icon 으로 "목걸이" 를 "주얼리" 하위로 drag
3. 자동 저장

### 3. 카테고리 상품 매핑

1. 카테고리 상세 -> Products 섹션 -> EllipsisHorizontal -> "Add"
2. 상품 목록 체크 -> Save
3. 제거: 상품 row 체크 -> 'R' 키 또는 "Remove"

### 4. Status / Visibility 검증

user-guide 인용 (§Product Category Status and Visibility):
- **Active** = "The category is active and shown on the storefront."
- **Inactive** = "The category is inactive and not shown on the storefront."
- **Public** = "The category is visible to customers on the storefront."
- **Private** = "The category is not visible to customers on the storefront. It's only used by admin users."
