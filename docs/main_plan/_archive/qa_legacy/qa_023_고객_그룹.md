## 시나리오 단계

### 1. 그룹 생성

1. Sidebar -> Customers -> Groups
2. "Create"
3. **Name** = "VIP" 또는 "신규회원"
4. Save

### 2. 고객 그룹 매핑

1. 그룹 상세 -> Customers 섹션 -> EllipsisHorizontal -> "Add"
2. 고객 체크 -> Save

### 3. 그룹 단위 promotion 적용

- qa_024 의 promotion 에서 target = customer group 선택

### 4. 그룹 편집 / 삭제

- 상세 -> EllipsisHorizontal -> Edit / Delete -> Confirm

---

## PASS 기준

- `customer_group` row 생성
- `customer_customer_group` link table 정합
- Promotion 적용 시 그룹 멤버만 할인 적용
