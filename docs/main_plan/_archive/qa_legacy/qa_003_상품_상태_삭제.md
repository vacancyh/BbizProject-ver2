---

## 시나리오 단계 (메두사 user-guide 원문 인용)

### 1. Status enum 4종 검증

user-guide 인용 (§Product Statuses): "A product can have one of the following statuses:"

| Status | 메두사 설명 (원문) |
|---|---|
| Published | "The product is available on the storefront and can be purchased." |
| Draft | "A product whose details you're still working on. It's not available on the storefront." |
| Proposed | "A product that is not yet approved for publishing. It's not available on the storefront." |
| Rejected | "A product that has been rejected and is not available on the storefront." |

- 각 status 별 상품 1건씩 만들고 storefront 노출 여부 확인
- Storefront `/products` 리스트에 **Published 만** 노출

### 2. Status 변경 단계

1. Products -> 상품 선택 -> 첫 섹션 헤더 EllipsisHorizontal -> "Edit"
2. Status 드롭다운 변경 -> Save
3. Storefront 재방문 -> 노출 변경 확인

### 3. 상품 삭제

user-guide 인용 (§Delete Product): "Deleting a product is irreversible."

1. 첫 섹션 헤더 EllipsisHorizontal -> "Delete"
2. 팝업 "Delete" 클릭 confirm

## PASS 기준

- `product.status` 컬럼 갱신 정합
- Published -> Draft 즉시 storefront 비노출
- Delete 시 `product` row + 연관 `product_variant` cascade 삭제 (soft delete = `deleted_at` set)
- inventory_item 은 별도 module 이므로 cascade 영향 확인
