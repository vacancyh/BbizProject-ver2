# QA-009 = 재고 항목 관리 (Inventory Items)

**출처**: `메두사_www_apps_user-guide_app_inventory_inventory_page.mdx`
**한국 모듈 연동**: 없음
**우선순위**: P1 (필수)

---

## 사전 조건

- Admin 로그인
- qa_001/qa_006 시나리오 완료 (variant 5+개)
- Stock location = "Seoul Warehouse" 1개

---

## 시나리오 단계

### 1. 재고 항목 조회

1. Sidebar -> Inventory
2. SKU 검색 / location 필터
3. 컬럼 = SKU / Title / Reserved / In Stock / Stocked Quantity

### 2. 재고 수량 갱신

1. SKU row 클릭 -> 상세 페이지
2. Location 별 "Stocked Quantity" 편집
3. Save

### 3. 재고 항목 직접 생성 (variant 없는 inventory item)

1. Sidebar -> Inventory -> "Create" 클릭
2. **SKU** / **Title** / **HS Code** / **Origin Country** 입력
3. 각 location 수량 입력
4. Save

### 4. 재고 항목 variant 연결

- 별도 product variant 의 "Edit" -> Inventory Kit 에서 inventory item 선택

---

## PASS 기준

- `inventory_item` row 생성
- `inventory_level` row = location 수 만큼 생성
- `stocked_quantity` 갱신 시 ledger 기록 (audit)
- Variant 매핑 시 `link table` 정합

---

## FAIL 케이스 (박제)

| 케이스 | 예상 결과 |
|---|---|
| SKU 중복 | unique 제약 |
| 음수 재고 입력 | 검증 실패 (대부분 차단) |
| Manage inventory OFF 인 variant | inventory 검증 skip |
| Reserved > Stocked | 주문 추가 불가 (재고 부족) |
