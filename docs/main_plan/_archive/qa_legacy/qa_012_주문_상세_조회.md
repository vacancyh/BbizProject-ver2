# QA-012 = 주문 상세 조회 + 주소 편집

**출처**: `메두사_www_apps_user-guide_app_orders_manage_page.mdx`
**한국 모듈 연동**: `state-machine` (주문 상태 조회)
**우선순위**: P1 (필수)

---

## 사전 조건

- 테스트 주문 1건 (storefront 또는 draft-order 로 생성)
- Admin 로그인

---

## 시나리오 단계 (메두사 user-guide 원문 인용)

### 1. 주문 상세 진입

user-guide 인용: "Go to Orders from the sidebar. Select one of the orders to open its details page."

### 2. 섹션별 정보 확인

user-guide 원문 섹션:
- **Summary** = "the summary of the items the customer purchased as well as totals related to taxes, shipping, and more"
- **Customer** = "customer's details, including their contact information and shipping address"
- **Activity** = "a summary of the changes made on the order. That includes payments captured, returned items, shipped items"
- **Payments** = "details related to the order's payments, showing a full history of the changes in the payment's status"
- **Unfulfilled Items** = "items that haven't been fulfilled yet"
- **Fulfillment Sections** = "For every fulfillment you create, a new fulfillment section is added"
- **JSON** = "raw order data in JSON structure"

### 3. 배송 주소 편집

user-guide 인용 (§Edit the Shipping Address):
1. Customer 섹션 헤더 -> EllipsisHorizontal -> "Shipping address"
2. 측면 윈도우에서 주소 편집 (한국 = 도로명 / 우편번호 / 상세주소)
3. Save

### 4. 청구 주소 편집

- Customer 섹션 -> EllipsisHorizontal -> "Billing address" -> Save

### 5. 이메일 편집

user-guide 인용: "This doesn't update the associated customer's email address or transfer the order to a new customer."

- Customer 섹션 -> EllipsisHorizontal -> "Email" -> Save

### 6. 고객 이전 (Transfer Customer Ownership)

user-guide 인용: "You can't transfer ownership to a guest customer ... The order is transferred to the new customer only after the original customer approves the transfer."

- Customer 섹션 -> "Transfer ownership" -> 신규 customer 선택 -> Save -> 원 고객 approval 대기

---

## PASS 기준

- 주문 상세 페이지 모든 섹션 렌더링 정합
- 주소 편집 -> `order.shipping_address` 갱신
- 이메일 편집 -> `order.email` 갱신 (customer.email 은 불변)
- Transfer ownership -> 원 고객 알림 발송 + approval 후 `order.customer_id` 갱신

---

## FAIL 케이스 (박제)

| 케이스 | 예상 결과 |
|---|---|
| Guest customer 로 transfer | 차단 "can't transfer ownership to a guest customer" |
| 주소 우편번호 = 빈값 | 검증 실패 |
| 한국 도로명 주소 → 영문 입력 | storefront 검색 / 배송사 연동 시 누락 가능 |
