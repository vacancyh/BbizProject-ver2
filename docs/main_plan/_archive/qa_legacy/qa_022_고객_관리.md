# QA-022 = 고객 관리 (Customers)

**출처**: `메두사_www_apps_user-guide_app_customers_manage_page.mdx`
**한국 모듈 연동**: 없음
**우선순위**: P1 (필수)

---

## 사전 조건

- Admin 로그인

---

## 시나리오 단계

### 1. 고객 생성

1. Sidebar -> Customers -> "Create"
2. **First name** / **Last name** / **Email** / **Phone**
3. **Company name** (옵션)
4. Save

### 2. 고객 편집

- 고객 상세 -> EllipsisHorizontal -> "Edit" -> 측면 윈도우 -> Save

### 3. 고객 주소 관리

- Addresses 섹션 -> "Add address" -> 한국 도로명 주소 입력 -> Save

### 4. 고객 주문 이력 조회

- 고객 상세 -> Orders 섹션 -> 주문 클릭 -> qa_012 진입

### 5. 고객 그룹 매핑

- Customer Groups 섹션 -> "Add" -> 그룹 체크 -> Save (qa_023 사후)

### 6. 고객 삭제

- EllipsisHorizontal -> "Delete" -> Confirm

---

## PASS 기준

- `customer` row 생성
- Email unique 제약
- Guest customer (storefront 비회원 결제) 와 registered customer 구분
- 한국 phone 형식 (+82 또는 010-XXXX-XXXX) 정합

## FAIL 케이스 (박제)

|---|---|
| Email 중복 | 400 |
| Email 형식 invalid | 검증 실패 |
| 주문 이력 존재 고객 삭제 | 차단 또는 soft delete |
| 만 14세 미만 가입 | (다음 사이클) |
