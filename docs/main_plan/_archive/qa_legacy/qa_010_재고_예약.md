## 시나리오 단계

### 1. 예약 자동 생성 (주문 시)

- Storefront 에서 결제 완료 시 자동으로 reservation 생성
- 검증: Inventory -> SKU 상세 -> Reservations 섹션에 row 표시

### 2. 예약 수동 생성

1. Sidebar -> Inventory -> "Reservations" 탭
2. "Create" 클릭
3. **Inventory item** / **Location** / **Quantity** / **Description**
4. Save

### 3. 예약 편집 / 삭제

- Reservation row -> EllipsisHorizontal -> "Edit" / "Delete"

### 4. 예약 vs 가용 재고 검증

- `available_quantity = stocked_quantity - reserved_quantity`
- Storefront 노출 = `available > 0` 일 때만 구매 가능

---

## PASS 기준

- 주문 완료 시 reservation row 자동 생성
- `inventory_level.reserved_quantity` 갱신
- Cancel order 시 reservation 자동 삭제
- Manual reservation 도 `available` 차감

---

## FAIL 케이스 (박제)

| 케이스 | 예상 결과 |
|---|---|
| Reservation > Stocked | 주문 진행 불가 |
| 주문 취소 시 reservation 잔존 | 데이터 무결성 위반 |
| Manage inventory = OFF 인 variant 주문 | reservation 생성 안 됨 (재고 무제한) |
