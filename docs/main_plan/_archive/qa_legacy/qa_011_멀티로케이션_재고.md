# QA-011 = 멀티-로케이션 재고 분산

**출처**: `메두사_www_apps_user-guide_app_settings_locations-and-shipping_locations_page.mdx`
**한국 모듈 연동**: 없음
**우선순위**: P1 (필수, 단 한국 D2C jewelry shop 의 경우 단일 로케이션 시작)

---

## 사전 조건

- Admin 로그인
- Stock location 2개 (예: "Seoul Warehouse" + "Busan Warehouse")

---

## 시나리오 단계

### 1. 추가 로케이션 생성

1. Sidebar -> Settings -> Locations & Shipping -> Locations
2. "Create" 클릭
3. **Name** / **Address** / **Sales channels** 입력
4. Save

### 2. SKU 별 로케이션 분산

- qa_009 의 inventory item 상세에서 각 location 수량 분산 입력 (Seoul = 30, Busan = 20)

### 3. 주문 시 로케이션 할당

- Storefront 주문 -> Shipping option 의 location 으로 자동 할당
- Admin 주문 상세 -> Summary -> 미할당 시 "Allocate items" 버튼 표시

user-guide 인용 (`orders_manage_page.mdx` §Allocate Order Items Manually): "Medusa allocates the ordered quantity from the stock location of the chosen shipping option in the order ... If one or more items haven't been allocated, you'll find an 'Allocate items' button at the bottom of the section."

### 4. 수동 재할당

1. 주문 상세 -> Summary -> "Allocate items" 클릭
2. Location 선택 + Items to Allocate 수량 입력
3. "Allocate Items" 클릭

---

## PASS 기준

- `stock_location` 2개 생성
- `inventory_level` row = 각 (item, location) pair
- 주문 할당 시 `reservation.location_id` 정합
- 재할당 시 기존 reservation 해제 + 신규 reservation 생성

---

## FAIL 케이스 (박제)

| 케이스 | 예상 결과 |
|---|---|
| 재고 0 location 으로 할당 | "can't receive the item unless you add inventory" 차단 |
| Sales channel 미연결 location | 해당 channel 주문 시 미할당 |
| Shipping option 의 location 과 실 재고 불일치 | 수동 재할당 필요 |
