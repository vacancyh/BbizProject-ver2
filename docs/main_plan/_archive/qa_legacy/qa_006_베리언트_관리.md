## 시나리오 단계 (메두사 user-guide 원문 인용)

### 1. 베리언트 생성 (반지 = 사이즈 5/6/7/8/9)

user-guide 인용: "You can only create a product variant if there are option combinations that aren't created as a variant yet."

1. 상품 상세 -> Variants 섹션 -> "Create"
2. Details Step:
   - **Title** = "14K 반지 / 사이즈 5"
   - **SKU** = "RING-001-5"
   - **사이즈** = "5"
   - **Manage Inventory** = ON
   - **Allow backorders** = OFF
   - **Has inventory kit** = OFF
3. Prices Step:
   - KRW = 320,000
4. "Save"

### 2. 베리언트 편집

user-guide 인용 (§Edit Product Variant Details): "In the Variants section, click on the EllipsisVertical in its row. Choose 'Edit' from the dropdown."

- **Title / Materials / Option values / SKU / EAN / UPC / Barcode** 편집 가능
- **Attributes** = weight / height / width / length / MID code / HS code / country of origin

### 3. 베리언트 가격 일괄 편집

user-guide 인용 (§Edit Product Variant Prices): "Click on the EllipsisVertical in the section's header. Choose 'Edit Prices' from the dropdown."

- Bulk Editor 로 전 베리언트 × 전 통화 가격 한번에 편집
- Tax-exclusive / Tax-inclusive 아이콘 구분 (KR region 설정 따라)

### 4. 베리언트 재고 일괄 편집

user-guide 인용 (§Manage Product Variant Inventory): "Choose 'Edit stock levels' from the dropdown."

- Bulk Editor 에서 SKU + 각 stock location 수량 일괄 편집

### 5. 베리언트 이미지 매핑

user-guide 인용 (§Manage Product Variant Media, v2.11.2+): "A product variant can have images specific to it. These are selected from the product's media."

- 베리언트 상세 -> Media 섹션 -> EllipsisVertical -> "Edit images"
- 우측 product media 에서 변형 전용 이미지 선택

### 6. 베리언트 삭제

user-guide 인용: "Deleting a product variant is irreversible."

- Variants row -> EllipsisVertical -> "Delete" -> Confirm

---

## PASS 기준

- `product_variant` row 생성 + `option_value` 매핑
- `inventory_item` 자동 생성 (`manage_inventory = true`)
- `price` 테이블에 KRW row 생성
- Variant 이미지 매핑 시 `product_image.variant_id` 갱신

## FAIL 케이스 (박제)

| 케이스 | 예상 결과 |
|---|---|
| SKU 중복 | 400 또는 unique 제약 위반 |
| Manage Inventory = OFF + 주문 | 재고 검증 skip = 무제한 판매 |
| Allow backorders = ON + 재고 0 | 주문 진행 가능 (백오더) |
| 옵션 조합 미존재 시 variant 생성 | 차단 (옵션 먼저 생성 의무) |
