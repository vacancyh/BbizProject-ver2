## 시나리오 단계

### 1. 캠페인 생성

1. Sidebar -> Promotions -> Campaigns 탭
2. "Create"
3. **Name** / **Identifier** / **Description**
4. **Budget**:
   - Type = `spend` / `usage`
   - Currency / Limit
5. **Validity** = starts_at / ends_at
6. Save

### 2. 프로모션 캠페인 매핑

- 프로모션 상세 -> Campaign 섹션 -> 캠페인 선택 -> Save

### 3. 캠페인 소진 검증

- Budget Type = `spend` 시 cumulative discount 가 limit 도달하면 모든 매핑 프로모션 자동 비활성
- Budget Type = `usage` 시 cumulative usage count

---

## PASS 기준

- `campaign` row 생성
- `promotion.campaign_id` 갱신
- Budget 소진 시 자동 비활성

---

## FAIL 케이스 (박제)

| 케이스 | 예상 결과 |
|---|---|
| Budget = 0 | 즉시 소진 |
| 캠페인 종료 후 프로모션 사용 | 적용 실패 |
| 한 프로모션을 두 캠페인 매핑 | 1:1 룰 (정책 따라) |
