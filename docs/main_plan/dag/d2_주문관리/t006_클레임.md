# 기능 상세명세 — t006 클레임

> Medusa `createClaimWorkflow` 호출/래핑. Claim.type(replace/refund). 결함/오배송 보상 처리. 검수 등급(d6 t005)으로 사업자 귀책 판정.

## 1. 기능 목적
- 결함·오배송 주문에 대해 클레임(보상)을 처리한다. replace(대체 발송) 또는 refund(환불). 사업자 귀책 시 배송비 사업자 부담. 검수 결과로 양호/불량 판정.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 클레임 생성 클릭 | 대상 라인 + 유형 선택 | 클레임 모달 | replace/refund 선택 |
| 2 | 증빙/사유 입력 후 접수 | createClaim | 접수됨 | Claim 생성 |
| 3 | replace 발송 / refund 처리 | 보상 실행 | 완료 | 보상 완료 알림 |

## 3. 화면/상태 정의
