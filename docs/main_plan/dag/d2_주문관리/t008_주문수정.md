# 기능 상세명세 — t008 주문 수정

> Medusa `createOrderEditWorkflow`(OrderChange→version 증가) + edit-email/배송지/청구지 호출/래핑. 발송 전 한정.

## 1. 기능 목적
- 발송 전 주문의 라인(수량/추가/삭제)·배송지·청구지·이메일을 수정한다. OrderChange로 버전 증가, OrderSummary 재계산. 차액 발생 시 추가결제/환불 연동.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 주문 수정 클릭 | 편집 가능 항목 활성 | 수정 모달 | 발송 전만 활성 |
| 2 | 라인/주소/이메일 변경 | OrderChange 생성(pending) | 변경 미리보기 | 차액 표시 |
| 3 | 확정 | version 증가 + summary 재계산 | 수정 완료 | 이력 기록 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|
| S1 | 수정 가능 | status ≤ preparing | 라인/주소/이메일 편집 | shipping 이후 금지 |
| S2 | 변경 미리보기 | 변경 입력 | 차액·신규 summary | - |
