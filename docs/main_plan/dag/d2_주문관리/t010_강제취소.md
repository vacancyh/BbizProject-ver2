# 기능 상세명세 — t010 강제 취소 (갭B)

> Medusa core 無(운영 특화) → 커스텀. cancelOrderWorkflow 래핑 + 진행중 주문(paid/preparing) 강제취소 + 자동 환불·재고복구. 블랙리스트(d5 t006) 연동. blocker task.

## 1. 기능 목적
- 관리자(SUPER/OPERATION)가 정책 위반·사기·블랙리스트 등록 등으로 진행중 주문을 강제 취소한다. 한 SERIALIZABLE 트랜잭션에서 재고복구+환불+알림 구동(F1). 사유 enum(fraud/staff) 기록.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 강제취소 클릭 | 이중확인 모달 | 확인 | 사유 입력 강제 |
| 2 | 사유 입력 + 확인 | 재고복구+환불+알림 트랜잭션 | 처리중 | 전체 성공/롤백 |
| 3 | 완료 | order.auto_cancelled/cancelled | canceled | 감사로그 기록 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|

| S2 | 취소 완료 | 트랜잭션 성공 | canceled + 환불 내역 | 부분 실패 시 전체 롤백 |
