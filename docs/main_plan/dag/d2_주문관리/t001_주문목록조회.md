# 기능 상세명세 — t001 주문 목록·검색

> Medusa `GET /admin/orders` 호출/래핑. 결제축/배송축 파생 2축 표시(설계 D2). 복사·재구현 금지.

## 1. 기능 목적
- 관리자가 전체 주문을 상태/기간/키워드로 검색·필터하고, 결제 상태축·배송 상태축을 파생 표시해 운영 가시성을 확보한다. CSV export 제공.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 주문 메뉴 진입 | 최근순 주문 목록 로드 | 목록 | 1페이지 표시 + 총건수 |
| 2 | 상태/기간/키워드 필터 적용 | 필터 쿼리 재조회 | 목록(필터됨) | 조건 일치 행만 |
| 3 | export 클릭 | CSV 생성·다운로드 | 다운로드 | 현재 필터 기준 CSV |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|
| S1 | 목록 로드 | 메뉴 진입 | 주문번호(ORD-YYYYMMDD-XXXXXX)·결제상태축·배송상태축·금액·일시 | - |
| S2 | 빈 결과 | 필터 0건 | 빈 상태 안내 | 에러 아님 |
| S3 | export 진행 | export 클릭 | 진행 토스트 | 중복 클릭 차단 |
