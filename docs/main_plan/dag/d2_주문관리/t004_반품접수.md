# 기능 상세명세 — t004 반품 접수

> Medusa `createReturnWorkflow` + `receiveReturnWorkflow` 호출/래핑. Return.status(requested/received/partially_received/canceled). 검수·환불방식은 d6 t005 + RMA link 연동.

## 1. 기능 목적
- 배송완료/구매확정 주문에 대해 반품(Return)을 접수하고 수거→수령 처리한다. 청약철회 7일(legal-kr) 사유는 link로 구분, 검수 결과(d6 t005)·환불방식(RMA link)으로 후속 환불(t007) 연결.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 반품 접수 클릭 | 반품 대상 라인 표시 | 반품 모달 | 라인/수량 선택 |
| 2 | 사유/배송비 부담 선택 후 접수 | createReturn (requested) | requested | Return 생성 |
| 3 | 입고 시 수령 처리 | receiveReturn (received) | received | 검수(d6 t005) 진입 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|
| S1 | 반품 요청 | delivered 이후 | 라인·사유·배송비부담 | 동일라인 중복 차단(409) |
| S2 | 부분 수령 | 일부 입고 | partially_received | 잔여 추적 |
| S3 | 수령 완료 | 전량 입고 | received | 검수 대기 |
