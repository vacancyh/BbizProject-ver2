# 기능 상세명세 — t002 주문 상세

> Medusa `GET /admin/orders/:id` 호출/래핑 + state-machine StateHistory 표시. 상품/결제/배송/이력/메모 통합 뷰.

## 1. 기능 목적
- 단일 주문의 라인아이템·금액(OrderSummary version)·결제 트랜잭션·배송/반품 상태·상태 전이 이력(StateHistory)·내부메모를 한 화면에서 조회하고, 후속 액션(t003~t011)으로 진입한다.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 목록에서 주문 클릭 | 상세 로드 | 상세 | 라인/금액/주소/이력 표시 |
| 2 | 이력 탭 클릭 | StateHistory 조회 | 이력 | 전이 순서 표시 |
| 3 | 후속 액션 버튼 | 해당 액션 진입(t003~t011) | 액션 모달/페이지 | 진입 성공 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|
| S1 | 상세 로드 | 주문 존재 | 라인아이템(스냅샷)·OrderSummary·결제/배송축·주소·이력·메모 | 미존재 시 404 |
| S2 | 취소 주문 | canceled | 취소 사유·환불 내역 | 액션 버튼 비활성 |
