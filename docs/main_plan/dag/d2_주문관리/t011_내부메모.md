# 기능 상세명세 — t011 내부 메모 (갭B)

> Medusa `metadata` 활용 + 커스텀 메모 모델. 주문별 운영/CS 내부 메모(고객 비노출). 작성자·시각 기록.

## 1. 기능 목적
- 관리자/CS가 주문에 내부 메모(고객 비노출)를 남긴다. CS 통합 이력에 연동. 작성자·시각 append, 수정/삭제 권한 제한.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 상세 메모 탭 | 메모 목록 로드 | 메모 | 시간순 표시 |
| 2 | 메모 입력 후 저장 | 메모 append(작성자/시각) | 저장됨 | 즉시 반영 |
| 3 | 메모 수정/삭제 | 권한 검증 후 처리 | 갱신 | 본인/SUPER만 |

## 3. 화면/상태 정의

| S2 | 메모 작성 | 입력 | 텍스트 | 빈 메모 금지 |
