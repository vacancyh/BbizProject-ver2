# 기능 상세명세 — t003 배송 처리(이행)

> Medusa `createFulfillment` + `allocate-items` + `createShipment` 워크플로 호출/래핑. fulfillment 1:N(부분배송) 지원. Vendure fulfillment-state 정합.

## 1. 기능 목적
- 결제완료(paid) 주문에 대해 재고 할당 → 이행(fulfillment) 생성 → 송장/택배사 입력 → 발송 처리한다. 부분배송(partially_delivered) 허용. 발송 시 order.status preparing→shipping 전이.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 상세에서 배송처리 클릭 | 이행 대상 라인 표시 | 이행 모달 | 라인 선택 가능 |
| 2 | 라인 선택 + 재고 할당 | allocate-items 실행 | 할당됨 | 재고 차감 확정 |
| 3 | 택배사/송장 입력 후 발송 | createShipment + status 전이 | shipping | 송장 저장 + 알림 발송 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|
| S1 | 이행 생성 | paid/preparing | 라인·수량·창고 | 미결제 주문 금지 |
| S2 | 부분배송 | 일부 라인만 이행 | partially_delivered 배지 | 잔여 라인 추적 |
| S3 | 발송 완료 | 송장 입력 | shipping 배지 | 송장 중복 금지 |
