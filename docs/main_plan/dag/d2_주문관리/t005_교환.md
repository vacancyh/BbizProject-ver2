# 기능 상세명세 — t005 교환

> Medusa `createExchangeWorkflow` 호출/래핑 + 다건 교환 그룹(order-exchange-group 커스텀, 설계 D11). 1회 회수 운송장 + 차액 합산 결제.

## 1. 기능 목적
- 반품(회수) + 신규 배송을 묶은 교환을 처리한다. 다건 교환은 exchange_group으로 묶어 1회 회수·차액 합산. 차액(+)은 추가결제, 차액(−)은 환불.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 교환 생성 클릭 | 회수 라인 + 신규 변형 선택 | 교환 모달 | 차액 자동 계산 |
| 2 | 차액 처리 방식 확정 | createExchange + group 묶음 | exchanging | Exchange + 회수 운송장 |
| 3 | 회수 입고 후 신규 발송 | 신규 fulfillment | exchanged | 교환 완료 알림 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|

| S2 | 차액 결제 대기 | 차액 > 0 | 추가결제 안내 | 미결제 시 보류 |
| S3 | 교환 완료 | 신규 발송 | exchanged | - |
