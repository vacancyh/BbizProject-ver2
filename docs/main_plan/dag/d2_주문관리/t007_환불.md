# 기능 상세명세 — t007 환불

> Medusa refund 워크플로 호출/래핑 + day-1 필수(멱등키·Pro-rata 부분환불·LIFO 보상). 청약철회 §18 3영업일 환불 의무. 정산(d7) 차감 연동.

## 1. 기능 목적
- 취소·반품·클레임에 따른 환불(전액/부분)을 처리한다. 부분취소 시 쿠폰·포인트·배송비 1원 단위 비례 배분(F6), 잔여<5만원 시 배송비 재청구(F7). 멱등키로 중복 환불 방지. 환불 = 정산 net 차감.
- 환불 수단 = 원결제 PG 취소(기본). PG 취소 불가·결제기간 경과 시 **고객 계좌 현금 입금환불**(정산 net 동일 차감). 현금영수증 발급 의무 없음(현금 결제 미운영).

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 환불 실행 클릭 | 환불 금액 자동 계산(비례배분) | 환불 모달 | 금액/포인트/쿠폰 복원 표시 |
| 2 | 금액 확인 후 환불 | refund + 멱등키 | 처리중 | PG 환불 요청 |
| 3 | 환불 완료 | order.cancelled/partial_cancelled 이벤트 | 완료 | 정산 차감 + 알림 |
