# 기능 상세명세 — t009 수기 주문 생성

> Medusa draft order(`is_draft_order=true`) 호출/래핑. 전화/CS 주문을 관리자가 수동 생성 후 결제 링크/수기 결제 확정.

## 1. 기능 목적
- 관리자가 고객 대신 주문을 생성한다(전화 주문/CS). 고객·상품·수량·주소·할인 입력 → draft 생성 → 결제(링크 발송 또는 수기 확정) → 정식 주문 전환.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 수기 주문 생성 클릭 | 고객/상품 검색 폼 | draft 폼 | 고객/상품 선택 |
| 2 | 라인·주소·할인 입력 | draft 저장 | draft | 금액 계산 |
| 3 | 결제 확정/링크 발송 | draft→order 전환 | paid/pending | 정식 주문 생성 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|
| S1 | draft 작성 | 메뉴 진입 | 고객·라인·주소·할인 | 재고 확인 |
| S2 | 결제 대기 | draft 완료 | 결제 링크/수기 결제 | - |
| S3 | 주문 전환 | 결제 완료 | order(ORD-…) | - |
