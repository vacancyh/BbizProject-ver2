# 기능 상세명세 — t008 쿠폰·포인트 경계 (엣지)

> 연계: d8 쿠폰프로모션·d5 포인트. 만료·한도·동시사용·환불 시 음수 등 쿠폰/포인트의 경계 조건을 방어.

## 1. 기능 목적
- 쿠폰/포인트의 만료·사용한도·동시사용·환불 복원 경계에서 정합을 보장한다(중복사용 0, 음수잔액 0).

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 쿠폰/포인트 적용 | 유효성·한도 검사 | 적용/거부 | 조건 충족만 |
| 2 | 동시 사용 시도 | UNIQUE 잠금 | 1회만 | 중복 0 |
| 3 | 환불 복원 | 음수 방지 절사 | 복원 | 잔액≥0 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |

| S2 | 환불 복원 | 환불 | 복원액·잔액 | 음수 금지 |

## 4. 입력/검증 규칙

| input_id | 입력값 | 필수 | 검증 규칙 | 실패 메시지 |

| I2 | 포인트 사용액 | 조건부 | ≤ 보유 잔액, ≤ 주문금액, **본인 소유 카트만**(IDOR 차단) | 잔액 부족 / 본인 장바구니가 아님 |

  총액 감소가 사용액과 일치(측정 999.9, 원 단위 반올림 오차 0.1).
- **기본값 OFF** — 회계 기준 합의 후 전환할 정책 항목. 상세: `user_plan/bizproject/금액정합_타임존_점검.md`
