# 기능 상세명세 — t001 결제 멱등성·중복결제 (엣지)

> 연계: d2 주문·d7 정산. 결제 경로의 중복·유실·불일치를 멱등키·webhook dedup·reconciliation으로 방어한다. 거래 무결성 blocker.

## 1. 기능 목적
- 네트워크 재시도/더블클릭/webhook 중복·유실 상황에서도 **정확히 1회 결제·1건 정산**을 보장한다.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 결제 요청(재시도 포함) | idempotency-key로 단일 처리 | 결제중 | 1회만 승인 |
| 2 | PG webhook 수신 | event ID dedup | 확정 | 중복 무시 |
| 3 | 일일 대사 배치 | 원장↔PG 대조 | 대사 | 불일치 flag |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
