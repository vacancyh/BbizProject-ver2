# 기능 상세명세 — t006 반품·환불 어뷰징 (엣지)

> 연계: d2 클레임·d5 제재. 거짓고객·반복환불·차지백 패턴을 탐지하고 리스크 기반으로 통제(검수의무/블랙리스트).

## 1. 기능 목적
- 환불/반품 어뷰징(serial returner·wardrobing·empty-box·friendly fraud)을 탐지하고, 리스크 등급에 따라 검수 강화·반품창 단축·블랙리스트를 적용한다.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 반품/환불 신청 | 고객 리스크 점수 산출 | 판정 | 등급 표시 |
| 2 | 고위험 감지 | 검수 의무 + 반품창 단축 | 강화 | 강화 적용 |
| 3 | 차지백 발생 | 카드 자동 블랙리스트 | 차단 | 재발 차단 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|
| S1 | 리스크 판정 | 신청 | 반품빈도·금액·패턴·등급 | 자동 거절 신중(오탐) |
| S2 | 블랙리스트 | 차지백/임계 초과 | 카드/고객 차단 | 정당 사유 시 해제 |
