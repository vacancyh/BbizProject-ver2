# 기능 상세명세 — t007 상태머신 전이 가드 (엣지)

> 연계: d2 주문(state-machine module). 불법 전이·역행·동시 전이를 FSM 가드로 차단하고 실패 시 rollback. 주문 무결성 blocker.

## 1. 기능 목적
- 주문/배송/환불 상태 전이를 FSM으로 강제한다. 불법 전이(역행/직접) 차단, 한국 PG 인증 단계 보장, 전이 실패 시 워크플로우 rollback.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 상태 전이 요청 | FSM 가드 검사 | 전이/거부 | 합법만 허용 |
| 2 | 부분 이행 | 부분 상태 부여 | PartiallyShipped | 정확한 상태 |
| 3 | 전이 중 오류 | onError rollback | 원복 | 정합 유지 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |

| S2 | rollback | 전이 실패 | 원복 상태 | 부분 적용 금지 |
