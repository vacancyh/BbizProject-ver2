# 기능 상세명세 — t004 청약철회 정책 경계 (엣지)

> 연계: d2 반품/환불·d6 배송. 한국 전자상거래법 §17~§18 경계(기산점·배송비 부담주체·철회불가 사유·3영업일 환불)를 강제.

## 1. 기능 목적
- 청약철회의 법적 경계를 자동 판정한다: 7일 기산점(배송완료일), 배송비 부담주체(단순변심=소비자/불량·오배송=사업자), 철회불가 사유, 3영업일 환불 SLA.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 청약철회 신청 | 기산점·기한 판정 | 판정 | 적법성 표시 |
| 2 | 사유 분류 | 배송비 부담주체 결정 | 분기 | 부담 정합 |
| 3 | 환불 처리 | 3영업일 SLA 추적 | 처리 | 기한내 환불 |
