# 기능 상세명세 — t002 재고 동시성·오버셀 (엣지)

> 연계: d3 재고·d2 주문. 동시 차감 race로 인한 오버셀/음수재고/예약 누수를 원자연산·낙관락으로 방어.

## 1. 기능 목적
- 고동시성 상황에서 재고 차감/예약/해제의 정합을 보장한다(오버셀 0, 음수재고 0, 예약 누수 0).

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 동시 주문 차감 | 원자적 조건부 차감 | 처리 | 재고≥0 보장 |
| 2 | 주문 취소 | 예약 복구(멱등) | 복구 | 이중복구 0 |
| 3 | 관리자 동시 수정 | 낙관락 version 검사 | 충돌 감지 | 마지막 손실 0 |

## 3. 화면/상태 정의
