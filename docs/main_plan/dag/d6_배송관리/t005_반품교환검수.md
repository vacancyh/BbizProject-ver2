# 기능 상세명세 — t005 반품·교환 검수 (갭B, rma-extension)

> Medusa core 無 → 커스텀(rma-extension, ★ 직전 세션 backend 구현분). 신청→수거→검수(양호/불량)→완료/거절 + 환불방식·반품정책·배송비 부담.

## 1. 기능 목적
- 반품(d2 t004)/교환(d2 t005) 입고품을 검수(양호/불량 등급)하고 환불방식·배송비 부담 주체·반품정책을 적용해 완료/거절한다. ReturnInspection·ReimbursementMethod link 활용. 자동 알림.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 검수 대기 목록 | received 반품 표시 | 목록 | 검수 대상 |
| 2 | 검수(양호/불량) 입력 | ReturnInspection 기록 | 검수됨 | 등급 저장 |
| 3 | 환불방식/배송비 적용 후 완료/거절 | 환불(d2 t007)/거절 + 알림 | 완료 | 후속 연동 |
