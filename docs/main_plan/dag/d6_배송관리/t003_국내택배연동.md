# 기능 상세명세 — t003 국내 택배 연동 (갭B)

> Medusa core 無 → 커스텀(delivery-ops module + provider adapter). 국내 택배사(CJ·우체국 등) + 기본택배사 + 배송추적.

## 1. 기능 목적
- 국내 택배사(CJ대한통운·우체국·한진 등)를 등록하고 기본 택배사를 지정한다. 운송장 발급 시 택배사별 송장 형식 검증 + 배송추적 연동.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 택배사 설정 진입 | 등록 택배사 목록 | 목록 | 표시 |
| 2 | 택배사 추가 + 기본 지정 | 저장 | 갱신 | 기본 1개 |
| 3 | 발송 시(d2 t003) | 택배사별 송장 검증 + 추적 | 발송 | 추적 가능 |
