# 기능 상세명세 — t002 배송 정책

> Medusa `shipping-profiles` + `shipping-option-types` + service-zone(지역별/금액별 배송비) 호출/래핑.

## 1. 기능 목적
- 배송 프로파일·옵션·서비스존을 정의하고 지역별/금액별 배송비 정책(무료배송 임계 포함)을 설정한다. 주문 배송비 계산 기준.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 배송 정책 진입 | 프로파일/존/옵션 표시 | 정책 | 표시 |
| 2 | 서비스존/배송비 설정 | 지역·금액 규칙 저장 | 저장 | 규칙 반영 |
| 3 | 무료배송 임계 설정 | 임계 저장 | 반영 | 계산 적용 |
