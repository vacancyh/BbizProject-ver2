# 기능 상세명세 — t006 재고 관리

> Medusa `inventory` list/detail + `adjust` 호출/래핑 + 갭B(원자 차감·음수방지 CHECK·배치 충돌). 위치별 재고.

## 1. 기능 목적
- SKU별 위치별 재고(가용/예약/입고예정)를 조회·증감 조정한다. 주문 이행 시 원자적 차감(SELECT FOR UPDATE), 음수 방지(CHECK), 동시 조정 충돌 처리.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 재고 메뉴 진입 | SKU 재고 목록 | 목록 | 가용/예약/입고예정 |
| 2 | 증감 조정 | adjust + 이력 | 조정됨 | 음수 차단 |
| 3 | 대량 조정 | stock 일괄 | 처리 | 충돌 처리 |
