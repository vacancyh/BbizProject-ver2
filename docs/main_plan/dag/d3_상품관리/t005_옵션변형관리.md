# 기능 상세명세 — t005 옵션·변형 관리

> Medusa `create-option/variant`, product-variants `edit`(SKU/바코드/가격), `manage-inventory-items` 호출/래핑. 카테고리별 옵션 템플릿 연계.

## 1. 기능 목적
- 상품 옵션(색상/사이즈 등)과 변형(SKU/바코드/가격/재고)을 관리한다. 카테고리별 옵션 템플릿(d4 t002) 적용. 변형별 재고 아이템 연결.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 옵션 추가 | create-option | 옵션 생성 | 옵션값 입력 |
| 2 | 변형 생성/편집 | SKU/바코드/가격 저장 | 변형 | SKU 유일 검증 |
| 3 | 재고 아이템 연결 | manage-inventory-items | 연결 | 재고 추적 |
