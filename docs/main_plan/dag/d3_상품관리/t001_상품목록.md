# 기능 상세명세 — t001 상품 목록

> Medusa `GET /admin/products` 호출/래핑. 노출 ON/OFF(is_visible) 제어 + export.

## 1. 기능 목적
- 상품을 상태/카테고리/노출여부/키워드로 검색·필터하고, 노출 ON/OFF를 토글하며 목록을 export 한다. 노출 ON 상품만 스토어프론트 표출(t→사용자 노출 연계).

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 상품 메뉴 진입 | 목록 로드 | 목록 | 썸네일/가격/재고/노출 표시 |
| 2 | 필터/검색 | 재조회 | 목록(필터) | 조건 일치 |
| 3 | 노출 토글 | status 갱신 | 갱신 | ON/OFF 즉시 반영 |
