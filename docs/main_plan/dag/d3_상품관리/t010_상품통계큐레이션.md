# 기능 상세명세 — t010 상품통계·홈큐레이션 (갭B)

> Medusa core 無 → 커스텀(analytics 집계 + curation module). 조회수/판매량/위시 + 인기검색어 + 베스트/신상품 섹션 + 금칙어.

## 1. 기능 목적
- 상품별 조회수·판매량·위시 집계를 보고, 홈 큐레이션 섹션(베스트/신상품/MD추천)을 구성한다. 인기검색어 관리 + 금칙어 필터.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 통계 탭 | 상품별 지표 집계 | 통계 | 조회/판매/위시 |
| 2 | 큐레이션 섹션 구성 | 섹션·상품·순서 설정 | 큐레이션 | 스토어 반영 |
| 3 | 인기검색어/금칙어 | 등록·필터 | 반영 | 금칙어 차단 |
