# 기능 상세명세 — t009 타임세일 (갭B)

> Medusa core 無 → 커스텀(flash-sale module). 기간·재고 제한 + 종료 시 원가 복원 + 소진 자동종료.

## 1. 기능 목적
- 상품에 한정 기간·한정 재고 타임세일가를 적용한다. 시작/종료 스케줄, 한정 재고 소진 시 자동 종료, 종료 시 원가 자동 복원.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 타임세일 생성 | 상품·세일가·기간·한정수량 입력 | 폼 | 스케줄 등록 |
| 2 | 시작 시각 도달 | 세일가 자동 적용 | 진행중 | 가격 전환 |
| 3 | 소진/종료 | 자동 종료 + 원가 복원 | 종료 | 원가 복원 |
