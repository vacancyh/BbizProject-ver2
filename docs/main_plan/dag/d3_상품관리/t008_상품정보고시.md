# 기능 상세명세 — t008 상품정보고시·KC·원산지 (갭B)

> Medusa core 無 → 커스텀(legal-kr 확장). 카테고리별 고시 템플릿 + 서버사이드 validation + versioning.

## 1. 기능 목적
- 전자상거래 상품정보제공고시(카테고리별 항목)·KC 인증·원산지를 상품에 입력·검증·버전관리한다. 카테고리별 필수 고시 항목 템플릿 자동 적용, 서버사이드 검증(누락 차단).

|--:|---|---|---|---|
| 1 | 상품 고시 탭 | 카테고리별 고시 템플릿 로드 | 고시 폼 | 필수 항목 표시 |
| 2 | 항목 입력 후 저장 | 서버 validation | 저장됨 | 누락 시 차단 |
