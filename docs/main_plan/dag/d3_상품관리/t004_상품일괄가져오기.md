# 기능 상세명세 — t004 상품 일괄 가져오기

> Medusa `products/import(CSV)` + `export` 호출/래핑. 대량 등록/수정 + 검증 리포트.

## 1. 기능 목적
- CSV로 상품을 대량 등록/수정하고, 검증 실패 행을 리포트한다. 기존 상품 export로 템플릿 제공.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | CSV 업로드 | 파싱·검증 | 미리보기 | 성공/실패 행 표시 |
| 2 | import 확정 | 비동기 일괄 처리 | 진행 | 완료 리포트 |
| 3 | export | 현재 상품 CSV | 다운로드 | 템플릿 제공 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|
| S1 | 업로드 검증 | CSV 업로드 | 성공/실패 행 + 사유 | 형식 오류 차단 |
| S2 | import 진행 | 확정 | 진행률 | 중복 실행 차단 |
| S3 | 완료 | 처리 끝 | 성공/실패 리포트 | - |
