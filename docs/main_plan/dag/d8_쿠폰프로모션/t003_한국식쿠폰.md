# 기능 상세명세 — t003 한국식 쿠폰 (갭B)

> Medusa promotion 래핑 + 커스텀(coupon-ops module). 정률/정액·최대할인·최소주문·대량발급(비동기)·자동발급·강제회수·취소복원.

## 1. 기능 목적
- 한국형 쿠폰을 발급·운영한다: 정률/정액, 최대할인·최소주문 조건, 대량 발급(비동기 job), 조건 자동발급, 강제 회수, 주문 취소 시 복원.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 쿠폰 생성 | 할인유형/조건 입력 | 폼 | 생성 |
| 2 | 대량 발급 | 비동기 job | 진행 | 발급 리포트 |
| 3 | 강제 회수/복원 | 회수/복원 처리 | 갱신 | 상태 반영 |
