# 기능 상세명세 — t001 카테고리 관리

> Medusa `categories` list/create/edit + organize(계층/순서) 호출/래핑.

## 1. 기능 목적
- 카테고리를 계층(부모-자식) 구조로 생성·편집·정렬한다. 노출 여부·순서 관리. 변경 시 slug 검증(t006)·캐시 무효화 연동.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 카테고리 메뉴 진입 | 트리 로드 | 트리 | 계층 표시 |
| 2 | 생성/편집 | 저장 | 갱신 | slug 자동/검증 |
| 3 | 드래그 정렬/계층 이동 | organize | 순서 반영 | 순서 저장 |
