# 기능 상세명세 — t002 카테고리-상품 연동

> Medusa categories `products`(추가/제거) 호출/래핑 + 카테고리별 옵션 템플릿(우리 핵심 기획).

## 1. 기능 목적
- 카테고리에 상품을 추가/제거하고, 카테고리별 옵션 템플릿(예: 의류=사이즈/색상)을 정의해 상품 등록(d3 t005) 시 자동 적용한다.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 카테고리 상세 진입 | 소속 상품 + 옵션템플릿 표시 | 상세 | 표시 |
| 2 | 상품 추가/제거 | link 갱신 | 갱신 | 연동 반영 |
| 3 | 옵션 템플릿 정의 | 템플릿 저장 | 저장 | 등록 시 자동 적용 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|

| S2 | 옵션 템플릿 | 편집 | 옵션 항목 정의 | - |
