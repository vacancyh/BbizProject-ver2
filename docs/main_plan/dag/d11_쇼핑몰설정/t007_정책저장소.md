# 기능 상세명세 — t007 정책 저장소 (갭B)

> Medusa core 無 → 커스텀(system_policies module). 운영 정책 통합 저장 + 이중확인 + 변경이력(SUPER). 감사=t011.

## 1. 기능 목적
- 흩어진 운영 정책(반품기한·포인트율·배송비·임계치 등)을 단일 저장소(system_policies)로 통합 관리한다. 변경은 SUPER + 이중확인 + 변경이력 기록.

| 3 | 확인 저장 | 갱신 + 이력 | 완료 | 변경이력 기록 |
