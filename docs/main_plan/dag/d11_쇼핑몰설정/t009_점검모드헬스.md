# 기능 상세명세 — t009 점검모드·헬스 (갭B)

> Medusa core 無 → 커스텀(ops module). 점검모드(scope) + 헬스(DB/Redis polling).

## 1. 기능 목적
- 점검모드를 범위(scope: 전체/쇼핑몰/관리자)별로 ON/OFF하고, 핵심 인프라(DB/Redis) 헬스를 주기 폴링해 표시한다.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 헬스 대시보드 | DB/Redis polling | 상태판 | up/down 표시 |
| 2 | 점검모드 ON(scope) | 적용 | 활성 | 안내 노출 |
| 3 | 점검모드 OFF | 해제 | 정상 | 복구 |
