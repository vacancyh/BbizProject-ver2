# 기능 상세명세 — t003 판매채널 (갭A)

> Medusa `sales-channels` 호출/래핑. list/create/edit + add-products. 단독몰=1채널 기본(우리 메뉴 미정의 → 신규 설계).

## 1. 기능 목적
- 판매채널을 관리한다. 단독몰은 기본 1채널 운영을 전제로 하되, Medusa 멀티채널 구조를 래핑해 채널-상품 연결을 노출한다.

|--:|---|---|---|---|
| 1 | 채널 목록 | sales-channels 조회 | 목록 | 표시 |
| 2 | 채널 생성/편집 | 갱신 | 편집 | 저장 |
| 3 | 상품 연결 | add-products | 연결 | 반영 |
