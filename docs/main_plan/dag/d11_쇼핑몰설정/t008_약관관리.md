# 기능 상세명세 — t008 약관 관리 (갭B)

> Medusa core 無 → 커스텀(legal-kr module). 약관/방침 버전 관리 + 동의 연동(d5 t008_동의이력).

## 1. 기능 목적
- 이용약관·개인정보처리방침·마케팅 동의문 등을 버전별로 관리하고, 개정 시 동의이력(d5)과 연동한다. 시행일 기준 버전 노출.
