# 기능 상세명세 — t011 감사 로그 (갭B · cross-cutting)

> Medusa core 無 → 커스텀(audit module). 모든 write 액션 append-only + 5년 보관 + PII 마스킹. 전 도메인 write 감사.

## 1. 기능 목적
- 모든 관리자 write 액션(생성/수정/삭제/상태전환)을 append-only로 기록하고 조회·필터·내보내기한다. 5년 보관, PII 등급별 마스킹.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 감사 로그 조회(필터) | 조회 | 목록 | actor·액션·대상 표시 |
| 2 | 상세 보기 | diff 표시 | 상세 | before/after |
| 3 | 내보내기 | CSV 생성 | 다운로드 | 행 정합 |
