# 기능 상세명세 — t008 동의 이력 (갭B)

> Medusa core 無 → 커스텀(consent module). 마케팅/약관 동의 수집·철회 이력 + 2년 재확인. 마케팅 발송(d12) 대상 판정 근거.

## 1. 기능 목적
- 고객의 마케팅(이메일/SMS/알림톡)·약관 동의/철회 이력을 시점별로 보존하고, 2년 재확인 대상을 관리한다. 발송(d12)은 동의자만 대상.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 고객 동의 탭 | 동의/철회 이력 표시 | 이력 | 시점별 표시 |
| 2 | 2년 재확인 도래 | 재확인 대상 표시 + 발송 | 재확인 | 대상 추출 |
| 3 | 발송 대상 판정(d12) | 동의자만 필터 | 필터 | 미동의 제외 |
