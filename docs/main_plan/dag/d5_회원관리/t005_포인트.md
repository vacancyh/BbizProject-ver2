# 기능 상세명세 — t005 포인트 (갭B)

> Medusa core 無 → 커스텀(point module). 가입/구매/리뷰/추천/출석 적립·사용·소멸 + 유효기간 + D-N 알림.

## 1. 기능 목적
- 적립(가입/구매/리뷰/추천/출석)·사용·소멸(유효기간)을 원장(append-only)으로 관리한다. 소멸 D-N 알림(d12). 0원 결제 자체 ledger 정합.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 적립 정책 설정 | 이벤트별 적립률 | 정책 | 저장 |
| 2 | 적립/사용 발생 | ledger append + 잔액 갱신 | 잔액 | 음수 금지 |
| 3 | 유효기간 도래 | 소멸 job + D-N 알림 | 소멸 | 멱등 |

## 3. 화면/상태 정의
