# 기능 상세명세 — t001 고객 관리

> Medusa `customers` list/create/detail(주문이력/주소)/edit + create-address 호출/래핑. PII 마스킹.

## 1. 기능 목적
- 회원/비회원 고객을 검색·조회·편집한다. 주문 이력·주소록·등급(d5 t004)·포인트(t005) 요약 표시. 권한 등급별 PII 마스킹.
