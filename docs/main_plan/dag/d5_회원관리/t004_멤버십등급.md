# 기능 상세명세 — t004 멤버십 등급 (갭B)

> Medusa core 無 → 커스텀(membership module). 구매금액 자동 등급 + 등급별 적립률·쿠폰 + 연초 리셋.

## 1. 기능 목적
- 누적 구매금액 기반 자동 등급(일반/실버/골드/VIP)을 산정하고, 등급별 적립률·쿠폰·가격(d8 t004)을 부여한다. 연초 등급 리셋.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 등급 정책 설정 | 구간/혜택 정의 | 정책 | 저장 |
| 2 | 구매 확정(d2) | 누적금액 갱신 + 등급 재산정 | 등급 변경 | 자동 승급 |
| 3 | 연초 도래 | 리셋 job | 리셋 | 멱등 |
