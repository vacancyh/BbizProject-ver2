# 기능 상세명세 — t003 관리자 계정·인증 (blocker)

> Medusa `users` list/invite/edit + `auth`(login/reset-password/invite 수락) 호출/래핑. RBAC(d11 t010) 진입점. 로컬 자동로그인 prefill.

## 1. 기능 목적
- 관리자 계정(User)을 초대·관리하고 역할(RBAC d11 t010)을 부여한다. 로그인/비밀번호 초기화/초대 수락 인증 플로우. 로컬 개발은 id=admin/pw prefill 자동입력(CLAUDE.md DEV 룰).

|--:|---|---|---|---|
| 1 | 로그인 진입 | 로컬: id/pw prefill | 로그인 | 1클릭 로그인 |
| 2 | 사용자 초대 | invite 토큰 발송 | 초대됨 | 수락 링크 |
