# 기능 상세명세 — t002 상품 통계

> Medusa `orders`+`products` 집계 호출/래핑. 상품별 판매량/조회수/전환 + 베스트 랭킹. 원천 = d3_상품관리.

## 1. 기능 목적
- 상품별 판매량·매출·조회수·구매전환율을 집계해 베스트 랭킹과 부진 상품 리스트를 제공한다.

| 2 | 정렬(판매량/매출/전환) | 재정렬 | 테이블 | 정렬 정합 |
| 3 | 상품 클릭 | 상세 통계 | 드릴다운 | 상세 표시 |
