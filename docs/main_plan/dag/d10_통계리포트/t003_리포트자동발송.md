# 기능 상세명세 — t003 리포트 자동발송 (갭B)

> Medusa core 無 → 커스텀(report-scheduler module). 일/주/월 매출리포트 스케줄 자동발송. 발송 채널=d12_마케팅(이메일).

## 1. 기능 목적
- t001/t002 집계를 기반으로 일·주·월 리포트를 스케줄에 따라 생성하고 지정 수신자에게 자동발송(이메일)한다. 멱등(중복 발송 방지).

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 스케줄 설정(주기·수신자) | 저장 | 설정 화면 | 스케줄 등록 |
| 2 | (배치) 주기 도래 | 집계+리포트 생성+발송 | 발송 로그 | 멱등 발송 |
| 3 | 발송 이력 조회 | 표시 | 이력 | 성공/실패 표시 |

## 3. 화면/상태 정의

| state_id | 상태명 | 진입 조건 | 표시 요소 | 금지/예외 |
|---|---|---|---|---|
| S1 | 스케줄 설정 | 진입 | 주기·수신자·포맷·ON/OFF | - |
| S2 | 발송 이력 | 진입 | 일시·대상·결과·재시도 | - |

## 4. 입력/검증 규칙
