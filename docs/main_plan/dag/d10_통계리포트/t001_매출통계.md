# 기능 상세명세 — t001 매출 통계

> Medusa `orders` 집계 호출/래핑. 기간별 매출/주문/환불 집계 + 추이 차트. 원천 = d2_주문관리.

## 1. 기능 목적
- 기간(일/주/월/사용자지정)별 총매출·주문수·환불액·순매출(매출-환불)을 집계해 추이 차트와 KPI 카드로 제공한다.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 기간 선택 | 집계 조회 | 통계 대시보드 | KPI 표시 |
| 2 | 그래프 단위 변경(일/주/월) | 재집계 | 추이 차트 | 차트 갱신 |
| 3 | CSV 내보내기 | 파일 생성 | 다운로드 | 행 정합 |
