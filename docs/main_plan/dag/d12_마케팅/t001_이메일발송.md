# 기능 상세명세 — t001 이메일 발송

> Medusa `notification`(이메일) 호출/래핑. [광고] 표기·List-Unsubscribe·야간차단·동의자만 발송(정보통신망법).

## 1. 기능 목적
- 동의 고객(세그먼트)에게 이메일을 발송한다. 광고성은 [광고] 제목 표기 + List-Unsubscribe + 야간(21~08시) 발송 차단.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 대상 세그먼트(t004) 선택 | 수신자 산출 | 작성 | 동의자만 |
| 2 | 제목/본문 + 광고여부 | 검증([광고] 자동) | 미리보기 | 규칙 통과 |
| 3 | 발송/예약 | notification 발송 | 발송 | 로그 기록 |
