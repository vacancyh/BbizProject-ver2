# 기능 상세명세 — t003 카카오 알림톡 (갭B)

> Medusa core 無 → 커스텀(kakao provider). KakaoBiz 알림톡 이벤트별 ON/OFF + 사전승인 템플릿. 실패 시 SMS 대체발송.

## 1. 기능 목적
- 이벤트(주문완료/배송출발/배송완료 등)별 알림톡을 ON/OFF 관리하고, 사전 승인된 템플릿으로 발송한다. 발송 실패 시 SMS(t002) 대체.

## 2. 사용자 흐름

| step | 사용자 행동 | 시스템 반응 | 화면/상태 | 성공 기준 |
|--:|---|---|---|---|
| 1 | 이벤트별 ON/OFF | 설정 저장 | 설정 | 토글 반영 |
| 2 | 템플릿 매핑 | 승인 템플릿 연결 | 편집 | 매핑 저장 |
| 3 | (이벤트) 발송 | 알림톡 발송(실패→SMS) | 발송 | 대체 처리 |
