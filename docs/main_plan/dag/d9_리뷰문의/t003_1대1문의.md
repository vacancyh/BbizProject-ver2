# 기능 상세명세 — t003 1:1 문의 (갭B)

> Medusa core 無 → 커스텀(inquiry module). CS 1:1 문의 조회/답변/상태 + 미답변 필터 + CS 통합이력(d11) 연동.

## 1. 기능 목적
- 고객 1:1 문의(주문/배송/환불/기타)를 접수·답변·상태 관리한다. 미답변 SLA 관리, 주문 연결, CS 통합이력(d11) 연동.
