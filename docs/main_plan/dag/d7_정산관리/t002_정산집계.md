# 기능 상세명세 — t002 정산 집계 (갭B)

> Medusa core 無 → 커스텀(settlement module). 일/월 매출·환불·PG수수료·순정산 + 날짜경계 귀속(paid_at) + 부분취소 차감.

## 1. 기능 목적
- 일별/월별 정산을 집계한다(net = sales − refund − pg_fee). `paid_at` 귀속(F17), 부분취소/환불 차감(PG취소·계좌입금환불 모두, d2 t007), 분쟁/사기 보류(held_amount). 매일 03:00 배치 + 월 마감.

## 2. 사용자 흐름

| 1 | 정산 진입 | 일/월 정산 목록 | 정산 | 매출/환불/수수료/순정산 |
| 2 | 일자 상세 | 거래 내역 + 보류 | 상세 | 차감 정합 |
| 3 | 월 마감 | 마감 처리 | 마감 | 멱등 |
